# Python errors explained, written by hand for Ace.
# tag: coding.python.errors
what does indexerror mean in python | indexerror list index out of range | python index error => IndexError means you used a position that does not exist, like `items[3]` on a list with 3 items (indexes 0 to 2). Check `len(items)` or loop with `for item in items:` instead.
what does keyerror mean in python | python keyerror | key error dictionary => KeyError means you asked a dict for a key it does not have, like `ages["Bob"]` when there is no "Bob". Use `ages.get("Bob")` or check `if "Bob" in ages:` first.
what does typeerror mean in python | python typeerror | type error python => TypeError means an operation got the wrong kind of value, like adding a string to a number or calling something that is not a function. The message says which types were involved.
what does valueerror mean in python | python valueerror | value error python => ValueError means the type was right but the value was not, like `int("abc")` or `math.sqrt(-1)`.
what does nameerror mean in python | name is not defined python | nameerror python => NameError means Python does not know that name. It is usually a typo, using a variable before you set it, or forgetting to import something.
what does attributeerror mean in python | has no attribute python | attributeerror python => AttributeError means the object does not have that attribute or method, like calling `.append` on a string. Check the spelling and what type the object really is.
what does nonetype object has no attribute mean | attributeerror nonetype | nonetype has no attribute python => A variable you expected to hold an object is None. Usually a function returned None, like `list.sort()`, or a search found nothing. Print the variable to find where it became None.
what does modulenotfounderror mean | no module named python | module not found python => Python cannot find that module. Install it with pip (`python -m pip install name`), check the spelling, and make sure you run the same Python that pip installed into, especially with virtual environments.
what does importerror mean in python | cannot import name python | importerror python => ImportError means the module was found but the name you asked for is not in it, or there is a circular import. Check the name and that two files are not importing each other at the top.
what is a circular import in python | circular import error | partially initialized module => Two files import each other, so one is used before it finishes loading. Move shared code into a third file, or import inside the function that needs it.
what does indentationerror mean | expected an indented block python | indentation error python => The code after a line ending in `:` (like if, for, def) must be indented. Indent the block by 4 spaces, and do not mix tabs and spaces.
what does unexpected indent mean python | indentationerror unexpected indent | extra space at start of line python => A line is indented more than it should be, often from pasting code. Line it up with the code around it.
what does unindent does not match any outer indentation level mean | unindent error python | indentation does not match => Lines in the same block are indented by different amounts, often a mix of tabs and spaces. Re-indent the block with spaces only.
what does taberror mean in python | inconsistent use of tabs and spaces | taberror python => You mixed tabs and spaces for indentation. Set your editor to insert 4 spaces for a tab and re-indent the file.
what does syntaxerror invalid syntax mean | invalid syntax python | syntax error python => Python could not understand the code near that spot. Look for a missing colon, bracket or quote on that line or the line before.
what does syntaxerror unterminated string literal mean | eol while scanning string literal | string not closed python => A string's opening quote has no matching closing quote on that line. Add the missing quote, or use triple quotes for text over many lines.
what does missing parentheses in call to print mean | print without brackets python | python 2 print error => That is Python 2 style `print "hi"`. In Python 3, print is a function, so write `print("hi")`.
what does return outside function mean | syntaxerror return outside function | return not in a function => `return` only works inside a `def`. Check your indentation; the return may have slipped out of the function.
what does expected colon mean python | missing colon python | syntaxerror expected ':' => Lines starting with if, elif, else, for, while, def, class, try and with must end with a colon.
what does cannot assign to literal mean | cannot assign to function call | syntaxerror cannot assign => The left side of `=` must be a variable name, not a value or a call. Maybe you meant `==` to compare.
what does zerodivisionerror mean | division by zero python | zerodivisionerror python => You divided by zero, which has no answer. Check the bottom number is not zero before dividing.
what does filenotfounderror mean | no such file or directory python | file not found python => Python cannot find the file at that path. Check the name and extension, and remember relative paths start from where you ran the script, not where the file is. `Path(__file__).parent / "name"` helps.
what does permissionerror mean in python | permission denied python | errno 13 python => Your program is not allowed to open that file or folder, maybe because it is open in another app, is a folder, or needs admin rights.
what does isadirectoryerror mean | is a directory python | open a folder python error => You tried to open a folder as if it were a file. Point to a file inside it.
what does fileexistserror mean | file exists error python | mkdir file exists => You tried to create a file or folder that already exists. Use `os.makedirs(path, exist_ok=True)` for folders.
what does recursionerror mean | maximum recursion depth exceeded | recursion error python => A function called itself too many times, more than about 1000 levels deep. Make sure there is a base case that stops, or use a loop instead.
what does unboundlocalerror mean | local variable referenced before assignment | cannot access local variable => You assign to a variable inside a function, so Python treats it as local, but you read it before the assignment. Pass it in as a parameter, or use `global` if it is a module variable.
what does int object is not subscriptable mean | object is not subscriptable python | not subscriptable error => You used `[ ]` on something that cannot be indexed, like a number. Check the variable holds a list, string or dict.
what does int object is not iterable mean | object is not iterable python | not iterable error => You tried to loop over something that is not a collection, like `for i in 5:`. Use `range(5)` to loop a number of times.
what does str object is not callable mean | object is not callable python | not callable error => You put `()` after something that is not a function, often because you named a variable `str`, `list` or `input` and hid the built-in. Rename the variable.
what does can only concatenate str not int to str mean | concatenate str and int | add number to string python => You used `+` between text and a number. Convert with `str(n)`, or use an f-string like `f"Score: {n}"`.
what does unsupported operand types mean | unsupported operand type python | typeerror unsupported operand => The operator does not work between those two types, like `"a" - 1` or `None + 5`. Check that both values are the types you expect.
what does list indices must be integers or slices not str mean | list indices must be integers | list index with string => You indexed a list with a string, like `items["name"]`. Lists use numbers; use a dict if you want names as keys.
what does missing 1 required positional argument mean | missing required argument python | positional argument missing => You called a function with fewer arguments than it needs. With methods, it often means you called it on the class instead of an object, so self was not filled in.
what does takes 1 positional argument but 2 were given mean | too many arguments python | positional arguments given error => You passed more arguments than the function accepts. In a class, forgetting `self` as the first parameter of a method causes this.
what does unhashable type list mean | typeerror unhashable type | unhashable dict python => You used a list or dict as a dict key or put it in a set. Use a tuple instead, like `tuple(my_list)`.
what does invalid literal for int with base 10 mean | invalid literal for int | int conversion error python => `int()` got text that is not a whole number, like "abc", "", or "3.5". Use `float()` for decimals and check the input first.
what does could not convert string to float mean | float conversion error python | convert string to float error => `float()` got text that is not a number, often an empty string or one with commas like "1,000". Strip spaces and remove commas first.
what does too many values to unpack mean | valueerror too many values to unpack | unpacking error python => There are more items than variables, like `a, b = [1, 2, 3]`. Match the count, or collect the rest with `a, *rest = ...`.
what does not enough values to unpack mean | expected 2 got 1 python | not enough values to unpack error => There are fewer items than variables, like `a, b = [1]`. Check what you are unpacking really has that many items.
what does dictionary changed size during iteration mean | runtimeerror dictionary changed size | modify dict while looping => You added or removed keys while looping over the dict. Loop over a copy: `for key in list(d):`.
what does stopiteration mean | python stopiteration | next on empty iterator => `next()` was called on an iterator that has no more items. Give a default, like `next(it, None)`, or use a for loop.
what does keyboardinterrupt mean | keyboardinterrupt python | ctrl c error => KeyboardInterrupt happens when you press Ctrl+C to stop the program. It is not a bug.
what does memoryerror mean | python memoryerror | out of memory python => The program ran out of memory, usually from building a huge list. Process data in pieces or use generators.
what does overflowerror mean | math range error python | overflowerror python => A float calculation got too big to store, like `math.exp(1000)`. Python integers never overflow, but floats do.
what does assertionerror mean | assertion error python | assert failed => An `assert` statement's condition was False. Read the message after the comma in the assert line to see what was expected.
what does notimplementederror mean | not implemented error python | raise notimplementederror => A method was meant to be written by a subclass but was not. Write that method in your class.
what does unicodedecodeerror mean | codec can't decode byte | utf-8 codec error => The file's bytes do not match the encoding Python used. Open it with `encoding="utf-8"`, or the right encoding for that file, or open in binary mode for non-text files.
what does unicodeencodeerror mean | charmap codec can't encode | emoji print error windows => Python could not turn some characters, like emoji, into the encoding of the console or file. Write files with `encoding="utf-8"`, or set the console to UTF-8.
what does jsondecodeerror mean | expecting value line 1 column 1 | invalid json python => The text you gave json.loads is not valid JSON, often because it is empty or is an HTML error page. Print the text to see what you really got.
what does connectionerror mean in python | requests connection error | max retries exceeded => The program could not reach the server: no internet, wrong address, or the server is down. Check the URL and your connection, and catch the error.
what does timeouterror mean | request timed out python | readtimeout requests => The server took too long to answer. Use a timeout like `requests.get(url, timeout=10)` and try again later.
what does ssl certificate verify failed mean | ssl error python | certificate verify failed => Python could not check the website's security certificate. On macOS, run the Install Certificates command that came with Python, or update certifi with pip. Do not turn verification off.
what does externally managed environment mean | pip externally-managed-environment | error externally managed pip => Your system Python is managed by the operating system, so pip refuses to install into it. Make a virtual environment with `python3 -m venv .venv`, activate it, and install there.
what does defaulting to user installation mean | pip user install | normal site-packages is not writeable => pip could not write to the main Python folder, so it installed the package just for your user. It usually still works.
what does no matching distribution found mean | could not find a version that satisfies | pip cannot find package => pip could not find that package for your Python version. Check the spelling on pypi.org and whether it supports your Python version.
what does indentationerror expected an indented block after function definition mean | empty function error python | function with no body => A def or if must have at least one indented line. Put `pass` inside if you are not ready to write it.
what does object has no attribute append mean | str has no attribute append | tuple has no attribute append => You called append on something that is not a list. Strings and tuples cannot be appended to; make a new one or use a list.
what does list object has no attribute split mean | split on a list python | list has no attribute => split is a string method. You have a list, so split each item instead: `[s.split() for s in items]`.
what does module has no attribute mean | module object has no attribute | partially initialized module has no attribute => The module does not have that name, or your own file has the same name as the module (like a file called random.py), so Python imported your file instead. Rename your file.
why is my python variable none | function returns none python | why does my function print none => A function with no `return` gives None, and so do methods like `list.sort()` and `list.append()`. Return the value you want, or do not assign the result of in-place methods.
why does my python program close instantly | python window closes immediately | console disappears python => When you double-click a script, the window closes when the program ends or crashes. Run it from a terminal to see output and errors, or add `input("Press Enter")` at the end.
why does my loop never end python | infinite loop python | while loop runs forever => The loop condition never becomes False, because nothing inside changes it. Make sure the variable in the condition is updated, or add a break.
why does my if statement always run python | if x == 1 or 2 | or condition always true => `if x == 1 or 2:` is always True because `2` alone is truthy. Write `if x == 1 or x == 2:` or `if x in (1, 2):`.
why is input not comparing to a number python | input returns string | input equals number false => input() always returns a string, so `"5" == 5` is False. Convert first: `int(input())`.
why does my float math look wrong python | 0.1 + 0.2 python | floating point python => Floats are stored in binary, so 0.1 + 0.2 is 0.30000000000000004. Round for display, use `math.isclose` to compare, or `decimal.Decimal` for money.
why does my list have the same item many times python | list of lists same row | grid changes every row => `[[0] * 3] * 3` makes three references to one inner list. Build it with `[[0] * 3 for _ in range(3)]`.
why does my default list keep growing python | mutable default argument | def f(items=[]) => A default list is made once and reused every call, so it keeps old items. Use `def f(items=None):` and inside write `if items is None: items = []`.
what does python is not recognized as an internal or external command mean | python not found in cmd | python command windows => Windows cannot find Python. Reinstall it with "Add python.exe to PATH" ticked, or run it with the `py` launcher.
what does no module named pip mean | pip missing python => pip is not installed for that Python. Run `python -m ensurepip --upgrade` to install it.
what does pygame error video system not initialized mean | pygame not initialized | pygame error display => You called a display function before `pygame.init()` or after `pygame.quit()`. Call init at the start and only quit when the loop is done.
what does tkinter tclerror mean | no display name and no $display | tkinter error => Tkinter could not open a window, often because there is no screen, like on a server. Run it on a computer with a desktop.
what does indexerror string index out of range mean | string index out of range | string index error => You asked for a character position past the end of the string. Remember the last index is `len(s) - 1`.
what does typeerror object of type nonetype has no len mean | len of none | nonetype has no len => The value you passed to len() is None. A function you called probably did not return anything.
what does nonetype object is not subscriptable mean | none is not subscriptable | subscript none python => You used `[ ]` on None, so the list or dict you expected was never returned. Check the function or `.get()` that gave you the value.
what does str object does not support item assignment mean | change letter in string error | string item assignment => Strings cannot be changed in place, so `s[0] = "X"` fails. Build a new string: `s = "X" + s[1:]`.
what does tuple object does not support item assignment mean | change tuple error | modify a tuple python => Tuples cannot be changed after they are made. Convert to a list, change it, and convert back if needed.
what does local variable might be referenced before assignment mean | possibly unbound variable | variable maybe not set => On some path through your code the variable is never set, like when an if is skipped. Give it a starting value before the if.
understand python errors | traceback most recent call last => Start at the last line, which names the error and why. The line above shows the file and line number where it happened; earlier lines show how the program got there.
how do i debug python code | find bugs python | debugging python tips => Read the traceback, print variables near the problem, use `breakpoint()` to pause and inspect, and test small pieces one at a time. Editors like VS Code have a debugger with breakpoints.
what is pdb | python debugger | pdb commands => pdb is Python's built-in debugger. After `breakpoint()` pauses the code, type `n` for next line, `s` to step into a function, `p x` to print x, `c` to continue and `q` to quit.
how do i catch any error in python | except exception python | catch all errors => `except Exception as e: print(e)` catches most errors and shows the message. Catch specific errors when you can, so real bugs are not hidden.
what is the exception hierarchy in python | baseexception vs exception | parent exception classes => All errors inherit from BaseException. Most come from Exception, while SystemExit and KeyboardInterrupt do not, which is why `except Exception` lets Ctrl+C still work.
how do i retry after an error python | retry loop python | try again on error => Loop a few times: `for attempt in range(3):` then `try:` the call and `break` on success, `except` an error then `time.sleep(1)` and try again.
how do i print the full error in python | print traceback python | traceback module => In an except block, `traceback.print_exc()` (after `import traceback`) prints the whole traceback, not just the message.
