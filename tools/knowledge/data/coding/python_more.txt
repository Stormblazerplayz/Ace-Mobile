how do i make a text adventure in python | text based game python | choose your own adventure python => Store rooms in a dict like `rooms = {"hall": {"north": "kitchen"}}`, keep the player's room in a variable, and loop: print the room, read a command with input(), and move if the exit exists.
how do i make a to do list app in python | todo list python | simple task list program => Keep tasks in a list, loop a menu with input() for add, show and remove, and save the list to a JSON file so it is still there next time.
how do i make a quiz in python | quiz game python | trivia game python => Put questions and answers in a list of dicts, loop through them, compare `input().strip().lower()` to the answer, and count the score.
how do i make rock paper scissors in python | rock paper scissors code | rps game python => Pick the computer's move with `random.choice(["rock", "paper", "scissors"])`, read the player's move, and compare them with a dict of what beats what, like `beats = {"rock": "scissors", ...}`.
how do i make a dice roller in python | dice simulator => `random.randint(1, 6)` rolls one die. For several dice, `[random.randint(1, 6) for _ in range(n)]` and `sum()` them.
how do i make a password generator in python | random password python | generate password => Build it with the secrets module: `"".join(secrets.choice(string.ascii_letters + string.digits + string.punctuation) for _ in range(16))`.
how do i make a timer in python | countdown python | countdown timer code => `for s in range(10, 0, -1): print(s) time.sleep(1)`, then print "Done!". Use `end="\r"` in print to overwrite the same line.
how do i make a stopwatch in python | stopwatch program | elapsed time python => Save `start = time.perf_counter()`, wait for Enter with input(), then print `time.perf_counter() - start` rounded to 2 decimals.
how do i make a snake game in python | snake pygame | snake game code python => In pygame, keep the snake as a list of grid positions, add a new head each tick in the moving direction, drop the tail unless it ate food, and end the game if the head hits a wall or its body.
how do i make a window in pygame | pygame window | open pygame screen => `pygame.init()`, `screen = pygame.display.set_mode((800, 600))`, then a loop that handles `pygame.QUIT`, fills the screen and calls `pygame.display.flip()`.
how do i move a sprite with arrow keys in pygame | pygame keyboard input | pygame movement => Each frame read `keys = pygame.key.get_pressed()` and change x or y when `keys[pygame.K_LEFT]` and the other arrows are pressed, then draw at the new spot.
how do i load an image in pygame | pygame image load | draw a picture pygame => `img = pygame.image.load("player.png").convert_alpha()` then `screen.blit(img, (x, y))` each frame.
how do i detect collisions in pygame | pygame collision | rect collide pygame => Use Rect objects: `player_rect.colliderect(enemy_rect)` is True when they overlap. Sprites can use `pygame.sprite.spritecollide`.
how do i play sound in pygame | pygame sound effect | pygame music => `pygame.mixer.Sound("hit.wav").play()` plays a sound effect. For background music use `pygame.mixer.music.load("song.mp3")` and `pygame.mixer.music.play(-1)` to loop it.
how do i show text in pygame | pygame font | draw score pygame => `font = pygame.font.SysFont(None, 36)`, `img = font.render(f"Score: {score}", True, (255, 255, 255))`, then `screen.blit(img, (10, 10))`.
how do i limit fps in pygame | pygame frame rate => Make `clock = pygame.time.Clock()` and call `clock.tick(60)` once per loop to run at most 60 frames per second. It also returns the milliseconds since the last frame.
how do i make a gui app in python | python desktop app | gui python options => Tkinter comes with Python and is easiest to start. PySide6 or PyQt make more polished apps, and CustomTkinter gives tkinter a modern look.
how do i make a button in tkinter | tkinter button click | tkinter command => `tk.Button(root, text="Click me", command=on_click).pack()`. Pass the function name without parentheses, or it runs right away.
how do i lay out widgets in tkinter | pack vs grid tkinter | tkinter layout => pack stacks widgets, grid places them in rows and columns with `.grid(row=0, column=1)`, and place uses exact positions. Do not mix pack and grid in the same container.
how do i update a label in tkinter | change label text tkinter | tkinter config => `label.config(text="New text")`, or use a StringVar and call `var.set("New text")`.
how do i run code repeatedly in tkinter | tkinter after | tkinter loop without freezing => `root.after(1000, update)` runs update after 1000 ms; call after again inside update to repeat. Never use time.sleep or a while loop in tkinter, because it freezes the window.
how do i scrape a website with python | web scraping python | beautifulsoup => Download the page with requests, then parse it with BeautifulSoup: `soup = BeautifulSoup(r.text, "html.parser")` and `soup.find_all("a")`. Check the site allows scraping and do not flood it with requests.
how do i send an email with python | smtplib python | email from python => Use smtplib with your mail provider's SMTP server and an app password, and build the message with `email.message.EmailMessage`. Never put your real password in code you share.
how do i automate my computer with python | automation python | pyautogui => Python can rename files with os and pathlib, fill spreadsheets with openpyxl, and control the mouse and keyboard with pyautogui. Start with small file tasks.
how do i rename lots of files with python | batch rename python | rename files in a folder => Loop with `for p in Path("folder").iterdir():` and call `p.rename(p.with_name(new_name))`. Test with print first so you do not rename the wrong files.
how do i read an excel file in python | openpyxl | excel python => Use openpyxl: `wb = openpyxl.load_workbook("file.xlsx")`, `ws = wb.active`, then `ws["A1"].value`. pandas `read_excel` is easier for whole tables.
how do i make a discord bot in python | discord.py | python bot discord => Install discord.py, create a bot in the Discord Developer Portal, and run it with your bot token kept secret (in an environment variable, not in your code). Discord requires users to be 13 or older.
how do i call the claude api from python | anthropic python sdk | ai api python => Install the `anthropic` package, set your API key in the ANTHROPIC_API_KEY environment variable, then create a client and send messages. Keep keys out of code you share.
how do i make python talk to an arduino | serial python arduino | send data to arduino => Use pyserial: `ser = serial.Serial("COM3", 9600, timeout=1)`, wait 2 seconds for the board to reset, then `ser.write(b"L")` and read replies with `ser.readline().decode().strip()`.
how do i read a webcam in python | camera python opencv | video capture python => `cap = cv2.VideoCapture(0)`, then in a loop `ok, frame = cap.read()` and `cv2.imshow("cam", frame)`. Break when `cv2.waitKey(1) == ord("q")` and call `cap.release()`.
how do i make a web server in python | simple web server python | host a website with python => For files, run `python -m http.server 8000` and open localhost:8000. For a real app, use Flask or FastAPI.
how do i make a rest api in python | api server python | json api python => With FastAPI: `@app.get("/items/{item_id}")` on a function that returns a dict, then run `uvicorn main:app --reload`. It returns JSON automatically.
how do i store settings in python | config file python | save preferences python => Save a dict as JSON with json.dump and load it at start, giving defaults for missing keys. configparser handles .ini files and tomllib reads .toml files.
how do i use environment variables in python | os environ api key | hide api keys python => Read secrets with `os.environ.get("MY_KEY")` instead of writing them in code. Set them in your terminal or a .env file loaded by python-dotenv, and add .env to .gitignore.
how do i make a progress bar in python | tqdm | loading bar python => Install tqdm and wrap any loop: `for item in tqdm(items):`. It shows a live progress bar in the terminal.
how do i color text in the terminal python | colored output python | print in color python => Use ANSI codes like `print("\033[31mRed\033[0m")`, or a package like colorama or rich, which also works well on Windows.
what is rich in python | rich library | pretty terminal output python => rich is a package for colorful terminal output, tables, progress bars and nice tracebacks: `from rich import print`.
how do i make a class with properties in python | getter setter python | property decorator => Use `@property` to read an attribute like a variable and `@name.setter` to check new values before saving them, like stopping health from going below 0.
what is polymorphism in python | polymorphism example python | same method different classes => Different classes can have a method with the same name, so code can call `animal.speak()` on a Dog or a Cat without caring which it is.
what is an abstract class in python | abc module python | abstractmethod => `from abc import ABC, abstractmethod` lets you make a base class with methods that subclasses must write. You cannot make an object from the abstract class itself.
what is composition vs inheritance | has a vs is a | composition python => Inheritance means "is a" (a Dog is an Animal). Composition means "has a" (a Car has an Engine object). Composition is often simpler to change later.
what is a static method vs class method | staticmethod vs classmethod | when to use classmethod => A static method is a plain function inside the class with no self or cls. A class method gets the class as cls and is often used to build objects another way.
what is __slots__ | slots python | save memory objects python => Setting `__slots__ = ("x", "y")` in a class fixes which attributes objects can have and makes them use less memory.
what is __eq__ in python | compare objects python | object equality => Define `__eq__(self, other)` to decide when two of your objects count as equal with `==`. By default, two different objects are never equal.
what is __len__ | len on my class | make len work on object => Define `def __len__(self): return len(self.items)` and `len(obj)` will work on your class.
what is __getitem__ | make my class indexable | square brackets on object => Define `__getitem__(self, i)` so `obj[i]` works on your class, like a custom list.
what is __call__ in python | callable object python | call an object like a function => Defining `__call__` lets you call an object like a function: `counter()` runs `counter.__call__()`.
what is __iter__ | for loop over my object => Define `__iter__` to return an iterator (often by using yield inside it), and you can loop over your object with for.
what is a closure in python | nested function remembers | python closure example => A closure is an inner function that remembers variables from the function it was made in, even after that function returned. Use `nonlocal` to change them.
what is nonlocal in python | nonlocal keyword | change outer function variable => `nonlocal count` inside an inner function lets it change a variable that belongs to the outer function.
what is functional programming in python | map filter reduce python | pure functions => It means building programs from functions that take inputs and return outputs without changing outside data. Python supports it with lambda, map, filter, comprehensions and functools.
what is memoization | cache results python | speed up recursion => Memoization saves results of a function so repeated calls with the same input are instant. In Python, put `@functools.cache` above the function.
what is a shallow vs deep copy python | shallow copy deep copy | copy nested list => A shallow copy makes a new outer list but shares the inner objects. A deep copy (`copy.deepcopy`) copies everything inside too.
how does python manage memory | reference counting python | python garbage collector => Python counts how many names point to each object and frees it when the count hits zero. A garbage collector also cleans up objects that point to each other.
what is bytecode in python | how does python run code | python interpreter explained => Python first compiles your code to bytecode, simple instructions, then the Python virtual machine runs them one at a time. That is why it is called interpreted.
what is a python package vs module | __init__.py | make a python package => A module is one .py file. A package is a folder of modules, usually with an `__init__.py`, imported like `from mygame.player import Player`.
how do i publish a package to pypi | upload to pypi | python packaging => Describe it in a pyproject.toml file, build it with `python -m build`, and upload with `twine upload dist/*`. Test on TestPyPI first.
what is pyproject toml | pyproject.toml python | python project config => pyproject.toml is the standard file describing a Python project: its name, version, dependencies and tool settings like ruff or pytest.
what is uv python | uv package manager | uv vs pip => uv is a very fast Python package and project manager made by Astral. It can replace pip and venv, like `uv venv` and `uv pip install requests`.
what is conda | anaconda python | conda vs pip => Conda is a package and environment manager popular for data science. It can install non-Python libraries too. pip with venv is enough for most projects.
what is pytest | testing python | write tests python => pytest runs test functions whose names start with `test_`. Write `assert add(2, 3) == 5`, then run `pytest` in the project folder.
how do i write a unit test in python | unit tests python | test a function python => Make a file like test_math.py with `def test_add(): assert add(2, 2) == 4`, and run pytest. Each test checks one small behavior.
what is ruff | python linter | format python code => ruff is a very fast linter and formatter that finds mistakes and style problems. Run `ruff check .` and `ruff format .`.
what is black python | black formatter | auto format python => black is an automatic code formatter. Run `black file.py` and it rewrites the file in one consistent style.
what is a linter | linting code | what does a linter do => A linter reads your code without running it and points out bugs, unused variables and style problems.
what is the python debugger in vs code | debug python vscode | breakpoints vs code python => Click left of a line number to set a red breakpoint, press F5 to start debugging, then step with F10 and F11 and watch variables in the side panel.
what is ipython | ipython shell | better python repl => IPython is an improved interactive shell with colors, tab completion and handy commands like `%timeit`. Jupyter is built on it.
what is google colab | colab notebook | run python online free => Google Colab runs Jupyter notebooks in the browser on Google's computers, including free GPU time, so you can code Python without installing anything.

what is a raspberry pi | raspberry pi python | what can a raspberry pi do => A Raspberry Pi is a small, cheap Linux computer. It runs Python and can control LEDs, motors and sensors through its GPIO pins, so it is great for robots.
how do i control gpio pins on a raspberry pi | gpiozero | blink led raspberry pi => Use gpiozero: `from gpiozero import LED` then `led = LED(17)` and `led.blink()`. Always add a resistor in series with an LED.
what is machine learning in python | ml python libraries | ai with python => Python is the main language for machine learning. scikit-learn is good for classic ML, and PyTorch is the most popular for neural networks.
what is pytorch | torch python | neural networks python => PyTorch is a library for building and training neural networks, with tensors (like NumPy arrays that can run on a GPU) and automatic gradients.
what is scikit-learn | sklearn | machine learning library python => scikit-learn has ready-made models like decision trees and linear regression with a simple pattern: `model.fit(X, y)` then `model.predict(X_new)`.

what is a python script vs program | what is a script => A script is usually a short program that automates a task, run from top to bottom. Bigger programs are split into modules and classes, but they are all Python code.
what is a shebang line | #!/usr/bin/env python3 | run python script directly linux => `#!/usr/bin/env python3` as the first line lets macOS and Linux run the file directly after `chmod +x script.py`. Windows ignores it.

how do i schedule a python script | run python every hour | cron python => Use cron on macOS and Linux (`crontab -e`) or Task Scheduler on Windows. Inside Python, the schedule package can run functions on a timer while the script stays open.
what is a daemon thread | daemon true python | background thread exits => A daemon thread stops automatically when the main program ends, while normal threads keep the program alive until they finish.
what is a race condition in python | threads changing same data | thread safety python => A race condition happens when two threads change the same data at once and the result depends on timing. Protect shared data with a `threading.Lock`.
what is async vs threading python | asyncio or threads | when to use asyncio => asyncio is great for many waits at once, like hundreds of web requests, using one thread. Threads are simpler for a few blocking tasks. Neither speeds up heavy math.
what does await do in python | await keyword | async function python => `await` pauses an async function until the slow thing finishes, letting other tasks run meanwhile. You can only use it inside `async def`.
what is a websocket in python | websockets python | real time connection python => A websocket keeps a connection open so the server and client can send messages any time, used for chat and live updates. The websockets package and FastAPI support them.
