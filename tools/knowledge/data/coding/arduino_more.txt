# More Arduino: modules, ESP32, code patterns and fixes, written by hand for Ace.
# tag: coding.arduino.more
how do i use a sound sensor with arduino | microphone module arduino | clap sensor arduino => Sound sensor modules have a digital output that goes HIGH or LOW past a level set by their little knob, and some have an analog output to read loudness with `analogRead`.
how do i use a soil moisture sensor | soil sensor arduino | plant watering arduino => Read its analog output with `analogRead`; wetter soil gives a different number than dry soil. Power it only while reading to stop the probe corroding fast.
how do i use a water level sensor arduino | rain sensor arduino | water sensor module => These modules give an analog value that changes as more of the sensor is wet. Read it with `analogRead` and pick a threshold by testing.
how do i use a flame sensor arduino | fire sensor module | ir flame sensor => A flame sensor module detects infrared light from flames and gives a digital or analog signal. It is for fun projects, not a real fire alarm.
how do i use a gas sensor arduino | mq2 sensor | mq135 arduino => MQ gas sensors give an analog value that rises with certain gases. They need a few minutes to warm up and get hot, and are not safety devices.
how do i use a tilt sensor arduino | tilt switch | ball switch arduino => A tilt switch has a little ball inside that connects or disconnects when tipped. Read it like a button with INPUT_PULLUP.
how do i use a reed switch arduino | magnetic door sensor | reed switch => A reed switch closes when a magnet is near, great for door and window sensors. Wire and read it like a button.
how do i use a hall effect sensor arduino | hall sensor | detect magnet arduino => A hall effect sensor detects magnetic fields. Digital ones switch near a magnet; analog ones give a value that changes with strength. They are used to count wheel turns.
how do i use an accelerometer with arduino | mpu6050 | gyroscope arduino => The MPU6050 measures tilt and rotation over I2C. Use a library like Adafruit MPU6050 to read acceleration and gyro values on each axis.
how do i use a compass module arduino | magnetometer | qmc5883 => A magnetometer module measures the Earth's magnetic field over I2C to find heading. Keep it away from motors and magnets and calibrate it.
how do i use a gps module with arduino | neo-6m gps | gps arduino => A GPS module like the NEO-6M sends position data over serial. The TinyGPSPlus library decodes latitude, longitude and time. It needs a view of the sky.
how do i use a load cell arduino | hx711 | weight scale arduino => A load cell measures weight with tiny signals, read through an HX711 amplifier board and its library. Calibrate it with a known weight.
how do i use a rotary encoder arduino | encoder knob | ky-040 => A rotary encoder gives two pulse signals as you turn it, and the order tells the direction. Use an Encoder library or interrupts to count clicks reliably.
how do i use a touch sensor arduino | capacitive touch | ttp223 => A TTP223 touch module outputs HIGH when touched, read with `digitalRead`. ESP32 boards also have built-in touch pins read with `touchRead`.
how do i use a vibration motor arduino | buzz motor | haptic motor arduino => A small vibration motor still needs more current than a pin gives, so drive it through a transistor with a diode across the motor.
how do i use a fan with arduino | dc fan arduino | control fan speed => Drive the fan through a transistor or MOSFET from its own supply, and use PWM with `analogWrite` to change its speed. Add a flyback diode.
how do i use a water pump with arduino | pump arduino | watering system arduino => A small pump is a motor, so use a MOSFET or relay module with a separate supply and a flyback diode. Keep water away from the electronics.
how do i use a solenoid with arduino | solenoid lock | solenoid arduino => A solenoid pulls in when powered and needs high current, often 12V. Switch it with a logic-level MOSFET and always add a flyback diode.
how do i use a laser module arduino | laser diode arduino | laser safety => Small laser modules turn on with a pin like an LED. Never point a laser at eyes, people or animals, even low power ones.
how do i use a led matrix arduino | max7219 | 8x8 led matrix => An 8x8 LED matrix with a MAX7219 driver needs just three data pins. The LedControl or MD_Parola library lets you draw dots and scroll text.
how do i use a tft screen with arduino | tft display | color screen arduino => SPI color TFT screens like the ILI9341 or ST7735 use the Adafruit GFX library plus a driver library to draw text, shapes and images.
how do i use an e-paper display | e ink arduino | epaper module => E-paper displays keep their image with no power and look like paper, but refresh slowly. Libraries like GxEPD2 drive them over SPI.
how do i use a real time clock | rtc module | ds3231 => An RTC module like the DS3231 keeps the time with a coin battery even when the Arduino is off. Use RTClib over I2C to set and read the date and time.
how do i use a relay module | relay module wiring | relay arduino code => Connect VCC, GND and IN to a pin. Many modules turn on when IN is LOW (active low), so test which way yours works. Keep mains wiring to qualified adults.
how do i use a membrane switch | arcade buttons arduino | big buttons arduino => Arcade and membrane buttons are just switches. Wire one side to a pin and the other to GND, and use INPUT_PULLUP.
how do i use a nrf24l01 | wireless arduino | radio module arduino => The nRF24L01 is a cheap 2.4 GHz radio for sending data between Arduinos using the RF24 library. It needs 3.3V and a capacitor across its power pins helps a lot.
how do i use lora with arduino | lora module | long range radio arduino => LoRa modules send small messages over long distances, even kilometers, using little power. They need the right frequency for your country.
how do i use a camera with arduino | esp32-cam | camera module arduino => The ESP32-CAM board has a camera and WiFi, and can stream video to a web page. A plain Uno is too slow for cameras.
how do i use a servo driver board | pca9685 | control many servos => The PCA9685 board controls up to 16 servos over I2C with its own power input, so the Arduino does not have to make all the pulses.
how do i use a motor shield | adafruit motor shield | l293d shield => A motor shield plugs on top and controls DC motors, steppers or servos with a library. Give it a separate battery for the motors.
what is an esp32 devkit | esp32 pins | esp32 dev board => ESP32 dev boards have WiFi, Bluetooth, a USB port and many GPIO pins at 3.3V. Some pins are input only or used at boot, so check a pinout for your board.
how do i upload to an esp32 | esp32 upload | esp32 boot button => Pick your ESP32 board and port and upload. If it says it cannot connect, hold the BOOT button while it starts uploading.
what is esp-now | esp now | esp32 to esp32 => ESP-NOW lets ESP32 and ESP8266 boards send small messages directly to each other without a WiFi router.
how do i make a web server on esp32 | esp32 webserver | control led from phone => Use the WebServer library: connect to WiFi, register a handler for a URL like /on, and open the board's IP address in a phone browser.
how do i get the time from the internet on esp32 | ntp esp32 | esp32 clock => Call `configTime` with a time zone offset and an NTP server like pool.ntp.org, then `getLocalTime` fills a time structure.
how do i make an esp32 sleep | deep sleep esp32 | save battery esp32 => `esp_deep_sleep_start()` shuts most of the chip down to save battery. Set a timer or pin wakeup first; the sketch starts from setup when it wakes.
what is preferences on esp32 | esp32 save settings | nvs esp32 => The Preferences library saves small values in the ESP32's flash memory so they survive power loss, like `prefs.putInt("score", 10)`.
what is the esp32 ble | bluetooth low energy esp32 | ble arduino => ESP32 boards support Bluetooth Low Energy, letting phones read sensor data or send commands. Libraries like NimBLE make it easier.
what is an arduino nano esp32 | nano esp32 | nano esp32 vs uno => The Nano ESP32 puts an ESP32-S3 with WiFi and Bluetooth in the small Nano shape, and is programmed from the Arduino IDE.
what is the arduino uno r4 led matrix | uno r4 wifi matrix | arduino_led_matrix => The Uno R4 WiFi has a built-in 12x8 red LED matrix you can draw on with the Arduino_LED_Matrix library, great for icons and scrolling text.
how do i read several buttons at once | multiple buttons arduino | button array => Keep the pin numbers in an array and loop through it, reading each with `digitalRead` and tracking each one's last state.
how do i control many leds | lots of leds arduino | shift register leds => Use a 74HC595 shift register to control 8 LEDs with 3 pins, chain several for more, or use addressable LEDs like NeoPixels.
what is a 74hc595 | shift register | 74hc595 arduino => The 74HC595 shift register turns three Arduino pins into 8 outputs using `shiftOut`. You can chain more for 16, 24 and beyond.
what is charlieplexing | charlieplexing leds | more leds fewer pins => Charlieplexing uses the fact that pins can be HIGH, LOW or input to drive many LEDs from few pins. It is clever but tricky to wire.
how do i fade an led | fade led arduino | breathe led => Loop a brightness value from 0 to 255 and back, calling `analogWrite(pin, brightness)` with a short delay, on a PWM pin. See File > Examples > 01.Basics > Fade.
how do i make a traffic light with arduino | traffic light project | traffic lights code => Wire red, yellow and green LEDs with resistors to three pins, then turn them on and off in order with delays, or with millis for a pedestrian button.
how do i make a reaction game with arduino | reaction timer arduino | button reaction game => Wait a random time, light an LED, save `millis()`, and when the button is pressed print `millis() - start` as the reaction time. Punish presses before the light.
how do i make a simon game with arduino | simon says arduino | memory game arduino => Use 4 LEDs and 4 buttons. Store a growing random sequence in an array, play it back with lights and tones, then check the player presses the same order.
how do i make a theremin with arduino | light theremin | ultrasonic theremin => Map a light sensor or distance reading to a frequency with `map`, then play it with `tone` on a piezo. Moving your hand changes the pitch.
how do i make a digital dice with arduino | dice arduino | led dice => Wire 7 LEDs in a dice pattern, and when a button is pressed pick `random(1, 7)` and light the matching pattern. Seed with `randomSeed(analogRead(A0))`.
how do i make a plant monitor arduino | plant watering project | soil alarm => Read a soil moisture sensor, and when it is too dry light an LED, sound a buzzer, or switch a small pump through a MOSFET.
how do i make a weather station arduino | weather station project | temperature humidity display => Read a sensor like a BME280 (temperature, humidity and pressure) and show the values on an OLED or send them over WiFi with an ESP32.
how do i make a door alarm arduino | alarm project | intruder alarm arduino => Use a reed switch or PIR sensor, and when it triggers sound a buzzer and flash an LED. Add a keypad code to turn it off.
how do i make a parking sensor arduino | distance beeper | parking assist arduino => Read an ultrasonic sensor and beep faster as distance shrinks by making the delay between beeps depend on the distance.
how do i make a smart light arduino | automatic night light | light sensor led => Read a photoresistor, and if it is dark (below a number you pick by testing) turn on an LED or NeoPixel, otherwise turn it off.
how do i make a binary counter with leds | binary leds arduino | count in binary => Use 4 LEDs for bits and light each with `bitRead(count, i)` as count goes from 0 to 15.
how do i make a morse code flasher | morse arduino | sos led => Store dots and dashes for each letter, then blink short for a dot and long (3 times as long) for a dash, with gaps between letters.
how do i make a fan that turns on when hot | temperature fan arduino | thermostat arduino => Read a temperature sensor, and when it goes over your setting turn on a fan through a MOSFET. Use two thresholds (on at 28, off at 26) so it does not flicker.
what is hysteresis | hysteresis arduino | stop flickering on off => Hysteresis means using a different level to turn on than to turn off, so a reading hovering near one threshold does not flip the output back and forth.
how do i send data from arduino to python | arduino to computer serial | pyserial arduino => Print values with `Serial.println` on the Arduino, and on the computer read them with Python's pyserial: `serial.Serial("COM3", 9600).readline()`.
how do i send commands to arduino from my computer | serial commands arduino | control arduino from pc => Send text over serial from the Serial Monitor or a program, then on the Arduino read it with `Serial.readStringUntil('\n')` and compare it to commands like "on".
how do i send several values over serial | csv over serial | parse serial values => Print them separated by commas on one line, like `Serial.print(a); Serial.print(','); Serial.println(b);`, then split each line on the other side.
how do i connect two arduinos | arduino to arduino | communicate between arduinos => Use serial (TX to RX, RX to TX and shared GND), I2C with one as controller and the other as peripheral, or radio modules for wireless.
what is the arduino map limit | map gives negative numbers | map out of range => `map` does not limit its result, so readings outside the input range give values outside the output range. Wrap it in `constrain` to keep it in range.
why does map not give decimals | map integer only | map float arduino => `map` uses whole numbers (long) and drops decimals. Write your own float version: `(x - inMin) * (outMax - outMin) / (inMax - inMin) + outMin` with floats.
how do i use arrays in arduino | array of pins | loop over pins arduino => `int leds[] = {2, 3, 4, 5};` then loop `for (int i = 0; i < 4; i++)` to use each pin. Arrays have a fixed size and start at index 0.
how do i get the length of an array in arduino | array size arduino | sizeof array => `sizeof(leds) / sizeof(leds[0])` gives the number of elements. It only works where the array was declared, not on an array passed to a function.
how do i make a function in arduino | arduino functions | custom function arduino => Write it outside setup and loop, like `void blink(int pin, int ms) { digitalWrite(pin, HIGH); delay(ms); digitalWrite(pin, LOW); }`, then call `blink(13, 200)`.
what is a struct in arduino | struct arduino | group variables arduino => A struct groups related values, like `struct Note { int freq; int length; };`, handy for melodies or settings.
what is an enum in arduino | enum states arduino | name your states => `enum State { IDLE, RUNNING, DONE };` gives readable names to states, used with a switch in loop.
what is a class in arduino | arduino class | object oriented arduino => You can write C++ classes, like a `Led` class with `on()` and `off()` methods, to keep code tidy when you have many similar parts.
how do i make my own arduino library | create library arduino | arduino library folder => Put a .h and .cpp file in a folder inside Arduino/libraries, with a class in them. Restart the IDE and `#include` it like any other library.
how do i split a sketch into tabs | arduino tabs | multiple files arduino => Use the tab menu to add new files. Extra .ino tabs are joined with the main one before compiling; .h and .cpp tabs work like normal C++ files.
what is the arduino.h header | arduino.h | include arduino.h => `Arduino.h` declares digitalWrite, millis and the rest. The IDE adds it automatically to .ino files, but your own .cpp and .h files must include it.
what is a pointer in arduino | pointers arduino | & and * arduino => Arduino is C++, so pointers work the same: `int* p = &x;` stores x's address and `*p` reads it. Many libraries pass arrays as pointers.
what is the difference between int and long on arduino | int vs long arduino | int too small arduino => On an Uno an int is 16 bits (up to 32,767) and a long is 32 bits (up to about 2.1 billion). Use long or unsigned long for big numbers like millis.
what is the difference between float and double on arduino | double on uno | float precision arduino => On AVR boards like the Uno, double is the same as float, 4 bytes with about 6 to 7 digits of precision. Many 32-bit boards have a real 8-byte double.
byte vs int arduino | when to use byte arduino | byte type arduino 0 to 255 => `byte` is an unsigned 8-bit number from 0 to 255, saving memory for small values like brightness or pin numbers.
how do i make a random number on arduino | arduino random seed | random different each time => Call `randomSeed(analogRead(A0))` once in setup using an unconnected pin for noise, then `random(1, 7)` gives 1 to 6.
how do i make a timer that repeats every second | arduino interval | do every second arduino => `if (millis() - last >= 1000) { last += 1000; /* do it */ }` runs once a second while loop keeps running other code.
how do i make a timer that runs once | one shot timer arduino | do something after 5 seconds => Save `start = millis()` and a flag when it begins, then in loop check `if (running && millis() - start >= 5000) { running = false; /* do it */ }`.
how do i count button presses | count presses arduino | press counter => Detect the change from not pressed to pressed (edge detection) and add 1 to a counter only then, with debouncing.
how do i do long press detection | long press arduino | hold button arduino => Save `millis()` when the button goes down; when it comes up, check how long it was held. Over about 1000 ms counts as a long press.
how do i read a potentiometer smoothly | pot jitter | stable analog reading => Average several readings, and only react when the value changes by more than a few steps, to ignore tiny jitters.
what does exit status 1 mean arduino | exit status 1 | compilation error arduino => It just means compiling failed. Scroll up in the output to the first red error message, which says what and where the problem is.
what does expected primary-expression before mean arduino | arduino expected primary expression | arduino syntax error => Something is missing or extra near that line, like a missing value, an extra bracket, or a type name where a value should go.
what does expected initializer before mean | expected initializer | arduino missing semicolon before => Usually a missing semicolon or bracket on the line above, or a typo in a type name.
what does does not name a type mean | does not name a type arduino | type not declared => The compiler does not know that type, often a library class whose #include is missing, or code placed outside any function by mistake.
what does a function-definition is not allowed here mean | function definition not allowed | function inside function arduino => You wrote a function inside another one, usually because a closing brace `}` is missing above. Count your braces.
what does stray in program mean | stray 302 in program | stray character error => Your code has a strange invisible or fancy character, often from copying code from a website, like curly quotes. Retype that line.
what does multiple libraries were found mean | multiple libraries found | library conflict arduino => Two installed libraries have the same header name. The IDE says which it used; remove the one you do not want if it picked wrong.
what does board at port is not available mean | port not available | serial port busy => Another program, like a second Serial Monitor, Cura or a Python script, is using the port. Close it and try again.
what does a fatal error occurred failed to connect to esp32 mean | failed to connect esp32 | esp32 timed out waiting for packet header => The ESP32 is not in upload mode. Hold BOOT while uploading starts, try a data USB cable, and check the right port and board are picked.
what does brown out detector was triggered mean | brownout esp32 | esp32 brownout reset => The ESP32's voltage dipped too low, often when WiFi starts. Use a better USB cable or power supply and add a capacitor.
what does guru meditation error mean | esp32 guru meditation | esp32 crash => The ESP32 crashed, often from reading a bad pointer, a stack overflow, or using a pin wrongly. Read the error type and use the ESP Exception Decoder to find the line.
what does watchdog reset mean | wdt reset | watchdog timer arduino => A watchdog resets the chip if code gets stuck. On ESP8266 and ESP32, long loops without `delay` or `yield` can trigger it.
what is a watchdog timer | wdt | watchdog explained => A watchdog timer resets the board if your code does not check in regularly, so a frozen gadget restarts itself.
why does my arduino not run without usb | arduino only works plugged in | battery not working arduino => The battery may be too weak or below about 7V into VIN, or the code waits for the Serial Monitor (like `while (!Serial)` on some boards). Remove that line for battery use.
why does my sensor read 0 or 1023 all the time | analog reading stuck | sensor always max => The wiring is probably wrong: the analog pin may be connected straight to 5V or GND, or the sensor's power or ground is loose.
why does my i2c device not work | i2c not found | i2c scanner finds nothing => Check SDA and SCL are not swapped, power and ground are connected, the address in code matches the scanner, and the voltage suits the device.
why does my motor not spin | motor not working arduino | dc motor not running => Check the motor driver has its own power, grounds are connected, the enable pin is set (or jumpered), and your battery is strong enough.
why does my stepper just vibrate | stepper not turning | stepper buzzing => The coil wires are probably in the wrong order, or the speed is too high. Check the pairs with a multimeter and slow it down.
why does my ultrasonic sensor give 0 | hc-sr04 not working | distance always zero => Check TRIG and ECHO are on the pins your code uses, it has 5V power, and add a timeout to `pulseIn`. Soft or angled surfaces may not echo back.
why is my neopixel strip showing wrong colors | neopixel colors wrong | led strip flicker => Check the color order setting (like NEO_GRB), connect grounds, add a resistor on data and a capacitor on power, and make sure the supply is strong enough.
why does my lcd show only boxes | lcd blank boxes | lcd not showing text => Turn the contrast knob on the back, check the I2C address (often 0x27 or 0x3F), and make sure you call `lcd.init()` or `lcd.begin()` and turn on the backlight.
what is arduino uno r3 vs r4 | uno r3 or r4 | difference uno r3 and r4 => The R4 has a much faster 32-bit chip, more memory, and USB-C. Most beginner code works on both, but some older libraries that use AVR registers only work on the R3.
what is an arduino starter kit | best arduino kit | arduino kit for beginners => A starter kit includes a board, breadboard, wires, LEDs, resistors, buttons, sensors and a project book, which is the easiest way to begin.
what is an arduino giga | arduino giga r1 | giga board => The GIGA R1 WiFi is a powerful Arduino with a dual-core chip, lots of memory and many pins, for big projects like audio and displays.
what is the arduino modulino | modulino | qwiic stemma qt => Modulino, Qwiic and STEMMA QT are plug-in sensor boards that connect over I2C with a small cable, so there is no breadboard wiring.
what is a grove system | seeed grove | grove connectors => Grove is Seeed Studio's system of modules with one standard 4-pin connector, making wiring sensors and outputs quick and mistake-free.
what is a perfboard | protoboard | make circuit permanent => Perfboard is a board with holes you solder parts onto, making a breadboard project permanent and sturdy.
what is a pcb | printed circuit board | design a pcb => A PCB is a board with copper tracks connecting parts. You can design one in free tools like KiCad and order it online from a factory.
what is kicad | kicad pcb | pcb design software => KiCad is free, open source software for drawing schematics and designing printed circuit boards.
what is a 3d printed enclosure | case for arduino | project box => A case protects your project. You can 3D print one, use a plastic project box, or build one from cardboard or LEGO.
how do i power a project for a long time | low power arduino | battery life arduino => Use sleep modes, turn off LEDs and sensors when not needed, avoid boards with power-hungry regulators and LEDs, and pick a big battery.
what is a power bank for arduino | usb power bank arduino | power bank turns off => A USB power bank can run an Arduino, but some switch off when the board draws too little power. A small extra load or a power bank with an always-on mode fixes it.
what is a solar panel arduino | solar powered arduino | solar charging => A small solar panel with a charge controller module can charge a battery that runs your project, good for outdoor sensors.
