# Roblox concepts, services, security, Studio and publishing, written by hand for Ace.
# tag: coding.roblox.concepts
what is replicatedstorage used for | when should i use replicatedstorage | replicated storage vs server storage => ReplicatedStorage holds things both the server and every client can see, like RemoteEvents, shared ModuleScripts and models the client needs to clone. ServerStorage is only on the server, so put secret things there.
what is serverstorage used for | why use server storage | where do i keep maps and tools on the server => ServerStorage holds things only the server can reach, like maps, tools to give out, and NPC templates. Clients cannot see or steal what is in it.
what is serverscriptservice for | where should server scripts go | why put scripts in serverscriptservice => ServerScriptService is the home for server Scripts and server-only ModuleScripts. Clients never receive its contents, so your server code stays hidden.
what is starterplayerscripts | where do i put localscripts | starter player scripts vs starter character scripts => LocalScripts in StarterPlayerScripts run once when the player joins and keep running. Scripts in StarterCharacterScripts are copied into the character and run again every respawn.
what is startergui used for | how does startergui work | startergui vs playergui => StarterGui is the template. Each time a character spawns, its ScreenGuis are copied into that player's PlayerGui, which is what the player sees and what your LocalScripts should change.
what is starterpack used for | how do i give everyone a tool at spawn | starterpack tools => Tools in StarterPack are copied into every player's Backpack each time they spawn.
what is replicatedfirst for | when to use replicated first | loading screen location => ReplicatedFirst is sent to the client before anything else, so it is the place for loading screen LocalScripts.
what goes in workspace | what does workspace hold => Workspace holds everything in the 3D world that players see and touch: parts, models, terrain and characters. Things outside Workspace are not drawn.
what is the explorer window | how do i open explorer in studio | explorer roblox studio => The Explorer shows every object in your game as a tree, grouped under services like Workspace and ReplicatedStorage. Open it from the View tab if it is closed.
what is the properties window | how do i see a part's properties | open properties studio => The Properties window shows and edits the settings of whatever you selected, like Size, Color and Anchored. Open it from the View tab.
what is the difference between a script and a localscript | script vs localscript | server script or local script => A Script runs on the server and changes things for everyone. A LocalScript runs on one player's device and is used for input, camera and GUI. Use RemoteEvents to connect them.
what is the client and the server in roblox | client vs server roblox | what runs on the server => The server is Roblox's computer that runs the real game for everyone. Each player's device is a client that shows the game and sends input. Important rules and data must live on the server.
what is filteringenabled | what does filtering enabled do | why cant clients change things for everyone => FilteringEnabled means changes made on a client do not copy to the server or other players. It is always on, and it stops exploiters from changing the game for everyone. Use RemoteEvents for real changes.
what is replication in roblox | how does replication work | what replicates to clients => Replication is the server copying objects and property changes to every client. Things in Workspace and ReplicatedStorage replicate; ServerStorage and ServerScriptService do not, and client changes do not go back up.
what is network ownership | network owner roblox | why is physics laggy for unanchored parts => The server or a player's device can own the physics of an unanchored part. Roblox gives ownership to the nearest player to make it smooth. Use `part:SetNetworkOwner(nil)` on the server to keep physics on the server.
what is an exploiter in roblox | how do hackers cheat in roblox games | what can exploiters do => Exploiters run their own code on their client. They can change anything on their own device and fire your RemoteEvents with fake data, but they cannot change the server directly, so the server must check everything.
how do i secure remote events | remote event security | stop exploiters abusing remotes => On the server, check the types and ranges of every argument, check the player is allowed to do it (distance, cooldowns, owning the item), and never accept values like damage, price or coins from the client.
what is a sanity check in roblox | server checks for remotes | validate client requests => A sanity check is the server making sure a request makes sense, like the player is close enough to the shop, has the money, and is not firing faster than possible. It is the main defense against exploits.
is client data safe | can the client lie => No. Anything sent from a client can be faked. Let the client send what it wants to do, and let the server decide if it is allowed and what happens.
what is a remoteevent vs remotefunction | remote event or remote function | which remote should i use => A RemoteEvent sends a message one way and does not wait. A RemoteFunction waits for an answer. Use RemoteEvents most of the time, and avoid InvokeClient because a client could never answer.
what is unreliableremoteevent | unreliable remote event roblox | when to use unreliable remotes => UnreliableRemoteEvent is like a RemoteEvent but messages may be dropped or arrive out of order. It is cheaper, so use it for frequent effects or positions where losing one message does not matter.
what is a bindableevent | bindable vs remote | when to use bindable events => A BindableEvent sends messages between scripts on the same side (server to server or client to client). RemoteEvents are for crossing between server and client.
what is a modulescript for | why use module scripts | module script benefits => A ModuleScript holds code you can reuse. Any script can `require` it to get what it returns, usually a table of functions, so you write it once and use it everywhere.
does a modulescript run on the server or client | where do modules run | require from client => A ModuleScript runs on whichever side requires it. If a LocalScript requires it, it runs on that client; each side gets its own copy.
what is runcontext | script runcontext property | run context client roblox => RunContext lets a Script choose where it runs: Legacy (old rules), Server, or Client. A Script with RunContext Client runs on clients even in Workspace or ReplicatedStorage.
what is the humanoidrootpart | humanoid root part | what is the root part of a character => HumanoidRootPart is the invisible main part of a character that everything is attached to. Move or measure the character with it.
what is r6 and r15 | r6 vs r15 | difference between r6 and r15 rigs => R6 characters have 6 body parts and simple animation. R15 characters have 15 parts and bend at elbows and knees for smoother animation. You choose it in Game Settings > Avatar.
what is a rig in roblox | how do i insert a dummy | rig builder studio => A rig is a character model with joints for animating. Insert one from the Avatar tab using the Rig Builder, then animate it in the Animation Editor.
what is a cframe | what does cframe mean | cframe explained => A CFrame (coordinate frame) stores a position and a rotation together. Setting a part's CFrame moves and turns it at once, like `part.CFrame = CFrame.new(0, 5, 0) * CFrame.Angles(0, math.rad(45), 0)`.
what is the difference between position and cframe | position vs cframe | should i use position or cframe => Position is only where the part is. CFrame is where it is and which way it faces. Use CFrame when you also care about rotation or moving welded models.
what is a vector3 | vector3 explained | what does vector3 new do => A Vector3 holds three numbers X, Y and Z, used for positions, sizes, directions and velocities. Make one with `Vector3.new(1, 2, 3)`.
what is lookvector | cframe lookvector | which way is a part facing => `part.CFrame.LookVector` is a length-1 Vector3 pointing where the part's front face points. Multiply it by a distance to move forward, like `part.Position + part.CFrame.LookVector * 10`.
what is magnitude in roblox | vector magnitude | how long is a vector => Magnitude is the length of a Vector3. `(a - b).Magnitude` is the distance between two points.
vector3 unit | normalize a vector roblox => `.Unit` gives a vector pointing the same way with a length of 1, so you can multiply it by any speed or distance.
what is a udim2 | udim2 explained | scale and offset gui => UDim2 is a GUI size or position with X and Y, each having Scale (fraction of the parent) and Offset (pixels). `UDim2.new(0.5, 0, 0, 50)` is half the parent wide and 50 pixels tall.
what is the difference between scale and offset | scale vs offset roblox | should i use scale or offset => Scale is a fraction of the parent (0.5 is half), so it adapts to every screen. Offset is fixed pixels. Scale is usually better so GUI looks right on phones and PCs.
what is anchorpoint | anchor point gui | how do i center a gui => AnchorPoint picks which point of the GUI its Position refers to. Set `AnchorPoint = Vector2.new(0.5, 0.5)` and `Position = UDim2.fromScale(0.5, 0.5)` to center it.
what is a color3 | color3 fromrgb vs new | how do colors work in roblox => Color3 is a color. `Color3.fromRGB(255, 0, 0)` uses 0 to 255 numbers, while `Color3.new(1, 0, 0)` uses 0 to 1. Both make red.
what is brickcolor vs color3 | brickcolor or color | old brick colors => BrickColor is an older palette of named colors like "Bright red". Color3 can be any color. Parts have both, and setting one changes the other, so Color3 is usually easier.
what is an enum in roblox | enum explained luau => An Enum is a fixed list of named options, like `Enum.Material.Neon` or `Enum.KeyCode.E`. Properties that take one choice from a list use Enums.
what are studs | how big is a stud | roblox units => A stud is Roblox's unit of length. A default character is about 5 studs tall, and Roblox treats 1 stud as about 28 cm for physics like gravity.
what is the default walkspeed | default jump power roblox | default player speed => Humanoids start with WalkSpeed 16 studs per second, JumpHeight 7.2 studs (or JumpPower 50 if UseJumpPower is on), and MaxHealth 100.
what is the default gravity in roblox | workspace gravity default | how strong is roblox gravity => Workspace.Gravity is 196.2 studs per second squared by default. Roblox's docs treat 1 stud as 28 cm, where real Earth gravity would be about 35 studs per second squared, so default Roblox gravity is stronger than real life.
what is the max part size in roblox | biggest part size | how big can a part be => A part can be up to 2048 studs on each side. Use several parts or terrain for anything bigger.
instance new explained | everything is an instance => Instance is the base class for every object in the game: parts, scripts, GUIs and services. `Instance.new("Part")` creates a new one.
what is the parent of an object | parent and children roblox | how does parenting work => Every object sits inside a Parent, making a tree. Setting `obj.Parent = workspace` puts it in the world, and destroying a parent also removes its children.
what is the difference between findfirstchild and waitforchild | findfirstchild vs waitforchild | when to use waitforchild => FindFirstChild returns the child right away or nil. WaitForChild pauses until the child exists. Use WaitForChild on the client for things the server creates, and FindFirstChild when it may not exist.
what is the difference between getchildren and getdescendants | getchildren vs getdescendants | get everything inside a model => GetChildren returns only the objects directly inside. GetDescendants returns everything inside at every depth, children of children included.
what is the difference between destroy and remove | destroy vs parent nil | remove deprecated roblox => `:Destroy()` deletes the object for good and disconnects its events. `:Remove()` is deprecated. Setting `Parent = nil` hides it but keeps it in memory so you can parent it again.
what is a connection in roblox | rbxscriptconnection | event connection explained => When you call `:Connect()` on an event you get a connection. It keeps your function listening until you call `:Disconnect()` or the object is destroyed.
what is the difference between heartbeat and renderstepped | heartbeat vs renderstepped | stepped vs heartbeat => RenderStepped runs on the client before each frame is drawn, good for camera. Stepped runs before physics and Heartbeat after physics each frame; Heartbeat is the usual choice for game logic.
what is delta time | dt in heartbeat | why multiply by dt => Delta time is how many seconds passed since the last frame. Multiplying speeds by dt makes movement the same speed no matter the frame rate.
what is task.wait vs wait | difference between wait and task wait | should i use wait or task.wait => Use `task.wait()`. It is more accurate and resumes on the next frame, while the old `wait()` is deprecated and can be throttled.
what is task.spawn vs spawn | spawn deprecated | task spawn or coroutine wrap => `task.spawn` runs a function right away on a new thread. The old `spawn()` is deprecated and starts late. `coroutine.wrap` also works but errors inside it are harder to see.
what is task.defer | task defer vs task spawn | when to use task.defer => `task.defer` runs a function a little later, after the code that is running finishes its turn, instead of immediately like task.spawn. It is useful when you want the rest of your code to finish first.
what is the debris service for | debris vs destroy => Debris lets you remove an object after some seconds without making your script wait: `Debris:AddItem(obj, 3)`.
what is a dictionary table in luau | luau table with keys | key value table roblox => A dictionary table uses names as keys: `local stats = {Coins = 10, Level = 2}`. Read it with `stats.Coins` and loop it with `for key, value in stats do`.
what is a leaderstats folder | how does leaderstats work | why must it be called leaderstats => A Folder named exactly "leaderstats" inside a Player tells Roblox to show the IntValue, NumberValue and StringValue objects inside it on the player list.
what is a datastore | how do datastores work | what is datastoreservice => A DataStore is Roblox's online save storage for your experience. You save values under keys, usually one key per player like their UserId, and load them next time they play.
why use pcall with datastores | pcall explained => `pcall` runs a function and catches errors instead of crashing the script: `local ok, result = pcall(function() return store:GetAsync(key) end)`. Use it for DataStores, HTTP and purchases because they can fail.
what is the difference between setasync and updateasync | setasync vs updateasync | which datastore save should i use => SetAsync overwrites the value. UpdateAsync reads the saved value and lets you return a new one, which is safer when many servers might write the same key. UpdateAsync is the usual choice for player data.
how much data can a datastore save | datastore size limit | datastore key size limit => Each key can hold up to 4,194,304 characters of JSON data, and key names and store names can be up to 50 characters.
how often can i save to a datastore | datastore limits | datastore request limits => Roblox limits how many DataStore requests a server can send per minute (it grows with the number of players) and how much each key can be read and written per minute. Check `DataStoreService:GetRequestBudgetForRequestType()` before saving in loops.
what is an ordereddatastore | ordered data store | ordereddatastore for leaderboards => An OrderedDataStore only stores whole numbers and can return them sorted, which is perfect for global leaderboards with `GetSortedAsync`.
what is memorystoreservice | memory store roblox | memorystore vs datastore => MemoryStoreService is fast, short-term storage shared across all servers, good for matchmaking queues and live leaderboards. Data expires (up to 45 days), so use DataStores for permanent saves.
what is messagingservice | messaging service roblox | send messages between servers => MessagingService lets servers of the same experience send messages to each other with `PublishAsync` and `SubscribeAsync`, for things like global announcements.
what is a session lock | data duplication roblox | why save data can duplicate => A session lock marks a player's data as in use by one server so another server cannot load and save old data at the same time. Libraries like ProfileStore handle this for you.
what is profileservice | profilestore roblox | should i use profileservice => ProfileService and its newer version ProfileStore are popular community modules that handle DataStore saving, session locking and auto-saving for you. They are not made by Roblox, but many games use them.
what is a game pass | gamepass roblox | what does a game pass do => A game pass is a one-time Robux purchase that gives a permanent perk in your experience, like VIP or double coins. Players own it forever.
what is a developer product | dev product roblox | gamepass vs developer product => A developer product can be bought many times, like coin packs or revives. Game passes are bought once. You must handle developer products in `MarketplaceService.ProcessReceipt`.
what is processreceipt | process receipt roblox | how to handle dev product purchases => ProcessReceipt is a callback on MarketplaceService that runs on the server when a developer product is bought. Give the item, then return `Enum.ProductPurchaseDecision.PurchaseGranted`, or NotProcessedYet if something failed so Roblox retries.
how much robux do i get from a gamepass sale | roblox marketplace fee | how much robux does roblox take => When someone buys your game pass or developer product, you get 70% of the Robux and Roblox keeps 30%.
what is premium payouts | how do premium payouts work | earn robux from premium players => Roblox pays you Robux based on how much time Roblox Premium members spend in your experience. You do not have to sell anything; it is automatic.
what is devex | developer exchange roblox | how do i turn robux into money => DevEx (Developer Exchange) lets creators trade earned Robux for real money. You must be at least 13, have a verified account, and have earned at least 30,000 Robux. The exchange rate can change, so check Roblox's DevEx page.
what are private server fees | private servers robux | how do private servers earn robux => You can charge a monthly Robux price for private servers in your experience, and you earn from each one that players keep subscribed.
what is the creator hub | create roblox com | where do i manage my game => The Creator Hub (create.roblox.com) is where you manage experiences, upload assets, make game passes and developer products, read analytics, and find the docs.
what is the creator store | toolbox roblox | free models safe => The Creator Store, shown in Studio's Toolbox, has free and paid models, plugins, audio and images. Be careful with free models: check them for hidden scripts before using them.
are free models dangerous | free model virus roblox | backdoor in free model => Some free models hide scripts that let others take control of your game (a backdoor). Search the model for Scripts, look for `require(` with a number or `getfenv`, and delete anything you do not understand.
what is a backdoor in roblox | backdoor script | how do i find backdoors => A backdoor is a hidden script, often from a free model or plugin, that lets someone else run code in your game. Search all scripts for require with numbers and strange code, and only use trusted plugins.
what is a plugin in roblox studio | studio plugins | how do i install plugins => Plugins add tools to Studio. Install them from the Creator Store, and they show up in the Plugins tab. Only install plugins from creators you trust, because they can change your game.
what is team create | collaborate roblox studio | edit with friends => Team Create (Collaboration) lets several people edit the same place at once. Scripts can use Collaborative Editing so two people can type in one script together.
what is a package in roblox | packages roblox studio | reuse models across games => A package is a model you can reuse in many places. When you update the package, every copy can update too, which is great for shared parts of several games.
what is streamingenabled | instance streaming roblox | streaming enabled pros and cons => StreamingEnabled (in Workspace) sends only the nearby part of the map to each client, so big maps load faster and use less memory. LocalScripts must use WaitForChild because far parts may not exist on the client.
what is a place vs an experience | places in a game | multiple places roblox => An experience (game) can contain several places, like a lobby and levels. Players teleport between them with TeleportService, and they share DataStores.
what is the starting place | start place roblox | main place of an experience => The start place is the place players join first when they click Play on your experience. Other places are reached by teleporting.
what is a universe id | gameid vs placeid | experience id => The universe ID (game.GameId) identifies the whole experience, while each place inside it has its own PlaceId.
what is studio play vs run | play vs run in studio | play here in studio => Play spawns your character and runs the game like a player. Run starts the server simulation without a character, so you can watch physics and scripts.
what is the command bar | studio command bar | run code in studio => The Command Bar (View > Command Bar) runs one line of Luau in Studio right away. It is handy for quick changes, like moving or renaming many parts.
what is the find all feature in studio | search all scripts studio | find text in every script => Press Ctrl+Shift+F (Cmd+Shift+F on Mac) to search every script in the place for some text, and replace it if you want.
what are the move scale rotate shortcuts in studio | studio tool shortcuts | ctrl 2 roblox => In Studio, Ctrl+1 is Select, Ctrl+2 Move, Ctrl+3 Scale and Ctrl+4 Rotate (Cmd on Mac).
how do i duplicate a part in studio | copy part shortcut studio | ctrl d roblox => Select it and press Ctrl+D (Cmd+D on Mac). The copy appears in the same spot, so move it after.
how do i group parts into a model | ctrl g roblox | make a model from parts => Select the parts and press Ctrl+G (Cmd+G on Mac). Ctrl+U ungroups them again.
how do i focus the camera on a part in studio | zoom to part studio | f key roblox studio => Select the part and press F to move the Studio camera to it.
how do i move the camera in roblox studio | studio camera controls | fly around in studio => Hold right mouse and use W, A, S, D to fly, Q and E to go down and up, and scroll to zoom. Hold Shift to move slower.
how do i change the move increment | snap to grid studio | studs per move studio => In the Model tab, set Move and Rotate snapping values, or turn snapping off to move freely.
how do i toggle local and world space in studio | ctrl l studio | rotate in local space => Press Ctrl+L (Cmd+L on Mac) to switch the move and rotate handles between world and local space.
how do i start a play test from the keyboard | f5 in studio | stop play test shortcut => Press F5 to Play and Shift+F5 to stop. F8 starts Run mode without a character.
how do i lock a part in studio | locked property studio | stop selecting a part => Turn on the part's Locked property so clicking in the 3D view will not select it. You can still select it in the Explorer.
what is a union vs a meshpart | union or mesh | which is better for performance => A Union is made from parts in Studio, and a MeshPart comes from a 3D file. MeshParts are usually lighter and more flexible, while too many complex unions can hurt performance.
what is collisionfidelity | collision fidelity roblox | why can i not walk into a mesh => CollisionFidelity sets how exact a mesh's hit box is: Box, Hull, Default or PreciseConvexDecomposition. Simpler is faster; precise follows the shape better.
what is cancollide cantouch and canquery | collision properties roblox | cantouch property => CanCollide makes things bump into the part. CanTouch makes Touched events fire. CanQuery makes raycasts and spatial queries see it (it only matters when CanCollide is off).
what is a surfaceappearance | pbr textures roblox | realistic materials mesh => SurfaceAppearance gives a MeshPart PBR textures: color, normal, metalness and roughness maps, so it looks realistic.
what is material variant | custom materials roblox | material manager => MaterialVariant lets you make custom versions of materials like Grass or Brick. You manage them in the Material Manager and they live in MaterialService.
what is lighting technology future | future lighting roblox | voxel vs shadowmap vs future => Lighting.Technology picks the lighting quality. Voxel is cheapest, ShadowMap adds sun shadows, and Future adds detailed shadows from every light. Players' graphics settings may lower it.
what is post processing in roblox | bloom blur color correction | screen effects roblox => Put effects like BloomEffect, BlurEffect, ColorCorrectionEffect, SunRaysEffect and DepthOfFieldEffect in Lighting (or the Camera) to change how the whole screen looks.
what is the microprofiler | profile performance roblox => The MicroProfiler shows how long each part of every frame takes. Open it with Ctrl+F6 (Cmd+F6) in Studio or the game to find what is causing lag.
what is the script performance window | find laggy scripts | script activity roblox => View > Script Performance shows how much time each script uses. A script with high activity is a good place to look for lag.
how many parts is too many in roblox | part count lag | does part count matter => There is no exact limit, but tens of thousands of unanchored or complex parts will lag. Anchor what does not move, merge small details into meshes, and use StreamingEnabled for big maps.
why use object pooling in roblox | reuse parts instead of destroying | part pooling => Creating and destroying many parts quickly, like bullets, is slow. Pooling keeps a set of parts and reuses them by moving them out of the way, which is faster.
what is collectionservice used for | tags in roblox | why use tags => CollectionService lets you tag many objects, like every lava part, and handle them all in one script instead of putting a copy of a script in each part.
what is a humanoid state | humanoid states roblox | humanoidstatetype => A Humanoid is always in a state like Running, Jumping, Freefall, Seated or Dead. Use `humanoid:GetState()` and the StateChanged event to react to them.
what is a forcefield | spawn protection roblox | forcefield blocks damage => A ForceField in a character protects it from TakeDamage and explosions. Players get one for a few seconds after spawning, set by SpawnLocation.Duration.
how do tools work | equip a tool => A Tool is an item a character can hold. It usually has a part named Handle, and you use its Equipped, Unequipped and Activated events to make it work.
what is a handle in a tool | tool needs a handle | requireshandle property => The Handle is the part the character holds. If your tool has no Handle, set RequiresHandle to false or it will not equip properly.
what is an accessory | add a hat to a character => An Accessory is a wearable item like a hat or backpack. Add it with `humanoid:AddAccessory(accessory)` and it attaches using a matching Attachment.
attachments for constraints | what do attachments do => An Attachment is a point and direction inside a part. Constraints, beams, trails and particles use attachments to know where to connect or emit from.
physics constraints | mover constraints => Constraints connect parts with physics rules, like hinges, ropes, springs, or movers like LinearVelocity and AlignPosition. They replaced old BodyMovers such as BodyVelocity, which are deprecated.
is bodyvelocity deprecated | bodyvelocity vs linearvelocity | bodygyro replacement => Yes. BodyVelocity, BodyPosition, BodyGyro and BodyForce are deprecated. Use LinearVelocity, AlignPosition, AlignOrientation and VectorForce instead.
what is a weldconstraint vs weld | weld vs weldconstraint | which weld should i use => A WeldConstraint keeps two parts in their current relative position and is easy to set up in Studio. A Weld uses C0 and C1 offsets you set in code. Motor6D is a weld that animations can move.
what is a motor6d | joints for animation => A Motor6D joins two parts like a weld but lets animations rotate and move it. Characters use Motor6Ds for all their limbs.
what is a beam vs a trail | beam vs trail roblox | how do trails work => A Beam draws a texture between two attachments. A Trail draws a fading ribbon behind a moving part between two attachments, good for sword swings.
what is a billboardgui vs surfacegui | billboard vs surface gui | gui in 3d world => A BillboardGui floats in the world and always faces the camera, like name tags. A SurfaceGui sticks to a face of a part, like a sign or screen.
what is a viewportframe | 3d model in gui | show a model in a gui => A ViewportFrame draws 3D objects inside a GUI. Put a model and a Camera inside it and set its CurrentCamera, which is great for item previews.
what is a uilistlayout | auto arrange gui | list layout roblox => A UIListLayout automatically lines up sibling GUI objects in a row or column. Use Padding for spacing and SortOrder with LayoutOrder to choose the order.
what is zindex | zindexbehavior | which gui is on top => ZIndex decides which GUI objects draw on top; higher is in front. ScreenGui.ZIndexBehavior Sibling sorts children within each parent, which is the usual setting.
what is textscaled | text scaled roblox | auto size text => TextScaled makes text grow or shrink to fill its box. It can make text too big, so pair it with a UITextSizeConstraint.
what is richtext in roblox | bold text in a textlabel | color part of text => Turn on RichText and use tags like `<b>bold</b>`, `<i>italic</i>` or `<font color="#FF0000">red</font>` inside the Text.
what is the core gui | coregui roblox | built in gui roblox => The core GUI is Roblox's own interface: player list, chat, backpack, health and the menu. You can hide parts of it with `StarterGui:SetCoreGuiEnabled`.
what is textchatservice | new roblox chat | legacy chat vs textchatservice => TextChatService is Roblox's chat system. The old Chat service (LegacyChatService) is being retired, so new games use TextChatService and its TextChannels and TextChatCommands.
do i have to filter text in roblox | text filter rules | is filtering required => Yes. Any text a player types that other players can see, like signs or pet names, must be filtered with TextService. Chat through TextChatService is filtered for you.
what is the luau type checker | strict mode luau | --!strict => Writing `--!strict` at the top of a script turns on strict type checking, so Studio warns you about type mistakes before you run. `--!nonstrict` is the gentler default.
what is parallel luau | actors roblox | multithreading roblox => Parallel Luau lets scripts inside Actor objects run some work at the same time on several CPU cores. Use `task.desynchronize()` for parallel work and `task.synchronize()` before changing the game.
what is os.clock vs tick vs time | os clock vs tick | best timer function roblox => Use `os.clock()` for measuring short times, `os.time()` for real dates in seconds, and `time()` for seconds since the game started. `tick()` is deprecated-style and best avoided.
what is a userid | userid vs username | why save data by userid => A UserId is a number that never changes for an account, while usernames can change. Always save data with the UserId as the key.
what is a display name | displayname vs name roblox | player display name => DisplayName is the name the player chooses to show, which can be shared with others. Name is their unique username. Use Name or UserId to identify them.
what is a group game | publish to a group | group owned experience => A group can own experiences so a team shares them. Robux earned goes to the group's funds, and you choose who can edit through group roles.
what is the roblox age rating | maturity questionnaire | content maturity roblox => Before going public, every experience fills in a maturity questionnaire, and Roblox gives it a content maturity label like Minimal, Mild or Moderate. Some players can only join experiences with certain labels.
what is the experience guidelines | roblox community standards | what is not allowed in roblox games => Roblox's Community Standards and Terms of Use say what experiences can include. Breaking them, like scams or inappropriate content, can get the game taken down or the account banned.
what is a hitbox in roblox | custom hitbox | hit detection roblox => A hitbox is the area that counts as hitting something. Many games use an invisible part plus `workspace:GetPartsInPart()` or raycasts instead of Touched for more reliable hits.
what is client side prediction | why do shots feel delayed | lag compensation roblox => Client side prediction shows the result on the player's screen right away while the server checks it. It makes the game feel fast even with ping, but the server still decides what really happened.
what is ping in roblox | high ping | what does ping mean => Ping is how many milliseconds it takes for a message to go between your device and the server and back. High ping makes actions feel delayed.
what is a server in roblox | how many servers does a game have | new server roblox => Each server is one running copy of your place with its own players, usually up to the max players you set. Roblox opens more servers as more people join.
what is a vip server vs private server | vip server roblox | reserved server => Private servers (once called VIP servers) are servers a player rents for their friends. Reserved servers are made by scripts with `TeleportService:ReserveServer` for things like matches.
what is a rig type for animations | animation priority | why is my animation overridden => AnimationPriority decides which animation wins when two play at once: Core, Idle, Movement, then Action (highest, plus Action2 to Action4). Set attack animations to Action so walking does not override them.
what is animation weight | adjust weight animation track | blend animations roblox => `track:AdjustWeight(w)` blends animations of the same priority; a higher weight has more influence. Fade times in `Play(fadeTime)` and `Stop(fadeTime)` smooth the change.
what is an animation event | keyframe marker | do something at a frame of animation => Add a marker in the Animation Editor and listen with `track:GetMarkerReachedSignal("Hit"):Connect(fn)` to run code at that moment, like dealing damage.
what is tween easing style | easing styles roblox | easingdirection explained => EasingStyle sets the speed curve of a tween, like Linear, Sine, Quad, Bounce, Elastic or Back. EasingDirection In starts slow, Out ends slow, and InOut does both.
what is tweeninfo | tweeninfo parameters | tweeninfo new explained => `TweenInfo.new(time, easingStyle, easingDirection, repeatCount, reverses, delayTime)` sets how a tween plays. Only time is required; RepeatCount -1 repeats forever.
seat vs vehicle seat | sit on a part => A Seat lets a character sit when they touch it. A VehicleSeat also reads WASD as Throttle and Steer so scripts can drive a vehicle.
what is the spawnlocation duration | spawn forcefield time | remove spawn protection => SpawnLocation.Duration is how many seconds of ForceField players get after spawning there. Set it to 0 for no protection.
what is a team color | teamcolor roblox | team spawn color => Each Team has a TeamColor (a BrickColor). Players on that team spawn at SpawnLocations with the same TeamColor when those spawns are not Neutral.
what is a script signature or comment header | --[[ ]] comments luau | block comment roblox => In Luau, `--` starts a one-line comment and `--[[ ... ]]` makes a comment over many lines.
what is the difference between a part and a meshpart | part vs mesh part | basepart types => A Part is a basic shape (block, ball, cylinder, wedge). A MeshPart uses a 3D model shape. Both are BaseParts, so they share properties like Anchored and Color.
model vs folder | why group parts => A Model groups parts and can have a PrimaryPart so you can move it all with PivotTo. A Folder just organizes objects and has no position.
what is primarypart | model primary part | set primary part => PrimaryPart is the part a Model uses as its main reference for pivoting and moving. Set it in Properties by clicking the model and choosing a part.
what is pivotto | pivot editor | getpivot roblox => `model:PivotTo(cf)` moves a model or part so its pivot point is at that CFrame, and `GetPivot()` reads it. The Pivot editor in the Model tab lets you move the pivot point.
what is the difference between a local and global variable in luau | local vs global roblox | why use local => A `local` variable only exists in the block where it is made. Globals can be reached anywhere in the script but are slower and easier to mess up, so always use local.
what are roblox global functions | built in functions roblox | game workspace script globals => Every script can use globals like `game`, `workspace`, `script`, `print`, `warn`, `typeof`, `pcall`, `require`, and libraries like `task`, `math`, `string` and `table`.
what is typeof vs type | check a value type luau => `type(x)` gives basic Lua types like "number" or "userdata". `typeof(x)` also knows Roblox types like "Vector3" and "Instance", so use typeof in Roblox.
what is isa in roblox | isa vs classname | check if something is a part => `obj:IsA("BasePart")` returns true for Parts, MeshParts and other BaseParts, while `obj.ClassName == "Part"` only matches exactly Part. IsA is usually better.
what is a robux | how to get robux to make games | do i need robux to make a game => You do not need Robux to make and publish a game; Studio and publishing are free. Robux is only needed for things like advertising or buying assets.

what are analytics on the creator hub | game analytics roblox | how many people play my game => The Creator Hub shows analytics like visits, concurrent players, retention and earnings for your experience, so you can see what works.
what is engagement based payouts | premium payouts explained | do i earn from premium => Premium Payouts are Robux Roblox pays based on how much time Premium subscribers spend in your experience.
how do i make my game less boring | ideas to keep players | retention tips roblox => Give clear goals, quick rewards in the first minutes, a reason to come back (daily rewards, upgrades, updates), and things to do with friends. Watch your analytics to see where players leave.
how do i make a roblox game for the first time | beginner roblox studio | where to start in roblox studio => Start with a template like Baseplate or Obby, learn to move and anchor parts, then add simple scripts like a kill brick or coin. Build small games first and finish them.
