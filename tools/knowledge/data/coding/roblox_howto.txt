# Roblox Studio how-tos, written by hand for Ace.
# tag: coding.roblox.howto
how do i make a part spin in roblox | make a part rotate forever | spinning part script | how to make something spin roblox studio => Put a Script in the part and rotate it a little every frame: `local part = script.Parent` then `game:GetService("RunService").Heartbeat:Connect(function(dt) part.CFrame = part.CFrame * CFrame.Angles(0, math.rad(90) * dt, 0) end)`. Anchor the part first so it does not fall.
how do i make a kill brick | make a part that kills you | lava brick script | how to make a part kill players when touched => Put a Script inside the part with `script.Parent.Touched:Connect(function(hit) local h = hit.Parent:FindFirstChildOfClass("Humanoid") if h then h.Health = 0 end end)`. Anchor the part so it stays in place.
how do i make a leaderboard in roblox | how to make leaderstats | make a coins leaderboard | how do i show points on the player list => In a server Script, use `Players.PlayerAdded` to make a Folder named exactly `leaderstats` inside the player, then put an IntValue (like "Coins") inside it. Roblox shows every value in leaderstats on the player list automatically.
how do i save data in roblox | how to save player coins | save progress roblox studio | how do i make data save when you leave => Use DataStoreService on the server: get a store with `DataStoreService:GetDataStore("PlayerData")`, call `SetAsync` or `UpdateAsync` in `Players.PlayerRemoving`, and `GetAsync` in `PlayerAdded`. Wrap each call in `pcall` because DataStore calls can fail, and turn on Studio API access in Game Settings to test.
how do i make a door that opens in roblox | opening door script | make a door open when clicked => Add a ClickDetector or ProximityPrompt to the door part, and in its event tween the door's CFrame or set `door.CanCollide = false` and `door.Transparency = 0.5`. Tweening with TweenService looks smoother than teleporting it.
how do i make a part move smoothly | tween a part roblox | how do i use tweenservice to move something => Use TweenService: `local tween = game:GetService("TweenService"):Create(part, TweenInfo.new(2), {Position = Vector3.new(0, 10, 0)})` then `tween:Play()`. Anchor the part or physics will fight the tween.
how do i make a part change color | change brick color with a script | make a part flash colors => Set its Color property with a Color3: `part.Color = Color3.fromRGB(255, 0, 0)` makes it red. For random colors use `Color3.fromRGB(math.random(0,255), math.random(0,255), math.random(0,255))`.
how do i make a gui button do something | button click script roblox | make a textbutton work when pressed => Put a LocalScript inside the TextButton and connect `script.Parent.Activated:Connect(function() print("clicked") end)`. Activated works for mouse, touch and gamepad, so it is better than MouseButton1Click for most buttons.
how do i open and close a gui with a button | toggle a frame visible | show and hide a menu roblox => In a LocalScript, flip the frame's Visible property: `button.Activated:Connect(function() frame.Visible = not frame.Visible end)`.
how do i teleport a player in roblox | move a player to a spot | teleport pad script => Set the character's pivot: `character:PivotTo(CFrame.new(0, 10, 0))`. For a teleport pad, do this inside a Touched handler after finding the character from `hit.Parent`.
how do i teleport players to another place in my game | teleport to a different place roblox | how to use teleportservice => On the server call `TeleportService:TeleportAsync(placeId, {player})` with the place ID of a place inside the same experience. It does not work in Studio play tests, so test it in a live server.
how do i make a speed boost | make a player run faster | change walk speed roblox => Find the character's Humanoid and raise WalkSpeed: `humanoid.WalkSpeed = 32`. The default is 16 studs per second.
how do i make players jump higher | change jump power roblox | super jump script => By default Humanoids use JumpHeight (7.2 studs). Set `humanoid.JumpHeight = 20`, or set `humanoid.UseJumpPower = true` and change `humanoid.JumpPower` (default 50) if you prefer that system.
how do i get the player from a touched part | find who touched a part | get player from hit => In the Touched handler use `local player = game.Players:GetPlayerFromCharacter(hit.Parent)`. It returns nil if the thing that touched was not a character, so check `if player then` before using it.
how do i give a player a tool | give a tool when they join | put a sword in the backpack => Clone the tool from ServerStorage into the player's Backpack on the server: `ServerStorage.Sword:Clone().Parent = player.Backpack`. To give it every spawn, also put a copy in StarterGear or put it in StarterPack for everyone.
how do i make a coin pickup | collectible coin script | make coins you can collect => Put a Script in the coin part, and on Touched find the player, add 1 to `player.leaderstats.Coins.Value`, then `coin:Destroy()`. Add a debounce so one touch only counts once.
how do i make a checkpoint in roblox | obby checkpoints | save where a player respawns => Use SpawnLocation parts. Set each one's `Neutral` to false and give it a Team, or simply set `player.RespawnLocation = spawnLocation` when the player touches it, so they respawn there next time.
how do i make an obby | how to build an obstacle course | tips for making an obby => Build anchored platforms with gaps, add kill bricks, use SpawnLocations as checkpoints, and add a leaderstats "Stage" value. Test every jump in Play mode so each one is possible.
how do i make a day and night cycle | day night cycle script | make time pass in roblox => In a server Script loop `while true do game.Lighting.ClockTime = (game.Lighting.ClockTime + 0.01) % 24 task.wait(0.1) end`. Change the numbers to make days faster or slower.
how do i play a sound in roblox | play music in my game | how to add a sound effect => Insert a Sound, set its SoundId to `rbxassetid://` plus the asset ID, then call `sound:Play()`. Put it in a part for 3D sound or in SoundService or Workspace for sound everyone hears everywhere.
how do i loop music | make background music repeat | sound looped roblox => Set `sound.Looped = true` before calling `sound:Play()`. It will restart by itself every time it ends.
how do i make a part invisible | hide a part in roblox | make a block see through => Set `part.Transparency = 1` to make it invisible. Also set `CanCollide = false` if players should walk through it.
how do i make a part you can walk through | turn off collisions on a part | no collide part => Set the part's CanCollide property to false. Keep CanTouch true if you still want Touched events to fire.
how do i anchor a part | stop a part from falling | what does anchored mean in roblox => Tick Anchored in the Properties window or set `part.Anchored = true` in a script. Anchored parts never move from physics, so they will not fall or get pushed.
how do i make a part with a script | create a part in code | spawn a block with a script => Use `local p = Instance.new("Part")`, set its properties like `p.Size`, `p.Position` and `p.Anchored`, then set `p.Parent = workspace` last so it appears.
how do i delete a part with a script | remove an object roblox | destroy a part in code => Call `part:Destroy()`. It removes the part and everything inside it, disconnects its events, and it cannot be brought back.
how do i make something disappear after a few seconds | delete a part after time | auto remove part => Use `game:GetService("Debris"):AddItem(part, 5)` to remove it after 5 seconds without pausing your script. `task.delay(5, function() part:Destroy() end)` also works.
how do i make a countdown timer in roblox | timer gui script | show a countdown on screen => Loop down and update a TextLabel: `for i = 10, 0, -1 do label.Text = tostring(i) task.wait(1) end`. Run the real timer on the server and send it to clients if everyone should see the same time.
how do i make a round system | intermission and rounds script | make game rounds roblox => Use a server loop: intermission countdown, teleport players to the map, wait for the round time or until one player is left, then teleport everyone back and repeat. Keep the state in one server Script so all players stay in sync.
how do i make a shop in roblox | buy items with coins | in game shop script => Make a GUI button that fires a RemoteEvent with the item name. On the server, check the price from a table on the server, check the player's coins, subtract them and give the item. Never trust a price sent by the client.
how do i make a sprint button | hold shift to run | sprint script roblox => In a LocalScript use UserInputService: on InputBegan with `Enum.KeyCode.LeftShift` set `humanoid.WalkSpeed = 24`, and on InputEnded set it back to 16.
how do i detect a key press in roblox | check if player pressed a key | keyboard input script => In a LocalScript, `UserInputService.InputBegan:Connect(function(input, gameProcessed) if gameProcessed then return end if input.KeyCode == Enum.KeyCode.E then print("E pressed") end end)`. The gameProcessed check skips keys typed into chat or text boxes.
how do i detect mouse clicks | get the mouse click position | click anywhere script roblox => Use UserInputService.InputBegan and check `input.UserInputType == Enum.UserInputType.MouseButton1`. To find what was clicked in 3D, raycast from `workspace.CurrentCamera:ScreenPointToRay(x, y)`.
how do i get the player's mouse | player get mouse roblox | mouse hit position => In a LocalScript, `local mouse = game.Players.LocalPlayer:GetMouse()` gives `mouse.Hit` (a CFrame where the mouse points) and `mouse.Target`. It is older but still works; UserInputService plus raycasting is the newer way.
how do i make a proximity prompt | press e to interact roblox | add an interact button => Insert a ProximityPrompt into a part, set ActionText and HoldDuration, then in a server Script use `prompt.Triggered:Connect(function(player) ... end)`.
how do i make a npc walk | move an npc to a point | make a dummy walk somewhere => Call `npc.Humanoid:MoveTo(targetPosition)` on the server. The NPC must have a Humanoid and an unanchored HumanoidRootPart, and MoveTo gives up after about 8 seconds if the goal is not reached.
how do i make an npc follow a path around walls | pathfinding roblox | npc that finds its way => Use PathfindingService: `local path = PathfindingService:CreatePath()`, `path:ComputeAsync(start, goal)`, then loop through `path:GetWaypoints()` and call `humanoid:MoveTo(wp.Position)` and `humanoid.MoveToFinished:Wait()` for each one.
how do i make an npc chase the player | zombie that follows players | enemy ai roblox => Every short interval, find the nearest player's HumanoidRootPart and call `humanoid:MoveTo(target.Position)`. Add pathfinding when there are walls in the way, and damage the player when they are close.
how do i play an animation | play an animation on my character | animation script roblox => Make an Animation object with your AnimationId, then `local track = humanoid.Animator:LoadAnimation(anim)` and `track:Play()`. The animation must be owned by you or your group, or it will not play in your game.
how do i make an animation in roblox | animate a character in studio | use the animation editor => Open the Avatar tab and use the Animation Editor on a rig, add keyframes, then publish it to Roblox to get an AnimationId. Set the priority to Action for moves that should override walking.
how do i make a part follow the player | part that follows you | attach something to the player => Weld it to the character: put a WeldConstraint with Part0 as the HumanoidRootPart and Part1 as your part, and make the part unanchored and Massless. For a floating pet, use AlignPosition instead of a weld.
how do i weld two parts together | weld parts roblox | make parts stick together => Insert a WeldConstraint, set Part0 and Part1 to the two parts and parent it to one of them. Only one of the welded parts should be anchored, or none if the assembly should move.
how do i make a car in roblox | build a drivable car | vehicle seat car => Use a VehicleSeat with wheels joined by HingeConstraints set to Motor. Read the seat's Throttle and Steer values in a script to set each hinge's AngularVelocity and steering angle.
how do i make a part float up and down | bobbing part script | hover animation part => Tween its position with a repeating tween: `TweenInfo.new(1, Enum.EasingStyle.Sine, Enum.EasingDirection.InOut, -1, true)`. A repeat count of -1 loops forever and true makes it reverse.
how do i make a tween repeat forever | loop a tween | tween that goes back and forth => In TweenInfo, set RepeatCount to -1 and Reverses to true: `TweenInfo.new(2, Enum.EasingStyle.Linear, Enum.EasingDirection.Out, -1, true)`.
how do i wait in a roblox script | pause a script for seconds | how to add a delay in lua => Use `task.wait(2)` to pause for 2 seconds. The old `wait()` still runs but is deprecated, so use task.wait.
how do i run code every frame | update loop roblox | something every frame => Connect to RunService: `RunService.Heartbeat:Connect(function(dt) end)` runs after physics each frame. On the client, `RunService.RenderStepped` runs before the frame is drawn and is good for camera code.
how do i make a gui only show for one player | show a message to one player | gui for a single player => Put the GUI in that player's PlayerGui, or fire a RemoteEvent to just that client with `remote:FireClient(player)` and let a LocalScript show it.
how do i show a message to everyone | announcement gui for all players | message all players roblox => From the server call `remote:FireAllClients("text")` and have a LocalScript in each client update a TextLabel when it receives it.
how do i send a message in chat with a script | system message in chat | make the chat say something => With TextChatService, a LocalScript can call `TextChatService.TextChannels.RBXGeneral:DisplaySystemMessage("Hello")` to show a system message to that player.
how do i make a gui scale on all screens | make ui fit mobile => Use Scale instead of Offset in Size and Position (like `UDim2.fromScale(0.3, 0.1)`), and add a UIAspectRatioConstraint to keep shapes. Test with the Device Emulator in Studio.
how do i make rounded corners on a gui | round frame corners | ui corner roblox => Insert a UICorner into the Frame or button and set its CornerRadius, like `UDim.new(0, 12)`.
how do i add an outline to a gui | border on a frame | ui stroke roblox => Insert a UIStroke into the GUI object and set Thickness and Color. For text, set its ApplyStrokeMode to Contextual to outline the letters.
how do i make a health bar | custom hp bar gui | show health on screen => Make a background Frame with a fill Frame inside, and in a LocalScript set `fill.Size = UDim2.fromScale(humanoid.Health / humanoid.MaxHealth, 1)` whenever `humanoid.HealthChanged` fires.
how do i make a name tag above a player | overhead gui | text above a head roblox => Clone a BillboardGui with a TextLabel into the character's Head on the server when CharacterAdded fires, and set its `Adornee` to the head and `StudsOffset` a bit upward.
how do i hide the default health bar | remove the roblox health gui | disable core gui => In a LocalScript call `game:GetService("StarterGui"):SetCoreGuiEnabled(Enum.CoreGuiType.Health, false)`. You can disable Backpack, PlayerList and Chat the same way.
how do i make the camera first person | lock first person roblox | force first person => Set `StarterPlayer.CameraMode = Enum.CameraMode.LockFirstPerson` in Properties, or set `player.CameraMode` on that player.
how do i change the camera to a fixed view | set the camera position with a script | cutscene camera => In a LocalScript set `camera.CameraType = Enum.CameraType.Scriptable` and then set `camera.CFrame`. Set CameraType back to Custom to give control back.
how do i make a camera shake | screen shake effect | shake camera roblox => In a LocalScript, for a short time set `humanoid.CameraOffset` to small random Vector3 values every frame, then set it back to `Vector3.zero`.
how do i make a cutscene | camera tween cutscene | move the camera smoothly roblox => Set the camera to Scriptable, then tween `camera.CFrame` between parts you placed as camera spots, waiting with `tween.Completed:Wait()` between shots.
how do i make a gun in roblox | shooting tool script | raycast gun => When the tool activates, the client sends the aim point to the server with a RemoteEvent; the server raycasts from the gun with `workspace:Raycast(origin, direction * range, params)` and damages a Humanoid if it hits one. Check range and fire rate on the server.
how do i make a sword in roblox | sword damage script | melee weapon roblox => Make a Tool with a Handle part, play a swing animation on Activated, and on the server damage Humanoids the blade touches while swinging, using a debounce so each swing hits once.
how do i make a gamepass do something | check if player owns a gamepass | give gamepass perks => On the server use `MarketplaceService:UserOwnsGamePassAsync(player.UserId, passId)` inside a pcall when the player joins, and give the perk if it returns true.
how do i prompt a gamepass purchase | buy gamepass button | sell a gamepass in game => In a LocalScript call `MarketplaceService:PromptGamePassPurchase(player, passId)` when the button is pressed. Listen to PromptGamePassPurchaseFinished on the server to give the perk right away.
how do i make a developer product | sell coins for robux | buy currency roblox => Create the product on the Creator Hub, prompt it with `MarketplaceService:PromptProductPurchase(player, productId)`, and on the server set `MarketplaceService.ProcessReceipt` to give the item and return `Enum.ProductPurchaseDecision.PurchaseGranted`.
how do i give a badge | award a badge in roblox | badge script => On the server call `BadgeService:AwardBadge(player.UserId, badgeId)` inside a pcall. Create the badge first on the Creator Hub under your experience.
how do i make a part glow | glowing part roblox | neon material => Set the part's Material to Neon for a bright glow look. For real light, add a PointLight or SurfaceLight inside it.
how do i add a light to a part | make a lamp in roblox | point light => Insert a PointLight into the part and set Brightness, Range and Color. SpotLight shines in one direction and SurfaceLight lights from one face.
how do i add particles | make fire or sparkles effect | particle emitter roblox => Insert a ParticleEmitter into a part and change Texture, Rate, Lifetime, Speed and Color. Call `emitter:Emit(20)` in a script to make a burst.
how do i make an explosion | explode script roblox | blow something up => `local e = Instance.new("Explosion") e.Position = pos e.Parent = workspace`. Set `e.DestroyJointRadiusPercent = 0` if it should not kill players.
how do i make a part shoot forward | launch a part | fling a projectile => Set its velocity once: `part.AssemblyLinearVelocity = part.CFrame.LookVector * 100`. For a steady push, use a LinearVelocity constraint.
how do i make a moving platform | platform that moves back and forth | elevator roblox => Tween an anchored part back and forth with a repeating tween, or use a PrismaticConstraint set to Servo for a physics platform that carries players better.
how do i make a conveyor belt | conveyor part roblox | belt that moves players => Set the anchored part's `AssemblyLinearVelocity` to the direction you want, like `part.AssemblyLinearVelocity = Vector3.new(0, 0, 10)`. The part stays still but pushes what stands on it.
how do i make a trampoline | bounce pad script | make players bounce => On Touched, find the character's HumanoidRootPart and set `root.AssemblyLinearVelocity = Vector3.new(0, 100, 0)` to launch them up.
how do i make a part damage over time | poison brick | slowly hurt players => While a player touches the part, call `humanoid:TakeDamage(5)` with a short task.wait between hits, and stop when TouchEnded fires or a cooldown runs out.
how do i heal a player | heal pad roblox | give health back => Raise their Health but not above MaxHealth: `humanoid.Health = math.min(humanoid.Health + 25, humanoid.MaxHealth)`.
how do i respawn a player with a script | force respawn roblox | reset a character => On the server call `player:LoadCharacter()`. It makes a new character at a spawn location.
how do i change respawn time | faster respawn roblox | respawn delay => Set `Players.RespawnTime` in the Players service properties. The default is 5 seconds.
how do i make teams | add teams to my game | red vs blue roblox => Add Team objects inside the Teams service, give each a TeamColor, and set `AutoAssignable`. SpawnLocations with a matching TeamColor and Neutral off spawn that team.
how do i change a player's team | switch team with a script | set team roblox => On the server set `player.Team = game.Teams.Red`. Their name color and spawn follow the new team.
how do i make a morph | change a player into a character | morph pad roblox => Clone your morph model, name it after the player, set `player.Character = newModel` on the server and position it, or use a HumanoidDescription with `humanoid:ApplyDescription(desc)` for avatar changes.
how do i change a player's clothes with a script | set shirt and pants | outfit script => Find the character's Shirt and Pants objects and set ShirtTemplate and PantsTemplate, or use `humanoid:ApplyDescription()` with a HumanoidDescription that has the clothing IDs.
how do i make a gui fade in | fade a frame | tween transparency => Tween the BackgroundTransparency (and TextTransparency for text) from 1 to 0 with TweenService, like `TweenService:Create(frame, TweenInfo.new(0.5), {BackgroundTransparency = 0}):Play()`.
how do i make a loading screen | custom loading screen roblox | replace roblox loading screen => Put a LocalScript in ReplicatedFirst, call `ReplicatedFirst:RemoveDefaultLoadingScreen()`, show your own ScreenGui, and hide it after `game:IsLoaded()` is true or the `game.Loaded` event fires.
how do i make a typewriter text effect | text appears one letter at a time | typing effect gui => Set the full text and then raise `label.MaxVisibleGraphemes` from 0 up to the text length with a short task.wait between each step.
how do i make a gui draggable | drag a frame with the mouse | movable window roblox => Add a UIDragDetector inside the frame. Without it, track InputBegan, InputChanged and InputEnded and move the frame by how far the mouse moved.
how do i get all players in the game | loop through every player | list of players roblox => `for _, player in game.Players:GetPlayers() do print(player.Name) end`. GetPlayers returns an array of everyone in the server.
how do i find a player by name | get a player from their username | search player name => Use `game.Players:FindFirstChild("Name")` for players in the server. `Players:GetUserIdFromNameAsync(name)` finds the UserId of any Roblox account.
how do i find the closest player | nearest player to a part | get closest character => Loop through Players:GetPlayers(), measure `(root.Position - part.Position).Magnitude` for each character, and keep the smallest one.
how do i check if a player is in a zone | detect players in an area | region detection roblox => Use `workspace:GetPartsInPart(zonePart)` or `workspace:GetPartBoundsInBox(cframe, size)` on a loop and look for characters in the results. Touched and TouchEnded work too but can flicker.
how do i make a part only touchable once | touched fires too many times | debounce touched => Use a debounce variable: `local busy = false` and in the handler `if busy then return end busy = true ... task.wait(1) busy = false`. For per-player cooldowns, store times in a table keyed by player.
how do i make a cooldown | ability cooldown script | stop spamming a button => Store the last use time with `os.clock()` and ignore the action if `os.clock() - last < cooldown`. Check cooldowns on the server for anything that matters.
how do i make a double jump | double jump script roblox | jump twice in the air => In a LocalScript, when the humanoid state changes to Freefall allow one extra jump; on a jump request while in the air call `humanoid:ChangeState(Enum.HumanoidStateType.Jumping)` once, then reset when Landed.
how do i make a dash ability | dash forward script | quick dash roblox => On key press, push the root part forward: `root.AssemblyLinearVelocity = root.CFrame.LookVector * 80`, or use a LinearVelocity for a short time, then add a cooldown.
how do i make players not collide with each other | turn off player collisions | collision groups roblox => Register a collision group with `PhysicsService:RegisterCollisionGroup("Players")`, call `PhysicsService:CollisionGroupSetCollidable("Players", "Players", false)`, and set each character part's `CollisionGroup = "Players"`.
how do i make a part only collide with some things | collision groups | stop parts hitting each other => Put the parts in collision groups with the CollisionGroup property and use the Collision Groups editor in Studio or PhysicsService to choose which groups can collide.
how do i make a part look at the player | rotate toward a target | make a turret aim => Use `CFrame.lookAt(part.Position, target.Position)` and set `part.CFrame` to it. Run it every frame to keep tracking.
how do i make an object orbit around another | circle around a part | orbit script => Each frame, increase an angle and set `part.Position = center + Vector3.new(math.cos(angle) * radius, 0, math.sin(angle) * radius)`.
how do i rotate a part with a script | turn a part 90 degrees | rotate part code => Multiply its CFrame by an angle: `part.CFrame = part.CFrame * CFrame.Angles(0, math.rad(90), 0)`. CFrame.Angles uses radians, so math.rad converts from degrees.
how do i move a model | move a whole model with a script | set model position => Use `model:PivotTo(newCFrame)`. It moves every part together. SetPrimaryPartCFrame is the older way and is deprecated.
how do i scale a model with a script | resize a model in code | make a model bigger => Call `model:ScaleTo(2)` to make it twice its original size. `model:GetScale()` returns the scale it has now.
how do i clone something | copy a part in a script | duplicate an object => `local copy = original:Clone()` then set `copy.Parent = workspace`. Clones start with no parent, so you have to parent them.
how do i spawn things randomly | random spawn positions | spawn parts at random places => Pick random coordinates with `math.random` or a Random object, like `Vector3.new(math.random(-50, 50), 10, math.random(-50, 50))`, and set your clone's position or pivot there.
how do i pick a random item from a table | random choice luau | random element roblox => `local item = list[math.random(1, #list)]`. The table must be an array with at least one item.
how do i make a gui show a player's coins | display leaderstats on a gui | coin counter text => In a LocalScript, read `player.leaderstats.Coins` and update a TextLabel in its `Changed` event: `coins.Changed:Connect(function(v) label.Text = "Coins: " .. v end)`.
how do i check when a value changes | detect value change | listen for property changes roblox => For value objects use `.Changed`. For any property use `part:GetPropertyChangedSignal("Transparency"):Connect(fn)`. For attributes use `GetAttributeChangedSignal("Name")`.
how do i use attributes in roblox | set custom properties on a part | attributes vs value objects => Use `part:SetAttribute("Health", 100)` and `part:GetAttribute("Health")`. Attributes appear at the bottom of the Properties window and are lighter than adding IntValue objects.
how do i tag parts and run code on all of them | collectionservice tags | tag editor roblox => Add a tag in the Properties window (Tags section) or with `CollectionService:AddTag(part, "Lava")`, then loop `CollectionService:GetTagged("Lava")` and listen to `GetInstanceAddedSignal("Lava")` for new ones. One script can then handle every lava part.
how do i make an inventory system | store items for a player | inventory roblox => Keep each player's items in a table on the server, change it only on the server, send updates to the client with a RemoteEvent for the GUI, and save the table with DataStoreService.
how do i make a pet that follows you | pet follow script | floating pet roblox => Make the pet unanchored and Massless, then use AlignPosition and AlignOrientation attached to the pet and to an offset Attachment in the HumanoidRootPart, so it smoothly follows behind the player.
how do i make a gui appear when touching a part | touch part open gui | show shop when stepping on pad => On the server, when the part is touched, fire a RemoteEvent to that player; the LocalScript then sets the frame Visible. You can also check the touch in a LocalScript for only the local character.
how do i make a npc talk | npc dialogue roblox | chat bubble on npc => Use `TextChatService:DisplayBubble(npc.Head, "Hello!")` from a LocalScript to show a bubble, or build your own dialogue GUI with a ProximityPrompt to start it.
how do i make a kick command | kick a player with a script | remove a player from the server => On the server call `player:Kick("Reason here")`. The player sees the message and leaves the server.
how do i make admin commands | chat commands roblox | make a command like kill me => Make a TextChatCommand with a PrimaryAlias like "/kill" inside TextChatService, and on the server listen to its Triggered event. Check the user ID against your admin list before doing anything.
how do i check if someone is in my group | group rank check | only let group members in => On the server use `player:GetRankInGroup(groupId)` or `player:IsInGroup(groupId)`; rank 0 means not in the group.
how do i stop a player from resetting | disable reset button | turn off reset character => In a LocalScript, keep retrying `StarterGui:SetCore("ResetButtonCallback", false)` inside a pcall until it works, since the core scripts may not be ready the first time.
how do i make a sound play when touching a part | touch sound effect | play sound on touch => Put a Sound in the part and call `script.Parent.Sound:Play()` in the Touched handler, with a debounce so it does not restart every frame.
how do i set the spawn point | change where players spawn | add spawn location => Insert a SpawnLocation from the Model tab and place it. If there are several, players spawn at a random one unless teams are set.
