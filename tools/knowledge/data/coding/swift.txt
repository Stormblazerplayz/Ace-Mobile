# Swift language, written by hand for Ace.
# tag: coding.swift
what is swift used for | swift programming language => Swift is Apple's programming language for iPhone, iPad, Mac, Apple Watch and Apple TV apps. It is fast, safe and fairly easy to read, and it also runs on Linux and Windows.
who made swift | when did swift come out | swift history => Apple released Swift in 2014 as a modern replacement for Objective-C. Chris Lattner started the project, and it became open source in 2015.
what is the difference between let and var in swift | let vs var | swift constants and variables => `let` makes a constant that cannot change after it is set, and `var` makes a variable that can. Use `let` by default and switch to `var` only when you need to change it.
how do i make a variable in swift | declare variable swift | swift var syntax => `var score = 0` makes a variable. Swift figures out the type from the value, or you can write it: `var score: Int = 0`.
what is type inference in swift | swift guesses the type | do i need to write types in swift => Swift works out a value's type from what you assign, so `let name = "Sam"` is a String without writing it. Write types when they are not obvious or there is no starting value.
what are the basic types in swift | swift data types | int double string bool swift => Common types are Int (whole numbers), Double and Float (decimals), String (text), Character, Bool (true or false), plus collections Array, Dictionary and Set.
what is the difference between double and float in swift | double vs float swift | which decimal type swift => Double has about 15 digits of precision and Float about 6. Swift uses Double by default for decimals, and you should too unless an API wants Float.
how do i convert an int to a double in swift | int to double swift | convert number types swift => Use the type as a function: `Double(myInt)`. Swift never mixes number types by itself, so `myInt + myDouble` is an error until you convert one.
how do i convert a string to an int in swift | string to int swift | parse number swift => `Int("42")` returns an optional Int, because the text might not be a number. Unwrap it: `if let n = Int(text) { ... }`.
how do i convert a number to a string in swift | number to text swift => `String(42)` or string interpolation `"\(42)"`.
what is string interpolation in swift | put a variable in a string swift | backslash parentheses swift => Write `\(value)` inside a string: `"You have \(coins) coins"`. Any expression works inside the parentheses.
what is an optional in swift | swift optionals explained | question mark after type swift => An optional can hold a value or nil (nothing). `var name: String?` might be a String or nil, and Swift makes you unwrap it before use so you cannot forget the nil case.
what is nil in swift | nil meaning swift => nil means "no value". Only optionals can be nil in Swift.
what is optional binding | if let swift | unwrap optional safely => `if let name = optionalName { print(name) }` runs the block only when there is a value, with `name` as the unwrapped value. Since Swift 5.7 you can write `if let name {`.
what is guard let in swift | guard statement swift | guard vs if let => `guard let user = user else { return }` exits early if the value is nil, and after it `user` is unwrapped for the rest of the function. It keeps code from nesting deeply.
what is force unwrapping in swift | exclamation mark swift | why is force unwrap bad => Writing `value!` takes the value out of an optional without checking. If it is nil, the app crashes, so only use it when you are completely sure it has a value.
what does unexpectedly found nil while unwrapping mean | fatal error unexpectedly found nil | swift crash nil => You force unwrapped an optional with `!` (or used an implicitly unwrapped optional) and it was nil. Use `if let`, `guard let` or `??` instead.
what is the nil coalescing operator | default value optional swift => `a ?? b` gives the value inside a if it has one, otherwise b. Example: `let name = savedName ?? "Player"`.
what is optional chaining in swift | question mark dot swift => `user?.profile?.name` reads through optionals and gives nil if any step is nil, instead of crashing.
what is an implicitly unwrapped optional | string! type swift | exclamation type swift => A type like `String!` is an optional that unwraps itself when used. It crashes if it is nil, so it is mostly seen with older APIs.
how do i write an if statement in swift | swift if else | if syntax swift => `if score > 10 { print("win") } else if score > 5 { print("close") } else { print("lose") }`. No parentheses are needed around the condition, but braces are required.
what is a switch statement in swift | swift switch | switch case swift => `switch value { case 1: ... case 2, 3: ... default: ... }`. Swift switches must cover every case and do not fall through, so no break is needed.
can swift switch on ranges | switch with ranges swift | switch case where => Yes: `case 0..<10:` matches a range, and `case let x where x > 100:` adds a condition.
what is a for in loop in swift | swift for loop | loop through numbers swift => `for i in 1...5 { print(i) }` loops 1 to 5. `for item in items { }` loops an array.
what is the difference between ... and ..< in swift | closed range vs half open | range operators swift => `1...5` includes 5 (closed range). `1..<5` stops before 5 (half-open), which is handy for indexes like `0..<array.count`.
how do i loop with a step in swift | stride swift | count by 2 swift => `for i in stride(from: 0, to: 10, by: 2)` gives 0, 2, 4, 6, 8. Use `through:` instead of `to:` to include the end.
how do i loop backwards in swift | reversed loop swift | count down swift => `for i in (1...10).reversed() { }` counts down from 10 to 1.
how do i get the index in a swift for loop | enumerated swift | index and value swift => `for (index, item) in items.enumerated() { }` gives both. Indices from enumerated start at 0.
what is a while loop in swift | swift while | repeat while swift => `while lives > 0 { }` checks first. `repeat { } while condition` always runs at least once.
how do i make a function in swift | func swift | swift function syntax => `func greet(name: String) -> String { return "Hi \(name)" }`, called as `greet(name: "Sam")`. The arrow shows the return type.
what are argument labels in swift | external parameter names | underscore parameter swift => Swift functions can have a label used when calling and a name used inside: `func move(to point: CGPoint)` is called `move(to: p)`. An underscore `_` means no label is needed.
what is a default parameter in swift | default value swift function | optional parameter swift => `func greet(name: String = "friend")` lets callers leave it out: `greet()`.
what is inout in swift | inout parameter | change a parameter swift => `func double(_ x: inout Int) { x *= 2 }` lets a function change the caller's variable. Call it with an ampersand: `double(&score)`.
what is a variadic parameter in swift | dot dot dot parameter swift | any number of arguments swift => `func sum(_ nums: Int...) -> Int` takes any number of Ints, available inside as an array.
can a swift function return multiple values | return tuple swift | multiple returns swift => Yes, return a tuple: `func minMax() -> (min: Int, max: Int)` and read `result.min`.
what is a tuple in swift | swift tuples | group values swift => A tuple groups a few values together, like `let point = (x: 3, y: 4)`, read with `point.x`. Use a struct for anything bigger.
what is an array in swift | swift array | make a list in swift => `var names = ["Ana", "Ben"]` is an Array of Strings. Add with `names.append("Cy")`, read with `names[0]`, and count with `names.count`.
how do i make an empty array in swift | empty array swift | array init swift => `var items: [String] = []` or `var items = [String]()`.
how do i remove from an array in swift | remove item swift array | array remove at => `items.remove(at: 0)` removes by index, `items.removeLast()` the last one, and `items.removeAll { $0 == "x" }` every match.
how do i check if an array contains something swift | contains swift | array includes swift => `items.contains("apple")` returns true or false. For conditions, `items.contains { $0.count > 5 }`.
how do i find the index of an item in swift | firstindex swift | array index of => `items.firstIndex(of: "apple")` returns an optional Int, nil if not found.
how do i sort an array in swift | sort vs sorted swift | sort descending swift => `items.sort()` sorts in place and `items.sorted()` returns a new array. Pass a rule for other orders: `scores.sorted(by: >)` sorts high to low.
what is map in swift | swift map function | transform an array swift => `map` makes a new array by changing each item: `let doubled = nums.map { $0 * 2 }`.
what is filter in swift | swift filter | keep some items swift => `filter` keeps items that match: `let evens = nums.filter { $0 % 2 == 0 }`.
what is reduce in swift | swift reduce | sum an array swift => `reduce` combines items into one value: `let total = nums.reduce(0, +)`.
what is compactmap in swift | compactmap vs map | remove nils swift => `compactMap` maps and throws away nil results: `["1", "x", "3"].compactMap { Int($0) }` gives `[1, 3]`.
what is flatmap in swift | flatten arrays swift | flatmap swift => `flatMap` maps each item to an array and joins them into one: `[[1, 2], [3]].flatMap { $0 }` gives `[1, 2, 3]`.
what is $0 in swift | dollar zero swift | shorthand closure arguments => `$0` is the first argument of a closure, `$1` the second. `nums.map { $0 * 2 }` is short for `nums.map { n in n * 2 }`.
what is a dictionary in swift | swift dictionary | key value swift => `var ages = ["Sam": 12, "Lee": 13]` maps keys to values. Reading `ages["Sam"]` gives an optional, because the key might be missing.
how do i loop through a dictionary in swift | iterate dictionary swift => `for (name, age) in ages { }`. Dictionaries have no set order, so sort the keys if order matters.
how do i get a default from a dictionary swift | dictionary default value swift | default subscript => `ages["Zed", default: 0]` returns 0 if the key is missing, and works for adding: `counts[word, default: 0] += 1`.
what is a set in swift | swift set | unique values swift => `var tags: Set = ["a", "b"]` holds unique values with no order and checks `contains` very quickly.
what is a struct in swift | swift struct | make a struct => A struct groups data and functions: `struct Player { var name: String; var score: Int }`. Swift gives it a free initializer: `Player(name: "Sam", score: 0)`.
what is a class in swift | swift class | make a class swift => A class is like a struct but is a reference type and supports inheritance: `class Enemy { var health = 100 }`. Classes need their own init if properties have no default values.
what is the difference between a struct and a class in swift | struct vs class swift | value type vs reference type => Structs are value types: assigning one makes a copy. Classes are reference types: assigning shares the same object. Structs cannot inherit. Apple recommends structs by default.
what is a value type | value types swift | copy on assign => A value type is copied when assigned or passed, so changing the copy does not change the original. Structs, enums, Int, String, Array and Dictionary are value types.
what is a reference type | reference types swift | shared object swift => A reference type is shared: two variables can point to the same object, so a change through one shows up in the other. Classes and actors are reference types.
what is mutating in swift | mutating func | change a struct property in a method => Methods that change a struct's own properties must be marked `mutating`, because structs are values. Classes do not need it.
what is an init in swift | initializer swift | constructor swift => `init` sets up a new instance and gives every stored property a value: `init(name: String) { self.name = name }`.
what is self in swift | self keyword swift | when do i need self => `self` means the instance the method was called on. You need it when a parameter has the same name as a property, like `self.name = name`, and sometimes inside closures.
what is inheritance in swift | subclass swift | override swift => `class Boss: Enemy { }` makes Boss inherit from Enemy. Use `override func` to replace a method and `super.method()` to call the parent's version.
what is final in swift | final class swift | prevent subclassing => `final class` cannot be subclassed and `final func` cannot be overridden. It also lets Swift make calls a bit faster.
what is a computed property in swift | computed vs stored property | get only property swift => A computed property calculates its value each time: `var area: Double { width * height }`. Stored properties hold a value in memory.
what is a property observer in swift | didset willset | run code when property changes swift => `var score = 0 { didSet { print("now \(score)") } }` runs code after the value changes. `willSet` runs just before.
what is lazy in swift | lazy var swift | lazy property => `lazy var data = loadData()` waits to create the value until it is first used, which saves time if it is never needed.
what is a static property in swift | static vs instance swift | type property => `static let maxLevel = 50` belongs to the type, not to each instance, and is read as `Game.maxLevel`.
what is an enum in swift | swift enum | enum cases swift => An enum lists fixed options: `enum Direction { case north, south, east, west }`. Use it with switch to handle every case.
what are associated values in swift enums | enum with values swift | enum case with data => Cases can carry data: `enum Result { case success(score: Int), failure(String) }`. Pull it out with `case .success(let score):` in a switch.
what is a raw value enum swift | enum string raw value | enum int swift => `enum Size: String { case small, large }` gives each case a raw value ("small", "large"). `Size(rawValue: "small")` makes one from text.
what is caseiterable | loop over all enum cases | allcases swift => Add `: CaseIterable` to an enum and `Direction.allCases` gives an array of every case.
what is a protocol in swift | swift protocols explained | protocol vs interface => A protocol lists properties and methods a type must have, like `protocol Drawable { func draw() }`. Structs, classes and enums adopt it and must provide those.
what is a protocol extension | default implementation protocol swift | extend a protocol => An extension on a protocol can give methods a default body, so every type that adopts the protocol gets them for free.
what is an extension in swift | extend a type swift | add methods to string swift => `extension String { var shouted: String { uppercased() + "!" } }` adds features to an existing type, even ones you did not write.
what is equatable in swift | == for my struct | conform to equatable => Add `: Equatable` to a struct and Swift writes `==` for you if all its properties are Equatable.
what is hashable in swift | hashable protocol | use struct as dictionary key => Hashable types can be dictionary keys and Set members. Adding `: Hashable` to a struct gets it automatically when all properties are Hashable.
what is identifiable in swift | identifiable protocol | id property swift => Identifiable means a type has an `id` that uniquely identifies it. SwiftUI's List and ForEach use it to tell items apart: `struct Task: Identifiable { let id = UUID() }`.
what is codable in swift | codable json swift | encode decode swift => Codable lets a type turn into and out of data like JSON. Add `: Codable` and use `JSONEncoder().encode(value)` and `JSONDecoder().decode(Type.self, from: data)`.
how do i decode json in swift | parse json swift | jsondecoder swift => Make a Codable struct matching the JSON keys, then `let item = try JSONDecoder().decode(Item.self, from: data)`. Use CodingKeys if the names differ.
what is comparable in swift | sort custom struct swift | comparable protocol => Comparable types support `<`, so they can be sorted. Implement `static func < (a: Self, b: Self) -> Bool` to say how.
what is customstringconvertible | description property swift | print my struct nicely => Adopt CustomStringConvertible and add `var description: String` to control what `print(item)` and string interpolation show.
what is a closure in swift | swift closures explained | closure syntax swift => A closure is a block of code you can pass around, like `{ (a: Int, b: Int) -> Int in a + b }`. Functions that take closures include map, filter and button actions.
what is trailing closure syntax | trailing closure swift | closure after parentheses => If the last argument is a closure, you can write it after the parentheses: `nums.sorted { $0 > $1 }` or `Button("Go") { start() }`.
what is an escaping closure | @escaping swift | closure called later => `@escaping` marks a closure parameter that may be stored and called after the function returns, like a completion handler.
what is weak self | [weak self] swift | retain cycle closure => `[weak self]` in a closure stops it from keeping its owner alive, preventing memory leaks. Inside, self is optional: `guard let self else { return }`.
what is a retain cycle | memory leak swift | strong reference cycle => A retain cycle happens when two objects (or an object and a closure) hold strong references to each other, so neither is ever freed. Break it with `weak` or `unowned`.
what is arc in swift | automatic reference counting | how swift manages memory => ARC counts how many strong references point to each class instance and frees it when the count reaches zero. You only need to think about it to avoid retain cycles.
what is weak vs unowned in swift | weak vs unowned | unowned reference => Both avoid retain cycles. `weak` becomes nil when the object goes away, so it is optional. `unowned` assumes the object lives at least as long and crashes if used after it is gone.
what are generics in swift | generic function swift => Generics let you write code that works with any type: `func first<T>(_ items: [T]) -> T?`. Array and Dictionary are generic types.
what is a generic constraint | where clause swift | t comparable => You can require a generic type to follow a protocol: `func largest<T: Comparable>(_ a: [T]) -> T?`.
what is some in swift | opaque type swift | some view => `some View` means "a specific type that conforms to View, but I am not saying which". The compiler knows the real type, which keeps SwiftUI fast.
what is any in swift | any keyword swift | existential type swift => `any Drawable` means a box that can hold any type conforming to Drawable, chosen at runtime. It is more flexible but a bit slower than `some`.
what is error handling in swift | throws swift | do try catch swift => Functions marked `throws` can fail. Call them with `try` inside `do { } catch { print(error) }`.
try question mark swift | try exclamation swift => `try?` turns an error into nil, so the result is optional. `try!` crashes if there is an error, so avoid it unless failure is impossible.
how do i make my own error in swift | custom error swift | throw error swift => Make an enum that conforms to Error: `enum LoginError: Error { case wrongPassword }`, then `throw LoginError.wrongPassword`.
what is defer in swift | defer statement swift | run code at end of scope => `defer { }` runs its code when the enclosing scope ends, no matter how it exits. It is used for cleanup like closing files.
what is async await in swift | swift concurrency | async function swift => `func load() async throws -> Data` marks a function that can pause while waiting. Call it with `try await load()` inside another async function or a Task.
what is a task in swift | task swift concurrency | start async work swift => `Task { await loadData() }` starts async work from normal code, like a button action. In SwiftUI, `.task { }` starts work when a view appears.
what is mainactor in swift | @mainactor | update ui on main thread swift => `@MainActor` makes code run on the main thread, which is where all UI updates must happen. SwiftUI views and many view models use it.
what is an actor in swift | actor swift | data race protection => An actor is like a class that protects its data so only one task touches it at a time, which prevents data races. Calls into it from outside use `await`.
what is sendable in swift | sendable protocol | swift 6 data race errors => Sendable marks types that are safe to pass between concurrent tasks. Swift 6's strict concurrency checking reports errors when non-Sendable data crosses actor boundaries.
what is async let | parallel async swift | run two async calls at once => `async let a = loadA()` and `async let b = loadB()` start both at once; then `let (x, y) = try await (a, b)` waits for both.
what is a taskgroup | withtaskgroup swift | many async tasks swift => `withTaskGroup` runs a dynamic number of child tasks in parallel and collects their results.
what is urlsession | network request swift | download data swift => URLSession fetches data from the web: `let (data, response) = try await URLSession.shared.data(from: url)`.
how do i make a url in swift | url from string swift | url optional swift => `URL(string: "https://example.com")` returns an optional URL, nil if the text is not a valid address. Unwrap it before use.
what is the result type in swift | result success failure | result enum swift => `Result<Success, Failure>` holds either `.success(value)` or `.failure(error)`. It was common for completion handlers before async/await.
what is a typealias in swift | typealias swift | rename a type => `typealias Score = Int` gives an existing type a new name to make code easier to read.
what is access control in swift | private public internal swift | fileprivate => `private` is visible only in its scope, `fileprivate` in its file, `internal` (the default) in its module, and `public`/`open` to other modules.
what is a module in swift | swift package module | import in swift => A module is a unit of code like an app or library. `import SwiftUI` or `import Foundation` brings another module's types into your file.
what is foundation in swift | import foundation | foundation framework => Foundation is Apple's base framework with Date, URL, Data, JSONEncoder, FileManager, UserDefaults and more. Many other frameworks import it for you.
what is a string index in swift | why cant i do string[0] in swift | get character at index swift => Swift strings are made of characters that can be different sizes, so you cannot use Int indexes. Use `str.first`, `Array(str)[0]`, or `str[str.index(str.startIndex, offsetBy: 2)]`.
how do i get a substring in swift | substring swift | prefix suffix swift => `str.prefix(3)` and `str.suffix(3)` give the start or end. The result is a Substring; wrap it in `String(...)` to keep it.
how do i split a string in swift | split string swift | components separated by => `"a,b,c".split(separator: ",")` gives an array of Substrings, and `components(separatedBy: ",")` gives Strings.
how do i check if a string contains text in swift | string contains swift | hasprefix swift => `str.contains("cat")`, `str.hasPrefix("Mr")` and `str.hasSuffix(".png")` all return Bool.
how do i make a string uppercase in swift | uppercased swift | lowercase swift => `str.uppercased()` and `str.lowercased()` return new strings. `capitalized` (from Foundation) capitalizes each word.
how do i trim whitespace in swift | trim string swift | remove spaces swift => `str.trimmingCharacters(in: .whitespacesAndNewlines)`.
how do i replace text in a swift string | replacing occurrences swift | string replace swift => `str.replacingOccurrences(of: "cat", with: "dog")` (Foundation), or `str.replacing("cat", with: "dog")` in newer Swift.
how do i get the length of a string in swift | string count swift | number of characters swift => `str.count` gives the number of characters, counting each emoji as one.
what is a character in swift | swift character type | single letter type => A Character is one visible character, which can be several Unicode scalars (like a flag emoji). Strings are collections of Characters.
what is a multiline string in swift | triple quotes swift | multi line text swift => Use three double quotes on their own lines: `"""` then lines of text then `"""`.
how do i format a number in swift | decimal places swift | format double swift => `String(format: "%.2f", value)` gives 2 decimals, or `value.formatted(.number.precision(.fractionLength(2)))` in newer Swift.
how do i get a random number in swift | random int swift | random in range swift => `Int.random(in: 1...6)` rolls a die. `Double.random(in: 0..<1)` and `items.randomElement()` work too.
how do i shuffle an array in swift | shuffled swift | random order array swift => `items.shuffle()` mixes in place and `items.shuffled()` returns a mixed copy.
what is a date in swift | current date swift | date now swift => `Date()` gives this exact moment. Format it with `date.formatted(date: .abbreviated, time: .shortened)` or a DateFormatter.
how do i wait a few seconds in swift | sleep swift async | delay in swift => In async code, `try await Task.sleep(for: .seconds(2))`. Do not block the main thread with sleep.
how do i print in swift | print swift | swift console output => `print("Hello")` writes to Xcode's console. `print(a, b, separator: ", ")` changes the separator.
what is a comment in swift | swift comments | documentation comment swift => `//` comments one line and `/* */` comments a block. `///` is a documentation comment that Xcode shows in Quick Help.
what is the ternary operator in swift | inline if swift => `let label = score > 10 ? "High" : "Low"`.
what are the operators in swift | swift math operators | remainder operator swift => `+ - * /` and `%` for remainder. Integer division drops the decimal, so `7 / 2` is 3. Swift does not allow `++`; use `+= 1`.
what happens when an int overflows in swift | arithmetic overflow swift | int too big crash => Swift crashes if Int math overflows instead of wrapping around. Use `&+` and similar operators if you really want wrapping.
what is int.max in swift | biggest int swift | int size swift => On iPhones, iPads and Macs, Int is 64-bit, so `Int.max` is 9,223,372,036,854,775,807.
what is a key path in swift | backslash keypath swift | \.name swift => A key path like `\.name` points to a property. It is used in `sorted(by:)` helpers, `map(\.name)` and SwiftUI's ForEach id.
what is a property wrapper in swift | @ in swift properties | what does @state mean swift => A property wrapper adds behavior to a property with an `@` attribute, like `@State` in SwiftUI or `@AppStorage` for saving settings.
what is a result builder | viewbuilder swift | resultbuilder => A result builder lets a closure list several values that get combined, which is how SwiftUI's body lists views without commas or return.
what is a macro in swift | swift macros | @observable macro => Swift macros generate code at compile time. `@Observable` and `#Preview` are macros that write boilerplate for you.
what is uuid in swift | uuid swift | unique id swift => `UUID()` makes a random unique identifier, often used as `let id = UUID()` in Identifiable structs.
what is userdefaults | save settings swift | userdefaults swift => UserDefaults stores small settings like a high score: `UserDefaults.standard.set(10, forKey: "best")` and `.integer(forKey: "best")`. In SwiftUI, `@AppStorage` wraps it.
what is filemanager | save files swift | documents directory swift => FileManager works with files and folders. `URL.documentsDirectory` gives your app's Documents folder, and `data.write(to: url)` saves data there.
how do i save data in an ios app | persist data swift | swiftdata vs userdefaults => Use UserDefaults or @AppStorage for small settings, Codable plus files for simple data, and SwiftData or Core Data for bigger structured data.
what is swiftdata | swiftdata explained | @model swift => SwiftData is Apple's framework for saving app data, added in iOS 17. Mark a class with `@Model`, add `.modelContainer(for: Item.self)` to the app, and use `@Query` in views to read data.
what is core data | core data vs swiftdata | core data swift => Core Data is Apple's older framework for saving and querying data. SwiftData is built on it with a simpler Swift-first API.
what is the swift package manager | spm | add a package xcode => Swift Package Manager adds libraries to a project. In Xcode, choose File > Add Package Dependencies and paste the package's Git URL.
what is package.swift | swift package manifest | make a swift package => Package.swift describes a Swift package: its name, products, targets and dependencies. `swift package init` creates one.
what is a playground in swift | swift playgrounds app | xcode playground => A playground runs Swift code and shows results as you type. The Swift Playgrounds app on iPad and Mac can also build real SwiftUI apps.
can i make an app on ipad | swift playgrounds ipad app | build app without mac => Yes. Swift Playgrounds on iPad can build SwiftUI apps and even submit them to App Store Connect. Bigger projects still need Xcode on a Mac.
what is objective-c | objective c vs swift | old ios language => Objective-C was Apple's main language before Swift. Many older APIs come from it, and Swift can still call Objective-C code.
what is uikit | uikit vs swiftui | old ios ui framework => UIKit is Apple's older framework for building iOS interfaces with view controllers. SwiftUI is newer and declarative, and the two can be mixed.
what is appkit | mac apps framework | appkit vs swiftui => AppKit is the older framework for Mac apps. SwiftUI works on Mac too, and you can mix it with AppKit.
what is the swift standard library | swift stdlib | built in swift types => The standard library has the basic types and tools: Int, String, Array, Dictionary, Optional, map, filter, sort and more, available without importing anything.
what is pattern matching in swift | if case swift | match enum case swift => `if case .success(let value) = result { }` checks one enum case and pulls out its data without a full switch.
what is a where clause in a for loop swift | for where swift | filter in loop swift => `for n in nums where n > 0 { }` only runs the body for items that match.
what is labeled break in swift | break outer loop swift | label statement swift => Put a label before a loop, like `outer: for i in ...`, then `break outer` leaves both loops at once.
what is fallthrough in swift | switch fallthrough | continue to next case => `fallthrough` at the end of a case makes the next case's code run too. Swift does not do this by default.
what is assert vs precondition in swift | assert swift | precondition swift => `assert` checks a condition only in debug builds. `precondition` checks in release builds too. `fatalError()` always stops the app.
what is a closure capture list | capture list swift | [weak self] meaning => The list in square brackets at the start of a closure, like `[weak self, count]`, says how outside values are captured: weakly, or copied at that moment.
what is copy on write in swift | arrays are copied swift | cow swift => Swift arrays, dictionaries and strings only really copy their storage when one copy changes, so passing them around is cheap.
what is a subscript in swift | custom subscript | square brackets on my type => `subscript(index: Int) -> Item { items[index] }` lets your type be read with `myType[2]`.
what is an operator overload in swift | custom operator swift | + for my struct => Write `static func + (a: Vec, b: Vec) -> Vec { ... }` in a type to make `+` work on it.
what are swift naming conventions | swift style | camelcase swift => Types use UpperCamelCase (like `PlayerView`), and variables, functions and cases use lowerCamelCase (like `playerScore`). Names should read clearly at the call site.
what is swift on the server | vapor swift | swift backend => Swift can run servers on Linux. Vapor and Hummingbird are popular frameworks for web APIs written in Swift.

what is a swift protocol with associated type | associatedtype swift | generic protocol => `associatedtype Item` lets a protocol use a placeholder type that each conforming type picks, like a container saying what it holds.
what is the difference between == and === in swift | identity operator swift => `==` checks if two values are equal. `===` checks if two class references point to the exact same object.

what is a convenience init | convenience initializer | designated vs convenience init => In classes, a designated init sets all properties, and a `convenience init` must call another init of the same class. It gives extra ways to create objects.
what is required init | required initializer swift | init must be implemented => `required init` forces every subclass to have that initializer too.
what is deinit in swift | deinitializer | when object is freed => `deinit { }` in a class runs just before the object is freed from memory. It is handy for checking for leaks.
what is a singleton in swift | static let shared | shared instance => A singleton is one shared object, made with `static let shared = MyManager()`. Use it sparingly, because it makes testing and changes harder.
what is dependency injection | pass dependencies swift | injection explained => Dependency injection means giving an object what it needs (like a data service) from outside instead of creating it inside, which makes code easier to test and change.
