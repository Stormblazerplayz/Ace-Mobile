# More Git and GitHub: commands, fixes and GitHub features, written by hand for Ace.
# tag: coding.git.more
what does git add . do | git add dot | add all files git => `git add .` stages every new and changed file in this folder and below, ready for the next commit. Check `git status` first so you do not add junk.
what does git add -p do | stage part of a file | git add patch => `git add -p` walks through each changed chunk and asks whether to stage it, so one commit can hold just part of your changes.
what does git commit -am do | commit all git | skip git add => `git commit -am "message"` stages changes to files Git already tracks and commits them in one step. Brand new files still need `git add`.
create and switch branch | new branch and switch => `git switch -c feature` makes a new branch and moves onto it. The older way is `git checkout -b feature`.
what is git checkout | checkout vs switch | git checkout explained => `git checkout` used to do many jobs: switch branches and restore files. Newer Git splits these into `git switch` and `git restore`, which are clearer.
git restore file | discard changes git restore => `git restore file.lua` throws away unstaged changes to that file, putting it back to the last commit. `git restore --staged file.lua` unstages it instead.
what does git show do | git show commit | see a commit git => `git show <hash>` prints a commit's message and exactly what it changed. `git show HEAD` shows the latest commit.
what does git log --oneline do | short git log | compact history git => `git log --oneline` shows each commit on one line with a short hash, and `--graph` adds a drawing of branches and merges.
how do i see the history of one file in git | git log file | file history git => `git log -p -- path/to/file` shows every commit that changed that file with the changes. `git log --follow` keeps tracking it through renames.
what does git diff --staged do | diff staged changes | see staged diff => `git diff --staged` shows what is staged for the next commit, while plain `git diff` shows changes not staged yet.
how do i see changes between two commits | git diff two commits | compare commits git => `git diff abc123 def456` shows everything that changed between those two commits. Add a file path to limit it.
what does git push -u do | set upstream git | push new branch git => `git push -u origin feature` pushes a new branch and links it to the remote one, so later you can just type `git push` and `git pull`.
what does git push --force do | force push | is force push bad => Force pushing replaces the remote branch with yours, deleting commits others may have. Use `--force-with-lease`, which refuses if someone else pushed, and never force push a shared main branch.
what does git remote -v do | see remotes git | which remote url => `git remote -v` lists your remotes, like origin, with their URLs for fetch and push.
how do i change my git remote url | git remote set-url | change origin url => `git remote set-url origin https://github.com/you/repo.git` points origin at a new address, like after renaming a repo.
how do i add a remote in git | git remote add | connect local repo to github => `git remote add origin <url>` links your local repo to a GitHub repo, then `git push -u origin main` uploads it.
what does git merge --abort do | cancel merge git | stop a merge => `git merge --abort` gives up on a merge that hit conflicts and puts everything back how it was before you started it.
what are conflict markers | <<<<<<< head | ======= in my file => Git writes `<<<<<<< HEAD`, your version, `=======`, the other version, then `>>>>>>> branch` into a file when changes clash. You must pick or combine them and remove the markers.
what does git rebase -i do | interactive rebase | edit old commits git => `git rebase -i HEAD~3` opens a list of your last 3 commits where you can reorder, reword, squash or drop them. Only do this to commits you have not shared.
what does git rebase --continue do | continue rebase | rebase conflict => After fixing a conflict during a rebase, `git add` the files and run `git rebase --continue`. `git rebase --abort` cancels the whole rebase.
what does git stash pop do | get stash back | apply stash git => `git stash pop` puts your most recent stashed changes back and removes them from the stash. `git stash apply` puts them back but keeps them stashed.
what does git stash list do | see stashes | multiple stashes git => `git stash list` shows all your stashes, newest first, as stash@{0}, stash@{1} and so on.
how do i stash untracked files | git stash -u | stash new files => Plain `git stash` skips brand new files. `git stash -u` includes untracked files too.
what does git reset --soft do | reset soft | undo commit keep changes => `git reset --soft HEAD~1` removes the last commit but keeps its changes staged, so you can recommit them differently.
what is the difference between reset and revert | reset vs revert | which undo to use git => `git revert` makes a new commit that undoes an old one, safe for shared branches. `git reset` moves your branch back and rewrites history, so only use it on commits you have not pushed.
you are in detached head state | detached head git => Detached HEAD means you checked out a commit, not a branch. Look around freely, but before committing make a branch with `git switch -c name` or your commits may get lost.
how do i get back a deleted branch | recover deleted branch git | undelete branch => Find the branch's last commit hash in `git reflog`, then `git branch name <hash>` brings it back.
find lost commit git | reflog recover => `git reflog` lists everywhere HEAD has been, even after a reset. Find the commit there and `git switch -c rescue <hash>` or cherry-pick it.
how do i delete a remote branch | delete branch on github | git push origin --delete => `git push origin --delete feature` removes the branch on the remote. `git fetch --prune` cleans up old remote branch names locally.
what does git fetch --prune do | prune remote branches | remove stale branches => `git fetch --prune` updates from the remote and removes local references to branches that were deleted on the remote.
how do i ignore a folder in git | gitignore folder | ignore directory git => Add a line with the folder name and a slash, like `build/`, to .gitignore. Everything inside is ignored.
what are gitignore patterns | gitignore wildcard | gitignore syntax => `*.log` ignores all .log files, `/secrets.txt` only the one at the top, `folder/` a whole folder, and a line starting with `!` un-ignores something.
why is my gitignore not working | gitignore ignored | file still tracked git => .gitignore only affects untracked files. If Git already tracks the file, run `git rm --cached file` and commit, then it will be ignored.
what should be in a gitignore | gitignore templates | common gitignore => Ignore build outputs, dependency folders (like node_modules or .venv), editor settings, logs and anything secret like .env files. GitHub offers templates for each language.
what is a .env file | env file | keep secrets out of git => A .env file holds secrets like API keys as NAME=value lines. Add it to .gitignore so it never gets committed, and share an example file without real values instead.
what is git rm | remove file git | delete file from repo => `git rm file.txt` deletes the file and stages the removal for your next commit.
what is git mv | rename file git | move file git => `git mv old.lua new.lua` renames or moves a file and stages it, so Git tracks it as a rename.
what does git init -b main do | init with main branch | start repo main branch => `git init -b main` creates a new repo whose first branch is called main.
what is a bare repository | bare repo git | git init --bare => A bare repository has no working files, only Git's data. Servers like GitHub store repos this way so people can push to them.
what is the .git folder | .git directory | hidden git folder => The hidden .git folder holds all of a repo's history and settings. Deleting it turns the folder back into plain files with no history.
how do i see which branch i am on | current branch git | what branch am i on => `git status` says "On branch ..." at the top, and `git branch` marks your current branch with a star. `git branch --show-current` prints just its name.
how do i list remote branches | git branch -r | see remote branches => `git branch -r` lists branches on the remote, and `git branch -a` lists both local and remote.
how do i check out a branch from github | get a remote branch | switch to remote branch => Run `git fetch` and then `git switch branch-name`. Git creates a local branch that tracks the remote one.
what is a tracking branch | upstream branch | branch tracking git => A tracking branch is a local branch linked to a remote branch, so `git status` can say if you are ahead or behind and `git pull` knows where to pull from.
what does git pull --rebase do | avoid merge commits pull => `git pull --rebase` replays your local commits on top of the newly downloaded ones, giving a straight history without extra merge commits.
what is a merge commit | merge commit git | two parents commit => A merge commit joins two branches and has two parent commits. GitHub can make one, squash, or rebase when merging a pull request.
squash merge github | squash pull request => Squash and merge combines all of a pull request's commits into one commit on main, keeping history tidy.
what is git diff ignore whitespace | diff whitespace | git diff -w => `git diff -w` ignores whitespace changes, so you only see real code changes.
what is git grep | search code git | git grep text => `git grep "TODO"` searches all tracked files for text, quickly and only in your repo's files.
commits per person | git shortlog -sn => `git shortlog -sn` counts commits for each author, a quick view of who did what.
what is git describe | git describe tags | version from git => `git describe` names the latest commit relative to the nearest tag, like v1.2.0-3-gabc123, handy for build versions.
what is git worktree | multiple working trees | git worktree add => `git worktree add ../hotfix main` checks out another branch in a second folder, so you can work on two branches at once without stashing.
what is git sparse checkout | sparse checkout | clone part of repo => Sparse checkout lets you only check out some folders of a huge repo, using `git sparse-checkout set folder`.
what is git gc | garbage collection git | clean up git repo => `git gc` cleans up and compresses Git's internal files. Git usually runs it automatically.
what is a git hash made of | sha-1 git | how git makes ids => Each commit ID is a hash of its contents, author, time and parent commits, so changing anything makes a different ID. Git uses SHA-1 by default and also supports SHA-256 repos as an option.
what is the difference between git add and git commit | add vs commit | why two steps git => `git add` chooses what goes in the next snapshot (staging); `git commit` saves that snapshot in history. The two steps let you commit only some changes.
what is the difference between commit and push | commit vs push | push vs commit => A commit saves a snapshot in your local repo. Push uploads your commits to a remote like GitHub so others (and your other devices) can get them.
what is the difference between a fork and a clone | fork or clone => A fork is your own copy of someone's repo on GitHub. A clone is a copy of a repo downloaded to your computer. Often you fork, then clone your fork.
how do i keep my fork up to date | sync fork | update fork from upstream => On GitHub press Sync fork, or add the original as `upstream`, then `git fetch upstream` and merge `upstream/main` into your main.
how do i contribute to open source | first open source contribution | open source pull request => Find a project with "good first issue" labels, read its CONTRIBUTING file, fork it, make a branch, commit your fix and open a pull request. Be polite and patient with reviews.
what is contributing.md | contributing guidelines | how to contribute file => CONTRIBUTING.md explains how to help a project: how to report bugs, the code style, and how to open pull requests.
what is a code of conduct | code_of_conduct.md | community rules github => A code of conduct sets rules for how people treat each other in a project's community.
what is a github discussion | github discussions | forum on github => Discussions is a forum tab on a GitHub repo for questions, ideas and chat that are not bug reports.
what is a github project board | github projects | kanban github => GitHub Projects is a planning board and table where you track issues and pull requests in columns like To do, In progress and Done.
what is a github milestone | milestones github | group issues release => A milestone groups issues and pull requests toward a goal or release and shows a progress bar.
what are github labels | issue labels | label issues github => Labels tag issues and pull requests, like bug, enhancement or good first issue, so they are easy to sort and find.
how do i close an issue with a commit | fixes #12 | link pull request to issue => Write "Fixes #12" or "Closes #12" in a pull request description or commit message; when it merges into the default branch, issue 12 closes automatically.
what is an issue template | issue templates github | bug report template => Issue templates pre-fill new issues with sections like steps to reproduce, so reports are more useful. They live in .github/ISSUE_TEMPLATE.
what is a pull request template | pr template | pull_request_template.md => A pull request template pre-fills every new pull request description with a checklist or sections. Put it at .github/pull_request_template.md.
what is codeowners | codeowners file | automatic reviewers github => A CODEOWNERS file names who owns which folders, and GitHub automatically requests their review on pull requests that touch them.
what is dependabot | dependabot github | automatic dependency updates => Dependabot opens pull requests to update your project's dependencies and warns you about known security problems in them.
what is github pages | host website github | github pages free => GitHub Pages hosts a static website straight from a repo for free, at username.github.io. Great for portfolios and project pages.
what is a github workflow file | .github/workflows | workflow yaml => GitHub Actions workflows are YAML files in .github/workflows that say when to run (like on push) and which steps to run, like installing and testing.
what is a github action secret | secrets in github actions | store api key github => Repository secrets store passwords and keys safely for Actions. Read them in a workflow as `${{ secrets.NAME }}`; they never show in logs.
what is a status check | required checks github | ci check pull request => Status checks are tests that run on a pull request, like CI. Branch rules can block merging until they pass.
what is a github release asset | release downloads | attach file to release => A release can include files like built games or apps for people to download, listed under Assets.
what is a github template repository | template repo | use this template => A template repository lets others start a new repo with the same files and folders, without copying the history.
what is github sponsors | sponsor a developer | github sponsors explained => GitHub Sponsors lets people support open source developers with money. Setting it up involves payments and tax details, so get a parent to help.
what is a github organization | github org | team on github => An organization is a shared GitHub account for a team or company that owns repos and gives members different permissions.
what is a collaborator on github | add collaborator | give someone access repo => In repo Settings > Collaborators, invite someone so they can push to your repo. Only invite people you trust.
what are github notifications | watch a repo | github notification settings => Watching a repo sends you notifications about its activity. Choose Participating to only hear about things you are involved in.
what is a personal access token | github token | pat github => A personal access token is like a password for apps and the command line to use your GitHub account. Give it only the permissions it needs and keep it secret.
what is two factor on github | github 2fa | secure github account => Two-factor authentication adds a code from an app or a security key when you sign in. GitHub requires it for anyone who contributes code.
what does git credential manager do | git asks password every time | save git login => Git Credential Manager remembers your GitHub login securely so Git stops asking every time you push. The GitHub CLI's `gh auth login` can set this up too.
what does support for password authentication was removed mean | password authentication removed github | github password not working git => GitHub no longer accepts your account password for Git over HTTPS. Use a personal access token, the GitHub CLI login, Git Credential Manager or SSH instead.
what does fatal remote origin already exists mean | remote origin already exists | origin exists error => You already have a remote called origin. Change its address with `git remote set-url origin <url>` instead of adding it again.
what does src refspec main does not match any mean | src refspec main | refspec error => You tried to push a branch that does not exist yet, usually because you have no commits or your branch is called master. Make a commit, or push the right branch name.
what does failed to push some refs mean | failed to push some refs | push rejected => The remote has commits you do not have. Run `git pull` (or `git pull --rebase`), fix any conflicts, then push again.
what does fatal not possible to fast-forward mean | not possible to fast forward | pull diverged => Your branch and the remote both have new commits. Choose how to combine them: `git pull --rebase` or `git pull --no-rebase` to merge.
what does you have divergent branches mean | divergent branches | need to specify how to reconcile => Git wants you to choose merge or rebase for pulls. Run `git config --global pull.rebase false` for merging or `true` for rebasing, once.
what does detected dubious ownership mean | dubious ownership git | safe.directory => Git found the repo folder belongs to another user account. If you trust it, run the `git config --global --add safe.directory` command the message suggests.
what does lf will be replaced by crlf mean | crlf warning | line endings git => Windows and Mac or Linux end lines differently. Git is warning it will convert them. It is usually harmless; a .gitattributes file can set rules for the project.
what does fatal refusing to merge unrelated histories mean on pull | unrelated histories pull | first pull fails => Your local repo and the remote started separately, often because GitHub made a README. Run `git pull origin main --allow-unrelated-histories` once, then fix any conflicts.
what does error pathspec did not match mean | pathspec did not match | file not found git => Git cannot find that file or branch name. Check spelling and capitals, and that you are in the right folder.
what does fatal bad object mean | bad object git | corrupt git => Git is pointing at an object it cannot find, often a typo in a hash or a damaged repo. Check the hash; if the repo is damaged, cloning again is often easiest.
what does your local changes would be overwritten mean | would be overwritten by merge | local changes overwritten => You have uncommitted changes in files that the pull or switch would change. Commit them, stash them with `git stash`, or discard them first.
what does cannot lock ref mean | cannot lock ref | ref lock error => Another Git process may be running, or a remote branch name clashes with a local one. Close other Git tools and run `git remote prune origin`.
what does index.lock file exists mean | index lock exists | another git process => Git thinks another Git command is still running. If none is, delete the .git/index.lock file and try again.
what does the requested url returned error 403 mean | git 403 | permission to repo denied => You are logged in as someone without push access, or your token lacks permission. Check which account you use and that you are a collaborator.
what does repository not found mean | repository not found git | git remote not found => The URL is wrong, the repo was renamed or deleted, or it is private and you are not signed in with access.
what does file is larger than 100 mb mean | github file size limit | file too big github => GitHub blocks files over 100 MB. Remove the file from your commits (rewriting history if needed) and use Git LFS for big assets.
what does warning adding embedded git repository mean | embedded git repository => You added a folder that has its own .git folder. Either remove that inner .git folder, or add it properly as a submodule.
how do i use git with roblox studio | rojo git => Use Rojo to sync scripts from files on your computer into Studio, then track those files with Git. Studio itself also keeps a version history for published places.
how do i use git on an ipad | git ipad app | working copy app => Apps like Working Copy let you clone, commit and push Git repos on an iPad, and other editors can open its files.
how do i use git in vs code | vs code source control | git in vs code => VS Code's Source Control tab shows changes, lets you stage, commit, push and pull with buttons, and shows diffs side by side.
git gui tools | git without command line => Git GUIs like GitHub Desktop, GitKraken, Fork and Sourcetree show your history and let you commit and branch by clicking.
what is conventional commits | commit message format | feat fix commit => Conventional Commits starts messages with a type, like `feat: add shop` or `fix: stop double jump`, so tools can build changelogs automatically.
what is a changelog | changelog.md | release notes file => A changelog lists notable changes in each version, newest first, so users know what changed.
what is a commit message body | long commit message | commit subject and body => The first line is a short summary (about 50 characters). Leave a blank line, then explain what and why in more detail if needed.
what is atomic commit | small commits | one change per commit => An atomic commit contains one logical change. Small focused commits are easier to review, revert and understand later.
what is a feature branch | feature branch workflow | branch per feature => In a feature branch workflow, each feature or fix gets its own branch, merged into main through a pull request when it is done.
trunk based | work on main => Trunk-based development means everyone merges small changes into main often, sometimes hiding unfinished features behind flags.
what is a feature flag | feature toggle | turn features on and off => A feature flag is a setting that turns a feature on or off without changing code, so you can ship unfinished work hidden or test with a few users.
what is a hotfix | hotfix branch | urgent fix release => A hotfix is a quick fix for a serious bug in a released version, often made on its own branch and released right away.
what is git blame used for | who wrote this line | annotate git => `git blame file` shows who last changed each line and in which commit, useful for understanding why code is the way it is (not for blaming people).
what is git log -s | pickaxe search git | find when code was added => `git log -S "functionName"` finds commits that added or removed that text, which helps you find when something appeared.
how do i count lines of code in a git repo | lines of code git | count code => `git ls-files | xargs wc -l` counts lines in tracked files on Mac or Linux. Tools like cloc give a breakdown by language.
how do i make git ignore file permission changes | filemode git | chmod changes git => `git config core.fileMode false` stops Git reporting files as changed when only their permissions changed.
how do i undo git add for all files | unstage everything | git reset all => `git restore --staged .` (or `git reset`) unstages everything but keeps your changes in the files.
revert pushed commit | undo commit on github => Use `git revert <hash>` and push. It adds a new commit that undoes the old one, which is safe because it does not rewrite shared history.
how do i edit a commit that is not the last one | change older commit | fixup commit => Make the fix, commit with `git commit --fixup <hash>`, then run `git rebase -i --autosquash <hash>~1`. Only do this before pushing.
how do i split a commit | split commit git | break up a commit => Start `git rebase -i`, mark the commit as edit, then `git reset HEAD~1`, and make several smaller commits before `git rebase --continue`.
how do i move commits to another branch | commit on wrong branch | moved commit to new branch => Create a branch where you are with `git branch new-branch`, then reset the old branch back with `git reset --hard HEAD~N` (N commits), and switch to the new one. Do this only before pushing.
how do i see unpushed commits | commits not pushed | what will i push => `git log origin/main..HEAD` lists commits you have that the remote does not.
how do i download one file from github | download single file github | raw file github => Open the file on GitHub and press the download (Raw) button, or copy the raw link.
how do i download a github repo as zip | download repo zip | get code without git => On the repo page, press Code, then Download ZIP. You get the files without Git history.
