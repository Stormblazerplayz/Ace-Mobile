# JavaScript, HTML, CSS, JSON, Node and Electron basics, written by hand for Ace.
# tag: coding.web.basics
what is javascript used for | js meaning => JavaScript is the programming language of web pages. It makes sites interactive, and with Node.js it also runs servers, tools and desktop apps like Electron apps.
is java the same as javascript | java vs javascript | difference between java and javascript => No. They are different languages that just have similar names. JavaScript runs in browsers and Node.js; Java is a separate language often used for Android and Minecraft Java Edition.
html meaning | what does html do => HTML (HyperText Markup Language) describes the structure and content of a web page with tags like `<h1>`, `<p>` and `<img>`.
css meaning | what does css do => CSS (Cascading Style Sheets) styles web pages: colors, fonts, spacing and layout. Rules look like `h1 { color: red; }`.
how do html css and javascript work together | html css js difference | web page three languages => HTML is the structure, CSS is the look, and JavaScript is the behavior. A page loads all three, usually from .html, .css and .js files.
how do i make a website | make my first web page | build a website from scratch => Make a file called index.html with a basic page, open it in a browser, then add a style.css and script.js and link them. Host it free with GitHub Pages when you are ready.
what is the basic html page structure | html boilerplate => `<!DOCTYPE html>` then `<html lang="en">` with a `<head>` (holding `<meta charset="utf-8">`, a viewport meta tag and `<title>`) and a `<body>` with your content.
what is the doctype | <!doctype html> | why doctype html => `<!DOCTYPE html>` at the top tells the browser to use modern standards mode. Without it, pages can render in quirks mode with odd old behavior.
what is the viewport meta tag | meta viewport | make website work on phone => `<meta name="viewport" content="width=device-width, initial-scale=1">` makes mobile browsers use the real screen width, so your responsive CSS works.
how do i link a css file | link stylesheet html | connect css to html => Put `<link rel="stylesheet" href="style.css">` inside the `<head>`.
how do i link a javascript file | script tag src | connect js to html => Put `<script src="script.js" defer></script>` in the head. `defer` waits until the HTML is parsed, so your code can find the elements.
what is the difference between id and class in html | id vs class | when to use id or class => An id must be unique on the page and is selected in CSS with `#name`. A class can be on many elements and is selected with `.name`. Use classes for styling.
what is a css selector | css selectors explained | how to select elements css => A selector picks which elements a rule styles: `p` for all paragraphs, `.card` for a class, `#main` for an id, `nav a` for links inside nav.
what is css specificity | why is my css not applying | css rule priority => When rules conflict, the more specific selector wins: ids beat classes, and classes beat tag names. If equal, the later rule wins. Avoid `!important` except as a last resort.
what is the css box model | box model css | content padding border margin => Every element is a box: content, then padding, then border, then margin outside. `box-sizing: border-box` makes width include padding and border, which is easier.
what is flexbox | css flexbox | how does flexbox work => Flexbox lays items in a row or column. Set `display: flex` on the parent, then use `justify-content` (main axis), `align-items` (cross axis) and `gap`.
how do i center a div | center something in css | center horizontally and vertically => On the parent use `display: flex; justify-content: center; align-items: center;` (give it a height). Or `display: grid; place-items: center;`.
grid vs flexbox | css grid or flexbox which to use => CSS Grid lays things out in rows and columns at once, great for whole page layouts. Flexbox is best for one row or column of items.
what is responsive design | make a website mobile friendly | responsive css => Responsive design makes pages work on any screen size using flexible layouts, relative units and media queries like `@media (max-width: 600px) { }`.
what are css units | px vs em vs rem | vh vw css => `px` is fixed, `rem` is relative to the root font size, `em` to the parent's, `%` to the parent's size, and `vw` and `vh` to the window width and height.
what is a css variable | custom properties css | --main-color css => Define `--brand: #3366ff;` inside `:root` and use it with `color: var(--brand);`. Change it once and every use updates.
how do i add a google font | custom font website | font on my website => Add the font's `<link>` from Google Fonts in your head, then use it with `font-family: "Font Name", sans-serif;`.
how do i make a dark mode website | prefers color scheme | dark mode css => Use `@media (prefers-color-scheme: dark) { }` to switch colors, ideally by changing CSS variables.
smooth hover effect css | animate on hover => `transition: background-color 0.3s;` makes property changes animate smoothly, like on `:hover`.
keyframes animation | make something move css => Define `@keyframes spin { to { transform: rotate(360deg); } }` and apply it with `animation: spin 2s linear infinite;`.
what is position absolute vs relative | css position explained | position fixed sticky => `relative` nudges an element from its normal spot and becomes the anchor for absolute children. `absolute` places it relative to that anchor. `fixed` sticks to the window, and `sticky` sticks once you scroll past.
what is a variable in javascript | let const var | declare variable js => Use `const` for values you will not reassign and `let` for ones you will. Avoid the old `var`, which has confusing scope rules.
what is the difference between let and const | let vs const javascript | can i change a const => `let` can be reassigned; `const` cannot. But a const object or array can still have its contents changed, like `list.push(1)`.
what is the difference between var and let | why not use var => `var` is function scoped and gets hoisted, which causes bugs. `let` and `const` are block scoped, so they only exist inside the braces where they are declared.
what are the data types in javascript | js types | primitive types javascript => JavaScript has string, number, bigint, boolean, undefined, null and symbol as primitives, plus objects (which include arrays and functions).
what is undefined vs null | null vs undefined javascript | difference undefined null => `undefined` means a variable has no value yet. `null` is a value you set on purpose to mean "nothing".
double equals vs triple equals | strict equality js => `===` checks value and type, so `5 === "5"` is false. `==` converts types first, so `5 == "5"` is true. Use `===` almost always.
what is nan in javascript | not a number js | why do i get nan => NaN means "Not a Number", the result of bad math like `"abc" * 2`. Check with `Number.isNaN(x)`; NaN is not even equal to itself.
how do i write a function in javascript | js function syntax | function declaration javascript => `function add(a, b) { return a + b; }`. You can also store a function in a variable as a function expression or an arrow function.
what is an arrow function | arrow function javascript | short function js => An arrow function is a shorter function written with an arrow made of an equals sign and a greater-than sign between the parameters and the body. It does not get its own `this`, which helps inside callbacks.
what is a callback in javascript | callback function js | pass a function js => A callback is a function you pass to another function to be called later, like the one you give to `addEventListener` or `setTimeout`.
js object | key value javascript => An object groups values by name: `const player = { name: "Sam", score: 10 };`. Read with `player.name` or `player["name"]`.
js array | list in javascript => An array is an ordered list: `const nums = [1, 2, 3];`. Read with `nums[0]`, get the size with `nums.length`, and add with `nums.push(4)`.
how do i loop through an array in javascript | for of loop js | iterate array js => `for (const item of items) { }` gives each item. `items.forEach(...)` also works, and a classic `for (let i = 0; i < items.length; i++)` gives the index.
how do i loop through an object in javascript | object keys loop => `for (const [key, value] of Object.entries(obj)) { }` gives each pair. `for (const key in obj)` gives keys.
what is a template literal | backticks javascript | string with variables js => Strings in backticks can hold expressions: `` `Score: ${score}` ``. They can also span several lines.
destructure object js | unpack array js => Destructuring pulls values out: `const { name, score } = player;` or `const [first, second] = list;`.
what is the spread operator | three dots javascript | ... in js => `...` spreads items out: `[...a, ...b]` joins arrays, `{ ...obj, score: 5 }` copies an object with a change, and `Math.max(...nums)` passes an array as arguments.
what is the dom | document object model | dom explained => The DOM is the browser's live tree of objects for the page's HTML. JavaScript changes the page by changing the DOM, like `element.textContent = "Hi"`.
how do i change text on a page with javascript | change html with js | update element text => Find the element and set its text: `document.querySelector("#title").textContent = "New title";`.
how do i make a button do something in javascript | button click js | onclick javascript => `button.addEventListener("click", function () { alert("Hi"); });` runs the function on every click. Using addEventListener is better than an onclick attribute in the HTML.
how do i get the value of an input in javascript | read input box js | text box value js => `const text = document.querySelector("#name").value;`. Number inputs still give a string, so use `Number(...)`.
how do i add a class with javascript | classlist add | toggle class js => `el.classList.add("active")`, `.remove("active")` and `.toggle("active")` change classes, which lets CSS do the styling.
how do i create an element with javascript | add element to page js => `const li = document.createElement("li"); li.textContent = "New"; list.append(li);`.
what is an event in javascript | event listener js | dom events => Events are things that happen, like click, input, keydown, submit and load. You react with `element.addEventListener("click", handler)`.
how do i stop a form from reloading the page | preventdefault form | form submit javascript => In the submit handler call `event.preventDefault()`, then handle the data with JavaScript.
what is asynchronous javascript | async javascript explained | why is js async => JavaScript runs one thing at a time, so slow tasks like network requests run in the background and call your code back when done, using callbacks, promises or async/await.
what is a promise | javascript promise explained | promise then catch => A promise is a value that will be ready later. Use `.then()` for the result and `.catch()` for errors, or `await` it inside an async function.
what is async await in javascript | async function js | await fetch => Mark a function `async` and use `await` to wait for a promise: `const res = await fetch(url); const data = await res.json();`. Wrap it in try/catch for errors.
how do i fetch data from an api in javascript | fetch api js | get json from url => `const res = await fetch(url); if (!res.ok) throw new Error(res.status); const data = await res.json();`.
what is cors | cors error | blocked by cors policy => CORS is a browser rule that stops a page from reading responses from another website unless that server allows it with headers. Fix it on the server, or call the API from your own backend.
what is local storage | save data in browser => `localStorage.setItem("best", "10")` saves text in the browser that stays after closing it, and `getItem("best")` reads it. Store objects with JSON.stringify and JSON.parse.
json meaning | what does json look like => JSON (JavaScript Object Notation) is a text format for data: objects in braces, arrays in brackets, like `{"name": "Sam", "scores": [1, 2]}`. Almost every language can read it.
what are json rules | valid json | json syntax rules => Keys must be in double quotes, strings use double quotes, and values are strings, numbers, true, false, null, objects or arrays. No comments and no trailing commas.
what does unexpected token in json mean | json parse error | invalid json error => The text is not valid JSON, often because of a trailing comma, single quotes, a comment, or because the server sent HTML instead. Print the raw text to see.
what does cannot read properties of undefined mean | typeerror cannot read property | undefined error js => You used `.something` on a value that is undefined, like a missing object or an element that was not found. Check the value before using it, or use optional chaining `obj?.name`.
what does is not a function mean in javascript | typeerror is not a function | not a function error => You called something that is not a function, often a typo in the method name or calling a method on the wrong type.
what does is not defined mean in javascript | referenceerror not defined | variable not defined js => You used a name that does not exist in that scope. Check spelling, that it was declared, and that the script loaded.
what does uncaught syntaxerror mean | unexpected token js | syntax error javascript => There is a typo the browser cannot parse, like a missing bracket, quote or comma. The console shows the file and line.
why does queryselector return null | getelementbyid null | element not found js => The selector does not match anything, or the script ran before the HTML loaded. Check the selector, and add `defer` to your script tag.
how do i open the browser console | developer tools | f12 console => Press F12 (or Ctrl+Shift+I, Cmd+Option+I on Mac) to open developer tools, then pick the Console tab. Errors show in red there.
what are browser dev tools | inspect element | developer tools explained => Dev tools let you inspect and edit HTML and CSS live, see console errors, watch network requests, debug JavaScript with breakpoints and test phone sizes.
what is console.log | print in javascript | debug with console log => `console.log(value)` prints to the browser console or terminal, the easiest way to see what your code is doing.
what is node.js | node js explained | javascript outside the browser => Node.js runs JavaScript outside the browser, so you can build servers, command-line tools and apps. Run a file with `node app.js`.
what is npm | npm install | node package manager => npm is Node's package manager. `npm install name` adds a package to node_modules and records it in package.json.
what is package.json | package json file | npm scripts => package.json describes a Node project: its name, dependencies and scripts. `npm run start` runs the "start" script listed in it.
what is node_modules | node modules folder | should i commit node_modules => node_modules holds installed packages. Do not commit it to Git; add it to .gitignore, since `npm install` recreates it.
what is package-lock.json | lock file npm | npm ci => package-lock.json records the exact versions installed so everyone gets the same ones. Commit it. `npm ci` installs exactly what it lists.
what is npx | npx command | run package without installing => npx runs a package's command without installing it globally, like `npx create-vite@latest`.
what is typescript | typescript vs javascript | ts explained => TypeScript is JavaScript with types, like `let score: number`. It catches mistakes before running and compiles to plain JavaScript.
what is a framework like react | what is react | react js => React is a popular JavaScript library for building interfaces from components. Other choices are Vue, Svelte and Angular.
what is vite | vite build tool | npm create vite => Vite is a fast tool for starting and building web projects. `npm create vite@latest` makes a new project with a dev server that reloads as you code.
what is a web server | how websites are served | web hosting explained => A web server is a computer program that sends web pages to browsers when they ask. Hosting means running your site on a server that is always online.
host website free | publish html site => GitHub Pages hosts static websites for free from a GitHub repository. Turn it on in the repo's Settings > Pages.
what is a static vs dynamic website | static site | dynamic site => A static site sends the same files to everyone. A dynamic site builds pages on a server, often from a database, like when you log in.
what is http | http vs https | what does https mean => HTTP is how browsers and servers talk. HTTPS is HTTP encrypted with TLS, so others cannot read or change the data. Always use HTTPS.
what are http methods | get vs post | http verbs => GET reads data, POST sends new data, PUT or PATCH change data, and DELETE removes it.
what are http status codes | 404 meaning | 200 status code => 200 means OK, 301 moved, 400 bad request, 401 not signed in, 403 forbidden, 404 not found, 429 too many requests, and 500 server error.
parts of a url | url explained => A URL like `https://example.com/page?id=5#top` has a scheme (https), a domain, a path, a query string after `?` and a fragment after `#`.
what is a domain name | dns explained | how does a website address work => A domain name is a human-friendly name for a server. DNS works like a phone book, turning names like example.com into IP addresses.
what is a cookie in web | browser cookies | what do cookies do => A cookie is a small piece of data a website stores in your browser, often to keep you logged in or remember settings.
web api explained | rest api => An API is a way for programs to talk. A web API lets your code request data from a server, usually as JSON over HTTPS.
what is accessibility in web | a11y web | accessible website => Accessibility means everyone can use your site, including people using screen readers or keyboards. Use real buttons and headings, alt text on images, good contrast and labels on form fields.
what is alt text | img alt attribute | image alt html => The `alt` attribute describes an image for screen readers and shows if the image fails to load: `<img src="cat.png" alt="Orange cat sleeping">`.
what is semantic html | semantic tags | why use semantic html => Semantic HTML uses tags that describe meaning, like `<nav>`, `<main>`, `<article>` and `<button>`, instead of only divs. It helps accessibility and search engines.
what is seo | search engine optimization | get my site on google => SEO means helping search engines understand your site: clear titles, headings, descriptions, fast pages, good content and links from other sites.
what is a favicon | website tab icon | add favicon => A favicon is the little icon on the browser tab. Add `<link rel="icon" href="favicon.png">` in the head.
draw with javascript | html5 canvas game => `<canvas>` is a drawing area. Get its context with `canvas.getContext("2d")` and draw with methods like `fillRect` and `drawImage`, often in a requestAnimationFrame loop for games.
how do i make a game loop in javascript | requestanimationframe loop | js game loop => Write `function loop(time) { update(); draw(); requestAnimationFrame(loop); }` and start it with `requestAnimationFrame(loop)`. The browser calls it before each repaint, usually 60 times a second.
how do i detect key presses in javascript | keydown event | keyboard input js => `window.addEventListener("keydown", function (e) { console.log(e.key); });` gives keys like "ArrowLeft" or " " for space. Track pressed keys in a Set for games.
this keyword js | what does this refer to => `this` is the object a function was called on. In regular functions it changes with how the function is called; arrow functions keep the `this` from where they were written.
js class | class syntax javascript => `class Player { constructor(name) { this.name = name; } jump() { } }` then `new Player("Sam")`. Use `extends` to inherit.
what is a module in javascript | import export js | es modules => Modules split code into files: `export function add() {}` in one and `import { add } from "./math.js";` in another. In HTML, load with `<script type="module">`.
what is hoisting | javascript hoisting | function hoisting => Hoisting means declarations are processed before code runs, so you can call a function declaration before it appears. `let` and `const` cannot be used before their line.
what is a closure in javascript | js closure | function remembers variables js => A closure is a function that keeps access to variables from where it was created, even after that outer function has finished.
what is the event loop | js event loop | how javascript runs async code => The event loop runs your code, then takes the next waiting task (like a finished timer or network response) from a queue and runs it, one at a time. That is how one thread handles async work.
what is settimeout vs setinterval | timer javascript | run code every second js => `setTimeout(fn, 1000)` runs once after 1 second. `setInterval(fn, 1000)` runs every second until you call `clearInterval`.
how do i make a random number in javascript | math random js | random integer javascript => `Math.floor(Math.random() * 6) + 1` gives a whole number from 1 to 6.
how do i round a number in javascript | tofixed js | round to 2 decimals js => `Math.round(x)` rounds to a whole number. `x.toFixed(2)` gives a string with 2 decimals.
how do i convert a string to a number in javascript | parseint vs number | string to int js => `Number("42")` converts the whole string (NaN if invalid). `parseInt("42px")` reads the number at the start, giving 42.
what is truthy and falsy in javascript | falsy values js | what is false in js => false, 0, "", null, undefined and NaN are falsy. Everything else is truthy, including "0", empty arrays and empty objects.
safe property access js | question mark dot javascript => `user?.profile?.name` gives undefined instead of an error if any part is missing.
what is the nullish coalescing operator | default value js => `value ?? "default"` uses the default only when value is null or undefined, unlike the or operator, which also replaces 0 and "".
what is regex in javascript | regular expressions js | regexp test => A regex is a pattern for matching text, like `/\d+/`. Use `/cat/i.test(text)` to check, and `text.replace(/a/g, "b")` to replace all.
what is a service worker | offline website | pwa => A service worker is a script that runs in the background of a site, letting it cache files and work offline. It is a key part of Progressive Web Apps (PWAs).
what is a pwa | progressive web app | install website as app => A PWA is a website that can be installed like an app, work offline and send notifications, using a web app manifest and a service worker.
what is webassembly | wasm | run c++ in browser => WebAssembly (Wasm) is a fast binary format browsers can run, so code from languages like C++ and Rust can run on web pages next to JavaScript.
what is electron | electron js | desktop app with javascript => Electron builds desktop apps for Windows, macOS and Linux with HTML, CSS and JavaScript. It bundles Chromium and Node.js, and apps like VS Code and Discord use it.
what is the main process in electron | main vs renderer process | electron processes => The main process runs Node.js, creates windows and handles the app's life. Each window has a renderer process that shows web content.
what is a browserwindow in electron | create window electron | new browserwindow => `new BrowserWindow({ width: 800, height: 600, webPreferences: { preload } })` makes a window, and `win.loadFile("index.html")` shows your page.
what is a preload script in electron | preload js electron | contextbridge => A preload script runs before the page loads with access to some Node APIs. Use `contextBridge.exposeInMainWorld("api", {...})` to give the page only the functions it needs.
what is ipc in electron | ipcmain ipcrenderer | electron communication => IPC lets renderer and main processes talk. In preload, call `ipcRenderer.invoke("save", data)`, and in main register `ipcMain.handle("save", handler)`, where handler gets the event and data and can return a result.
what is context isolation in electron | contextisolation | electron security => Context isolation keeps your page's JavaScript separate from Electron internals and the preload script. Keep it on (the default), keep nodeIntegration off, and expose only what you need with contextBridge.
why should i turn off nodeintegration in electron | nodeintegration true danger | electron safe settings => With nodeIntegration on, any script in the page, even from a bad link or ad, could use Node to read files or run programs. Keep it off and use a preload with contextBridge.
how do i start an electron app | electron quick start | npm start electron => Run `npm init`, `npm install --save-dev electron`, make main.js that creates a BrowserWindow, set `"start": "electron ."` in package.json scripts, and run `npm start`.
how do i package an electron app | electron forge | build exe from electron => Use Electron Forge or electron-builder to make installers like .exe, .dmg or .AppImage. For example `npm run make` with Electron Forge.
what is the app object in electron | app whenready | app quit electron => `app` controls the app's life: `app.whenReady().then(createWindow)` starts it, and on Windows and Linux you usually call `app.quit()` when all windows close.
how do i make a tray icon in electron | electron tray | menu bar icon electron => `new Tray("icon.png")` adds an icon to the system tray or menu bar, and `tray.setContextMenu(Menu.buildFromTemplate([...]))` gives it a menu.
how do i save files in electron | fs in electron | write file electron => Do file work in the main process with Node's fs module, triggered from the renderer through IPC. `app.getPath("userData")` is a good folder for app data.
how do i open a file dialog in electron | dialog showopendialog | pick a file electron => In the main process call `dialog.showOpenDialog({ properties: ["openFile"] })`, which returns the chosen file paths.
how do i debug electron | electron devtools | open devtools electron => Call `win.webContents.openDevTools()` to debug the renderer like a web page. Debug the main process with `--inspect` and Chrome or VS Code.
why is my electron app big | electron app size | electron vs tauri => Electron apps include a whole Chromium browser and Node.js, so even small apps are often over 100 MB. Tauri is a lighter alternative that uses the system's web view.
how do i auto update an electron app | electron autoupdater | update electron app => Electron has an autoUpdater module, and electron-updater (with electron-builder) can check GitHub Releases or your server for new versions.
what is a shortcut in electron | globalshortcut | keyboard shortcut electron => `globalShortcut.register("CommandOrControl+Shift+K", fn)` adds a shortcut that works even when the app is not focused. Menus can also have accelerators.
what is vs code | visual studio code | best code editor => VS Code is a free code editor from Microsoft with extensions for almost every language, a built-in terminal, Git support and debugging. It is itself built with Electron.
what is live server | auto reload html | preview html vs code => Live Server is a VS Code extension that serves your page locally and reloads the browser every time you save.
what is markdown | markdown syntax | md file => Markdown is a simple text format: `# Heading`, `**bold**`, `*italic*`, `- list item` and links in brackets and parentheses. README files on GitHub use it.
what is yaml | yaml file | yml => YAML is a settings format that uses indentation instead of braces, like `name: Ace` and lists with `- item`. Indentation must use spaces.
what is xml | xml vs json | xml format => XML is a data format using tags like HTML, `<name>Sam</name>`. JSON is shorter and more common for web APIs.
what is csv | csv file | comma separated values => CSV is a plain text table where each line is a row and commas separate the columns. Spreadsheets can open and save it.
