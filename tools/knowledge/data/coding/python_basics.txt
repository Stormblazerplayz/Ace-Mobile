# Python language basics, written by hand for Ace.
# tag: coding.python.basics
what is python used for | why learn python => Python is a popular programming language known for being easy to read. It is used for scripts, websites, data science, AI, automation, games with pygame, and tools like Storm's PrintPilot.
who made python | when was python made | why is it called python => Guido van Rossum created Python and released it in 1991. It is named after the comedy group Monty Python, not the snake.
how do i install python | download python | get python on my computer => Download the installer from python.org. On Windows, tick "Add python.exe to PATH" during install. On macOS you can also use Homebrew with `brew install python`.
how do i run a python file | run a py file | how to start a python script => Open a terminal in the file's folder and run `python myfile.py` (or `python3 myfile.py` on macOS and Linux). In an editor like VS Code you can press the Run button.
what is the python shell | python repl | interactive python => Typing `python` alone opens the interactive shell (REPL) with a `>>>` prompt, where each line runs right away. Type `exit()` to leave.
what is the difference between python 2 and 3 | python2 vs python3 | should i learn python 2 => Python 3 is the modern version, and Python 2 stopped getting updates in 2020. Always learn and use Python 3; print is a function in it, so you write `print("hi")`.
how do i make a variable in python | python variables | assign a variable python => Write a name, an equals sign and a value: `score = 10`. You do not declare a type; Python figures it out, and you can change it later.
what are the rules for python variable names | can variable names have spaces python | valid variable name => Names can use letters, digits and underscores but cannot start with a digit or have spaces. They are case sensitive, and the usual style is snake_case like `player_score`.
what data types does python have | python types list | basic types in python => The common ones are int (whole numbers), float (decimals), str (text), bool (True or False), list, tuple, dict, set and None.
what is none in python | what does none mean | none vs null python => None means "no value". Functions that do not return anything give None. Check for it with `if x is None:`.
what is the difference between a list and a tuple | list vs tuple python | when to use a tuple => A list can be changed after it is made; a tuple cannot. Use tuples for fixed groups like coordinates `(x, y)` and lists for collections that grow or change.
python set explained | when to use a set => A set holds unique items with no order, like `{1, 2, 3}`. It removes duplicates and checks `x in my_set` very fast.
how do i make a list in python | create a list python | list syntax python => Use square brackets: `fruits = ["apple", "banana", "cherry"]`. An empty list is `[]`.
how do i get an item from a list in python | list index python | first item of a list => Use its index in brackets, starting at 0: `fruits[0]` is the first item and `fruits[-1]` is the last.
what is slicing in python | list slice python | get part of a list python => Slicing takes a section: `items[1:4]` gives indexes 1, 2 and 3. `items[:3]` is the first three, `items[2:]` is from index 2 on, and `items[::-1]` is reversed.
how do i check if something is in a list python | in operator python | is item in list => Use `in`: `if "apple" in fruits:`. It also works on strings, tuples, sets and dict keys.
how do i loop through a list in python | for loop over list python | iterate list python => `for fruit in fruits: print(fruit)`. Use `for i, fruit in enumerate(fruits):` if you also need the index.
how do i loop a number of times in python | repeat code 10 times python | for i in range => `for i in range(10):` runs 10 times with i from 0 to 9. `range(1, 11)` goes from 1 to 10.
how do i write a while loop in python | python while loop | loop until something happens python => `while lives > 0:` keeps running the indented code as long as the condition is True. Make sure something inside changes the condition or it never ends.
what does break do in python | exit a loop python | stop a loop early => `break` immediately leaves the loop it is in. Code after the loop then runs.
what does continue do in python | skip loop iteration python | continue statement => `continue` skips the rest of this pass through the loop and goes to the next one.
what does pass do in python | pass statement | empty function python => `pass` does nothing. It fills a spot where Python needs code, like an empty function or class you will finish later.
what is an else on a loop in python | for else python | while else => A loop's `else` block runs only if the loop finished without hitting `break`. It is handy for "searched everything and did not find it".
how do i write an if statement in python | python if elif else | if syntax python => `if score > 90:` then an indented block, optionally `elif score > 70:` and `else:`. Every block is indented, usually by 4 spaces.
what is the difference between = and == in python | equals vs double equals | assignment vs comparison => `=` stores a value in a variable. `==` asks if two values are equal and gives True or False.
is vs equals python | when to use is => `==` checks if values are equal. `is` checks if they are the exact same object. Use `is` only for None, True and False.
what are and or not in python | logical operators python | python boolean operators => `and` needs both sides True, `or` needs at least one, and `not` flips True and False. Python uses these words instead of the symbols some other languages use.
what are comparison operators in python | greater than python | less than or equal python => `==` equal, `!=` not equal, `<` less, `>` greater, `<=` and `>=`. You can chain them: `if 0 <= x < 10:`.
what does // do in python | floor division python | integer division python => `//` divides and rounds down to a whole number, so `7 // 2` is 3. Normal `/` always gives a float, so `7 / 2` is 3.5.
what does % do in python | modulo python | remainder python => `%` gives the remainder, so `7 % 3` is 1. `n % 2 == 0` checks if n is even.
what does ** do in python | power in python | exponent python => `**` raises to a power, so `2 ** 10` is 1024. `x ** 0.5` is the square root.
what is += in python | plus equals python | shorthand operators python => `x += 1` means `x = x + 1`. There are also `-=`, `*=`, `/=`, `//=` and `%=`. Python has no `++`.
how do i make a function in python | def in python | define a function python => `def greet(name):` then an indented body, like `return "Hi " + name`. Call it with `greet("Sam")`.
what does return do in python | return statement python | return vs print => `return` sends a value back to the code that called the function and ends the function. `print` only shows it on screen and the function gives back None.
what are default arguments in python | default parameter value python | optional argument python => Give a parameter a default: `def greet(name="friend"):`. Callers can leave it out. Never use a list or dict as a default, because the same one gets reused every call.
what are keyword arguments in python | kwargs python | named arguments python => You can pass arguments by name: `make_pizza(size=12, topping="cheese")`. `**kwargs` in a function collects extra named arguments into a dict.
what is *args in python | args python | any number of arguments python => `def total(*args):` collects any number of positional arguments into a tuple, so `total(1, 2, 3)` gives args `(1, 2, 3)`.
what is a lambda in python | lambda function python | anonymous function python => A lambda is a tiny one-line function: `square = lambda x: x * x`. It is mostly used as a key for sorting, like `sorted(people, key=lambda p: p.age)`.
what is scope in python | local vs global variable python | global keyword python => Variables made inside a function are local to it. To change a module-level variable inside a function, write `global name` first, but passing and returning values is usually cleaner.
what is a docstring in python | function documentation python | triple quote comment => A docstring is a string right under a `def` or `class` line, in triple quotes, that explains what it does. `help(function)` shows it.
how do i get user input in python | read input python | ask a question in python => `name = input("What is your name? ")`. input always gives a string, so use `int(input())` for numbers.
how do i make a number from input in python | convert input to int | input number python => `age = int(input("Age: "))`. If they type something that is not a number, it raises ValueError, so you can wrap it in try/except.
what is an f string in python | f strings python | format strings with variables python => Put f before the quotes and variables in braces: `f"Hi {name}, you have {coins} coins"`. You can format too: `f"{price:.2f}"` shows 2 decimals.
how do i join strings in python | concatenate strings python | add strings together python => Use `+`: `"Hello " + name`. To join a number, convert it with `str(5)` or use an f-string.
how do i get the length of a string in python | string length python | count characters python => `len("hello")` gives 5.
how do i reverse a string in python | backwards string python | reverse text python => `text[::-1]` gives the string backwards.
are strings mutable in python | change a character in a string python | strings immutable => No, strings cannot be changed in place. Make a new string instead, like `s = s[:2] + "X" + s[3:]` or `s.replace(...)`.
how do i make a multi line string in python | triple quotes python | multiline text python => Use triple quotes: `"""line one` and on the next line `line two"""`. Or use `\n` inside a normal string for a new line.
what are escape characters in python | backslash n python | new line in a string => A backslash starts a special character: `\n` new line, `\t` tab, `\\` a backslash, `\"` a quote inside double quotes.
what is a raw string in python | r string python | r before a string => `r"C:\new\folder"` is a raw string where backslashes are kept as typed. Raw strings are common for Windows paths and regex patterns.
what is a dictionary used for in python | how do dictionaries work python | look up values by key => A dict stores key-value pairs, like `ages = {"Sam": 12, "Lee": 13}`. Read with `ages["Sam"]`, add with `ages["Ana"] = 11`, and loop with `for name, age in ages.items():`.
how do i check if a key is in a dictionary python | key exists python | in operator dictionary => `if "Sam" in ages:` checks the keys. Or use `ages.get("Sam")`, which returns None instead of an error.
how do i delete a key from a dictionary python | remove key dict python | del dictionary => `del ages["Sam"]` removes it (KeyError if missing), or `ages.pop("Sam", None)` to be safe.
how do i loop through a dictionary in python | iterate dict python | for key value in dict => `for key, value in d.items():`. Looping `for key in d:` gives just the keys.
can dictionary keys be lists in python | unhashable type list | what can be a dict key => No. Keys must be unchangeable (hashable), like strings, numbers or tuples. Lists and dicts cannot be keys.
what is a list comprehension | list comprehension python | one line for loop list => A short way to build a list: `squares = [n * n for n in range(10)]`. Add a filter with `if`: `[n for n in nums if n > 0]`.
what is a dictionary comprehension | dict comprehension python | build a dict in one line => `{name: len(name) for name in names}` makes a dict in one line, like a list comprehension with key: value.
what is a set comprehension | set comprehension python | unique values comprehension => `{word.lower() for word in words}` builds a set, removing duplicates.
what is unpacking in python | unpack a tuple python | multiple assignment python => You can split a sequence into variables: `x, y = (3, 4)`. Use `*` to grab the rest: `first, *rest = [1, 2, 3, 4]`.
how do i swap two variables in python | swap values python | a b = b a => `a, b = b, a`. Python builds the tuple on the right first, then unpacks it.
what is truthy and falsy in python | what counts as false python | empty list is false => False, None, 0, 0.0, empty strings, and empty lists, dicts, sets and tuples are falsy. Almost everything else is truthy, so `if items:` checks the list is not empty.
what is a nested list in python | 2d list python | grid in python => A list of lists: `grid = [[0] * 3 for _ in range(3)]` makes a 3 by 3 grid; read with `grid[row][col]`. Do not use `[[0] * 3] * 3`, which shares one inner list.
why does changing one list change the other python | list copy problem python | lists are references => `b = a` makes both names point to the same list. Use `b = a.copy()` or `b = list(a)` for a separate copy, and `copy.deepcopy` for nested lists.
what is mutable and immutable in python | mutable vs immutable | which types can change python => Mutable objects can change in place: lists, dicts and sets. Immutable ones cannot: ints, floats, strings, tuples and frozensets.
what is the underscore variable in python | for _ in range python | what does _ mean => `_` is a name people use for a value they do not care about, like `for _ in range(5):`. In the shell it also holds the last result.
what is a module in python | python modules explained | import a module => A module is a .py file of code you can reuse. `import math` loads the math module, and `math.sqrt(9)` uses it.
how do i import from another file in python | import my own file python | use functions from another py file => Put both files in the same folder and write `import helpers` or `from helpers import greet`. The file name without .py is the module name.
what is from import in python | from x import y | import specific function python => `from math import sqrt` lets you write `sqrt(9)` instead of `math.sqrt(9)`. Avoid `from x import *` because it hides where names came from.
what does import as do | alias an import => `import numpy as np` gives a module a shorter name, so you write `np.array`.
what is if name equals main | if __name__ == "__main__" | __name__ python => Code under `if __name__ == "__main__":` only runs when you run the file directly, not when another file imports it. It is where you put the program's start.
what is the python standard library | built in modules python | what comes with python => The standard library is the big set of modules that come with Python, like math, random, os, json, datetime, re and pathlib. You do not need pip to use them.
what is pip | how do i install a python package | pip install => pip is Python's package installer. Run `pip install requests` in a terminal (or `python -m pip install requests`) to download a package from PyPI.
what is pypi | python package index | where do pip packages come from => PyPI (pypi.org) is the Python Package Index, the online library pip downloads packages from.
how do i see installed packages | pip list | pip freeze => `pip list` shows installed packages. `pip freeze > requirements.txt` saves them with versions so others can install the same ones.
what is requirements.txt | install from requirements txt | requirements file python => requirements.txt lists the packages a project needs. Install them all with `pip install -r requirements.txt`.
how do i uninstall a python package | pip uninstall | remove a package => Run `pip uninstall packagename`.
how do i upgrade a python package | pip upgrade | update a package python => Run `pip install --upgrade packagename`. Upgrade pip itself with `python -m pip install --upgrade pip`.
venv python | why use a virtual environment => A virtual environment is a private folder of packages for one project, so projects do not fight over versions. Make one with `python -m venv .venv`.
how do i activate a venv | activate virtual environment | venv activate windows mac => On Windows run `.venv\Scripts\activate`, and on macOS or Linux run `source .venv/bin/activate`. Type `deactivate` to leave it.
what does pip command not found mean | pip is not recognized | pip not working => Python's Scripts folder is not on your PATH, or pip is not installed. Try `python -m pip install ...`, which always uses the pip that belongs to that Python.
what does python is not recognized mean | python not recognized windows | python command not found => Python is not installed or not on PATH. Reinstall from python.org and tick "Add python.exe to PATH", or try the `py` launcher on Windows.
how do i read a file in python | open and read a file python | read text file => `with open("notes.txt") as f: text = f.read()`. Use `f.readlines()` for a list of lines, or `for line in f:` to go line by line.
how do i write to a file in python | save text to a file python | write file python => `with open("out.txt", "w") as f: f.write("Hello\n")`. "w" erases the file first; "a" adds to the end.
what does with open do | with statement python | why use with for files => `with` opens the file and closes it automatically when the block ends, even if there is an error. It is the safe way to handle files.
what are file modes in python | r w a python | open modes => "r" read (default), "w" write and erase, "a" append, "x" create only if new, and add "b" for binary like "rb" for images.
how do i read a file line by line in python | loop over lines in a file | readline python => `with open("data.txt") as f:` then `for line in f: print(line.strip())`. strip removes the newline at the end.
how do i save a list to a file python | save data python | store data in a file => For simple data use json: `json.dump(my_list, open("data.json", "w"))` and load it back with `json.load(open("data.json"))`.
what is encoding when opening files | utf-8 file python | unicodedecodeerror reading file => Text files are stored with an encoding. Use `open(path, encoding="utf-8")` to read most files correctly, especially ones with emoji or accents.
what is a class in python | python classes explained | make a class python => A class is a blueprint for objects: `class Dog:` with methods inside. Each object made from it, like `rex = Dog()`, has its own data.
what is __init__ in python | init method python | constructor python => `__init__` runs when you make a new object and sets up its data: `def __init__(self, name): self.name = name`.
what is self in python | why self in python methods | self parameter => `self` is the object the method is working on. Python passes it automatically, so `rex.bark()` calls `bark(rex)`, and inside you use `self.name`.
what is an attribute in python | instance attribute python | object variable python => An attribute is a variable stored on an object, like `self.name`. Read it with `rex.name`.
what is a method in python | method vs function python | class functions => A method is a function defined inside a class. It gets `self` first and is called on an object: `rex.bark()`.
what is inheritance in python | subclass python | class inherits from another => `class Puppy(Dog):` makes Puppy get all of Dog's methods. It can add new ones or override old ones, and call the parent with `super()`.
what is __str__ in python | print an object nicely python | str method class => Define `def __str__(self): return f"Dog {self.name}"` and `print(rex)` shows that text instead of `<__main__.Dog object at ...>`.
what is __repr__ | repr vs str python | __repr__ method => `__repr__` gives a developer-friendly text for an object, shown in the shell and in lists. If there is no `__str__`, print uses `__repr__`.
what are dunder methods in python | magic methods python | double underscore methods => Dunder methods like `__init__`, `__str__`, `__len__`, `__eq__` and `__add__` let your class work with built-in features like len() and `+`.
what is a class attribute vs instance attribute | class variable python | shared variable between objects => A class attribute is defined in the class body and shared by all objects. Instance attributes are set on self and belong to one object.
what is encapsulation in python | private variables python | underscore before a name => Python has no truly private variables. A single underscore `_name` means "internal, please do not touch", and double underscore `__name` makes the name harder to reach from outside.
what is a dataclass | dataclasses python | @dataclass => `@dataclass` above a class writes `__init__`, `__repr__` and `__eq__` for you from the fields: `@dataclass class Point: x: int` then `y: int` on the next line.
what is an enum in python | enum class python | named constants python => `from enum import Enum` then `class Color(Enum): RED = 1` gives named constants you use as `Color.RED`.
what is a decorator in python | @ symbol python | how do decorators work => A decorator wraps a function to add behavior. `@timer` above `def work():` is the same as `work = timer(work)`. Common ones are `@property`, `@staticmethod` and `@lru_cache`.
what is a generator in python | yield python | generator function => A function with `yield` is a generator: it gives values one at a time and pauses between them, so it uses little memory for long sequences.
what is a generator expression | parentheses comprehension python | lazy list python => `(n * n for n in range(1000000))` is like a list comprehension but makes values only when needed, so it uses almost no memory. `sum(n for n in nums)` uses one.
what is an iterator in python | iterable vs iterator | how does a for loop work python => An iterable is anything you can loop over (lists, strings, dicts). Python calls `iter()` on it to get an iterator, then `next()` until StopIteration ends the loop.
what are type hints in python | type annotations python | def f(x: int) -> str => Type hints show what types are expected: `def area(w: float, h: float) -> float:`. Python does not enforce them, but editors and tools like mypy use them to catch bugs.
what is mypy | type checking python | check types python => mypy is a tool that reads your type hints and reports type mistakes without running the code. Install it with `pip install mypy` and run `mypy file.py`.
what is a try except in python | handle errors python | try except syntax => Put risky code in `try:` and handle errors in `except ValueError:`. The program keeps going instead of crashing. Catch specific errors, not everything.
what is finally in python | try finally | code that always runs python => A `finally:` block runs after try and except no matter what, even if there was an error, so it is used for cleanup like closing things.
what is else in a try block | try except else python | try else => A `try` can have `else:` that runs only if no error happened. It keeps the try block small.
how do i raise an error in python | raise exception python | throw error python => `raise ValueError("age must be positive")`. It stops the function and can be caught with try/except.
how do i make my own exception python | custom exception python | exception class => `class OutOfCoins(Exception): pass` then `raise OutOfCoins("not enough coins")`.
what is assert in python | assert statement python | python assert => `assert x > 0, "x must be positive"` raises AssertionError if the condition is False. It is for catching bugs while developing, not for checking user input.
what is a traceback in python | read a python error | how to read error messages python => A traceback shows the chain of calls that led to the error. Read from the bottom: the last line is the error type and message, and the line above it is where it happened.
how do i print without a new line in python | print end python | print on same line => `print("Loading", end="")` stops the newline. `end=" "` puts a space instead.
how do i print several things with a separator | print sep python | print with commas => `print(a, b, c, sep=", ")` prints the values with ", " between them.
how do i round to 2 decimals in python | round decimals python | 2 decimal places python => `round(3.14159, 2)` gives 3.14. To show 2 decimals as text, use `f"{x:.2f}"`.
how do i format a number with commas in python | thousands separator python | 1,000 python => `f"{1234567:,}"` gives "1,234,567".
how do i pad a number with zeros python | leading zeros python | 001 python => `f"{7:03}"` gives "007", or `str(7).zfill(3)`.
how do i get the current date in python | today's date python | datetime now => `from datetime import date` then `date.today()`. For date and time, `datetime.now()` from `from datetime import datetime`.
how do i format a date in python | strftime python | date to string python => `now.strftime("%Y-%m-%d %H:%M")` gives something like "2025-06-01 14:30". %Y year, %m month, %d day, %H hour, %M minute.
how do i measure how long code takes python | time code python | timing a function => `start = time.perf_counter()`, run the code, then `print(time.perf_counter() - start)`. The timeit module is good for tiny snippets.
how do i pause a python program | sleep python | wait in python => `import time` then `time.sleep(2)` pauses for 2 seconds.
how do i exit a python program | quit python script | stop program python => Use `sys.exit()` after `import sys`. In the shell, `exit()` or Ctrl+D (Ctrl+Z then Enter on Windows) works.
how do i stop a running python program | ctrl c python | stop an infinite loop python => Press Ctrl+C in the terminal. It raises KeyboardInterrupt, which stops the program.
how do i clear the screen in python | clear terminal python | cls python => `os.system("cls" if os.name == "nt" else "clear")` clears the terminal on Windows and on macOS or Linux.
how do i make a random password in python | secrets module python | secure random python => Use the secrets module for anything secure: `"".join(secrets.choice(string.ascii_letters + string.digits) for _ in range(12))`. random is not safe for passwords.
how do i sort a list of dictionaries python | sort by key python | sort objects by field => `sorted(players, key=lambda p: p["score"], reverse=True)` sorts by score from highest to lowest.
how do i remove duplicates from a list python | unique items list python | dedupe a list => `list(set(items))` removes duplicates but loses order. `list(dict.fromkeys(items))` keeps the original order.
how do i flatten a list of lists python | flatten nested list | combine lists python => `[x for row in grid for x in row]` turns `[[1, 2], [3]]` into `[1, 2, 3]`.
how do i count items in a list python | count occurrences python => `items.count("a")` counts one value. `collections.Counter(items)` counts every value at once.
how do i find the index of an item python | position of item in list => `items.index("b")` gives its position, but raises ValueError if missing, so check `if "b" in items` first.
how do i make a list of numbers python | list of range python | numbers 1 to 100 list => `list(range(1, 101))` gives the numbers 1 to 100.
how do i add two lists together python | combine two lists python | merge lists => `a + b` makes a new combined list, and `a.extend(b)` adds b's items into a.
how do i get the last item of a list python | last element python | list -1 => `items[-1]` is the last item, `items[-2]` the second to last.
how do i check if a list is empty python | empty list check => `if not items:` is True for an empty list. `if items:` is True when it has something.
how do i make a copy of a list python | duplicate a list python | clone list python => `new = old.copy()` or `new = old[:]`. For lists inside lists, use `copy.deepcopy(old)`.
how do i convert a list to a string python | list to text python | join list python => `", ".join(names)` joins strings. For numbers, `", ".join(str(n) for n in nums)`.
string to list of characters | split string into list => `list("abc")` gives each character, and `"a b c".split()` gives a list of words.
how do i check if a string is a number python | is numeric python | validate number input => `s.isdigit()` works for positive whole numbers. For decimals and negatives, try `float(s)` inside try/except ValueError.
how do i check the python version | python version command | which python do i have => Run `python --version` (or `python3 --version`) in a terminal, or `import sys; print(sys.version)` in code.
what is the latest python version | newest python | python 3.13 => As of 2025, Python 3.13 and 3.14 are the newest releases. Anything 3.10 or newer is fine for learning.
what is pep 8 | python style guide | how should python code look => PEP 8 is Python's style guide: 4 spaces per indent, snake_case for functions and variables, CapWords for classes, and lines kept short. Tools like black and ruff format code to match.
what is a python ide | best editor for python | where should i write python => VS Code with the Python extension and PyCharm are popular. IDLE comes with Python and is fine for beginners. Thonny is made for learners.
what is jupyter notebook | ipynb file | python notebook => Jupyter notebooks (.ipynb) mix code cells, output and notes in one page, popular for data science. You can open them in VS Code or with `pip install notebook`.
what is pygame | make games in python | pygame basics => Pygame is a library for making 2D games in Python. Install with `pip install pygame`, then you write a loop that handles events, updates the game and draws each frame.
how does a pygame game loop work | pygame loop | pygame event loop => Each frame: loop through `pygame.event.get()` (quit when you see pygame.QUIT), update positions, draw with `screen.fill()` and `screen.blit()`, call `pygame.display.flip()`, and `clock.tick(60)` to cap at 60 FPS.
what is tkinter | python gui | make a window in python => Tkinter is Python's built-in GUI library. `root = tk.Tk()`, add widgets like `tk.Button(root, text="Hi").pack()`, then `root.mainloop()` to show the window.
what is the requests library | http requests python | download a web page python => requests makes web requests easy: `r = requests.get(url)` then `r.text` or `r.json()`. Install it with `pip install requests`.
how do i read json from an api in python | api call python | get json python => `data = requests.get(url, timeout=10).json()` gives Python dicts and lists. Check `r.status_code == 200` first.
what is flask | flask python | make a website with python => Flask is a small web framework. You write functions with `@app.route("/")` that return pages, then run `flask run` to start a local web server.
what is fastapi | fastapi python | make an api in python => FastAPI is a modern Python framework for building web APIs. You write functions with decorators like `@app.get("/items")`, it checks data with type hints, and it makes interactive docs at /docs. Run it with uvicorn.
what is django | django python | django vs flask => Django is a big "batteries included" web framework with a database layer, admin site and login system built in. Flask is smaller and you add pieces yourself.
what is numpy | numpy python | numpy arrays => NumPy gives fast arrays for math on lots of numbers at once, like `np.array([1, 2, 3]) * 2`. Much of data science and AI is built on it.
what is pandas | pandas python | dataframes python => pandas handles tables of data (DataFrames) like a spreadsheet in code: read a CSV with `pd.read_csv("file.csv")`, then filter, sort and summarize it.
what is matplotlib | make a graph in python | plot python => matplotlib draws charts: `import matplotlib.pyplot as plt`, `plt.plot(xs, ys)`, then `plt.show()`.
what is opencv | opencv python | computer vision python => OpenCV (`pip install opencv-python`, imported as cv2) reads images and camera video and has tools for things like edge detection and face detection.
what is pyserial | talk to arduino from python | serial port python => pyserial (`pip install pyserial`, imported as serial) talks to serial devices: `ser = serial.Serial("COM3", 9600)`, then `ser.write(b"1")` and `ser.readline()`.
what is pyinstaller | turn python into an exe | make python app executable => PyInstaller bundles your script and Python into an app: `pip install pyinstaller` then `pyinstaller --onefile app.py`. The result is in the dist folder.
what is asyncio | async await python | asynchronous python => asyncio lets one program wait on many slow things (like network calls) at the same time. Write `async def` functions, `await` slow calls, and start with `asyncio.run(main())`.
what is threading in python | threads python | run two things at once python => The threading module runs functions in parallel threads, good for waiting on files or the network. Because of the GIL, threads do not speed up heavy math; use multiprocessing for that.
what is the gil | global interpreter lock | why is python slow with threads => The GIL (Global Interpreter Lock) lets only one thread run Python code at a time in standard CPython, so threads do not speed up CPU-heavy work. Python 3.13 added an optional free-threaded build without it.
what is multiprocessing in python | use all cpu cores python | process pool => The multiprocessing module runs code in separate processes, each with its own Python, so CPU-heavy work can use several cores at once.
is python slow | why is python slower than c++ | python speed => Python is slower than compiled languages like C++ because it is interpreted and very flexible. Libraries like NumPy run their heavy parts in fast C code, which helps a lot.
what is cpython | python implementations | pypy => CPython is the standard Python from python.org, written in C. PyPy is another version with a just-in-time compiler that can run some programs much faster.
what is a .pyc file | __pycache__ folder | compiled python files => Python saves compiled bytecode in .pyc files inside `__pycache__` so modules load faster next time. It is safe to delete; Python makes them again.
what is the walrus operator | := in python | assignment expression => `:=` assigns inside an expression: `while (line := f.readline()):` reads and checks in one go. It was added in Python 3.8.
what is match case in python | switch statement python | match statement => Python 3.10 added `match value:` with `case 1:`, `case "quit":` and `case _:` (the default). It is Python's version of a switch, and it can also match shapes of data.
what is the ternary operator in python | one line if else python | conditional expression => `label = "even" if n % 2 == 0 else "odd"`.
what is a context manager in python | __enter__ __exit__ | with statement custom => A context manager sets something up and cleans it up in a `with` block. Files are one; you can make your own with `__enter__` and `__exit__` or `@contextlib.contextmanager`.
what is recursion depth in python | recursionerror maximum recursion depth | too much recursion python => Python stops a function that calls itself too deeply (about 1000 levels by default) with RecursionError. Add a base case, or rewrite it as a loop.
what is pickle in python | save objects to file python | pickle module => pickle saves almost any Python object to a file with `pickle.dump(obj, f)` and loads it with `pickle.load(f)` (open files in "wb" and "rb"). Never unpickle files from people you do not trust.
what is argparse | command line arguments python | parse arguments => argparse reads options typed after your script, like `python app.py --name Sam`. `parser.add_argument("--name")` then `args = parser.parse_args()` gives `args.name`.
what is logging in python | logging vs print | python logging module => The logging module prints messages with levels like DEBUG, INFO, WARNING and ERROR, and can write to files. `logging.basicConfig(level=logging.INFO)` then `logging.info("started")`.
how do i make a simple calculator in python | python calculator project | beginner python project ideas => Read two numbers and an operator with input(), use if/elif to pick +, -, * or /, and print the result. Other good first projects are a number guessing game, a to-do list, and a dice roller.
how do i make a number guessing game in python | guess the number python | guessing game code => Pick `secret = random.randint(1, 100)`, then loop: read a guess with `int(input())`, say "higher" or "lower", and break when they get it right.
how do i read a csv file in python | open csv python | csv reader => `import csv`, then `with open("data.csv", newline="") as f:` and `for row in csv.reader(f): print(row)`. Each row is a list of strings.
how do i list files in a folder python | get all files in a directory python | glob python => `os.listdir("folder")` gives names, and `glob.glob("folder/*.png")` finds files matching a pattern. `pathlib.Path("folder").glob("*.png")` does the same with Path objects.
how do i check if a file exists python | file exists check | os path exists => `os.path.exists("file.txt")` or `Path("file.txt").exists()` returns True if it is there.
how do i get the folder my script is in python | script directory python | __file__ python => `Path(__file__).parent` is the folder that holds the running script, so `Path(__file__).parent / "data.txt"` works no matter where you run it from.
file path of script | __file__ variable => `__file__` is the path of the Python file that is running. Use it to find files next to your script.
how do i run a shell command from python | run terminal command python | call a program from python => `subprocess.run(["ls", "-l"], capture_output=True, text=True)` runs it and gives you its output in `.stdout`.
how do i make python wait for enter | press enter to continue python | pause until key => `input("Press Enter to continue...")` waits until the user presses Enter.
how do i check what type a variable is python | isinstance vs type => `type(x)` shows the type. To check in an if, use `isinstance(x, int)`, which also accepts subclasses.
how do i convert between types in python | type conversion python | casting python => Use the type as a function: `int("5")`, `float("2.5")`, `str(10)`, `list("abc")`, `bool(0)`. Converting bad text raises ValueError.
what is an integer overflow in python | how big can numbers get python | python big numbers => Python integers have no size limit; they grow as big as memory allows, so `2 ** 1000` works fine. Floats do have limits.
what is the difference between append and extend | append vs extend python | add list to list => append adds its argument as one item, so `[1].append([2, 3])` gives `[1, [2, 3]]`. extend adds each item, giving `[1, 2, 3]`.
what is the difference between sort and sorted | sort vs sorted python | sorted returns => `list.sort()` sorts the list in place and returns None. `sorted(x)` returns a new sorted list and works on any iterable.
what is the difference between remove pop and del | remove vs pop vs del python | delete from list => `remove(x)` deletes by value, `pop(i)` deletes by index and returns the item, and `del items[i]` deletes by index (or a slice) without returning it.
what is an index out of range | list index out of range meaning | why index out of range => It means you asked for a position the list does not have, like `items[5]` on a 3-item list. Indexes go from 0 to `len(items) - 1`.
