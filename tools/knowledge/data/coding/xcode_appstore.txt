# Xcode, TestFlight and the App Store, written by hand for Ace.
# tag: coding.xcode
what is xcode | what is xcode used for | do i need xcode => Xcode is Apple's free app for building apps for iPhone, iPad, Mac, Watch, TV and Vision Pro. It has the code editor, SwiftUI previews, simulators, debugger and tools to upload to the App Store. It only runs on a Mac.
how do i get xcode | download xcode | install xcode => Download Xcode free from the Mac App Store, or from developer.apple.com for beta versions. It is big, so make sure you have plenty of free disk space.
can xcode run on windows | xcode on ipad | xcode without a mac => No. Xcode only runs on macOS. On iPad, Swift Playgrounds can build SwiftUI apps; on Windows people use a Mac in the cloud or borrow a Mac.
how do i make a new project in xcode | create ios app xcode | start a swiftui project => Choose File > New > Project, pick iOS (or Multiplatform) App, give it a name and organization identifier, and choose SwiftUI as the interface.
what is a bundle identifier | bundle id ios | com.name.app => The bundle identifier, like `com.storm.ace`, is your app's unique ID. It must be unique on the App Store and cannot change after you publish.
what is a target in xcode | xcode targets | app target vs extension => A target is one thing Xcode builds, like your app, a widget extension or a test bundle. Each has its own settings and files.
what is a scheme in xcode | edit scheme xcode | xcode scheme explained => A scheme says which target to build and how to run, test and archive it. Edit it from Product > Scheme > Edit Scheme to change settings like launch arguments.
how do i run my app in the simulator | xcode simulator | test app on fake iphone => Choose a simulator device at the top of the Xcode window and press Command+R. Command+. (period) stops it.
how do i run my app on my iphone or ipad | run on real device xcode | install my app on my phone => Connect the device, trust the computer, turn on Developer Mode in Settings > Privacy & Security, choose it in Xcode, and press Run. Add your Apple ID in Xcode settings under Accounts so it can sign the app.
what is developer mode on iphone | turn on developer mode | developer mode ipad => Developer Mode lets an iPhone or iPad run apps you install from Xcode. Turn it on in Settings > Privacy & Security > Developer Mode, then restart. It shows up after you connect to Xcode once.
do i need to pay to test on my iphone | free apple developer account | personal team xcode => No. A free Apple ID can run your apps on your own devices, but they expire after 7 days and some features are limited. You need the paid program to use TestFlight or the App Store.
how much is the apple developer program | apple developer cost | developer account price => As of 2025, the Apple Developer Program costs 99 US dollars per year. You must be 18 or older to enroll, so a parent or guardian enrolls for a younger developer.
what are the most useful xcode shortcuts | xcode keyboard shortcuts | xcode shortcuts list => Command+R run, Command+B build, Command+. stop, Command+Shift+K clean build folder, Command+Shift+O open quickly, Command+/ comment lines, Ctrl+I re-indent, Option+Command+Return show the preview canvas.
how do i comment out code in xcode | command slash xcode | toggle comment xcode => Select the lines and press Command+/ to comment or uncomment them.
how do i fix indentation in xcode | reindent xcode | format code xcode => Select the code and press Ctrl+I to re-indent it. Newer Xcode versions can also format with swift-format from the Editor menu.
how do i find a file in xcode | open quickly xcode | jump to file xcode => Press Command+Shift+O and type part of a file, type or function name.
how do i rename a variable everywhere in xcode | refactor rename xcode | rename symbol => Right-click the name and choose Refactor > Rename, or put the cursor on it and press Ctrl+Command+E to edit all uses in the file.
how do i search my whole project in xcode | find in project | search all files xcode => Press Command+Shift+F to search every file in the project.
what is clean build folder | xcode clean build | weird xcode errors fix => Product > Clean Build Folder (Command+Shift+K) deletes old build files. It fixes many strange errors after big changes.
what is derived data in xcode | delete derived data | xcode derived data folder => Derived Data is where Xcode keeps builds and indexes. Deleting it (in ~/Library/Developer/Xcode/DerivedData) forces a fresh build and can fix stuck builds or previews.
how do i use breakpoints in xcode | debug in xcode | pause app in xcode => Click a line number to add a blue breakpoint. When the app hits it, it pauses, and you can look at variables, step with F6 (over) and F7 (into), and type `po value` in the console.
what is po in the xcode console | lldb commands | print variable debugger => In the debugger console, `po x` prints an object's description and `p x` prints its value. `v x` reads a variable quickly without running code.
what is the view debugger | debug view hierarchy | ui layers xcode => While running, click Debug View Hierarchy to see your app's screens as 3D layers, which helps find hidden or misplaced views.
what are instruments | xcode instruments | profile ios app => Instruments (Product > Profile, Command+I) measures your app's speed, memory, leaks and energy use. Time Profiler shows which functions take the most time.
what is the memory graph | find memory leaks xcode | debug memory graph => The Debug Memory Graph button pauses the app and shows objects in memory and what holds them, which helps find retain cycles.
what is info.plist | info plist ios | app settings plist => Info.plist holds app settings like display name, permissions messages and supported orientations. Many are also editable in the target's Info tab.
how do i ask for camera permission ios | nscamerausagedescription | privacy permission message => Add the matching privacy key in the Info tab, like Privacy - Camera Usage Description, with a sentence explaining why. The app crashes if it asks for the permission without one.
what are capabilities in xcode | signing and capabilities | add icloud to app => In the target's Signing & Capabilities tab, click + Capability to add features like iCloud, Push Notifications, Game Center or HealthKit.
what is code signing | provisioning profile | signing certificate xcode => Code signing proves an app comes from you and was not changed. Turning on "Automatically manage signing" with your team selected lets Xcode handle certificates and profiles.
what does no signing certificate found mean | signing error xcode | failed to register bundle identifier => Xcode cannot sign the app. Add your Apple ID in Settings > Accounts, pick your team in Signing & Capabilities, and change the bundle ID if someone else already uses it.
what is the asset catalog | assets.xcassets | add images to xcode => Assets.xcassets stores images, colors and the app icon. Drag images in, then use them by name, like `Image("logo")`.
how do i add a file to my xcode project | drag files into xcode | add swift file xcode => Use File > New > File (Command+N) for new Swift files, or drag files into the Project navigator and tick your target so they get included.
what is a swift package in xcode | add dependency xcode | package dependencies => Packages are libraries you add with File > Add Package Dependencies. They show up under Package Dependencies in the navigator.
what is the minimum deployment target | ios deployment target | which ios version to support => The deployment target is the oldest OS version your app supports. Newer APIs like @Observable need iOS 17, so choose based on the features you need.
what does is only available in ios 17 or newer mean | available ios version error => You used an API newer than your deployment target. Raise the target or wrap it in `if #available(iOS 17, *) { }`.
what is a build configuration | debug vs release | release build xcode => Debug builds include extra checks and are easy to debug. Release builds are optimized and are what you ship. Archive uses Release by default.
how do i archive my app | product archive xcode | upload app to app store connect => Choose Any iOS Device as the destination, then Product > Archive. When it finishes, the Organizer opens; click Distribute App to upload to App Store Connect.
what is app store connect | appstoreconnect | where to publish ios apps => App Store Connect (appstoreconnect.apple.com) is where you create your app's listing, upload builds, set prices, manage TestFlight and submit for review.
what is testflight | testflight beta testing | share my app with friends => TestFlight lets people install beta versions of your app. Internal testers on your team get builds right away; external testers need a quick Beta App Review first. Builds expire after 90 days.
how do i add testflight testers | invite testers testflight | public testflight link => In App Store Connect open TestFlight, make a group, and add testers by email or turn on a public link. Testers install the TestFlight app to get your build.
what is app review | how long does app review take => Apple reviews every App Store app against the App Review Guidelines. Most reviews finish within a day or two, but it can take longer, and rejections come with reasons you can fix.
app store rejection reasons | guideline 4.2 minimum functionality => Common reasons are crashes, broken features, missing privacy info, placeholder content, or an app that is too simple (guideline 4.2). Read the message, fix it, and reply or resubmit.
what do i need to submit an app | app store submission checklist | publish ios app requirements => You need a paid developer account, an app icon, screenshots for required device sizes, a description, a privacy policy URL, the App Privacy details, an age rating, and a build uploaded from Xcode.
what is the app privacy label | privacy nutrition label | app privacy details => App Store Connect asks what data your app collects and how it is used, and shows that as a privacy label on your App Store page. Answer it honestly.
what is a privacy manifest | privacyinfo.xcprivacy | required reason api => A privacy manifest (PrivacyInfo.xcprivacy) lists the data your app and its SDKs collect and why it uses certain APIs, like UserDefaults. Apple requires it for many apps and SDKs.
how many screenshots do i need app store | app store screenshot sizes | screenshots for iphone and ipad => You need screenshots for the largest iPhone size and, if your app runs on iPad, the largest iPad size. App Store Connect scales them for smaller devices. Simulator screenshots work.
how do i take a screenshot in the simulator | simulator screenshot | save simulator screen => Press Command+S in the Simulator to save a screenshot to the desktop.
what is an app version vs build number | cfbundleversion | version and build xcode => The version (like 1.2) is what users see. The build number must go up for every upload of that version, like 1, 2, 3.
what does redundant binary upload mean | build number already used | upload failed same build => You uploaded a build number that was already used for that version. Increase the build number in the target's General tab and archive again.
how do i make my app free or paid | app pricing app store | set app price => Set the price in App Store Connect under Pricing and Availability. Free apps can still sell in-app purchases.
what is an in app purchase | iap ios | sell things in my app => In-app purchases let users buy things inside the app, like extra levels or coins. Set them up in App Store Connect and use StoreKit in your code.
what is storekit | storekit 2 | storekit swift => StoreKit is Apple's framework for in-app purchases and subscriptions. StoreKit 2 uses async/await, like `try await product.purchase()`.
how much does apple take from app sales | app store commission | apple 30 percent => As of 2025, Apple usually keeps 30% of paid apps and in-app purchases, or 15% for developers in the App Store Small Business Program, which covers developers earning under 1 million US dollars a year.
what is a storekit configuration file | test purchases xcode | sandbox testing iap => A StoreKit configuration file lets you test purchases in Xcode without App Store Connect. Sandbox accounts test real purchase flows on devices with no charge.
how do i make my app work on iphone and ipad | universal app | supported destinations xcode => In the target's General tab, add both iPhone and iPad under Supported Destinations. Then make your layout adapt with size classes and NavigationSplitView.
how do i make my app run on mac | mac catalyst | designed for ipad on mac => Add a Mac destination: native macOS with SwiftUI, Mac Catalyst, or "Designed for iPad" which runs the iPad app on Apple silicon Macs.
what is a crash log | crash reports xcode | find why my app crashed => Xcode's Organizer shows crash reports from TestFlight and App Store users. In the debugger, the red line and console message show where a crash happened.
what does build succeeded but app crashes mean | app crashes on launch | crash at startup ios => Look at the console and the highlighted line in Xcode. Common causes are force-unwrapping nil, a missing permission message in Info.plist, or a missing environment object.
what does command swiftcompile failed mean | swiftcompile failed with nonzero exit code | xcode build failed => The Swift compiler hit an error. Open the Issue navigator (Command+5) to see the real error message above it.
what does module not found xcode mean | no such module | no such module swift => Xcode cannot find that framework or package. Make sure the package is added and linked to your target, then clean the build folder.
what does could not launch the app mean | could not attach to pid | app will not install on iphone => Try unplugging and replugging, unlocking the device, trusting the computer, checking Developer Mode is on, and restarting Xcode and the device.
what does unable to install app mean | app installation failed | could not install app ios => Often the device's iOS is older than the deployment target, storage is full, or signing failed. Read the details in the error, and check the deployment target.
what does the simulator is slow mean | simulator lag | simulator performance => The simulator uses your Mac's CPU and graphics, so it can be slow for games. Close other apps, use a simpler device, or test on a real device.
ci for ios | automatic builds xcode => Xcode Cloud is Apple's service that builds, tests and sends your app to TestFlight automatically when you push code. It includes some free hours with the developer program.
what is a unit test in xcode | xctest => Unit tests check small parts of your code automatically. Newer projects use Swift Testing with `@Test` functions and `#expect(...)`; older ones use XCTest with `XCTAssertEqual`. Run them with Command+U.
what is a ui test | xcuitest | automate taps test => UI tests launch your app and tap buttons automatically to check screens work, using XCUIApplication.
what is git in xcode | source control xcode | commit in xcode => Xcode has Git built in. Use the Source Control navigator to commit, branch and push, or Integrate > Commit (Option+Command+C).
what is a .gitignore for xcode | ignore xcuserdata | what to ignore in xcode git => Ignore folders like `xcuserdata/`, `DerivedData/` and `.DS_Store`, which are personal or temporary.
what is the apple developer documentation | apple docs | where to learn swiftui => Apple's documentation at developer.apple.com has every API, plus guided tutorials like "Develop in Swift" and the SwiftUI tutorials.
what is wwdc | apple developer conference | wwdc videos => WWDC is Apple's yearly developer conference, usually in June, where new versions of iOS, Swift and SwiftUI are announced. Its session videos are free in the Developer app.
what is a beta version of xcode | xcode beta | should i use xcode beta => Betas let you try new iOS features early. They can be buggy, and you cannot submit App Store apps built with a beta Xcode, so keep the release version installed too.
what is the app sandbox | sandbox ios | why cant my app read other files => Each iOS app runs in its own sandbox and can only read its own files, plus what the user shares with it, like through a document picker.
what is a document based app | documentgroup swiftui | files app support => DocumentGroup in SwiftUI makes an app that opens and saves documents through the Files app, like a drawing or text editor.
cloudkit | sync data between devices swift => CloudKit stores data in iCloud. SwiftData can sync automatically through CloudKit when you turn on the iCloud capability and a container.
what is push notifications ios | send notifications to my app => Push notifications come from a server through Apple Push Notification service (APNs). For reminders that do not need a server, use local notifications with UNUserNotificationCenter.
how do i make a local notification ios | schedule notification swift | reminder notification => Ask permission with `UNUserNotificationCenter.current().requestAuthorization`, then add a UNNotificationRequest with content and a trigger like UNTimeIntervalNotificationTrigger.
what is game center | gamekit | leaderboards ios game => Game Center (GameKit) adds leaderboards, achievements and multiplayer to Apple games. Turn on the Game Center capability and set leaderboards up in App Store Connect.
what is an app clip | app clips ios | small part of an app => An App Clip is a tiny part of an app that opens instantly from a link, QR code or NFC tag, without installing the full app.
what is the human interface guidelines | hig apple | apple design rules => The Human Interface Guidelines are Apple's design advice for making apps feel at home on each platform: layout, typography, controls, accessibility and more.
