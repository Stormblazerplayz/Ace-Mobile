# Even more C++: Unreal, game code, templates, memory and comparisons, written by hand for Ace.
# tag: coding.cpp.more
what is uclass | uclass macro | unreal uclass => `UCLASS()` above a class tells Unreal's reflection system about it, so the editor, Blueprints and garbage collector can see it. It pairs with `GENERATED_BODY()` inside.
what is uproperty | uproperty macro | unreal uproperty => `UPROPERTY(EditAnywhere)` above a member lets you see and edit it in the Unreal editor. Other specifiers like BlueprintReadWrite expose it to Blueprints.
what is ufunction | ufunction macro | blueprintcallable => `UFUNCTION(BlueprintCallable)` above a function lets Blueprints call it. UFUNCTION is also needed for functions bound to some events.
what is generated_body | generated_body unreal | unreal generated body => `GENERATED_BODY()` goes inside every UCLASS or USTRUCT. Unreal's header tool fills it with generated code, so the file must include its .generated.h header last.
what is an actor in unreal | aactor | unreal actor => An Actor (AActor) is anything you can place in an Unreal level, like a door or enemy. Its `BeginPlay` runs when the game starts and `Tick` runs every frame if enabled.
what is a pawn and character in unreal | apawn vs acharacter | unreal character class => A Pawn is an Actor a player or AI can control. ACharacter is a Pawn with a capsule, skeletal mesh and walking movement built in.
what is a component in unreal | uactorcomponent | unreal components => Components add abilities to Actors, like a static mesh, a light, a collision box or your own UActorComponent with custom logic.
what is tick in unreal | unreal tick function | deltaseconds unreal => `Tick(float DeltaSeconds)` runs every frame for Actors with ticking enabled. Multiply movement by DeltaSeconds so it is smooth at any frame rate.
what is beginplay | beginplay unreal | unreal start function => `BeginPlay()` runs once when an Actor enters play, like Start in other engines. Call `Super::BeginPlay()` first when you override it.
what is ue_log | unreal print | print to log unreal => `UE_LOG(LogTemp, Warning, TEXT("Hi %d"), Score);` writes to the Output Log. `GEngine->AddOnScreenDebugMessage` prints on screen.
what is text macro unreal | text() unreal | why text in unreal => `TEXT("...")` makes a wide-character string literal that Unreal's string types expect.
what is fstring | fstring unreal | fname vs ftext => FString is Unreal's normal editable string. FName is a fast, unchanging name used for identifiers, and FText is for text shown to players and translated.
what is tarray | tarray unreal | unreal array => TArray is Unreal's dynamic array, like std::vector: `TArray<int32> Scores; Scores.Add(10);`. TMap and TSet are its map and set.
what is int32 in unreal | unreal integer types | uint8 unreal => Unreal uses fixed-size types like int32, uint8 and int64 so sizes are the same on every platform.
what is a blueprint | blueprints vs c++ | unreal visual scripting => Blueprints are Unreal's visual scripting with nodes and wires. Many teams write core systems in C++ and use Blueprints for quick gameplay tweaks.
what is live coding in unreal | hot reload unreal | unreal live coding => Live Coding lets you recompile C++ while the Unreal editor is open with Ctrl+Alt+F11. Changes to headers and new UPROPERTYs often still need a full restart.
how do i start unreal c++ | unreal c++ beginner | learn unreal c++ => Install Unreal and Visual Studio (Windows) or Xcode (Mac), make a C++ project from a template, and start by adding a C++ Actor class with a UPROPERTY and some Tick code.
what is a game object in c++ | entity class c++ | game entity => Many C++ games have a base class like Entity with position, update and draw functions, and subclasses for the player and enemies. Others use entity component systems.
what is an entity component system | ecs | ecs c++ => An ECS stores entities as IDs, data as components (like Position or Health) and logic in systems that loop over matching components. It is fast and flexible; EnTT is a popular C++ library.
how do i store many enemies in c++ | vector of enemies | list of objects c++ => Use `std::vector<Enemy> enemies;` for plain objects, or `std::vector<std::unique_ptr<Enemy>>` if you need subclasses with virtual functions.
how do i remove dead enemies from a vector | erase if c++ | remove objects while looping c++ => Do not erase inside a range-for loop. After updating, call `std::erase_if(enemies, [](const Enemy& e) { return e.dead; });` (C++20).
what is std::erase_if | erase_if | c++20 erase_if => `std::erase_if(container, pred)` (C++20) removes every element for which pred returns true, and works for vectors, maps and more.
how do i make a 2d vector math class c++ | vector2 struct c++ | vec2 c++ => Make `struct Vec2 { float x, y; };` and overload `+`, `-` and `*` as functions, plus a `length()` using `std::sqrt(x * x + y * y)`.
how do i check collision between rectangles in c++ | aabb collision | rectangle overlap c++ => Two axis-aligned boxes overlap when `a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y`.
how do i check collision between circles c++ | circle collision | distance collision c++ => Two circles touch when the distance between centers is less than the sum of their radii. Compare squared distances to skip the square root.
how do i load an image in sfml | sfml texture | sfml sprite => Load a `sf::Texture` from a file with `loadFromFile`, then make an `sf::Sprite` from it and `window.draw(sprite)` each frame.
how do i make a window in sfml | sfml window | sfml hello => Make an `sf::RenderWindow`, then loop while it is open: poll events, `window.clear()`, draw, and `window.display()`.
how do i make a window in raylib | raylib window | raylib hello => `InitWindow(800, 450, "Game"); while (!WindowShouldClose()) { BeginDrawing(); ClearBackground(RAYWHITE); EndDrawing(); } CloseWindow();`.
how do i get keyboard input in raylib | iskeydown raylib | raylib input => `IsKeyDown(KEY_RIGHT)` is true while a key is held and `IsKeyPressed(KEY_SPACE)` only on the frame it is pressed.
what is sdl | sdl2 sdl3 | simple directmedia layer => SDL is a C library for windows, input, audio and 2D drawing that works on most platforms and is used by many engines. SDL3 is the newest major version.
what is opengl in c++ | glfw | glad => To use OpenGL from C++ you usually use GLFW (or SDL) to make a window and GLAD to load OpenGL functions, then write shaders in GLSL.
what is glm | glm math | math library graphics c++ => GLM is a header-only C++ math library that matches OpenGL's shader math, with vec3, mat4 and functions like `glm::rotate`.
what is a template class | class template c++ | template struct => A class template like `template <typename T> class Box { T value; };` lets one class work with any type: `Box<int>` and `Box<std::string>`.
what is template specialization | specialize template c++ | template<> => Specialization gives a different version of a template for one type, like `template <> void print<bool>(bool b)`.
what is sfinae | substitution failure | enable_if => SFINAE is an older trick where templates that fail to compile for a type are quietly skipped. C++20 concepts do the same job much more clearly.
what is a type trait | type_traits | std is_integral => Type traits in `<type_traits>` answer questions about types while compiling, like `std::is_integral_v<T>` or `std::is_same_v<A, B>`.
what is auto return type | auto function c++ | deduced return type => A function declared `auto f()` lets the compiler deduce the return type from the return statement.
what is a trailing return type | -> in function declaration c++ | auto f() -> int => `auto add(int a, int b) -> int` puts the return type after the parameters. It is handy when the type depends on the parameters.
what is uniform initialization | braces everywhere c++ | list initialization => Using braces like `Player p{"Sam", 100};` works for almost every type and prevents narrowing conversions.
what is an aggregate | aggregate initialization | designated initializers => A simple struct with public members can be filled with braces in order, `Point p{1, 2};`, or by name in C++20: `Point p{.x = 1, .y = 2};`.
what is a spaceship operator | three way comparison c++ | c++20 spaceship operator => The spaceship operator, written as less-than, equals and greater-than together, compares two values in one step (C++20). Declaring it with `= default` in a class gives you all six comparison operators at once.
what is std::source_location | source_location | current line c++ => `std::source_location::current()` (C++20) gives the file, line and function name, handy for logging.
what is std::expected | expected c++23 | return error without exception => `std::expected<int, std::string>` (C++23) holds either a value or an error, a clear way to return failures without exceptions.
what is std::print | print c++23 | std println => `std::print("Score: {}\n", score);` and `std::println` (C++23) print formatted text directly, like `std::format` plus cout.
what is std::jthread | jthread | joining thread c++20 => `std::jthread` (C++20) is a thread that joins automatically when destroyed and supports stop requests, so you cannot forget to join it.
what is std::atomic | atomic c++ | atomic counter => `std::atomic<int> count;` can be safely changed by many threads at once without a mutex, for simple values like counters and flags.
what is std::async | async c++ | std future => `auto f = std::async(std::launch::async, work);` runs work on another thread, and `f.get()` waits for the result.
what is a condition variable | std condition_variable | wait for signal c++ => A condition variable lets one thread sleep until another thread signals that something is ready, used with a mutex.
what is a deadlock in c++ | lock order | two mutexes deadlock => A deadlock happens when two threads each hold a lock the other needs. Lock in the same order everywhere, or use `std::scoped_lock` to lock several at once.
what is std::filesystem | filesystem c++ | list files c++ => `<filesystem>` (C++17) works with files and folders: `std::filesystem::exists(p)`, `create_directory`, and `directory_iterator` to list a folder.
how do i list files in a folder in c++ | directory_iterator | files in directory c++ => `for (const auto& entry : std::filesystem::directory_iterator("levels")) std::cout << entry.path() << "\n";`
how do i read a whole file into a string c++ | file to string c++ | read entire file => Open an `std::ifstream`, then `std::string text((std::istreambuf_iterator<char>(in)), std::istreambuf_iterator<char>());` or read it into a `std::stringstream` with `ss << in.rdbuf();`.
how do i read a csv file in c++ | csv c++ | parse csv c++ => Read each line with getline, then split it on commas with a stringstream and getline using ',' as the separator. Quoted fields need a real CSV library.
how do i write binary files in c++ | binary file c++ | ofstream binary => Open with `std::ios::binary` and use `out.write(reinterpret_cast<const char*>(&value), sizeof(value));`. Saving plain structs this way is not portable between machines.
how do i check if a file opened c++ | file open failed c++ | is_open => `if (!in) { /* failed */ }` or `if (!in.is_open())` after opening. Then check the path and the working directory.
why can't my program find my file c++ | working directory c++ | relative path not found => Relative paths start from the working directory, which IDEs often set to the build folder. Put the file there, use an absolute path, or change the run settings.
what is cin.ignore | cin ignore | clear input buffer c++ => `std::cin.ignore(n, '\n')` throws away up to n characters or until a newline, used to clear leftover input before getline.
how do i make a menu loop in c++ | console menu c++ | do while menu => Use a `do { show menu; read choice; switch (choice) { ... } } while (choice != 0);` loop so the menu repeats until the user quits.
how do i make a text adventure in c++ | text game c++ | console game c++ => Store rooms in a struct with a description and exits, keep the index of the room the player is in, read commands with getline, and use if or switch to move between rooms.
how do i make tic tac toe in c++ | tic tac toe c++ | noughts and crosses c++ => Store the board in `char board[3][3]`, print it each turn, read a row and column, check the cell is free, and check rows, columns and diagonals for a win.
how do i make a guessing game in c++ | number guessing c++ | guess the number c++ => Pick a random number with `<random>`, loop reading guesses with cin, say higher or lower, and count tries until it is right.
how do i make a class for a bank account c++ | bank account class | oop example c++ => Make the balance private, with public `deposit` and `withdraw` functions that check the amount is valid, and a `getBalance() const`.
how do i compare c++ and c# | c++ vs c# | c# or c++ => C# is easier, has garbage collection and is used by Unity and Godot. C++ is faster and lower level, used by Unreal and engines themselves.
how do i compare c++ and java | c++ vs java | java or c++ => Java runs on a virtual machine with garbage collection and is used for Android and Minecraft Java Edition. C++ compiles to native code and gives manual control over memory.
how do i compare c++ and rust | c++ vs rust | rust or c++ => Rust is a newer systems language that checks memory safety while compiling, preventing many bugs C++ allows. C++ has a much bigger existing ecosystem, especially in games.
how do i compare c++ and lua | c++ vs lua | lua and c++ together => Lua is a small, easy scripting language often embedded inside C++ games so designers can script behavior without recompiling. Roblox's Luau grew from Lua.
how do i compare c++ and python | python vs c++ | should i learn python or c++ => Python is easier and faster to write; C++ runs much faster and is used for games and hardware. Many people learn Python first, then C++.
what is c | c language | c vs c++ which first => C is the older, smaller language C++ grew from, with no classes or templates. It is used for operating systems, embedded devices and many libraries.
what is objective-c vs c++ | objective c++ | objc and c++ => Objective-C adds message-style objects to C and was Apple's main language before Swift. Objective-C++ (.mm files) mixes it with C++.
can swift call c++ | swift c++ interop | use c++ from swift => Since Swift 5.9, Swift can call many C++ APIs directly when C++ interoperability is turned on in the build settings.
what is webassembly c++ | emscripten | c++ in the browser => Emscripten compiles C++ to WebAssembly so it runs in web browsers at near-native speed. Raylib and SDL games can be built for the web this way.
what is a c++ game jam | game jam c++ | small game in c++ => A game jam is an event where you make a game in a short time, like a weekend. With C++, raylib is a quick choice for jams.
what is a memory pool | memory pool c++ | custom allocator => A memory pool grabs one big block of memory up front and hands out pieces of it, which is faster than many small `new` calls in games.
what is cache friendly code | data locality | why vectors are fast => CPUs read memory in chunks, so data stored together (like in a vector) is much faster to loop over than data scattered around (like a linked list of pointers).
what is a profiler for c++ | perf | visual studio profiler => A profiler shows which functions take the most time. Visual Studio, Xcode Instruments, perf on Linux and Tracy are popular for C++ and games.
what is valgrind | valgrind memcheck | find memory leaks linux => Valgrind runs your program and reports memory errors and leaks, mainly on Linux. It is slower than AddressSanitizer but needs no recompiling.
what is clang-tidy | clang tidy | c++ linter => clang-tidy checks C++ code for bugs and style problems and can fix some automatically. Many IDEs show its warnings as you type.
what is clang-format | format c++ code | c++ code formatter => clang-format automatically formats C++ code using rules in a .clang-format file, so everyone's code looks the same.
what is a precompiled header | pch | speed up c++ compile => A precompiled header compiles big headers once and reuses them, which makes large projects build much faster.
why does c++ take so long to compile | slow compile c++ | faster c++ builds => Headers get re-read for every .cpp file, and templates add work. Include only what you need, use forward declarations, precompiled headers and parallel builds.
forward declare class | class declaration only => `class Enemy;` tells the compiler a class exists without its details. You can then use `Enemy*` or `Enemy&` and include the full header only in the .cpp.
what is a circular include | headers include each other | circular dependency c++ => Two headers including each other causes errors. Break the loop with forward declarations and include the full headers in the .cpp files.
what is inline variable | inline variable c++17 | global in header => An `inline` variable (C++17) can be defined in a header included by many files without multiple definition errors.
what is std::exit vs return from main | exit vs return c++ | end program c++ => Returning from main cleans up local objects properly. `std::exit` ends immediately and skips local destructors, so prefer returning.
what is the main function with arguments | argc argv | command line arguments c++ => `int main(int argc, char* argv[])` receives command line arguments: argc is how many, argv holds them as C strings, and argv[0] is the program name.
what is system() in c++ | system command c++ | run command c++ => `std::system("command")` runs a shell command. It is slow, depends on the operating system and can be unsafe with user input.
what is a lookup table | lookup table c++ | precompute values => A lookup table stores precomputed answers in an array, like sine values, so the program reads them instead of calculating each time.
what is bit masking | bitmask c++ | flags with bits => Store several on/off flags in one integer: set with `flags |= FLAG`, clear with `flags &= ~FLAG`, and test with `flags & FLAG`.
what is endianness | big endian little endian | byte order => Endianness is the order bytes of a number are stored in memory. Most PCs, phones and Arduinos are little-endian; it matters for files and networks.
what is a struct padding | padding c++ | sizeof struct bigger => The compiler adds gaps between struct members so each is aligned, so `sizeof` can be bigger than the members added up. Ordering members from big to small reduces it.
what is volatile in c++ | volatile c++ | hardware registers volatile => `volatile` tells the compiler a value can change outside the program, like a hardware register or a variable changed in an interrupt, so it must reread it every time. It does not make threads safe.
what is a callback with void pointer | void pointer c++ | void* explained => `void*` is a pointer to anything, used in C libraries to pass user data. You must cast it back to the right type; templates and std::function are safer in C++.
what is a dangling else | dangling else | if without braces bug => Without braces, an `else` belongs to the nearest `if`, which can surprise you. Always use braces around if and else blocks.
why does my if run when it should not c++ | if semicolon bug | if (x); bug => A semicolon right after the condition, like `if (x > 5);`, ends the if, so the next block always runs. Remove the semicolon.
why does my while loop never end c++ | infinite loop c++ | while loop stuck => The condition never becomes false; check the variable changes inside the loop, and watch for `=` instead of `==` in the condition.
why does my program print weird numbers c++ | random numbers printed => You are probably reading an uninitialized variable or an array past its end. Initialize everything and check indexes.
why does integer division give 0 c++ | 1/2 is 0 c++ | divide ints get zero => Dividing two ints drops the decimal, so `1 / 2` is 0. Make one of them a double, like `1.0 / 2`, or use `static_cast<double>`.
why does my float comparison fail c++ | float equality c++ | compare doubles c++ => Floats have tiny rounding errors, so `==` often fails. Check if the difference is below a small amount, like `std::abs(a - b) < 1e-6`.
why does my char print as a number c++ | uint8_t prints character | char vs number output => `std::cout` prints char types (including uint8_t) as characters. Cast to int to see the number: `std::cout << int(c);`.
why is my vector empty after push_back in a function c++ | vector not changing | pass vector by reference => The function got a copy. Take the parameter by reference, `std::vector<int>& v`, so changes reach the caller's vector.
why does my program crash when i use a pointer c++ | pointer crash c++ | null pointer crash => The pointer is probably null, already deleted, or pointing to a local variable that went away. Initialize pointers to nullptr and check before using them.
why does my class not compile when i use it before defining it | incomplete class | order of classes c++ => C++ reads files top to bottom. Define or include a class before using its members, or forward declare it if you only need pointers or references.
