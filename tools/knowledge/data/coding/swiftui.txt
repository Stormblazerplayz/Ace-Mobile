# SwiftUI, written by hand for Ace.
# tag: coding.swiftui
swiftui explained | what is swiftui used for => SwiftUI is Apple's framework for building app screens by describing what they should look like in Swift code. It updates the screen for you when your data changes, and works on iPhone, iPad, Mac, Watch, TV and Vision Pro.
what is a view in swiftui | swiftui view protocol | make a view swiftui => A view is a struct that conforms to View and has a `body` property describing what to show: `struct ContentView: View { var body: some View { Text("Hi") } }`.
what is the body property in swiftui | var body some view | body swiftui => `body` returns the view's content. SwiftUI calls it again whenever the data the view depends on changes, so keep it fast and free of side effects.
why some view | some view meaning => `some View` means body returns one specific view type that Swift works out for you. It lets you build complex views without writing out their long type names.
how do i show text in swiftui | text view swiftui | display a label swiftui => `Text("Hello")`. Style it with modifiers like `.font(.title)`, `.bold()` and `.foregroundStyle(.blue)`.
what is a modifier in swiftui | swiftui modifiers explained | dot modifiers swiftui => A modifier is a method that returns a changed view, like `.padding()`, `.background(.red)` or `.font(.headline)`. You chain them, and their order matters.
why does modifier order matter in swiftui | padding before background | swiftui modifier order => Each modifier wraps the view so far. `.padding().background(.red)` colors the padded area, but `.background(.red).padding()` adds padding outside the red.
what is a vstack | vstack swiftui | stack views vertically => VStack arranges views top to bottom: `VStack(alignment: .leading, spacing: 8) { Text("A"); Text("B") }`.
what is an hstack | hstack swiftui | views side by side swiftui => HStack arranges views left to right. Use `Spacer()` inside to push views apart.
what is a zstack | zstack swiftui | put views on top of each other => ZStack layers views on top of each other, back to front, like a background image with text over it.
what is a spacer in swiftui | spacer swiftui | push views apart => `Spacer()` takes up all free space in a stack, pushing other views to the edges.
what is lazyvstack | lazy stack swiftui | lazyvstack vs vstack => LazyVStack only creates rows when they scroll onto the screen, so it is better for long lists inside a ScrollView. VStack makes everything at once.
what is a scrollview in swiftui | scrollview swiftui | make content scroll => Wrap content in `ScrollView { VStack { ... } }` to scroll it. Use `ScrollView(.horizontal)` for sideways scrolling.
what is a list in swiftui | list swiftui | table view swiftui => List shows rows in a scrolling, styled list: `List(items) { item in Text(item.name) }`. Items need to be Identifiable or you pass `id:`.
what is foreach in swiftui | foreach swiftui | loop in a view => `ForEach(items) { item in Text(item.name) }` makes a view for each item inside a stack or List. It needs Identifiable items or an `id:` key path.
what does id self mean in foreach | foreach id \.self | foreach with strings => `ForEach(names, id: \.self)` uses each value itself as its ID. It only works well when every value is unique.
how do i delete rows in a swiftui list | ondelete swiftui | swipe to delete swiftui => Add `.onDelete { offsets in items.remove(atOffsets: offsets) }` to the ForEach inside the List.
how do i reorder rows in a swiftui list | onmove swiftui | drag to reorder list => Add `.onMove { from, to in items.move(fromOffsets: from, toOffset: to) }` to the ForEach and an EditButton to start editing.
what is a section in swiftui | section swiftui list | group rows => `Section("Settings") { ... }` groups rows in a List or Form with a header.
what is a form in swiftui | form swiftui | settings screen swiftui => Form groups controls like Toggle, TextField and Picker in a settings-style layout.
what is @state in swiftui | state swiftui | @state explained => `@State private var count = 0` stores a value owned by the view. When it changes, SwiftUI redraws the view. Use it for simple local values.
what is @binding in swiftui | binding swiftui | pass state to child view => `@Binding var isOn: Bool` lets a child view read and change a value owned by its parent. The parent passes it with a dollar sign: `ChildView(isOn: $isOn)`.
what does the dollar sign mean in swiftui | $ in swiftui | $variable swiftui => `$name` gives a Binding to a @State or @Binding value, so a control like TextField or Toggle can change it.
what is @observable in swiftui | @observable class => Mark a class `@Observable` and SwiftUI views that read its properties update when they change. It came in iOS 17 and replaces ObservableObject for most apps.
what is observableobject | @published swiftui | observableobject vs observable => ObservableObject is the older way (before iOS 17) to share a model: mark properties `@Published` and hold it with @StateObject or @ObservedObject. @Observable is simpler and is preferred on iOS 17 and later.
what is @stateobject | stateobject vs observedobject | @observedobject swiftui => With ObservableObject, `@StateObject` creates and owns the object so it survives view updates, while `@ObservedObject` just watches one passed in. With @Observable you use `@State` instead.
what is @environment in swiftui | environment swiftui => `@Environment` reads values SwiftUI shares down the view tree, like `@Environment(\.dismiss) var dismiss` to close a sheet, or `\.colorScheme` for dark mode.
how do i share a model with many views swiftui | environment object | pass data down swiftui => Put an @Observable model into the environment with `.environment(model)` and read it in any child view with `@Environment(Model.self) var model`.
what is @bindable | bindable swiftui | binding to observable property => `@Bindable var model` lets you make bindings to properties of an @Observable object, like `TextField("Name", text: $model.name)`.
what is @appstorage | appstorage swiftui | save settings swiftui => `@AppStorage("highScore") var highScore = 0` saves the value in UserDefaults and updates views when it changes.
what is @scenestorage | scenestorage swiftui | restore state => `@SceneStorage` saves small values per window, so the app can restore things like the selected tab after being closed.
what is @focusstate | focusstate swiftui | keyboard focus swiftui => `@FocusState var focused: Bool` with `.focused($focused)` on a TextField lets you show or hide the keyboard by setting it to true or false.
what is @query in swiftui | query swiftdata | fetch swiftdata swiftui => `@Query var items: [Item]` loads SwiftData objects into a view and keeps the list updated. Add sorting like `@Query(sort: \Item.date)`.
what is a button in swiftui | button swiftui | make a button swiftui => `Button("Tap me") { count += 1 }`. For a custom look, use `Button { action() } label: { Label("Save", systemImage: "tray") }`.
how do i style a button in swiftui | buttonstyle swiftui | bordered prominent button => Use `.buttonStyle(.borderedProminent)` or `.bordered`, add `.tint(.green)`, or make your own ButtonStyle.
what is a textfield in swiftui | textfield swiftui | text input swiftui => `TextField("Name", text: $name)` lets the user type into a @State string. Add `.textFieldStyle(.roundedBorder)` for a box.
what is a securefield | password field swiftui | hidden text input => `SecureField("Password", text: $password)` hides the typed characters.
what is texteditor | multiline text input swiftui | texteditor swiftui => `TextEditor(text: $notes)` is a scrolling box for typing many lines.
what is a toggle in swiftui | toggle swiftui | switch control swiftui => `Toggle("Sound", isOn: $soundOn)` shows an on/off switch bound to a Bool.
what is a slider in swiftui | slider swiftui | slider range swiftui => `Slider(value: $volume, in: 0...1)` lets the user pick a Double in a range. Add `step:` for set increments.
what is a stepper in swiftui | stepper swiftui | plus minus control => `Stepper("Count: \(count)", value: $count, in: 0...10)` shows plus and minus buttons.
what is a picker in swiftui | picker swiftui | choose from options swiftui => `Picker("Color", selection: $color) { Text("Red").tag("red"); Text("Blue").tag("blue") }`. Change its look with `.pickerStyle(.segmented)` or `.menu`.
what is a datepicker in swiftui | datepicker swiftui | choose a date => `DatePicker("Due", selection: $date, displayedComponents: .date)` picks a date, time, or both.
what is a colorpicker in swiftui | colorpicker swiftui | choose color swiftui => `ColorPicker("Color", selection: $color)` shows the system color picker bound to a Color.
what is an image in swiftui | image swiftui | show a picture swiftui => `Image("photo")` shows an image from the asset catalog. Add `.resizable()` and `.scaledToFit()` so it fits its frame.
what are sf symbols | sf symbols swiftui | system images swiftui => SF Symbols are thousands of Apple icons you can use for free in your apps: `Image(systemName: "star.fill")`. The SF Symbols app lets you browse them.
what is a label in swiftui | label swiftui | icon and text swiftui => `Label("Settings", systemImage: "gear")` shows an icon and text together, and adapts to where it is used.
what is asyncimage | load image from url swiftui | asyncimage swiftui => `AsyncImage(url: url) { image in image.resizable() } placeholder: { ProgressView() }` downloads and shows a picture from the web.
what is a progressview | loading spinner swiftui => `ProgressView()` shows a spinner, and `ProgressView(value: 0.5)` shows a progress bar.
what is a shape in swiftui | circle rectangle swiftui | draw shapes swiftui => SwiftUI has shapes like `Circle()`, `Rectangle()`, `RoundedRectangle(cornerRadius: 12)` and `Capsule()`. Color them with `.fill(.blue)` or outline with `.stroke(.red, lineWidth: 2)`.
how do i make rounded corners in swiftui | cornerradius swiftui | clip shape rounded => Use `.clipShape(RoundedRectangle(cornerRadius: 12))` or `.clipShape(.rect(cornerRadius: 12))`. The older `.cornerRadius()` modifier is deprecated.
how do i add a shadow in swiftui | shadow swiftui | drop shadow view => `.shadow(color: .black.opacity(0.2), radius: 8, x: 0, y: 4)`.
how do i set a background color in swiftui | background swiftui | full screen background color => `.background(.blue)` colors behind a view. For the whole screen use a ZStack with `Color.blue.ignoresSafeArea()` behind your content.
what is the safe area in swiftui | ignoressafearea | content under notch => The safe area keeps content away from the notch, Dynamic Island and home indicator. `.ignoresSafeArea()` lets a background extend under them.
what is frame in swiftui | frame modifier | set size of view swiftui => `.frame(width: 100, height: 50)` sets a size, and `.frame(maxWidth: .infinity)` makes a view stretch to fill the width.
what is padding in swiftui | padding swiftui | space around a view => `.padding()` adds standard space on all sides, `.padding(.horizontal, 20)` on chosen sides.
what is a gradient in swiftui | lineargradient swiftui | gradient background => `LinearGradient(colors: [.blue, .purple], startPoint: .top, endPoint: .bottom)` can be used as a background or fill.
what is a color in swiftui | color swiftui | custom color swiftui => Use built-in colors like `.red`, make one with `Color(red: 0.2, green: 0.5, blue: 1)`, or add a Color Set in the asset catalog and use `Color("Brand")`.
how do i support dark mode in swiftui | dark mode swiftui | colorscheme swiftui => System colors and asset catalog colors with dark variants switch automatically. Read `@Environment(\.colorScheme)` to change things yourself, and preview with `.preferredColorScheme(.dark)`.
what is navigationstack | navigationstack swiftui | navigation swiftui => NavigationStack holds a stack of screens. Put `NavigationLink("Details") { DetailView() }` inside it to push a new screen with a back button.
what is navigationlink | navigationlink swiftui | go to another screen swiftui => NavigationLink pushes a new view when tapped inside a NavigationStack. With `navigationDestination(for:)`, you can link with a value instead of a view.
what is navigationdestination | navigationdestination swiftui | value based navigation => `.navigationDestination(for: Item.self) { item in DetailView(item: item) }` says which view to show when a `NavigationLink(value: item)` is tapped.
how do i navigate with code in swiftui | navigation path swiftui | push screen programmatically => Bind a `NavigationStack(path: $path)` to an array or NavigationPath, then append a value to push a screen or remove the last to go back.
is navigationview deprecated | navigationview vs navigationstack | navigationview swiftui => Yes. NavigationView is deprecated; use NavigationStack (or NavigationSplitView for sidebars) on iOS 16 and later.
what is navigationsplitview | sidebar swiftui | ipad split view swiftui => NavigationSplitView shows a sidebar and detail columns, perfect for iPad and Mac apps. On iPhone it collapses into a normal stack.
how do i set a navigation title in swiftui | navigationtitle | title at top swiftui => Add `.navigationTitle("Home")` to the content inside a NavigationStack. `.navigationBarTitleDisplayMode(.inline)` makes it small.
what is a toolbar in swiftui | toolbar swiftui | add button to navigation bar => `.toolbar { ToolbarItem(placement: .topBarTrailing) { Button("Add") { } } }` adds buttons to the navigation bar or bottom bar.
what is a tabview in swiftui | tab bar swiftui | tabs swiftui => TabView shows tabs at the bottom. Newer SwiftUI uses `Tab("Home", systemImage: "house") { HomeView() }` inside it; older code uses `.tabItem` on each view.
what is a sheet in swiftui | sheet swiftui | present modal swiftui => `.sheet(isPresented: $showSettings) { SettingsView() }` slides a view up from the bottom when the Bool is true.
how do i close a sheet in swiftui | dismiss sheet swiftui | close modal swiftui => Inside the sheet, read `@Environment(\.dismiss) var dismiss` and call `dismiss()`, or set the parent's Bool back to false.
what is fullscreencover | full screen modal swiftui | cover swiftui => `.fullScreenCover(isPresented: $show) { GameView() }` presents a view that covers the whole screen.
what is an alert in swiftui | alert swiftui | show popup message swiftui => `.alert("Game Over", isPresented: $showAlert) { Button("OK") { } } message: { Text("Try again!") }`.
what is a confirmation dialog | action sheet swiftui | confirmationdialog => `.confirmationDialog("Delete?", isPresented: $ask) { Button("Delete", role: .destructive) { } }` shows choices, often from the bottom.
what is a popover in swiftui | popover swiftui | ipad popover => `.popover(isPresented: $show) { InfoView() }` shows a bubble on iPad and Mac, and a sheet on iPhone.
what is a context menu | long press menu swiftui | contextmenu => `.contextMenu { Button("Copy") { } }` shows a menu when you long press (or right click on Mac).
what is a menu in swiftui | menu button swiftui | dropdown swiftui => `Menu("Options") { Button("Rename") { }; Button("Delete") { } }` shows a pop-up menu when tapped.
what is swipeactions | swipe actions swiftui | list row swipe => `.swipeActions { Button("Pin") { } }` on a list row adds custom buttons when the user swipes the row.
what is onappear | onappear swiftui | run code when view shows => `.onAppear { }` runs when the view appears on screen. For async work, `.task { }` is better because it cancels when the view disappears.
what is the task modifier | .task swiftui | load data swiftui => `.task { await loadData() }` starts async work when the view appears and cancels it automatically when the view goes away.
what is onchange in swiftui | onchange swiftui | react to value change => `.onChange(of: score) { oldValue, newValue in }` runs code when a value changes.
what is ontapgesture | tap gesture swiftui | detect tap swiftui => `.onTapGesture { }` runs code when the view is tapped. Use a Button instead when it acts like a button, for accessibility.
what is draggesture | drag gesture swiftui | move view with finger => `.gesture(DragGesture().onChanged { value in offset = value.translation })` tracks a drag. Use `.offset(offset)` to move the view.
what is a long press gesture | onlongpressgesture | hold gesture swiftui => `.onLongPressGesture { }` runs after the user holds down for a moment.
how do i animate in swiftui | withanimation swiftui | swiftui animation => Wrap a state change in `withAnimation { isOpen.toggle() }`, and views that depend on it animate. Or add `.animation(.spring, value: isOpen)` to a view.
what is a transition in swiftui | transition swiftui | animate view appearing => `.transition(.slide)` or `.transition(.scale)` sets how a view animates in and out when it is added or removed inside withAnimation.
what is matchedgeometryeffect | hero animation swiftui | matched geometry => `.matchedGeometryEffect(id: "card", in: namespace)` on two views makes SwiftUI animate one into the other, like a card growing into a full screen.
what is a spring animation | spring swiftui | bouncy animation swiftui => `.spring(duration: 0.5, bounce: 0.3)` makes a natural bouncy animation, often used with withAnimation.
what is phaseanimator | keyframe animation swiftui | keyframeanimator => PhaseAnimator steps a view through a set of states, and KeyframeAnimator animates values along keyframes, both added in iOS 17.
what is geometryreader | geometryreader swiftui | get view size swiftui => GeometryReader gives the size and position of the space a view is offered. It takes all available space, so use it carefully. `containerRelativeFrame` is a simpler option on iOS 17.
what is a grid in swiftui | lazyvgrid swiftui | grid layout swiftui => `LazyVGrid(columns: [GridItem(.adaptive(minimum: 100))]) { ... }` lays items out in a grid that fits the screen width. `Grid` is better for small fixed tables.
what is a canvas in swiftui | draw with canvas swiftui | custom drawing => `Canvas { context, size in context.fill(Path(ellipseIn: rect), with: .color(.red)) }` gives fast drawing for many shapes.
what is a path in swiftui | draw a custom shape swiftui | path swiftui => `Path { p in p.move(to: a); p.addLine(to: b) }` draws custom lines and curves. Conform to Shape to make a reusable custom shape.
what is timelineview | timelineview swiftui | update every second swiftui => `TimelineView(.periodic(from: .now, by: 1)) { context in Text(context.date.formatted()) }` redraws on a schedule, like a clock.
how do i make a timer in swiftui | timer swiftui => Use `.task { while !Task.isCancelled { try? await Task.sleep(for: .seconds(1)); seconds -= 1 } }`, or TimelineView for display, or `Timer.publish` with `.onReceive`.
what is a preview in swiftui | #preview swiftui | xcode canvas preview => `#Preview { ContentView() }` shows your view live in Xcode's canvas while you code. Press Option+Command+Return to show or hide the canvas.
why is my swiftui preview not working | preview crashed | xcode preview failed => Read the diagnostics button on the canvas. Common causes are a build error, a crash in the view's code, or missing environment objects in the #Preview. Try Editor > Canvas > Refresh or clean the build folder.
what is the app struct in swiftui | @main swiftui | app entry point swiftui => The `@main struct MyApp: App` is where the app starts. Its body has a WindowGroup with your first view.
what is windowgroup | scene swiftui | windowgroup swiftui => WindowGroup is a scene that shows your main view. On iPad and Mac, it lets users open several windows of your app.
what is scenephase | app goes to background swiftui | scenephase swiftui => `@Environment(\.scenePhase) var phase` tells you if the app is active, inactive or in the background, so you can save data with `.onChange(of: phase)`.
what is a view model in swiftui | mvvm swiftui | where to put logic swiftui => A view model is a class (usually @Observable) that holds a screen's data and logic, keeping views simple. Many SwiftUI apps use this MVVM pattern, though small apps can just use @State.
how do i split a big swiftui view | extract subview swiftui | view too big swiftui => Move parts into their own small View structs and pass data with parameters or bindings. It makes code easier to read and helps the compiler.
what is viewbuilder | @viewbuilder swiftui | return different views => `@ViewBuilder` lets a function or property return different views from if/else branches without wrapping them in AnyView.
what is anyview | anyview swiftui | type erasure swiftui => AnyView hides a view's real type so different views can be returned as one type. Prefer @ViewBuilder or Group, since AnyView can slow updates.
what is group in swiftui | group swiftui | group views together => `Group { }` groups views without changing layout, so you can apply one modifier to all of them.
what is viewmodifier | custom modifier swiftui | reusable style swiftui => Make a struct that conforms to ViewModifier with a `body(content:)` method, then add an extension like `func cardStyle() -> some View { modifier(CardStyle()) }`.
what is a custom view in swiftui | reusable component swiftui | make my own view => Make a new struct conforming to View with properties for what it shows, like `struct Badge: View { let text: String; var body: some View { Text(text).padding() } }`.
what is environmentvalues | custom environment value | @entry swiftui => You can add your own environment values with `@Entry` inside `extension EnvironmentValues`, then set them with `.environment(\.myValue, x)`.
what is a font in swiftui | change font swiftui | custom font swiftui => Use system styles like `.font(.title)` or `.font(.system(size: 24, weight: .bold))`. For custom fonts, add the file, list it in Info.plist, and use `.font(.custom("Name", size: 20))`.
what is dynamic type | text size accessibility | font scaling swiftui => Dynamic Type lets users choose bigger or smaller text. Built-in text styles like `.body` and `.title` scale automatically, so use them instead of fixed sizes.
how do i make my swiftui app accessible | accessibility swiftui | voiceover swiftui => Use real Buttons and Labels, add `.accessibilityLabel("Close")` to icon-only buttons, support Dynamic Type, and test with VoiceOver and the Accessibility Inspector.
linelimit swiftui | truncate text swiftui => `.lineLimit(2)` stops text after 2 lines with an ellipsis. `.lineLimit(nil)` allows unlimited lines.
how do i make text multiline in swiftui | text wrap swiftui | text not wrapping => Text wraps by default. If it is cut off, remove any `.lineLimit(1)`, and add `.fixedSize(horizontal: false, vertical: true)` if a parent is squeezing it.
what is markdown in swiftui text | bold in text swiftui | text with links swiftui => A Text with a string literal supports Markdown like `Text("**Bold** and [link](https://apple.com)")`.
what is attributedstring | styled text swiftui | attributed text => AttributedString lets parts of text have different styles, like one red word, and Text can display it.
how do i combine texts with different styles | concatenate text swiftui | two colors in one text => Join Text views with string interpolation in newer SwiftUI, like `Text("Score: \(Text("10").bold())")`. Adding Texts with `+` is the older way and is being deprecated.
what is a mapkit map in swiftui | map swiftui | show a map => `Map()` shows a map. Add `Marker("Home", coordinate: coord)` inside it to place pins (iOS 17).
what is photospicker | pick photo swiftui | photos picker => `PhotosPicker(selection: $item, matching: .images) { Text("Pick") }` lets users choose a photo, then load it with `item.loadTransferable(type: Data.self)`.
what is sharelink | share button swiftui | share sheet swiftui => `ShareLink(item: url)` shows a share button that opens the system share sheet.
what is a link in swiftui | link view => `Link("Apple", destination: URL(string: "https://apple.com")!)` opens a website. `@Environment(\.openURL)` opens URLs from code.
what is charts in swiftui | swift charts | make a graph swiftui => Swift Charts draws graphs: `Chart(data) { BarMark(x: .value("Day", $0.day), y: .value("Steps", $0.steps)) }`. There are LineMark, PointMark and more.
what is spritekit with swiftui | spriteview | 2d game swiftui => SpriteKit is Apple's 2D game framework. Show a scene in SwiftUI with `SpriteView(scene: myScene)`.
what is realitykit | realityview | 3d swiftui => RealityKit renders 3D and AR content. In SwiftUI, RealityView shows RealityKit scenes, including on Vision Pro.
what is uiviewrepresentable | use uikit in swiftui | wrap uikit view => UIViewRepresentable wraps a UIKit view so SwiftUI can show it. You write makeUIView and updateUIView.
what is uihostingcontroller | swiftui in uikit | host swiftui view => UIHostingController puts a SwiftUI view inside a UIKit app.
what is the difference between swiftui and uikit | swiftui vs uikit which to learn | should i learn uikit => SwiftUI is declarative and quicker to write; UIKit is older and gives fine control. New apps usually start with SwiftUI, and you can drop into UIKit when needed.
what is declarative ui | declarative vs imperative | how swiftui works => Declarative UI means you describe what the screen should look like for the data you have, and the framework updates it. Imperative UI means you change each view yourself step by step.
what is the source of truth in swiftui | single source of truth | where should data live => Each piece of data should be owned in one place (a @State or a model), and other views get bindings or read it from there, so nothing gets out of sync.
why is my swiftui view not updating | view does not refresh | state change not showing => The value probably is not tracked: use @State for local values, an @Observable class for models, and make sure you change the original, not a copy. Mutating a plain struct copy will not update the view.
why does my @state reset | state variable resets swiftui | state lost when view changes => @State belongs to the view's identity. If the view is recreated with a new identity (like a changing `.id()` or a different if branch), its state starts over. Keep shared data in a parent or model.
what is view identity in swiftui | .id modifier swiftui | structural identity => SwiftUI tracks views by their position in the code and by `.id()`. Changing a view's id makes SwiftUI treat it as a new view, resetting its state.
what is equatable view | improve swiftui performance | slow swiftui list => Keep body cheap, break big views into smaller ones, use lazy stacks for long lists, give ForEach stable IDs, and avoid heavy work like sorting inside body.
how do i hide the keyboard in swiftui | dismiss keyboard swiftui | keyboard covers textfield => Use @FocusState and set it to false, or add `.scrollDismissesKeyboard(.interactively)` to a ScrollView. SwiftUI moves fields above the keyboard automatically in most layouts.
how do i change the keyboard type swiftui | number pad swiftui | keyboardtype => `.keyboardType(.numberPad)` on a TextField shows a number keyboard. `.textInputAutocapitalization(.never)` turns off capitals.
what is onsubmit | return key swiftui | submit textfield => `.onSubmit { send() }` runs when the user presses Return in a TextField. `.submitLabel(.send)` changes the Return key's label.
how do i make a search bar in swiftui | searchable swiftui | search list swiftui => Add `.searchable(text: $query)` to a view inside a NavigationStack, then filter your items with the query.
how do i make pull to refresh swiftui | refreshable swiftui | pull down refresh => Add `.refreshable { await reload() }` to a List or ScrollView.
what is a badge in swiftui | tab badge swiftui | badge count => `.badge(3)` shows a count on a tab item or list row.
how do i hide the status bar swiftui | statusbar hidden | full screen game swiftui => `.statusBarHidden(true)` hides it, and `.persistentSystemOverlays(.hidden)` hides the home indicator for games.
how do i lock orientation in swiftui | portrait only app | landscape only ios => In the target's General tab under Deployment Info, untick the orientations you do not want. On iPad, apps that support all orientations work best with multitasking.
how do i detect device rotation swiftui | ipad vs iphone layout => Read `@Environment(\.horizontalSizeClass)`; `.regular` usually means iPad or a wide window and `.compact` means iPhone portrait or a narrow window. Switch layouts with it.
how do i make an ipad layout in swiftui | adaptive layout swiftui | viewthatfits => Use NavigationSplitView for sidebars, size classes to switch layouts, `ViewThatFits` to pick the first view that fits, and adaptive grids.
what is viewthatfits | viewthatfits swiftui | choose layout that fits => `ViewThatFits { HStack { ... }; VStack { ... } }` shows the first option that fits in the space, falling back to the next.
what is a layout protocol | custom layout swiftui | layout swiftui => Conforming to Layout lets you write your own container, like a flow layout, by placing subviews yourself in `placeSubviews`.
what is a container relative frame | containerrelativeframe | size relative to screen => `.containerRelativeFrame(.horizontal) { width, _ in width * 0.8 }` sizes a view as a fraction of its container, handy in scroll views.
what is scrolltargetbehavior | paging scroll swiftui | snap scrolling swiftui => `.scrollTargetBehavior(.paging)` makes a ScrollView snap page by page, and `.viewAligned` with `.scrollTargetLayout()` snaps to each view.
what is scrollviewreader | scroll to item swiftui | scroll to bottom swiftui => Wrap content in `ScrollViewReader { proxy in ... }` and call `proxy.scrollTo(id, anchor: .bottom)`. On iOS 17 you can also use `.scrollPosition(id:)`.
what is an enum for app state swiftui | switch view by state | loading error loaded swiftui => Store a state like `enum LoadState { case loading, loaded([Item]), failed(String) }` and use a switch in body to show the right view for each case.
how do i load json from the bundle in swiftui | read json file in app => `let url = Bundle.main.url(forResource: "data", withExtension: "json")!`, then `let data = try Data(contentsOf: url)` and decode it with JSONDecoder.
how do i play a sound in swiftui | avaudioplayer swiftui | play mp3 ios => Add the file to the project, then use AVFoundation: `player = try AVAudioPlayer(contentsOf: url)` and `player.play()`. Keep the player in a property so it is not freed mid-sound.
how do i add haptics in swiftui | sensoryfeedback => `.sensoryFeedback(.success, trigger: score)` plays a haptic when the value changes (iOS 17). Older code uses UIImpactFeedbackGenerator.
how do i open settings app from swiftui | open app settings link | settings url ios => `openURL(URL(string: UIApplication.openSettingsURLString)!)` opens your app's page in the Settings app.
how do i show a widget for my app | widgetkit | home screen widget swift => Add a Widget Extension target in Xcode. Widgets use WidgetKit with SwiftUI views and a TimelineProvider that says when to update.
what is an app intent | app intents | siri shortcut swift => App Intents let your app's actions show up in Shortcuts, Siri, Spotlight and widgets. You write a struct conforming to AppIntent with a `perform()` method.
what is a live activity | live activities | dynamic island app => Live Activities show live info on the Lock Screen and in the Dynamic Island, built with ActivityKit and WidgetKit.
what is swiftui on the mac | mac app swiftui | menu bar app swiftui => SwiftUI apps can run on macOS. `MenuBarExtra` makes a menu bar app, and `Settings` adds a preferences window.
what is the inspector in swiftui | inspector modifier | side panel swiftui => `.inspector(isPresented: $show) { InspectorView() }` shows a side panel on iPad and Mac (iOS 17).
how do i add a splash screen in swiftui | launch screen ios | launch screen swiftui => Set a Launch Screen in the target's Info settings with a background color and image. iOS shows it while the app starts; it cannot be animated.
how do i change the app icon | app icon xcode | set app icon => Open Assets.xcassets, select AppIcon, and drop in a 1024 by 1024 PNG. Xcode makes the smaller sizes for you.
how do i make a game in swiftui | swiftui game loop | simple game swiftui => For simple games, use TimelineView(.animation) or a Canvas redrawn every frame, store positions in an @Observable model, and update them by the time since the last frame. For bigger 2D games, use SpriteKit.
