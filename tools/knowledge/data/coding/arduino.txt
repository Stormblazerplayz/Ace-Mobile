# Arduino and electronics basics, written by hand for Ace.
# tag: coding.arduino
what is an arduino | what is arduino used for | arduino explained => Arduino is a small, cheap programmable board (a microcontroller) plus free software for writing code to it. You use it to read sensors and control LEDs, motors, buzzers and screens.
what is a microcontroller | microcontroller vs computer | what is an mcu => A microcontroller is a tiny computer on one chip, with its own processor, memory and input/output pins. It runs one program over and over, which is perfect for gadgets and robots.
what is the arduino uno | arduino uno specs | uno r3 => The Uno R3 is the classic beginner board. It uses an ATmega328P running at 16 MHz with 32 KB of flash, 2 KB of RAM, 14 digital pins (6 with PWM) and 6 analog inputs, and works at 5V.
what is the arduino uno r4 | uno r4 minima | uno r4 wifi => The Uno R4 boards (Minima and WiFi) keep the Uno shape but use a faster 32-bit Renesas RA4M1 chip at 48 MHz with much more memory. The WiFi version adds an ESP32-S3 for WiFi and Bluetooth and an LED matrix.
what is the arduino nano | arduino nano vs uno | small arduino => The Nano is a tiny board with nearly the same chip and pins as the Uno, made to plug into a breadboard. Newer Nanos like the Nano ESP32 and Nano 33 BLE use different chips.
what is the arduino mega | arduino mega 2560 | when to use a mega => The Mega 2560 has many more pins (54 digital, 16 analog) and more memory than an Uno, handy for big projects like 3D printers or lots of LEDs and sensors.
what is an esp32 | esp32 vs arduino | esp32 wifi board => The ESP32 is a cheap, fast microcontroller with built-in WiFi and Bluetooth. You can program it with the Arduino IDE after adding the ESP32 boards package.
what is an esp8266 | nodemcu | esp8266 board => The ESP8266 is an older, cheap WiFi microcontroller, often on NodeMCU or Wemos D1 Mini boards. It runs at 3.3V and can be programmed from the Arduino IDE.
what is a raspberry pi pico | pico vs arduino | rp2040 => The Raspberry Pi Pico is a cheap microcontroller board with the RP2040 chip (the Pico 2 uses the RP2350). You can program it in MicroPython, C/C++ or with the Arduino IDE.
what is the difference between arduino and raspberry pi | arduino vs raspberry pi | pi or arduino => An Arduino is a microcontroller that runs one sketch instantly and is great for real-time hardware. A Raspberry Pi is a full Linux computer with a desktop, good for heavier tasks like cameras and websites.
what is the arduino ide | download arduino ide | arduino software => The Arduino IDE is the free app where you write sketches, pick your board and port, and upload. Version 2 adds autocomplete, a debugger for some boards and a Serial Plotter.
what is a sketch in arduino | arduino sketch | .ino file => A sketch is an Arduino program, saved as a .ino file inside a folder with the same name. Every sketch has a `setup()` and a `loop()` function.
what is the difference between setup and loop | setup vs loop | arduino program structure => `setup()` runs once when the board powers on or resets, for things like `pinMode` and `Serial.begin`. `loop()` then runs over and over forever.
what language does arduino use | is arduino c++ | arduino programming language => Arduino sketches are C++ with a few helpers added, like `digitalWrite` and `millis`. The IDE adds the `#include <Arduino.h>` and function prototypes for you.
how do i upload code to arduino | upload sketch | arduino upload steps => Plug in the board with a USB data cable, pick it under Tools > Board and the port under Tools > Port, then click the right arrow Upload button.
what does verify do in arduino ide | compile button arduino | check mark button arduino => The check mark Verify button compiles your sketch to find errors without uploading it.
arduino port not showing | no com port arduino | arduino not detected => Try a different USB cable (many are charge only), another USB port, and check the board is getting power. Clone boards with a CH340 chip may need the CH340 driver.
what does avrdude stk500_getsync not in sync mean | avrdude error | not in sync resp => The IDE could not talk to the board while uploading. Check the board and port are right, nothing is wired to pins 0 and 1, and try another cable or pressing reset just before uploading.
what does was not declared in this scope mean in arduino | not declared in this scope arduino | arduino scope error => You used a name the compiler does not know there. Check spelling and capitals (`digitalWrite` not `digitalwrite`), declare variables before use, and include the library's header.
what does no such file or directory mean in arduino | missing library arduino | include file not found => A `#include` points to a library you have not installed. Install it with the Library Manager (Sketch > Include Library > Manage Libraries).
what does sketch too big mean | sketch uses too much memory | program storage space exceeded => Your code does not fit in flash. Remove unused libraries, shorten text, or use a board with more memory like a Mega or ESP32.
what does low memory available stability problems mean | arduino out of ram | global variables use too much memory => You are using most of the RAM, which can cause random crashes. Wrap fixed text in `F("...")` for Serial prints, use smaller types, and avoid big arrays and the String class.
what is the f macro | f() in arduino | serial print f => `Serial.println(F("Hello"));` keeps the text in flash memory instead of copying it into the small RAM. It is a cheap way to save memory on an Uno.
what is the library manager | install arduino library | add library arduino => In the IDE open the Library Manager, search a name like "Servo" or "Adafruit NeoPixel" and click Install. Then `#include` it at the top of your sketch.
what is the board manager | add esp32 to arduino ide | install board package => Boards Manager installs support for other boards. For ESP32, add Espressif's board URL in Preferences, then install "esp32" from Tools > Board > Boards Manager.
what is the serial monitor | open serial monitor | see serial prints => The Serial Monitor (magnifying glass icon) shows text your board sends with `Serial.print`. Set its baud rate to match your `Serial.begin`.
serial monitor shows weird characters | garbage in serial monitor | serial monitor gibberish => The baud rate in the Serial Monitor does not match the one in `Serial.begin(...)`. Make them the same, like 9600 or 115200.
what is the serial plotter | graph sensor data arduino | serial plotter arduino => Tools > Serial Plotter draws a live graph of numbers you print with `Serial.println`. Print several numbers separated by commas or spaces to get several lines.
what is baud rate | baud rate arduino | 9600 vs 115200 => Baud rate is how many bits per second go over serial. Both sides must match. 9600 is the classic default and 115200 is faster.
what is a digital pin | digital pins arduino | what are pins 0 to 13 => Digital pins are either HIGH or LOW, on or off. On an Uno, pins 0 to 13 are digital, and the analog pins A0 to A5 can be used as digital too.
what is an analog pin | analog pins arduino | a0 to a5 => Analog input pins (A0 to A5 on an Uno) can measure a voltage, not just on or off. `analogRead` gives 0 to 1023 on an Uno for 0 to 5V.
what is pwm | pulse width modulation | fake analog output => PWM switches a pin on and off very fast. The share of time it is on (the duty cycle) sets the average power, which dims LEDs and slows motors. Use `analogWrite(pin, 0 to 255)`.
which pins can do pwm on uno | pwm pins arduino uno | tilde pins => On an Uno R3, pins 3, 5, 6, 9, 10 and 11 can do PWM. They are marked with a ~ on the board.
what is high and low | high vs low arduino | what voltage is high => HIGH means the pin is at the board's voltage (5V on an Uno, 3.3V on many newer boards) and LOW means 0V (ground).
what is input_pullup | internal pull up resistor | button without resistor => `pinMode(pin, INPUT_PULLUP)` turns on a resistor inside the chip that holds the pin HIGH. Wire the button from the pin to GND, and it reads LOW when pressed.
what is a floating pin | floating input | random readings from button => An input pin with nothing connected picks up noise and reads random HIGHs and LOWs. Use INPUT_PULLUP or a pull-down resistor so it always has a definite value.
what is a pull down resistor | pull up vs pull down | 10k resistor button => A pull-down resistor (often 10k ohms) connects the pin to GND so it reads LOW until the button connects it to 5V. A pull-up does the opposite.
what is led_builtin | built in led arduino | pin 13 led => Most boards have a small LED on the board, reachable as `LED_BUILTIN` (pin 13 on an Uno). Blinking it is the classic first test.
how do i blink an led on arduino | blink sketch | blink example => In setup use `pinMode(LED_BUILTIN, OUTPUT)`. In loop set it HIGH, `delay(1000)`, set it LOW, `delay(1000)`. File > Examples > 01.Basics > Blink has it ready.
how do i wire an led to arduino | led circuit | led resistor arduino => Connect the pin to a resistor (220 to 330 ohms), the resistor to the LED's long leg (anode), and the short leg (cathode) to GND.
why does an led need a resistor | led without resistor | current limiting resistor => An LED barely resists current, so without a resistor too much current flows and can burn out the LED or the pin. The resistor keeps the flow to a safe amount.
how do i tell which leg of an led is positive | led polarity | anode and cathode => The longer leg is the anode (+). The shorter leg, next to the flat edge of the LED, is the cathode (-) and goes toward ground.
how do i calculate a resistor for an led | led resistor value | ohms law led => Resistance = (supply voltage - LED voltage) / current. For 5V, a red LED (about 2V) and 15 mA: (5 - 2) / 0.015 = 200 ohms, so use 220.
what is ohm's law | v = i r | ohms law explained => Voltage = current x resistance (V = I x R). If you know two of them you can work out the third.
what is voltage | voltage explained => Voltage is the push that makes electric current flow, measured in volts (V). Arduino Uno pins use 5V; many newer boards use 3.3V.
what is current | what is an amp | electric current explained => Current is how much electricity flows, measured in amps (A) or milliamps (mA). An Uno pin should supply no more than about 20 mA continuously (40 mA is the absolute max).
what is resistance | what is an ohm | resistor explained => Resistance slows down current and is measured in ohms (Ω). Resistors have colored bands that show their value.
how do i read resistor color codes | resistor colors | resistor bands => Colors stand for digits: black 0, brown 1, red 2, orange 3, yellow 4, green 5, blue 6, violet 7, gray 8, white 9. Two digit bands, then a multiplier band: brown black orange is 10 x 1,000 = 10k ohms.
what is a breadboard | how does a breadboard work | breadboard rows => A breadboard lets you build circuits without solder. Each short row of 5 holes is connected, and the long rails on the sides are connected along their length for power and ground.
what is gnd | what is ground | why connect grounds => GND (ground) is the 0V reference that current returns to. All parts in a circuit, including separate power supplies, need their grounds connected together.
what is the 5v pin | 3.3v pin arduino | power pins arduino => The 5V and 3.3V pins supply power to sensors and small parts. They cannot power big things like motors; those need their own supply.
what is vin | vin pin arduino | power arduino with battery => VIN takes about 7 to 12V from a battery or adapter and the board's regulator lowers it to 5V. You can also use the barrel jack, or 5V over USB.
how do i power an arduino | arduino power supply | arduino battery => Use USB (5V), a 7 to 12V adapter in the barrel jack, or a battery into VIN. A 9V battery works but drains fast; a pack of AA batteries lasts longer.
can i connect a motor directly to an arduino pin | motor on arduino pin | why use a motor driver => No. Motors need far more current than a pin can give and create voltage spikes that can damage the board. Use a transistor or motor driver and a separate power supply.
what is a transistor | transistor as a switch | npn transistor arduino => A transistor is an electronic switch. A small current from an Arduino pin into its base or gate lets a much bigger current flow through it to run a motor or LED strip.
what is a mosfet | logic level mosfet | mosfet arduino => A MOSFET is a transistor that switches big loads. Pick a "logic level" one (like IRLZ44N) so a 5V or 3.3V pin can fully turn it on.
what is a flyback diode | diode across motor | why diode on relay => When a motor or relay coil turns off it creates a voltage spike. A diode across it (like a 1N4007, stripe toward +) safely absorbs the spike.
what is a relay | relay module arduino | switch mains with arduino => A relay is a switch flipped by an electromagnet, letting a small signal control a separate circuit. Never work with mains wall power yourself; ask an adult electrician.
what is a motor driver | l298n | tb6612 => A motor driver (like L298N or the more efficient TB6612FNG) lets an Arduino control the speed and direction of DC motors using its own power supply.
what is an h bridge | h-bridge motor | reverse a motor arduino => An H-bridge is a circuit of four switches that can send current through a motor either way, so it can spin forward or backward. Motor driver chips contain H-bridges.
how do i control a servo with arduino | servo arduino | sg90 servo => Include `<Servo.h>`, make `Servo s;`, call `s.attach(9);` in setup, then `s.write(90);` to move to 90 degrees. Most hobby servos turn from 0 to 180 degrees.
how do i wire a servo | servo wires | servo colors => Brown or black is GND, red is power (5V), and orange or yellow is the signal to a pin. Big or several servos need a separate 5V supply with grounds connected.
what is a continuous rotation servo | 360 servo | servo that spins => A continuous servo spins all the way round. `write(90)` stops it, values below go one way and above go the other, with speed depending on how far from 90.
what is a stepper motor | stepper arduino | 28byj-48 => A stepper moves in small exact steps, great for precise positions like 3D printers. Drive it with a driver like ULN2003 (for 28BYJ-48) or A4988, and the Stepper or AccelStepper library.
what is a dc motor | dc motor arduino | hobby motor => A DC motor spins when powered, faster with more voltage. Control speed with PWM through a motor driver, and direction with an H-bridge.
how do i use an ultrasonic sensor | hc-sr04 | distance sensor arduino => Send a 10 microsecond HIGH pulse on TRIG, then `pulseIn(echoPin, HIGH)` gives the echo time in microseconds. Distance in cm is about time x 0.0343 / 2.
how does an ultrasonic sensor work | how does hc-sr04 measure distance | sonar sensor => It sends out a sound pulse too high to hear (40 kHz) and times the echo. Sound travels about 343 m/s, so half the round trip time tells the distance.
how do i use a potentiometer | potentiometer arduino | knob arduino => Connect the outer legs to 5V and GND and the middle leg to A0. `analogRead(A0)` gives 0 to 1023 as you turn it.
how do i read a button | button arduino | push button wiring => Wire one side of the button to a pin and the other to GND, use `pinMode(pin, INPUT_PULLUP)`, and `digitalRead(pin) == LOW` means pressed.
what is button debouncing | debounce arduino | button triggers multiple times => Buttons bounce, flickering on and off for a few milliseconds when pressed. Only accept a change if it stays the same for about 20 to 50 ms, using `millis()` to time it.
how do i detect a button press once | edge detection button | state change detection => Keep the last reading in a variable and act only when it changes from HIGH to LOW. File > Examples > 02.Digital > StateChangeDetection shows this.
how do i use a buzzer | piezo buzzer arduino | play sound arduino => A passive piezo plays notes with `tone(pin, frequency)` and stops with `noTone(pin)`. An active buzzer just beeps when the pin is HIGH.
how do i play a melody on arduino | arduino music | notes on buzzer => Store note frequencies (like 262 for middle C) and durations in arrays and loop through calling `tone(pin, note, duration)` with a short delay between notes.
how do i use an rgb led | rgb led arduino | mix colors led => An RGB LED has red, green and blue LEDs in one. Give each leg its own resistor and PWM pin, and mix colors with `analogWrite` values from 0 to 255.
what is a common anode rgb led | common cathode vs common anode | rgb led reversed => Common cathode shares GND, so 255 is full brightness. Common anode shares 5V, so it is backwards: 0 is full brightness and 255 is off.
what is a neopixel | ws2812b | addressable led strip => NeoPixels (WS2812B) are LEDs you can set to any color one by one through a single data pin. Use the Adafruit NeoPixel or FastLED library and a strong 5V supply for long strips.
how much power do neopixels need | neopixel power supply | led strip current => Each NeoPixel can use up to about 60 mA at full white, so 60 of them could need 3.6 A. Use a separate 5V supply, connect grounds, and add a 300 to 500 ohm resistor on the data line.
how do i use an lcd with arduino | 16x2 lcd | i2c lcd => A 16x2 LCD with an I2C backpack needs only 4 wires (VCC, GND, SDA, SCL). Use a LiquidCrystal I2C library, then `lcd.print("Hi")`. Adjust the contrast knob if you see nothing.
how do i use an oled screen | ssd1306 | oled arduino => Small 128x64 SSD1306 OLEDs usually use I2C at address 0x3C. The Adafruit SSD1306 and GFX libraries let you draw text and shapes, then call `display.display()` to show them.
what is i2c | i2c explained | sda and scl => I2C is a way for many devices to share two wires: SDA (data) and SCL (clock). Each device has an address. On an Uno, SDA is A4 and SCL is A5. Use the Wire library.
how do i find an i2c address | i2c scanner | what address is my sensor => Run an I2C scanner sketch, which tries every address with `Wire.beginTransmission` and prints those that answer. Many screens are 0x3C or 0x27.
what is spi | spi explained | mosi miso sck => SPI is a fast way to talk to devices like SD cards and some screens, using MOSI, MISO, SCK and a chip select (CS) pin for each device. On an Uno these are pins 11, 12, 13 and usually 10.
what is uart | serial communication | tx and rx pins => UART is plain serial: TX sends and RX receives. Connect TX of one device to RX of the other, and share GND. On an Uno, pins 0 and 1 are also used by USB.
why should i not use pins 0 and 1 | pins 0 and 1 arduino | upload fails with wires on pin 0 => On an Uno, pins 0 (RX) and 1 (TX) are used for USB serial and uploading. Things connected there can block uploads and mess up the Serial Monitor.
what is 3.3v logic | 5v vs 3.3v | can i connect 5v to esp32 => Many boards and sensors (ESP32, Raspberry Pi, newer Arduinos) use 3.3V signals and can be damaged by 5V. Use a level shifter or voltage divider between 5V and 3.3V devices.
what is a voltage divider | divide voltage resistors | lower 5v to 3.3v => Two resistors in series split a voltage: Vout = Vin x R2 / (R1 + R2). For example 1k and 2k turn 5V into about 3.3V for a signal (not for powering things).
how do i use a temperature sensor | tmp36 | temperature arduino => The TMP36 gives an analog voltage: temperature in °C = (voltage - 0.5) x 100. Digital sensors like the DHT22 or DS18B20 use libraries and are more accurate.
how do i use a dht11 or dht22 | dht sensor arduino | humidity sensor => Install the DHT sensor library by Adafruit, create `DHT dht(pin, DHT22);`, call `dht.begin()`, then `dht.readTemperature()` and `dht.readHumidity()`. Read at most once every 2 seconds.
how do i use a light sensor | ldr | photoresistor arduino => Put the photoresistor and a 10k resistor in series between 5V and GND, and read the middle with `analogRead`. The number changes with how bright it is.
how do i use a pir motion sensor | pir sensor | motion detector arduino => A PIR sensor's output pin goes HIGH when it sees movement of warm bodies. Read it with `digitalRead`. It needs about a minute to settle after power on.
how do i use a joystick module | joystick arduino | thumbstick => The joystick has two potentiometers: read VRx and VRy with `analogRead` (about 512 in the middle) and the push button SW with INPUT_PULLUP.
how do i use an ir remote | ir receiver arduino | tv remote arduino => Use an IR receiver like the VS1838B with the IRremote library. It decodes button codes from a remote so your sketch can react to each button.
how do i use a keypad | 4x4 keypad | membrane keypad arduino => The Keypad library scans the rows and columns. Define the key layout and pins, then `keypad.getKey()` returns the pressed key or nothing.
how do i use a 7 segment display | seven segment arduino | tm1637 => A TM1637 4-digit module needs just two data pins and a library to show numbers. A bare 7-segment needs a pin and resistor per segment.
how do i use an rfid reader | rc522 | rfid arduino => The RC522 module uses SPI and the MFRC522 library to read the ID of RFID cards and tags. It runs on 3.3V, so do not power it from 5V.
how do i save data on arduino | eeprom | save data after power off => EEPROM keeps data when power is off. Use `EEPROM.put(address, value)` and `EEPROM.get(address, value)`. It wears out after about 100,000 writes per spot, so do not write every loop.
how do i use an sd card with arduino | sd card module | log data to sd card => An SD module uses SPI and the built-in SD library. `SD.begin(csPin)`, then open a file with `SD.open("log.txt", FILE_WRITE)`, print to it, and close it.
how do i connect arduino to wifi | wifi arduino | esp32 wifi connect => Use a WiFi board like an ESP32 or Uno R4 WiFi. Call `WiFi.begin(ssid, password)` and wait until `WiFi.status() == WL_CONNECTED`.
how do i use bluetooth with arduino | hc-05 | bluetooth module arduino => The HC-05 or HC-06 acts like a wireless serial port, often used with SoftwareSerial. ESP32 boards have Bluetooth built in.
what is softwareserial | software serial arduino | extra serial port uno => The SoftwareSerial library makes a serial port on other pins, useful on an Uno that has only one hardware serial. It is slower and less reliable than hardware serial.
what is millis | millis vs delay | non blocking delay => `millis()` gives milliseconds since the board started. Instead of `delay`, check `if (millis() - last >= 1000)` so your loop keeps running and can do other things.
why is delay bad | problem with delay | arduino freezes during delay => `delay()` stops everything, so buttons and sensors are ignored while it waits. Using `millis()` timing lets you do several things at once.
how do i do two things at once on arduino | multitasking arduino | blink without delay => Give each task its own `previousMillis` and interval, and in `loop` check each one with `millis()`. See File > Examples > 02.Digital > BlinkWithoutDelay.
does millis overflow | millis rollover | millis after 50 days => `millis()` rolls back to 0 after about 49.7 days. If you always subtract (`millis() - start >= interval`) with unsigned long variables, the math still works across the rollover.
why use unsigned long for millis | millis variable type | timer variable arduino => `millis()` returns an unsigned long. Storing it in an int overflows after about 32 seconds on an Uno and breaks your timing.
what is an interrupt | interrupt arduino | attachinterrupt explained => An interrupt makes the board instantly run a small function (an ISR) when a pin changes, even in the middle of loop. On an Uno only pins 2 and 3 have external interrupts.
what are the rules for an isr | interrupt service routine rules | volatile variable interrupt => Keep ISRs very short: no `delay`, no Serial prints. Variables shared with loop must be declared `volatile`.
what is a state machine on arduino | arduino state machine | modes in arduino => Keep a variable like `state` (e.g. IDLE, RUNNING, DONE) and use a switch in loop to do different things in each state. It keeps complex projects tidy.
what is a library in arduino | arduino libraries explained | what does include do in arduino => A library is reusable code for a part or task, like Servo or Wire. Install it with the Library Manager and add `#include <Name.h>` at the top.
what is map in arduino used for | scale sensor value | convert 0 1023 to 0 255 => `map(value, 0, 1023, 0, 255)` rescales a sensor reading into another range, like turning a knob reading into LED brightness.
how do i print variables to serial | serial print variable | print text and number arduino => `Serial.print("Temp: "); Serial.println(temp);`. `print` stays on the same line and `println` ends the line.
how do i read text from the serial monitor | serial input arduino | read serial command => Check `Serial.available() > 0`, then read with `Serial.read()` for one byte, `Serial.parseInt()` for a number, or `Serial.readStringUntil('\n')` for a line.
what is the string class in arduino | string vs char array arduino | arduino string memory => The `String` class is easy to use but can fragment the small RAM on an Uno over time. For long-running projects, char arrays are safer.
what is an arduino shield | shields arduino | motor shield => A shield is a board that plugs on top of an Arduino to add features like motor control, Ethernet or a screen, with no extra wiring.
what is a jumper wire | dupont wires | male to female wires => Jumper wires connect parts on a breadboard. Male ends have pins and female ends have sockets; use the kind that matches each part.
what is a multimeter | how to use a multimeter | measure voltage => A multimeter measures voltage, current and resistance. It is the best tool for finding why a circuit does not work, like a loose wire or a dead battery.
what is soldering | should i learn soldering | soldering safety => Soldering joins parts with melted metal using a hot iron. Learn with an adult, use a stand, wear eye protection, work with airflow and wash your hands after.
what is a short circuit | short circuit arduino | arduino gets hot => A short is when power connects straight to ground with nothing in between, so huge current flows. Unplug at once if anything gets hot or smells, then check your wiring.
how do i not break my arduino | arduino safety tips | arduino mistakes to avoid => Do not short 5V to GND, do not put more than 5V on a pin (3.3V on 3.3V boards), do not draw over about 20 mA from a pin, and do not power motors from the board.
is arduino safe for kids | arduino electricity safe | can arduino shock you => Low voltage Arduino projects (5 to 12V) are safe to touch. Stay away from wall mains power, be careful with lithium batteries, and never short a battery.
what is a lipo battery | lithium battery safety | 18650 battery arduino => Lithium batteries hold a lot of energy and can catch fire if shorted, punctured or charged wrong. Use a proper charger module or protected cells, and ask an adult.
what is a capacitor | capacitor arduino | why use a capacitor => A capacitor stores a little charge and smooths out power dips. A 100 µF to 1000 µF one across a motor or LED strip supply helps prevent resets. Mind the polarity on electrolytic ones.
why does my arduino keep resetting | arduino resets randomly | brownout arduino => Usually the power dips when a motor or many LEDs turn on. Give them their own supply, connect grounds, and add a big capacitor across the supply.
what is tinkercad circuits | arduino simulator | simulate arduino online => Tinkercad Circuits is a free website where you can wire up and code a virtual Arduino, great for testing without parts. Wokwi is another online simulator.
what is wokwi | wokwi simulator | esp32 simulator => Wokwi is a free online simulator for Arduino, ESP32 and Raspberry Pi Pico, with many virtual parts like servos, screens and sensors.
what is platformio | platformio vs arduino ide | vs code arduino => PlatformIO is an extension for VS Code that builds and uploads to Arduino and many other boards, with better project and library management than the Arduino IDE.
micropython vs arduino | should i use micropython or arduino | arduino c++ or micropython => MicroPython lets you program boards like the Pico and ESP32 in Python instead of C++. It is easier but slower and uses more memory.
what is circuitpython | circuitpython vs micropython | adafruit circuitpython => CircuitPython is Adafruit's beginner-friendly version of MicroPython. Boards show up as a USB drive and you just save code.py to run it.
what are some beginner arduino projects | arduino project ideas | what should i build with arduino => Try a traffic light, a reaction timer game, a night light with a light sensor, a distance alarm with an ultrasonic sensor, a servo that waves, or a temperature display.
how do i make a robot with arduino | arduino robot car | build a robot => A simple robot car uses two DC motors with a motor driver, a battery pack, and an ultrasonic sensor to avoid walls. Start with a kit so the parts fit together.
how do i make a line following robot | line follower arduino | ir line sensor => Use IR sensors pointing at the floor that read dark lines differently from a light floor. Turn the motors based on which sensor sees the line.
how do i make a game controller with arduino | arduino keyboard | arduino as a usb keyboard => Boards with native USB, like the Leonardo, Micro and Uno R4, can act as a keyboard or mouse with the Keyboard and Mouse libraries. The Uno R3 cannot.
can an arduino control roblox | arduino and roblox | connect arduino to a game => Roblox scripts cannot read USB devices. An Arduino acting as a USB keyboard, gamepad or mouse can send key presses that Roblox reacts to.
what is a sensor | types of sensors | sensors for arduino => A sensor measures something in the real world, like light, temperature, distance, motion, sound or tilt, and turns it into a signal the board can read.
what is an actuator | arduino outputs | what are outputs => An actuator makes something happen in the real world, like an LED, motor, servo, buzzer or relay. Sensors are inputs and actuators are outputs.
what is an analog to digital converter | adc | what does adc mean => An ADC turns a voltage into a number. The Uno's 10-bit ADC gives 1024 steps (0 to 1023), while many newer boards have 12-bit ADCs (0 to 4095).
how do i turn an analog reading into volts | analogread to voltage | convert reading to voltage => On a 5V Uno, voltage = reading x 5.0 / 1023.0. Use 3.3 instead of 5.0 on 3.3V boards.
what is aref | analog reference pin | aref arduino => AREF sets the top voltage that analogRead compares against. Most projects leave it alone and use the default board voltage.
what is the reset button | reset arduino | restart sketch => The reset button restarts your sketch from `setup()`. It does not erase the code.
how do i erase an arduino | clear arduino code | delete sketch from arduino => Just upload a new sketch, which replaces the old one. Uploading the empty BareMinimum example makes it do nothing.
what is the bootloader | arduino bootloader | burn bootloader => The bootloader is a tiny program on the chip that lets you upload sketches over USB. You only need to burn it on blank chips, using another Arduino or a programmer.
what is ttl | ttl serial | usb to ttl adapter => TTL serial is UART at logic voltage (5V or 3.3V). A USB to TTL adapter (like CP2102 or CH340) lets a computer talk to boards without USB.
what is a logic level shifter | level converter | 5v to 3.3v converter => A level shifter safely converts signals between 5V and 3.3V devices, often both ways, for I2C, SPI or serial.
what is a common ground | why share ground => Signals are measured compared to ground, so two boards or a board and a separate motor supply must have their GNDs connected or things act strangely.
what is a datasheet | read a datasheet | datasheet arduino => A datasheet is the maker's document for a part, with its pins, voltages, limits and how to use it. Checking it prevents a lot of fried parts.
what is pinout | arduino pinout | pin diagram => A pinout is a diagram showing what each pin on a board or chip does. Search "Arduino Uno pinout" or check the official board docs.
what is an arduino nano every | nano every | nano every vs nano => The Nano Every has the Nano shape but uses an ATmega4809, with more memory than the classic Nano. Some older libraries that poke registers directly do not work on it.
what is an arduino leonardo | leonardo vs uno | atmega32u4 => The Leonardo uses an ATmega32u4 with built-in USB, so it can act as a keyboard or mouse. It has similar pins to the Uno.
what is the arduino cloud | arduino iot cloud | arduino cloud editor => Arduino Cloud is Arduino's online service for writing code in a browser and building internet dashboards for WiFi boards like the ESP32 and Nano 33 IoT.
how do i debug arduino code | arduino debugging | find bug in sketch => Add `Serial.println` lines to print values and see which parts run. Test one part at a time, check wiring with a multimeter, and use the IDE 2 debugger on boards that support it.
why is my led not lighting | led not working arduino | led stays off => Check the LED is the right way round (long leg toward the pin), the resistor is in line, the pin is set to OUTPUT, the ground is connected, and you used the right pin number.
why does my servo jitter | servo shaking | servo twitching => Usually not enough power. Power servos from a separate 5V supply with shared ground, and add a capacitor. Calling `write` with constantly changing values can also cause jitter.
why does analogread give random numbers | analog readings jumping | noisy sensor => An unconnected analog pin floats and gives random values. Check the wiring, and smooth readings by averaging several in a row.
how do i average sensor readings | smoothing arduino | moving average => Add up several readings in a loop and divide by how many you took, or keep a running array of the last few. File > Examples > 03.Analog > Smoothing shows one way.
what is the arduino forum | where to get arduino help | arduino help => forum.arduino.cc is the official forum where people help with projects. Post your code, a wiring diagram and what you expected versus what happened.
what is fritzing | draw arduino circuit | wiring diagram software => Fritzing is a program for drawing breadboard wiring diagrams and schematics, handy for planning and sharing projects.
what is a schematic | read a schematic | circuit diagram symbols => A schematic is a circuit drawing using symbols, like a zigzag for a resistor and a triangle with a line for a diode. It shows connections, not where parts physically sit.
what is a series circuit | series vs parallel | parallel circuit => In series, parts are in one line and share the same current. In parallel, parts are on separate branches and share the same voltage.
what is power in electronics | watts | p = v i => Power is how fast energy is used, in watts: P = V x I. A 5V motor using 0.5 A uses 2.5 watts.
what is a buck converter | step down converter | lm2596 => A buck converter efficiently lowers a voltage, like 12V to 5V, wasting less as heat than a linear regulator.
what is a voltage regulator | 7805 | regulator arduino => A regulator keeps a steady output voltage, like the 7805 giving 5V. Linear regulators waste extra voltage as heat, so they get hot with big drops.
