# More Swift: newer language features, testing, SpriteKit games and app how-tos, written by hand for Ace.
# tag: coding.swift.more
what is an if expression in swift | if as an expression swift | let x = if swift => Since Swift 5.9, `if` and `switch` can produce a value: `let label = if score > 10 { "High" } else { "Low" }`. Each branch must be a single expression.
what is a switch expression in swift | switch returns value swift | let x = switch => Since Swift 5.9 you can write `let name = switch dir { case .up: "Up" case .down: "Down" }`, assigning straight from a switch.
what is an indirect enum | indirect enum swift | recursive enum swift => Marking an enum `indirect` lets a case hold the same enum type inside it, which is needed for recursive data like a tree of expressions.
what is an autoclosure | @autoclosure swift | autoclosure explained => `@autoclosure` wraps an argument in a closure automatically, so it is only evaluated if needed. `assert` uses it so its message is not built unless the check fails.
what is @discardableresult | discardable result swift | unused result warning swift => Swift warns when you ignore a function's return value. Mark the function `@discardableResult` if ignoring it is normal.
what is @escaping | escaping closure meaning | closure escapes function => A closure is `@escaping` when it is stored or called after the function returns, like a completion handler. Swift makes you mark it so you think about memory.
what is typed throws | throws(myerror) swift | swift 6 typed throws => Swift 6 lets a function say exactly which error type it throws, like `func load() throws(LoadError)`, so callers know what they must handle.
swift 6 changes | swift 6 language mode => Swift 6 (2024) added a language mode with complete data-race safety checking at compile time, typed throws, and more. Projects can move to it gradually.
what is strict concurrency checking | data race safety swift | sendable warnings => Strict concurrency checking makes the compiler prove that data shared between tasks and threads cannot cause data races. It is on by default in the Swift 6 language mode.
what is nonisolated in swift | nonisolated keyword | nonisolated func => `nonisolated` marks a member of an actor (or a @MainActor type) that does not need the actor's protection, so it can be called without `await`.
what is a sendable closure | @sendable closure | sendable function => A `@Sendable` closure can safely be passed between concurrent tasks because it only captures values that are safe to share.
what is a noncopyable type | ~copyable swift | noncopyable struct => A type marked `~Copyable` cannot be copied, only moved, which is useful for unique resources like a file handle. It arrived in Swift 5.9.
what is consume in swift | consume operator | borrowing and consuming => `consume x` ends a variable's lifetime and hands its value on. `borrowing` and `consuming` parameters say whether a function just looks at a value or takes it.
what are parameter packs in swift | each and repeat swift | variadic generics swift => Parameter packs (Swift 5.9) let a generic function take any number of different types, using `each T` and `repeat each T`.
what is regex in swift | swift regex literal | regexbuilder => Swift 5.7 added Regex. Write `/\d+/` as a regex literal or use the RegexBuilder DSL, then `text.firstMatch(of: regex)` or `text.contains(regex)`.
how do i check if a string is a number in swift | is numeric swift => `Int(text) != nil` is true when the whole string is a valid whole number. Use `Double(text)` for decimals.
how do i format a date in swift | date to string swift | date formatting swift => `date.formatted(date: .abbreviated, time: .shortened)` gives a readable date for the user's language. In SwiftUI use `Text(date, style: .date)`.
how do i add days to a date in swift | date math swift | calendar add days => `Calendar.current.date(byAdding: .day, value: 7, to: Date.now)` gives a date one week later, as an optional.
how do i find the time between two dates swift | date difference swift | days between dates => `Calendar.current.dateComponents([.day], from: start, to: end).day` gives whole days. For seconds, use `end.timeIntervalSince(start)`.
how do i format a number with decimals in swift | two decimal places swift => `value.formatted(.number.precision(.fractionLength(2)))` shows two decimals. `String(format: "%.2f", value)` also works with Foundation.
how do i format money in swift | currency format swift | price string swift => `price.formatted(.currency(code: "USD"))` shows a price with the right symbol and separators for the user's region.
how do i format a percent in swift | percent format swift | show percentage swift => `0.42.formatted(.percent)` shows 42%.
what is measurement in swift | measurement units swift | convert units swift => `Measurement(value: 5, unit: UnitLength.kilometers)` stores a value with a unit, can convert with `.converted(to: .miles)`, and formats nicely.
what is locale in swift | locale swift | user language swift => `Locale.current` holds the user's language and region settings. Formatting APIs use it so dates and numbers look right everywhere.
how do i localize a swift app | translate ios app | string catalog => Use a String Catalog (Localizable.xcstrings) in Xcode. Text in SwiftUI is looked up automatically, and Xcode collects strings for you to translate.
what is the sequence protocol | sequence in swift | make a type loopable swift => A type that conforms to `Sequence` can be used in a for-in loop and gets map, filter and more for free.
what is the collection protocol | collection swift | collection vs sequence => `Collection` is a Sequence you can go through many times and index into, like Array, String, Dictionary and Set.
closedrange | range type swift => `0..<5` is a `Range` (up to, not including 5) and `0...5` a `ClosedRange` (including 5). You can loop over them and check `range.contains(x)`.
what is a one sided range | partial range swift | array[2...] => `array[2...]` takes from index 2 to the end and `array[..<3]` takes up to index 3. They return slices; wrap them in `Array(...)` to get an array.
what is an array slice | arrayslice swift | slice index swift => An ArraySlice is a view into part of an array that keeps the original indexes, so the first index may not be 0. Convert with `Array(slice)`.
substring vs string | substring type => A `Substring` shares memory with the string it came from. Convert it with `String(sub)` before storing it long term.
how do i loop over characters with index swift | enumerated string swift | character index loop => `for (i, ch) in text.enumerated()` gives each Character with a counter starting at 0.
how do i remove duplicates from an array in swift | unique array swift | dedupe array swift => `Array(Set(items))` removes duplicates but loses order. To keep order, loop and add items to a Set you check as you go.
how do i count occurrences in swift | count items swift | frequency swift => Use a dictionary: `for item in items { counts[item, default: 0] += 1 }`. Or `items.filter { $0 == x }.count` for one value.
how do i group an array in swift | dictionary grouping swift | group by swift => `Dictionary(grouping: players, by: { $0.team })` makes a dictionary from each team to its players.
how do i sort by a property in swift | sort structs swift | sort by name swift => `players.sorted { $0.score > $1.score }` sorts by score, highest first. Or use a key path: `players.sorted(using: KeyPathComparator(\.name))`.
sum swift | total of array swift => `numbers.reduce(0, +)` adds them all up.
how do i get the average in swift | average of array swift => `Double(numbers.reduce(0, +)) / Double(numbers.count)`. Check the array is not empty first to avoid dividing by zero.
how do i make a 2d array in swift | grid in swift => `var grid = Array(repeating: Array(repeating: 0, count: cols), count: rows)` then `grid[r][c] = 1`.
how do i copy an array in swift | array copy swift | arrays are values => Just assign it: `var copy = original`. Arrays are value types, so changing the copy does not change the original.
how do i check if an index is valid in swift | safe index swift | index out of range swift => Check `array.indices.contains(i)` before `array[i]`. Reading a bad index crashes with "Index out of range".
how do i make a struct conform to equatable automatically | auto equatable | synthesized conformance => If all stored properties are Equatable (or Hashable or Codable), just add the protocol to the struct and Swift writes the code for you.
how do i use a custom key name with codable | json key different name swift => Add `enum CodingKeys: String, CodingKey { case userName = "user_name" }` inside the struct to map Swift names to JSON keys.
how do i save codable data to a file in swift | write json to file swift | save struct to disk => Encode with `try JSONEncoder().encode(value)` and write with `try data.write(to: url)`, using a URL in `URL.documentsDirectory`. Read it back with `Data(contentsOf:)` and decode.
how do i read a file from the app bundle in swift | bundle main url | load file from bundle => `Bundle.main.url(forResource: "levels", withExtension: "json")` finds a file you added to the project, then load it with `Data(contentsOf:)`.
what is a swift package | reuse code swift => A Swift package is a folder of reusable code with a Package.swift file. Add others' packages in Xcode with File > Add Package Dependencies and a Git URL.
what is spritekit used for | spritekit games | 2d game ios => SpriteKit makes 2D games on iPhone, iPad and Mac, with sprites, physics, particles, sounds and actions, and it works great in Swift Playgrounds.
what is an skscene | skscene | spritekit scene => An SKScene is one screen of a SpriteKit game. Override `didMove(to:)` to set it up and `update(_:)` to run code every frame.
what is an skspritenode | skspritenode | sprite in spritekit => An SKSpriteNode shows an image or colored rectangle. Make one with `SKSpriteNode(imageNamed: "player")`, set its `position`, and `addChild` it to the scene.
what is an skaction | skaction | animate in spritekit => SKAction animates nodes: `node.run(.move(to: point, duration: 1))`. Combine actions with `.sequence`, `.group` and `.repeatForever`.
how do physics work in spritekit | skphysicsbody | spritekit physics => Give a node `physicsBody = SKPhysicsBody(circleOfRadius: 20)` and SpriteKit adds gravity, collisions and bouncing. Set `isDynamic = false` for things that should not move.
how do i detect collisions in spritekit | didbegin contact | contacttestbitmask => Give bodies a `categoryBitMask` and a `contactTestBitMask`, set the scene's `physicsWorld.contactDelegate = self`, then handle hits in `didBegin(_ contact:)`.
what is categorybitmask | collisionbitmask | spritekit bitmasks => Bitmasks label physics bodies. `categoryBitMask` says what a body is, `collisionBitMask` what it bounces off, and `contactTestBitMask` what it reports touching.
how do i handle touches in spritekit | touchesbegan spritekit | tap in spritekit => Override `touchesBegan(_:with:)` in your scene and use `touch.location(in: self)` to find where the player tapped.
how do i show text in spritekit | sklabelnode | score label spritekit => Use `SKLabelNode(text: "Score: 0")`, set its font and position, add it to the scene and update `label.text` when the score changes.
what is skemitternode | particles spritekit | spritekit particle effect => SKEmitterNode makes particle effects like fire, smoke and sparks. Design one in Xcode's particle editor (.sks file) and load it with `SKEmitterNode(fileNamed:)`.
what is skcameranode | spritekit camera | follow player spritekit => An SKCameraNode controls what part of the scene you see. Set `scene.camera = cam` and move the camera to follow the player.
how do i play a sound in spritekit | skaction playsoundfilenamed | spritekit sound effect => `run(.playSoundFileNamed("jump.wav", waitForCompletion: false))` plays a short sound effect. Use AVAudioPlayer or SKAudioNode for music.
how do i make a tilemap in spritekit | sktilemapnode | tiles spritekit => SKTileMapNode draws a grid of tiles from a tile set you make in Xcode, good for platformer levels and top-down maps.
what is gameplaykit | gameplaykit swift | gkstatemachine => GameplayKit adds game helpers like state machines (GKStateMachine), random sources, pathfinding grids and entity-component systems, and works with SpriteKit.
how do i make a game loop in spritekit | update function spritekit | per frame spritekit => SpriteKit calls your scene's `update(_ currentTime:)` once per frame. Save the last time to work out delta time for smooth movement.
can i make a 3d game in swift | 3d games swift | realitykit games => Yes. RealityKit (and the older SceneKit) handle 3D, and Metal gives low-level GPU control. Many developers also use Unity or Godot to target iOS.
what is metal | metal api | metal shaders => Metal is Apple's low-level graphics and GPU computing API, used by game engines and for custom shaders. It is powerful but complex for beginners.
can i make a game in swift playgrounds | games in swift playgrounds | playgrounds game => Yes. Swift Playgrounds on iPad and Mac can build App projects with SwiftUI and SpriteKit, and you can even send them to App Store Connect.
what is swift playgrounds app project | app project playgrounds | build app on ipad => An App project in Swift Playgrounds is a real SwiftUI app you can build, run and share from an iPad or Mac, and upload to App Store Connect.
how do i pass data to another view in swiftui | send data between views | pass value to view => Give the next view a property, like `DetailView(player: player)`. Use @Binding if the child must change it, or share an @Observable model through the environment.
how do i make a model object in swiftui | data model swiftui | make a class for data => Make an `@Observable class GameModel` holding your data and logic, create it with @State in the app or a parent view, and pass it down or put it in the environment.
how do i put a model in the environment swiftui | environment object observable | .environment(model) => With an @Observable class, `.environment(model)` on a parent makes it available below; children read it with `@Environment(GameModel.self) var model`.
how do i show a list of my own structs in swiftui | list of custom items | identifiable list => Make the struct `Identifiable` with an `id` property (often `let id = UUID()`), then `List(items) { item in Text(item.name) }`.
how do i add items to a list in swiftui | append to list swiftui | add row swiftui => Keep the items in a @State array (or in your model). Appending to it, like `items.append(newItem)`, updates the List automatically.
how do i edit items in a swiftui list | bindable list rows | list with bindings => Use `List($items) { $item in TextField("Name", text: $item.name) }` to get a binding to each row.
how do i make a grid of buttons in swiftui | button grid swiftui | tic tac toe grid swiftui => Use `LazyVGrid` with three flexible columns and a ForEach over 0..<9, each a Button that updates your board array.
how do i make a timer countdown in swiftui | countdown swiftui | seconds left swiftui => Keep `@State var secondsLeft = 30` and use `.onReceive(Timer.publish(every: 1, on: .main, in: .common).autoconnect()) { _ in secondsLeft -= 1 }`, stopping at 0.
how do i move a view with drag in swiftui | draggable view swiftui | drag to move swiftui => Store an offset in @State, update it in `DragGesture().onChanged { offset = $0.translation }`, and apply `.offset(offset)`.
how do i make a view fill the screen in swiftui | full screen view swiftui | max width infinity => Use `.frame(maxWidth: .infinity, maxHeight: .infinity)` and `.ignoresSafeArea()` for backgrounds that should go edge to edge.
how do i center a view in swiftui | center swiftui | align center swiftui => Views in stacks are centered by default. To center in the whole screen, put Spacers around it or use `.frame(maxWidth: .infinity, maxHeight: .infinity)`.
how do i add an image to my swiftui app | add picture xcode | asset catalog image => Drag the image into Assets.xcassets, give it a name, then use `Image("name").resizable().scaledToFit()`.
how do i use a custom font in swiftui | custom font ios | add font to app => Add the .ttf or .otf file to the project, list it under Fonts provided by application in Info, then use `.font(.custom("FontName", size: 20))`.
how do i open a website from swiftui | link button swiftui => Use `Link("Visit", destination: URL(string: "https://example.com")!)`, or `@Environment(\.openURL) var openURL` and call `openURL(url)`.
how do i vibrate the phone in swiftui | vibration swiftui | haptic feedback on tap => On iOS 17 add `.sensoryFeedback(.impact, trigger: tapCount)`, which plays a haptic whenever the value changes.
how do i make dark mode colors in swiftui | adaptive colors | color set dark mode => Use system colors like `.primary` and `Color(.systemBackground)`, or make a Color Set in the asset catalog with separate light and dark values.
how do i show an emoji in swiftui | emoji in text | emoji swift => Just put it in a string: `Text("🔥 Streak")`. Swift strings fully support emoji, and each counts as one Character.
how do i save a high score in swiftui | high score swiftui | save best score => `@AppStorage("highScore") var highScore = 0` keeps it saved between launches. Update it when the score beats it.
how do i make a settings screen in swiftui | settings page swiftui | settings form => Use a `Form` with Sections, Toggles, Pickers and Steppers bound to @AppStorage values so choices are saved automatically.
how do i make an onboarding screen in swiftui | first launch screen | welcome screen swiftui => Store `@AppStorage("seenIntro") var seenIntro = false` and show the intro in a sheet or fullScreenCover when it is false, setting it true at the end.
how do i make a launch screen in ios | launch screen storyboard | launch screen info plist => Set up the Launch Screen in the target's Info settings with a background color and image, or use a LaunchScreen storyboard. It shows while the app loads.
how do i support landscape in my ipad app | ipad orientations | landscape ipad swiftui => iPad apps should support all orientations. Check the device orientation settings in your target's General tab, and use flexible layouts.
what is size class | horizontalsizeclass | compact vs regular => `@Environment(\.horizontalSizeClass) var sizeClass` tells if the screen is compact (like iPhone portrait) or regular (like iPad), so you can switch layouts.
how do i make an app for apple watch | watchos app | swiftui watch app => Add a watchOS target in Xcode. watchOS apps use SwiftUI and have small screens, so keep them simple.
what is visionos | apple vision pro apps | visionos swiftui => visionOS runs on Apple Vision Pro. Apps are built with SwiftUI and RealityKit, with windows, volumes and immersive spaces.
what is an app extension | extensions ios | share extension => An app extension adds features outside your app, like widgets, share extensions, keyboards or Live Activities. It is a separate target in Xcode.
what is an app group | app groups ios | share data with widget => An App Group lets your app and its extensions, like a widget, share files and UserDefaults with `UserDefaults(suiteName:)`.
what is a deep link | universal link | url scheme ios => A deep link opens a specific screen in your app from a URL. Custom URL schemes and universal links do this; handle them with `.onOpenURL`.
how do i send notifications in ios | local notifications | usernotifications => Ask permission with `UNUserNotificationCenter.current().requestAuthorization`, then schedule a `UNNotificationRequest` with content and a trigger like a time interval.
what is push notification | apns | remote notifications => Push notifications come from a server through Apple Push Notification service (APNs). They need a paid developer account, a capability and a server to send them.
what is cloudkit | icloud sync | cloudkit swift => CloudKit stores data in iCloud so it syncs across a user's devices. SwiftData can sync through CloudKit with a few settings.
how do i use the camera in swiftui | camera swiftui | take photo app => Add a camera usage description in Info, then use a UIImagePickerController wrapped in UIViewRepresentable or AVFoundation's capture session for full control.
what is sign in with apple | apple login | authenticationservices => Sign in with Apple lets users log in with their Apple Account privately. SwiftUI has `SignInWithAppleButton` in AuthenticationServices.
what is face id in apps | localauthentication | biometric login => The LocalAuthentication framework's `LAContext` lets your app ask for Face ID or Touch ID. Add a Face ID usage description in Info.
what does fatal error unexpectedly found nil mean | found nil while implicitly unwrapping => A `!` force unwrap or implicitly unwrapped optional was nil. Use `if let`, `guard let` or `??` to handle the nil case safely.
does not conform to protocol | protocol conformance error => Your type is missing something the protocol requires. Click the error's Fix button in Xcode to add stubs, then fill them in.
what does generic parameter could not be inferred mean | could not be inferred swift | type inference error => Swift cannot work out a type from your code. Add a type annotation, like `let items: [String] = []`.
what does the compiler is unable to type-check this expression mean | expression too complex swift => One expression is too complex for Swift to work out quickly. Break it into smaller steps with intermediate variables and explicit types.
what does publishing changes from within view updates mean | modifying state during view update | state change in body => You changed state while SwiftUI was drawing a view. Move the change into an action, `.onAppear`, `.task` or `.onChange` instead of the body.
what does referencing initializer on foreach requires identifiable mean | foreach identifiable error | foreach requires id => ForEach needs a way to tell items apart. Make the type Identifiable or pass `id: \.self` for simple values like strings.
mutating self closure | struct closure error => A struct method passed `self` into an escaping closure, which Swift forbids. Use a class, or copy the values you need into the closure.
what does extra argument in call mean swift | extra argument in call | missing argument label swift => You passed an argument the function does not accept, or the labels are wrong. Compare your call with the function's definition.
what does consecutive statements on a line must be separated by mean | consecutive statements | separated by semicolon swift => Swift found two statements on one line, usually from a missing operator, a typo or an extra word. Fix the line or add a line break.
what does no exact matches in call to initializer mean | no exact matches | initializer error swift => None of the type's initializers fits the arguments you gave. Check the types and labels, for example passing a String where an Int is needed.
never mutated consider let | change var to let => You declared a `var` that never changes. Make it `let`, which tells readers it is constant.
what does result of call is unused mean | result unused swift | unused result => You called a function that returns a value and ignored it. Use the value, assign it to `_`, or check whether you meant a different function.
conditional binding must be optional | if let not optional => You used `if let` on something that is not optional, so there is nothing to unwrap. Just use the value directly.
what does ambiguous use of mean swift | ambiguous use of | ambiguous swift error => Several functions or types match the name, and Swift cannot tell which you mean. Add type information or a module name.
what is xcode cloud | xcode cloud ci | build in the cloud xcode => Xcode Cloud is Apple's continuous integration service that builds, tests and sends your app to TestFlight automatically when you push code.
what is swiftui preview macro | #preview | preview macro swift => `#Preview { ContentView() }` shows a live preview of a view in Xcode's canvas. It replaced the older PreviewProvider struct.
what is a swift macro example | attached macro => Macros generate code while compiling. `@Observable`, `#Preview` and `#expect` are macros; right-click one in Xcode and choose Expand Macro to see the code it writes.
