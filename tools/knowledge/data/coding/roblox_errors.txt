# Roblox script errors and debugging, written by hand for Ace.
# tag: coding.roblox.errors
attempt to index nil with roblox error | why does it say attempt to index nil | index nil error luau => It means you used a dot or colon on something that is nil, like `player.Character.Humanoid` when Character has not loaded yet. Find which name in the line is nil, then wait for it with WaitForChild or check `if thing then` before using it.
what does infinite yield possible mean | infinite yield possible on waitforchild | why does waitforchild never finish => WaitForChild has waited over 5 seconds and the child still has not appeared. Usually the name is spelled wrong, the object is in a different place, or it only exists on the server and the client is looking.
what does attempt to call a nil value mean | attempt to call nil roblox | error calling a function that is nil => You tried to call something as a function but it is nil. The function name is probably misspelled, the module did not return it, or you used `.` where you needed `:` or the other way around.
what does attempt to perform arithmetic on nil mean | arithmetic on nil roblox | cannot add nil => You did math with a value that is nil, like `coins.Value + amount` where amount was never set. Print the values before the line to see which one is nil.
what does attempt to compare number with nil mean | compare nil error luau | number less than nil error => You used `<`, `>`, `<=` or `>=` with a nil value. Make sure both sides exist, and give variables a default like `local x = value or 0`.
what does attempt to concatenate nil mean | concatenate nil error | cannot join nil with string => You used `..` to join text with a nil value. Wrap it with `tostring(value)` or check that the variable was set.
what does expected end got eof mean | expected end error | missing end in luau => You opened a block with `function`, `if`, `for`, `while` or `do` and did not close it with `end`. Count your ends, and use Format Document to see the indentation.
what does expected then mean | if statement error roblox | expected then got => An `if` or `elseif` line needs `then` after the condition, like `if x > 5 then`. Also check that you used `==` for comparing, not `=`.
for loop error luau | while loop expected do => `for` and `while` lines need `do` at the end, like `for i = 1, 10 do` or `while running do`.
what does unexpected symbol near mean | unexpected symbol error | syntax error near roblox => There is a typo near that spot, often a missing comma in a table, a stray bracket, or a quote that was never closed. Look at the line before the one shown too.
what does is not a valid member of mean | is not a valid member of workspace | not a valid member error roblox => The script looked for a child or property name that does not exist on that object. Check spelling and capitals, check the object is really there in the Explorer, and use WaitForChild if it loads later.
what does script timeout exhausted allowed execution time mean | script exhausted execution time | roblox script froze => A loop ran too long without yielding. Add `task.wait()` inside long or endless loops so Roblox gets a chance to do other work.
what does stack overflow mean in roblox | stack overflow luau => A function called itself (or functions called each other) too many times with no stop. Check your recursion has a base case, and check you are not setting a property inside its own Changed event.
what does httpservice is not allowed to access roblox resources mean | http requests are not enabled | httpservice not enabled => HttpService is turned off by default. Turn on Allow HTTP Requests in Game Settings > Security, and note that it cannot call roblox.com websites directly.
what does studio access to api services is not enabled mean | datastore not working in studio | api services studio => Studio cannot use DataStores until you turn on Enable Studio Access to API Services in Game Settings > Security, and the place must be published.
what does argument 1 missing or nil mean | argument missing or nil error | missing argument roblox => A function needed a value but got nil, often because a variable was never set or a FindFirstChild returned nil. Check what you pass in on that line.
what does unable to cast value to object mean | unable to cast error roblox | cast error luau => You passed the wrong type to a Roblox function, like a string where it wanted a Vector3 or an Instance. Check the function's parameter types in the docs.
what does unable to assign property mean | unable to assign property roblox | cannot set property error => The value has the wrong type for that property, like `part.Position = 5` instead of a Vector3, or the property is read-only.
what does requested module experienced an error while loading mean | module script error loading | require failed roblox => The ModuleScript itself crashed when it ran. Look for the first red error above that message, which points to the real line inside the module.
what does module code did not return exactly one value mean | module must return one value | modulescript return error => A ModuleScript must end with `return` and exactly one value, usually a table like `return Module`. You may have forgotten the return line.
what does attempted to call require with invalid arguments mean | require invalid argument | require not working => require needs a ModuleScript object or an asset ID number, not a string name. Use `require(game.ReplicatedStorage.MyModule)`.
what does lacking permission mean in roblox | current identity cannot error | lacking capability error roblox => The script tried to use something it is not allowed to, like a plugin-only or Roblox-only API from a normal game script. Use the regular API that normal scripts are allowed to call.
what does maximum event re-entrancy depth exceeded mean | event re-entrancy depth | event fires itself => An event handler keeps causing the same event to fire again, like changing a property inside its own Changed handler. Add a check so it does not set the value again.
what does tweenservice create property named cannot be tweened mean | cannot tween property | tween error roblox => That property cannot be tweened, either because it does not exist on that object or its type (like a string or boolean) is not tweenable. Tween numbers, Vector3, CFrame, Color3, UDim2 and similar types.
what does remote event invocation queue exhausted mean | remote event queue exhausted | event queue full roblox => A RemoteEvent was fired many times but nothing was listening on the other side. Make sure OnServerEvent or OnClientEvent is connected and the remote is the same object both sides use.
what does datastore request was added to queue mean | datastore queue warning | too many datastore requests => You sent DataStore requests faster than the limits allow, so they are being queued. Save less often, save when players leave and on a timer, and combine data into one key per player.
what does 502 api services rejected request mean | datastore 502 error | datastore server error roblox => The DataStore service had a temporary server problem. Wrap calls in pcall and try again after a short wait.
what does 104 cannot store in data store mean | cannot store dictionary in data store | datastore 104 error => You tried to save something DataStores cannot hold, like an Instance, a Vector3, or a table with mixed keys. Save plain numbers, strings, booleans and tables of them.
what does key name exceeds the 50 character limit mean | datastore key too long | datastore key limit => DataStore key names can be at most 50 characters. Use short keys like `"Player_" .. player.UserId`.
what does value exceeds limit datastore mean | datastore value too big | how much can a datastore key hold => Each DataStore key can hold up to 4,194,304 characters of data after it is turned into JSON. If you hit it, store less data or split it across keys.
what does exception while signaling cannot resume dead coroutine mean | cannot resume dead coroutine | dead coroutine error => You tried to resume a coroutine that already finished or errored. Check `coroutine.status(co)` is "suspended" before resuming.
what does infinite yield possible on playergui mean | playergui waitforchild infinite yield | gui not found in playergui => The GUI name in WaitForChild does not match the ScreenGui in StarterGui, or the GUI was made in a server script after the LocalScript started. Check the exact name.
what does animation failed to load mean | animation not playing roblox | failed to load animation => The animation is not owned by the experience owner. Publish the animation to the same account or group that owns the game, then use that new ID.
what does sound failed to load mean | audio not playing roblox | failed to load sound rbxassetid => The audio ID is wrong, private, or not allowed in your experience. Use audio you uploaded or audio from the Creator Store that is allowed in all experiences.
what does image failed to load mean | decal not showing roblox | image id not working => Use the image asset ID, not the decal ID. Paste the decal into Studio once and it converts to the image ID, or use the Asset Manager to copy the right ID.
what does failed to load package mean | package not loading studio | package error roblox => The package is private or you lost access to it. Ask the owner for permission, or replace it with your own copy.
what does gamepass purchase failed mean | gamepass not working in studio | prompt purchase test studio => Purchases in Studio are only tests and charge nothing. If ownership checks fail, make sure you use the game pass ID (not the asset ID) and wrap UserOwnsGamePassAsync in pcall.
why is my script not running | roblox script does not work | nothing happens when i press play => Check where the script lives: server Scripts run in Workspace and ServerScriptService, LocalScripts only in player places like StarterGui or StarterPlayerScripts. Then check the Output window for red errors and make sure the script is Enabled.
why does my localscript not work in workspace | localscript in a part | localscript not running in a part => LocalScripts do not run in Workspace unless they are inside a player's character. Move it to StarterPlayerScripts and find the part from there, or use a Script with RunContext Client.
why does my gui not update | text label not changing | gui text will not change => You might be changing the copy in StarterGui instead of the player's copy. In a LocalScript, use `player.PlayerGui` or `script.Parent` to reach the GUI the player sees.
why does my part fall through the floor | parts falling through map | part falls into void => The part or the floor might have CanCollide off, or the floor is not anchored, or the part moves so fast it passes through. Anchor the floor and keep CanCollide on.
why does my character fall apart when i spawn | character breaks on spawn | player dies instantly on spawn => Usually something in StarterCharacterScripts or a custom StarterCharacter is missing a Humanoid, HumanoidRootPart or neck joint, or a script sets Health to 0. Check the Output for errors.
why does my touched event fire many times | touched fires multiple times | touched event spam => Touched fires for every body part that touches, many times per second. Use a debounce variable or a cooldown table per player.
why does my tween not work | tween does nothing roblox | tween not playing => Make sure you call `:Play()`, that the part is anchored, that the property name is spelled right, and that nothing else is setting the same property every frame.
why does my datastore not save | data not saving roblox | lost data when rejoining => Turn on API access in Studio, save in PlayerRemoving and BindToClose, wrap calls in pcall and print errors, and make sure you load with the same key you save with, like the UserId.
why do changes from my localscript not show for others | client changes not replicating | only i can see it => Changes made by the client stay on that client. This is FilteringEnabled. Send a RemoteEvent to the server and make the change there so everyone sees it.
why does player.character return nil | character is nil error | character not loaded yet => The character has not spawned yet. Use `player.Character or player.CharacterAdded:Wait()`, and listen to CharacterAdded again for each respawn.
why does my script only work the first time | script breaks after respawn | stops working after dying => You saved the old character or humanoid in a variable, and after respawning it is gone. Get the new character each time in CharacterAdded, or put the script in StarterCharacterScripts.
why does my remote event not fire | onserverevent not working | fireserver does nothing => Check both scripts use the same RemoteEvent in ReplicatedStorage, the server script is in ServerScriptService, and OnServerEvent's first argument is the player, so your data comes second.
why is my value always nil on the server | fireserver sends nil | remote event data is nil => The first argument of OnServerEvent is always the player who fired it. Write `function(player, data)` instead of `function(data)`.
why does my while loop crash studio | while true do freezes | studio not responding loop => The loop has no wait in it. Put `task.wait()` inside every endless loop.
why does my gui not show up | screengui not visible | gui missing in game => Check the ScreenGui is in StarterGui, Enabled is on, the frames are Visible, they are not off screen or zero size, and that no script hides it at start.
why is my sound not playing | sound not working roblox | audio silent => Check the SoundId, that Volume is above 0, that the Sound is in Workspace, a part, or SoundService, and that you call `:Play()`. A sound inside a part is quiet when you are far from it.
why does my npc not move | moveto not working | npc stuck => Make sure no part of the NPC is anchored, it has a HumanoidRootPart, and the path is not blocked. MoveTo also stops after about 8 seconds, so call it again for long walks.
why is my part not moving when i change position | position does not move welded part | setting position breaks welds => Setting Position on a welded part moves only that part and breaks the weld. Move the whole model with `model:PivotTo(cframe)` or move the root part's CFrame.
why does my game lag in studio but not in the real game | studio is slow | studio performance => Studio runs extra tools and plugins, and play testing runs the client and server on one computer. Test in a live server to see real performance.
how do i read the output window | where are errors in roblox studio | output window roblox => Open View > Output. Red lines are errors with the script name and line number; click them to jump to the line. Blue lines show where the error came from.
how do i debug a roblox script | find bugs in my script | debugging tips roblox => Read the error in Output, add `print()` lines to see values, use breakpoints by clicking left of a line number, and step through with the debugger while play testing.
how do i use breakpoints in roblox studio | pause a script at a line | studio debugger => Click in the margin left of a line number to add a red breakpoint. When the game reaches it, it pauses and you can look at variables in the Watch and Call Stack windows.
what is the developer console | open dev console roblox | f9 console => Press F9 in a running game (Ctrl+F9 in Studio) to open the Developer Console. It shows client and server logs, memory, and network stats, which helps debug live servers.
what is the script analysis window | script analysis roblox | warnings in studio => View > Script Analysis lists problems Studio finds before running, like unknown globals or unused variables. Fixing them catches many bugs early.
why does it say unknown global | unknown global warning | w000 unknown global => You used a variable name that was never made with `local` and is not a built-in. It is usually a typo or a variable defined in another scope.
what does deprecated mean in roblox | deprecated function roblox | why is wait deprecated => Deprecated means Roblox has a newer replacement and stops improving the old one. It still works for now, but use the new thing, like `task.wait` instead of `wait`.
what does it mean when a script is disabled | script enabled property | why is my script grey => A disabled script does not run. Check its Enabled property in the Properties window.
what does attempt to index number with mean | index number error | attempt to index number => You used `.` on a number, like `coins.Value.Value` or `5.Name`. Remove the extra `.Value` or use the object instead of its value.
what does attempt to index string with mean | index string error roblox | string with name error => You used `.` on a string as if it were an object, like `player.Name.Character`. Use the object, not its name.
what does attempt to index instance with mean | index instance error | instance with error roblox => You used a name that is not a property or child of that object. Check spelling and capitals, since Luau names are case sensitive.
what does invalid argument to ipairs mean | table expected got nil | ipairs error luau => You looped over something that is not a table, usually nil. Make sure the function you called returned a table.
what does bad argument to tostring mean | bad argument error luau | bad argument #1 => A built-in function got the wrong type or a missing value in that argument number. Check what you passed in at that position.
what does upvalue error mean in luau | upvalue luau | what is an upvalue => An upvalue is a local variable from an outer function that an inner function uses. Errors mentioning upvalues usually mean that outer variable is nil.
what does gameprocessedevent mean | gameprocessed in inputbegan | why do keys fire while typing in chat => In InputBegan, the second argument is true when Roblox already used the input, like typing in chat or clicking a GUI button. Return early when it is true.
why does findfirstchild return nil | findfirstchild not finding | findfirstchild nil => The child does not exist yet or the name does not match exactly, including capitals and spaces. Use WaitForChild if it loads later, or look in the right parent.
why is my health not changing | takedamage not working | humanoid health not going down => TakeDamage does nothing if the character has a ForceField, like right after spawning. Set Health directly to ignore force fields, and make sure you changed it on the server.
why can i not see my part in game | part invisible in game | part missing when playing => Check Transparency is below 1, that the part is anchored or it may fall away, that it is inside Workspace, and that no script deletes or moves it.
why does my gui look different on my phone | gui off screen on mobile | ui broken on ipad => You probably used Offset (pixels) instead of Scale. Switch Size and Position to Scale and add a UIAspectRatioConstraint, then test with the Device Emulator.
why are my parts moving by themselves | parts sliding roblox | parts drifting => Unanchored parts are pushed by physics and gravity. Anchor parts that should stay still.
why does my model fall apart when i press play | model breaks on play | parts separate when playing => Its parts are not anchored and not welded. Anchor them, or weld them together with WeldConstraints if the model should move as one.
why does my exploit protection not work | exploiters still cheating | anti cheat roblox => Anything on the client can be changed by exploiters, so checks only work on the server. Check every RemoteEvent's data on the server, rate limit it, and never trust client values like damage or price.
what does the yellow warning in output mean | orange text in output | warnings roblox studio => Orange warnings come from `warn()` or from Roblox telling you about something risky, like an infinite yield. The game keeps running, but it often explains a bug.
what does ancestor of this instance is locked mean | parent property is locked | cannot set parent locked => You tried to change the Parent of something that was destroyed or that Roblox locked, like a service. Destroyed objects cannot be parented again; make a new clone.
what does the parent property of is locked mean | destroyed object parent | cannot reparent destroyed part => The object was already destroyed with `:Destroy()`, so it can never be parented again. Clone a fresh copy before destroying, or remove it with `Parent = nil` if you want to reuse it.
why does my clone not appear | clone not showing | cloned part not in workspace => Clones have no parent, so set `clone.Parent = workspace` (or wherever it belongs). Also check its position is where you expect.
why does setasync throttle | datastore throttle | datastore too many writes same key => Each key has a limit on how much can be read and written per minute, and writing the same key over and over hits it fast. Save less often, like on leave and every few minutes, and keep all of a player's data in one table under one key.
what does http 429 mean | too many requests error | 429 error => 429 means Too Many Requests: the server is rate limiting you because you sent requests too fast. Wait and try again more slowly.
what does http 403 mean in roblox | forbidden error roblox | 403 error => 403 means Forbidden: you are not allowed to do that request, often because of a missing permission, a private asset, or a disabled setting like API access.
