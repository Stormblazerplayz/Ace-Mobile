# More Python error messages explained, written by hand for Ace.
# tag: coding.python.errors
what does list object is not callable mean | list is not callable python | called a list like a function => You put `()` after a list, often because you named a variable `list` and then called `list(...)`, or wrote `items(0)` instead of `items[0]`.
what does float object is not callable mean | float not callable python | number not callable => You put `()` right after a number, like `2(3 + 4)`. Python needs `2 * (3 + 4)`, or you reused a function's name for a number.
what does dict object is not callable mean | dict is not callable | dictionary called like function => You wrote `scores("sam")` instead of `scores["sam"]`, or named a variable `dict` and then called `dict()`.
what does bool object is not callable mean | bool not callable python | true is not callable => You put `()` after a True or False value, often because a variable and a method share a name.
what does module object is not callable mean | module not callable python | import random random() => You called the module instead of a function inside it. Use `random.random()` or `from random import random`.
what does builtin_function_or_method object is not subscriptable mean | method not subscriptable | forgot brackets on method => You used `[ ]` on a function, like `items.pop[0]`. Call it with round brackets: `items.pop(0)`.
what does function object is not subscriptable mean | function not subscriptable python | brackets on function => You used square brackets on a function name. Call the function first, then index the result: `get_list()[0]`.
what does string indices must be integers mean | string indices must be integers | str index with str => You indexed a string with text, often because you thought a value was a dict but it is a string. Print `type(x)` to check.
what does takes 0 positional arguments but 1 was given mean | forgot self python | method missing self => A method inside a class is missing `self` as its first parameter. Write `def jump(self):`.
what does got an unexpected keyword argument mean | unexpected keyword argument python | wrong argument name python => You passed `name=value` but the function has no parameter with that name. Check the spelling against the definition.
what does got multiple values for argument mean | multiple values for argument python | argument given twice => The same parameter got a value by position and again by name. Remove one of them.
what does positional argument follows keyword argument mean | positional after keyword | argument order error python => Arguments with names must come after plain ones. Write `f(1, 2, size=3)`, not `f(size=3, 1)`.
what does non-default argument follows default argument mean | default argument order python | parameter order error => In a def, parameters with defaults must come last: `def f(a, b=2):` works, `def f(a=1, b):` does not.
what does __init__ should return none mean | init should return none | return in init python => `__init__` must not return a value. Remove the `return something` line, since it only sets up the object.
what does name self is not defined mean | self is not defined python | self error python => You used `self` outside a method, or forgot it in the method's parameters. `self` only exists inside methods that list it first.
what does eoferror mean python | eof when reading a line | eoferror input => `input()` hit the end of input with nothing to read. This happens in some online editors or when input is piped in. Give input, or catch `EOFError`.
what does invalid character in identifier mean | invalid character python | smart quotes python error => You have a character Python does not accept, often curly quotes or a special dash copied from a website. Retype the quotes and symbols yourself.
what does invalid decimal literal mean | invalid decimal literal python | number next to letters error => A number runs straight into letters, like `2nd_place = 1`. Names cannot start with a digit, so use `second_place`.
what does leading zeros in decimal integer literals are not permitted mean | 007 error python => Python does not allow numbers like `007`. Write `7`, or use text `"007"` if you need the zeros.
what does break outside loop mean | break outside loop python | continue not properly in loop => You used `break` or `continue` where there is no loop around it, often due to wrong indentation.
what does can't multiply sequence by non-int of type float mean | multiply list by float | multiply string by float error => You multiplied a string or list by a decimal number. Convert input to a number first, like `float(text) * 1.5`.
what does list.remove(x): x not in list mean | x not in list python | remove missing item error => You tried to remove a value that is not in the list. Check `if x in items:` before calling `items.remove(x)`.
what does substring not found mean | substring not found python | str index valueerror => `text.index("x")` raises this when the text is missing. Use `text.find("x")`, which returns -1 instead.
what does math domain error mean | math domain error python | sqrt negative python => You gave a math function a value it cannot handle, like `math.sqrt(-1)` or `math.log(0)`.
what does i/o operation on closed file mean | operation on closed file | closed file error python => You used a file after its `with` block ended or after `close()`. Do the reading or writing inside the `with` block.
what does object of type int has no len mean | int has no len python | len of number => `len()` only works on things like strings and lists. Use `len(str(number))` to count a number's digits.
what does nonetype object is not iterable mean | none not iterable python | cannot loop over none => You looped over something that is None, often a function that forgot to `return` its list.
what does cannot unpack non-iterable int object mean | cannot unpack int | unpack non iterable python => You wrote `a, b = 5`. The right side needs as many values as names, like `a, b = 5, 6`.
what does cannot import name mean | importerror cannot import => The module exists but does not have that name, or two modules import each other. Check spelling and the library's version.
what does cannot assign to function call mean | assign to function call | cannot assign to expression => The left side of `=` must be a variable, not something like `len(x) = 3`. If you meant to compare, use `==`.
what does was never closed mean python | ( was never closed | bracket never closed python => A bracket, parenthesis or brace has no matching closing one. The real mistake is often on the line before the error.
what does perhaps you forgot a comma mean | forgot a comma python | invalid syntax comma => Python found two values next to each other with nothing between them, often in a list or function call. Add the missing comma.
what does name true is not defined mean | true not defined python | lowercase true python => Python's booleans are written `True` and `False` with capital letters, and empty is `None`.
what does f-string expecting } mean | f string error python | f-string syntax error => An f-string has an unmatched brace. Close every `{` you open, and double a brace to show it as text, so `f"{{hi}}"` prints {hi}.
what does object of type set is not json serializable mean | not json serializable | json dump error python => JSON only supports dicts, lists, strings, numbers, booleans and None. Convert sets to lists and objects to dicts before saving.
what does expecting property name enclosed in double quotes mean | json expecting property name | json single quotes error => JSON needs double quotes around keys and strings, and no trailing commas. Python-style single quotes are not valid JSON.
what does coroutine was never awaited mean | coroutine never awaited | runtimewarning coroutine => You called an async function without `await`, so it never ran. Write `await fetch()`, or `asyncio.run(main())` at the top level.
what does asyncio.run cannot be called from a running event loop mean | running event loop error | asyncio run in jupyter => An event loop is already running, like in Jupyter. Use `await main()` there instead of `asyncio.run(main())`.
what does no such table mean sqlite | sqlite no such table | operationalerror no such table => The table does not exist in that database file. Run your CREATE TABLE first, and check you are opening the file you think you are.
what does database is locked mean sqlite | sqlite database is locked | sqlite locked error => Another connection is still writing. Commit and close connections when done, and avoid keeping two writers open.
what does raise_for_status mean | requests httperror | 404 error requests python => `response.raise_for_status()` raises `HTTPError` for 4xx and 5xx codes. A 404 means the page does not exist, so check the URL.
what does address already in use mean python | address already in use | port in use python => Another program, or an old copy of yours, is already using that port. Stop it, or pick a different port.
what does can't compare offset-naive and offset-aware datetimes mean | naive vs aware datetime | timezone compare error python => One datetime has a timezone and the other does not. Make both aware, like `datetime.now(timezone.utc)`, before comparing.
what does unsupported format string passed to nonetype mean | format nonetype error | f string none format => You formatted a value that is None, like `f"{x:.2f}"` with x being None. Find out why x is None.
what does maximum recursion depth exceeded while calling a python object mean | recursion depth while calling | infinite recursion property => Often a property or `__getattr__` calls itself by using its own name. Store the value in a different name like `self._hp`.
what does list assignment index out of range mean | list assignment index out of range | assign past end list => You set `items[5] = x` on a list that is too short. Use `append` to add new items.
what does key error 0 mean python | keyerror 0 | dict indexed with number => You used `[0]` on a dictionary, which looks for the key 0. Use `list(d.values())[0]` or loop over the dict instead.
what does attributeerror nonetype object has no attribute group mean | re match none | regex group none => `re.match` or `re.search` found nothing and returned None. Check `if m:` before calling `m.group()`.
what does valueerror too many values to unpack expected 2 mean | loop over dict unpack error | for k v in dict error => Looping over a dict gives only keys. Use `for k, v in d.items():` to get both.
what does typeerror unhashable type dict mean | unhashable dict | dict in set error => Dicts cannot be set items or dict keys because they can change. Use a tuple of the values, or a frozenset.
what does typeerror argument of type int is not iterable mean | in operator int error | int not iterable in => You used `in` with a number on the right, like `5 in 10`. The right side must be a list, string, set or similar.
what does typeerror can only join an iterable mean | join error python | join list of ints => `str.join` needs strings. Convert numbers first: `", ".join(map(str, numbers))`.
what does sequence item 0 expected str instance int found mean | expected str instance int found | join numbers error => Same cause: `join` got numbers. Use `", ".join(str(n) for n in numbers)`.
what does valueerror invalid literal for int with base 10 empty string mean | int of empty string | int('') error => You called `int("")`, often from pressing Enter with no input. Check `if text:` or use try/except to ask again.
what does indexerror pop from empty list mean | pop from empty list | pop error python => You called `pop()` on an empty list. Check `if items:` first.
what does runtimeerror set changed size during iteration mean | set changed size | modify set while looping => You added or removed from a set while looping over it. Loop over a copy: `for x in set(things):`.
what does typeerror object is not iterable custom class mean | make class iterable | my class not iterable => Your class has no `__iter__`. Add one that yields items, or loop over its list attribute instead.
what does indentationerror unexpected unindent mean | unexpected unindent | indentation try without except => A block ended too early, often a `try:` with no `except` or `finally` after it. Finish the block properly.
what does syntaxerror invalid syntax on else mean | else invalid syntax python | else without if python => The else is not lined up with its if, or there is something between them. Make else start at the same indent as the if.
what does syntaxerror expected an indented block mean | expected an indented block | empty block python => A line ending in `:` must be followed by indented code. Put `pass` there if the block should do nothing yet.
