# Git and GitHub, written by hand for Ace.
# tag: coding.git
what is git used for | git explained => Git is a version control system: it saves snapshots (commits) of your project so you can see history, undo mistakes, try ideas on branches and work with others.
github vs git | what is github used for => Git is the tool on your computer. GitHub is a website that hosts Git repositories online, with pull requests, issues, Actions and Pages for working with others.
who made git | when was git made | git history => Linus Torvalds created Git in 2005 to manage the Linux kernel's code.
how do i install git | download git | get git on windows => On Windows install Git for Windows from git-scm.com. On macOS run `git --version` and accept the Command Line Tools prompt, or use Homebrew. On Linux use your package manager.
how do i set my name in git | git config user name | set up git first time => Run `git config --global user.name "Your Name"` and `git config --global user.email "you@example.com"`. Git stamps every commit with these.
what is a repository | what is a repo | git repository meaning => A repository (repo) is a project folder that Git tracks, including the full history stored in a hidden `.git` folder.
how do i start a git repo | git init | make a folder a git repository => Run `git init` inside the project folder. It creates the `.git` folder and starts tracking from there.
what is git clone | clone a repository | download a repo from github => `git clone <url>` downloads a full copy of a repository, history and all, into a new folder.
what is a commit | git commit meaning | what does committing do => A commit is a saved snapshot of your staged changes with a message, author and time. Commits form the project's history.
how do i make a commit | git commit command | save changes in git => Stage files with `git add file` (or `git add .` for everything), then `git commit -m "Describe the change"`.
what is the staging area | git add explained | what does git add do => The staging area holds the changes that will go into your next commit. `git add` puts changes there, so you can commit only some of your edits.
what does git status do | git status | see what changed git => `git status` shows the branch you are on, which files changed, which are staged, and which are not tracked yet.
what does git diff do | git diff | see changes before commit => `git diff` shows line-by-line changes you have not staged. `git diff --staged` shows what is staged for the next commit.
what does git log do | git log | see commit history => `git log` lists commits, newest first. `git log --oneline --graph` gives a short view with branch lines.
what is a good commit message | how to write commit messages | commit message tips => Start with a short summary in the imperative, like "Add jump sound", under about 50 characters. Add a blank line and more detail if needed. Commit small, related changes together.
what is a branch in git | git branches explained | why use branches => A branch is a separate line of work. Make one for each feature or fix so main stays working, then merge it back when done.
how do i make a new branch | git branch create | git switch -c => `git switch -c new-feature` creates a branch and moves to it. The older command is `git checkout -b new-feature`.
how do i switch branches | git checkout branch | git switch => `git switch branch-name`. Commit or stash your changes first if Git complains.
how do i see all branches | list branches git | git branch command => `git branch` lists local branches with a star on the one you are on. `git branch -a` includes remote ones.
how do i delete a branch | git delete branch | remove old branch => `git branch -d name` deletes a merged branch. `-D` forces it even if not merged, so be careful.
what is main vs master | main branch git | master branch => They are just names for the default branch. Newer repositories use `main`; older ones often use `master`.
what is git merge | merge a branch | combine branches git => `git merge feature` (while on main) brings the feature branch's commits into main.
what is a merge conflict | fix merge conflict | git conflict markers => A conflict happens when two branches changed the same lines. Git marks them with `<<<<<<<`, `=======` and `>>>>>>>`; edit the file to keep the right code, remove the markers, then `git add` and commit.
what is git rebase | rebase vs merge | git rebase explained => Rebase moves your branch's commits so they sit on top of another branch, making a straight history. Merge keeps both histories and adds a merge commit. Never rebase commits others already pulled.
what is a remote in git | git remote add origin | what is origin => A remote is a copy of the repo elsewhere, like on GitHub. `origin` is the usual name for the one you cloned from. `git remote -v` lists them.
what does git push do | git push | upload commits to github => `git push` sends your new commits to the remote. The first time on a new branch, use `git push -u origin branch-name`.
what does git pull do | git pull | get latest changes git => `git pull` downloads new commits from the remote and merges them into your branch. It is a `git fetch` plus a merge (or rebase).
what is git fetch | fetch vs pull | git fetch explained => `git fetch` downloads new commits from the remote without changing your files. You can look first, then merge.
what does rejected non fast forward mean | git push rejected | updates were rejected => The remote has commits you do not have. Run `git pull` to bring them in, fix any conflicts, then push again.
what is .gitignore | gitignore file | ignore files in git => A .gitignore file lists files and folders Git should not track, like `node_modules/`, `.venv/`, build output, and files with secrets.
how do i stop tracking a file | remove file from git but keep it | git rm cached => Run `git rm --cached file`, add it to .gitignore, and commit. The file stays on your disk.
how do i undo changes to a file | discard changes git | git restore => `git restore file` throws away unstaged changes to that file. This cannot be undone, so be sure.
how do i unstage a file | git restore staged | undo git add => `git restore --staged file` takes it out of the staging area but keeps your changes.
how do i change my last commit message | git commit amend | fix last commit => `git commit --amend -m "New message"`. Only amend commits you have not pushed yet.
how do i undo the last commit | git reset head~1 | uncommit git => `git reset --soft HEAD~1` undoes the last commit but keeps the changes staged. If it was already pushed, use `git revert` instead.
what is git revert | revert a commit | undo a pushed commit => `git revert <commit>` makes a new commit that undoes an old one. It is safe for shared branches because it does not rewrite history.
what is git reset hard | git reset --hard | danger of reset hard => `git reset --hard <commit>` moves your branch back and throws away all later changes in your files. It is easy to lose work, so think twice.
what is git stash | stash changes | save work without committing => `git stash` shelves your uncommitted changes so you can switch branches. `git stash pop` brings them back.
what is head in git | git head meaning | detached head => HEAD points to the commit you are looking at, usually the tip of your branch. "Detached HEAD" means you checked out a commit directly; make a branch if you want to keep new work there.
what is a commit hash | sha in git | commit id => Every commit has a unique ID, a long hex hash like `a1b2c3d...`. You can usually use just the first 7 characters.
what is git tag | tag a release | version tags git => `git tag v1.0` labels a commit, usually a release. Push tags with `git push --tags`.
what is git reflog | recover lost commit | git reflog explained => `git reflog` lists everywhere HEAD has been, even after resets. Find the lost commit's hash and `git switch -c rescue <hash>` to get it back.
what is git blame | who changed this line | git blame command => `git blame file` shows who last changed each line and in which commit. Editors like VS Code show this inline.
what is git cherry pick | cherry-pick | copy one commit to another branch => `git cherry-pick <hash>` copies one commit onto your branch.
what is git bisect | find which commit broke it | git bisect explained => `git bisect` does a binary search through history: you mark commits good or bad, and Git finds the first bad one quickly.
what is a fork on github | fork vs clone | fork a repo => A fork is your own copy of someone else's repository on GitHub. You change your fork and open a pull request to suggest the changes back.
what is a pull request on github | how to make a pull request | open a pr => Push your branch, then on GitHub click Compare & pull request. Describe the change, and others can review, comment and merge it.
review a pull request | pr review => Code review is when others read your changes in a pull request, suggest fixes and approve them before merging. It catches bugs and spreads knowledge.
what are merge options on github | squash and merge | rebase and merge => GitHub can merge a pull request with a merge commit, squash all its commits into one, or rebase them onto the base branch. Squash keeps main's history tidy.
what is a github issue | github issues | report a bug on github => Issues track bugs, ideas and tasks for a repository. You can label them, assign them and close them from a commit or pull request with words like "Fixes #12".
what is github actions | ci cd github | automatic tests on github => GitHub Actions runs workflows (YAML files in `.github/workflows/`) on events like pushes, for tests, builds and deployments.
what is ci | ci build => Continuous integration means automatically building and testing every change, so problems show up right away instead of piling up.
what is a readme | what to put in a readme => README.md is the first file people see in a repo. Explain what the project does, how to install and run it, and how to contribute.
what is a license on github | open source license | mit license => A license says what others may do with your code. MIT is short and permissive; GPL requires shared changes to stay open. With no license, others have no right to reuse it.
what is github desktop | git gui | github desktop app => GitHub Desktop is a free app for committing, branching and syncing with GitHub without typing commands. VS Code and Xcode also have Git built in.
what is the gh cli | github cli | gh command => `gh` is GitHub's command-line tool. `gh repo clone`, `gh pr create` and `gh pr checkout` work with GitHub from the terminal.
how do i log in to github from git | git authentication | personal access token github => GitHub no longer accepts account passwords for Git over HTTPS. Sign in with GitHub Desktop or `gh auth login`, use a personal access token, or set up an SSH key.
what is an ssh key for github | ssh github | git ssh setup => An SSH key pair lets you push without a password. Make one with `ssh-keygen -t ed25519`, add the public key (.pub) in GitHub's settings, and keep the private key secret.
what does permission denied publickey mean | github ssh error | permission denied (publickey) => GitHub did not accept your SSH key. Check it is added to your GitHub account and loaded in your SSH agent, or switch the remote to HTTPS.
what does fatal not a git repository mean | not a git repository | git command in wrong folder => You ran a git command outside a repository. `cd` into the project folder, or run `git init` if it is new.
what does please tell me who you are mean | git user email not set | author identity unknown => Git needs your name and email for commits. Set them with `git config --global user.name` and `user.email`.
what does your branch is behind mean | branch is behind origin | git behind by commits => The remote has newer commits. Run `git pull` to catch up.
what does your branch is ahead mean | ahead of origin by | git ahead => You have local commits that are not pushed yet. Run `git push`.
what does nothing to commit working tree clean mean | nothing to commit | working tree clean => Every change is already committed; there is nothing new to save.
what does untracked files mean | untracked files git | git not tracking new file => Git sees new files it has never been told to track. `git add` them to include them, or put them in .gitignore.
what does refusing to merge unrelated histories mean | unrelated histories git | merge unrelated => The two branches do not share a starting commit, often after making a new repo on GitHub with a README. `git pull origin main --allow-unrelated-histories` joins them.
what does large files detected mean | github file too large | file exceeds 100 mb => GitHub blocks files over 100 MB. Remove the file from history, or use Git LFS for big assets.
what is git lfs | large file storage | git lfs explained => Git LFS stores big files like models, textures and audio outside the normal repo history and keeps small pointers in Git. Track types with `git lfs track "*.psd"`.
i committed a password what do i do | leaked api key github | secret in git history => Treat the secret as leaked: revoke or change it right away. Removing it from history is not enough, since others may have copied it already.
how do i see what changed in a commit | git show | view a commit => `git show <hash>` shows the commit's message and its changes.
how do i compare two branches | git diff branches | difference between branches => `git diff main..feature` shows what changed between them. `git log main..feature` lists the commits only on feature.
how do i rename a branch | git branch -m | rename branch git => `git branch -m old-name new-name`. If it was pushed, push the new one and delete the old one on the remote.
how do i go back to an old version of a file | restore file from commit | git checkout old file => `git restore --source <hash> file` puts that file back the way it was in that commit.
how do i squash commits | combine commits git | squash locally => Interactive rebase (`git rebase -i`) can squash commits into one. GitHub's "Squash and merge" button does it when merging a pull request.
what is a submodule | git submodule | repo inside a repo => A submodule is a Git repository inside another one, pinned to a certain commit. They are useful but tricky; many projects use package managers instead.
monorepo vs many repos | one big repository => A monorepo keeps many related projects in one repository, making shared changes easier at the cost of a bigger repo.
semver | version numbers meaning => SemVer versions look like MAJOR.MINOR.PATCH, like 2.4.1. Bump MAJOR for breaking changes, MINOR for new features, PATCH for bug fixes.
what is a release on github | github releases | publish app download => A GitHub Release attaches notes and files, like installers, to a tag so people can download a version.
what is gitflow | branching strategy | trunk based development => A branching strategy is a team's rule for branches. Trunk-based development keeps short-lived branches merged into main often; Git Flow uses long-lived develop and release branches.
what is a protected branch | branch protection github | require reviews => Branch protection rules on GitHub can block direct pushes to main and require pull requests, reviews or passing checks before merging.
what is a draft pull request | draft pr | work in progress pr => A draft pull request shows work in progress that is not ready to merge. Mark it ready for review when it is done.
how do i update my branch with main | keep branch up to date | merge main into branch => On your branch run `git fetch` then `git merge origin/main` (or `git rebase origin/main`), fix conflicts, and push.
how do i clone a specific branch | git clone branch | clone only one branch => `git clone -b branch-name <url>` checks out that branch after cloning.
what is a shallow clone | git clone depth 1 | faster clone => `git clone --depth 1 <url>` downloads only the latest snapshot, not the whole history, which is much faster for big repos.
what is git config | git settings | global git config => `git config` sets options. `--global` applies to all your repos, like your name, default branch name and editor.
how do i set the default branch name | init.defaultbranch | default main branch => `git config --global init.defaultBranch main` makes new repos start on main.
what is a git alias | git shortcuts | make git commands shorter => `git config --global alias.st status` lets you type `git st`. Aliases save typing for long commands.
what is a hook in git | git hooks | pre-commit hook => Hooks are scripts Git runs at certain moments, like pre-commit to run a linter before each commit. They live in `.git/hooks`, or are managed by tools like pre-commit.
what is a commit graph | git log graph | visualize git history => `git log --oneline --graph --all` draws the branches and merges as lines in the terminal. GUI tools show the same picture.
why use git for solo projects | do i need git alone | git for one person => Yes, Git helps even alone: you can undo bad changes, try risky ideas on a branch, see what changed when something broke, and back up to GitHub.
how often should i commit | commit frequency | when to commit => Commit whenever you finish a small working step, like adding one feature or fixing one bug. Small commits are easier to understand and undo.
what is a dirty working tree | uncommitted changes => A dirty working tree has changes that are not committed. A clean one matches the last commit.
what is the git index | git index meaning | index vs staging => The index is Git's name for the staging area, the list of what goes into the next commit.
what is a fast forward merge | fast-forward git | no merge commit => If main has not moved since you branched, Git can just move main forward to your branch's tip, with no merge commit. That is a fast-forward.
what is origin main | origin/main meaning | remote tracking branch => `origin/main` is your local record of where main was on the remote the last time you fetched. `git fetch` updates it.
what is git clean | remove untracked files | git clean -fd => `git clean -fd` deletes untracked files and folders. Run `git clean -n` first to see what it would delete.
what is github copilot | ai in github | copilot code suggestions => GitHub Copilot is an AI assistant that suggests code inside editors like VS Code. Always read and test what it suggests.
what is a gist | github gist | share code snippet => A gist is a quick way to share a code snippet or small file on GitHub, and each one is a tiny Git repository.
what is github codespaces | code in browser github | cloud dev environment => Codespaces gives you a full VS Code environment in the browser, running on a cloud machine with your repo ready to go.
what is a contribution graph | github green squares | github contributions => The green squares on a GitHub profile show how many contributions (commits, pull requests, issues) someone made each day.
what is a star on github | github stars | star a repo => Starring a repo bookmarks it and shows the owner you like it. Star counts give a rough idea of popularity.
what is git for roblox | rojo | version control roblox => Roblox Studio has its own version history, but tools like Rojo sync scripts to files on your computer so you can use Git and VS Code for Roblox projects.
what is git for unity | unity gitignore | game project git => Game engines make many generated files. Use the engine's standard .gitignore, and Git LFS for big art and audio files.
what is sourcetree | gitkraken | git gui apps => Sourcetree and GitKraken are desktop apps that show your Git history visually and let you commit, branch and merge with clicks.
how do i make a repo on github | create github repository | new repo github => Click New on GitHub, name it, pick public or private, and create it. Then follow its instructions to push an existing folder with `git remote add origin` and `git push -u origin main`.
should my repo be public or private | public vs private repo | private github repo => Public repos can be seen by anyone, which is great for open source and portfolios. Make it private if it has unfinished or personal work. Never put secrets in either.
what is a commit sign off | signed commits | verified commit github => Signed commits use a GPG or SSH key to prove you made them, and GitHub shows a Verified badge.
what is the difference between git pull and git pull rebase | pull rebase | pull with rebase => `git pull --rebase` puts your local commits on top of the new remote ones instead of making a merge commit, keeping history straight.
how do i see who is working on a repo | git shortlog | contributors list => `git shortlog -sn` counts commits by each author. GitHub's Insights tab shows contributors too.
how do i search git history | git log grep | find commit by message => `git log --grep="jump"` finds commits whose message mentions jump. `git log -S "functionName"` finds commits that added or removed that text.
