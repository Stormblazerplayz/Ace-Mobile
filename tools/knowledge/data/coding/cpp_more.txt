# More C++ how-tos, pitfalls and ideas, written by hand for Ace.
# tag: coding.cpp.howto
how do i reverse a string in c++ | reverse text c++ | flip a string c++ => `std::reverse(s.begin(), s.end());` from `<algorithm>` reverses it in place. Or make a reversed copy with `std::string r(s.rbegin(), s.rend());`.
how do i split a string in c++ | split by comma c++ | string split c++ => C++ has no built-in split. Put the text in a `std::stringstream` and call `std::getline(ss, part, ',')` in a loop to get each piece.
what is stringstream | std stringstream | sstream c++ => `std::stringstream` from `<sstream>` treats a string like a stream, so you can read words or numbers out of it with `>>` or build text with `<<`.
how do i make a string uppercase in c++ | uppercase string c++ | to upper whole string => Loop over it: `for (char& c : s) c = std::toupper(static_cast<unsigned char>(c));`. Or use `std::transform` with toupper.
how do i check if a string contains a word in c++ | substring search c++ | string has text c++ => `if (s.find("word") != std::string::npos)` is true when it appears. C++23 adds `s.contains("word")`.
how do i trim spaces from a string in c++ | trim c++ | remove whitespace c++ => There is no built-in trim. Use `s.find_first_not_of(" \t")` and `s.find_last_not_of(" \t")` to find the ends, then take a `substr`.
how do i count characters in a string c++ | count letter c++ | how many times a char appears => `std::count(s.begin(), s.end(), 'a')` returns how many 'a' characters there are.
how do i loop over a string in c++ | each character c++ | iterate string c++ => `for (char c : s) { }` visits each character. Use `for (size_t i = 0; i < s.size(); i++)` if you need the index.
how do i compare strings in c++ | string equals c++ | are two strings the same c++ => With std::string just use `==`, `!=`, `<` and so on. For old C strings (char arrays) use `std::strcmp`, since `==` compares addresses.
how do i make a 2d array in c++ | 2d vector c++ | grid in c++ => `std::vector<std::vector<int>> grid(rows, std::vector<int>(cols, 0));` makes a rows by cols grid of zeros. Read with `grid[r][c]`.
how do i pass a vector to a function c++ | vector parameter c++ | function takes vector => Use `const std::vector<int>& v` to read it without copying, or `std::vector<int>& v` to change it. Passing by value copies the whole vector.
how do i return multiple values from a function c++ | return two values c++ | return a pair => Return a `std::pair`, `std::tuple` or a small struct, then unpack with structured bindings: `auto [min, max] = getRange();`.
what are structured bindings | auto [a, b] c++ | unpack a pair c++ => Structured bindings (C++17) unpack pairs, tuples and structs into names: `for (const auto& [name, score] : scores) { }` loops over a map nicely.
how do i loop over a map in c++ | iterate map c++ | map for loop c++ => `for (const auto& [key, value] : m) { }` goes through every pair, in sorted key order for std::map.
how do i check if a key exists in a map c++ | map has key c++ | key in map c++ => `if (m.count(key))`, `if (m.find(key) != m.end())`, or in C++20 `if (m.contains(key))`. Avoid `m[key]` for checking since it adds the key.
how do i remove duplicates from a vector c++ | unique values vector | dedupe vector c++ => Sort it, then `v.erase(std::unique(v.begin(), v.end()), v.end());`. Or copy the values into a `std::set`.
how do i remove an element from a vector by value c++ | erase value from vector | erase remove idiom => In C++20, `std::erase(v, x);`. Before that, use the erase-remove idiom: `v.erase(std::remove(v.begin(), v.end(), x), v.end());`.
how do i sum a vector in c++ | add up vector c++ | total of vector => `std::accumulate(v.begin(), v.end(), 0)` from `<numeric>`. Use `0.0` as the starting value for doubles, or the decimals get cut off.
how do i find the biggest number in a vector c++ | max of vector c++ | largest element c++ => `*std::max_element(v.begin(), v.end())` gives the largest value. Make sure the vector is not empty first.
how do i sort with a custom rule in c++ | custom comparator c++ | sort by score c++ => Pass a lambda: `std::sort(v.begin(), v.end(), [](const Player& a, const Player& b) { return a.score > b.score; });` sorts by score, highest first.
how do i shuffle a vector in c++ | random order c++ | shuffle deck c++ => `std::shuffle(v.begin(), v.end(), rng);` with a `std::mt19937 rng{std::random_device{}()};`. The old `std::random_shuffle` was removed in C++17.
how do i get a random float in c++ | random decimal c++ | uniform_real_distribution => `std::uniform_real_distribution<double> dist(0.0, 1.0);` then `dist(rng)` gives a double from 0 up to (not including) 1.
how do i check if a number is prime in c++ | prime number c++ | is prime function => Return false below 2, then test dividing by every i where `i * i <= n`. If none divide evenly, it is prime.
how do i check if a number is even in c++ | even or odd c++ | odd number c++ => `if (n % 2 == 0)` means even. For negative numbers `n % 2` can be -1, so test `!= 0` for odd.
how do i swap two variables in c++ | swap values c++ | exchange two numbers c++ => `std::swap(a, b);` from `<utility>` swaps them.
how do i round a number to 2 decimals in c++ | round to two places c++ | two decimal places c++ => For printing, use `std::fixed << std::setprecision(2)`. To change the value, `std::round(x * 100.0) / 100.0`.
how do i get the absolute value in c++ | abs c++ | make number positive c++ => `std::abs(x)` from `<cmath>` (or `<cstdlib>` for ints) returns x without its minus sign.
how do i read numbers until the end in c++ | read all input c++ | while cin => `while (std::cin >> x) { }` keeps reading numbers until input ends or a non-number appears.
why does getline skip input after cin | cin then getline problem | getline not waiting => `cin >> x` leaves the Enter key's newline behind, so getline reads an empty line. Call `std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');` before getline.
how do i check if cin failed | invalid input c++ | user typed letters instead of number => After `std::cin >> n`, check `if (!std::cin)`. Then call `std::cin.clear()` and ignore the rest of the line before asking again.
how do i clear the console in c++ | clear screen c++ | system cls => There is no standard way. `system("cls")` works on Windows and `system("clear")` on Mac or Linux, but they are slow and not portable.
press any key to continue c++ | console closes immediately | c++ window closes right away => Run it from a terminal so the window stays open, or add `std::cin.get();` before the end of main to wait for Enter.
how do i get the time in c++ | current date c++ | time now c++ => `std::chrono::system_clock::now()` gives the time now. C++20 can print it with `std::format("{}", now)`. Older code used `std::time(nullptr)`.
how do i measure how long code takes in c++ | timer c++ | benchmark c++ => Save `auto t0 = std::chrono::steady_clock::now();`, run the code, then `std::chrono::duration<double, std::milli>(steady_clock::now() - t0).count()` gives milliseconds.
how do i make a game loop in c++ | c++ game loop | update and draw loop => A game loop repeats: read input, update the game by the time since the last frame (delta time), then draw. Libraries like SFML, SDL and raylib give you the window and timing.
delta time in c++ | deltatime c++ | frame independent movement c++ => Delta time is how long the last frame took. Multiply speeds by it (position += speed * dt) so things move at the same speed at any frame rate.
how do i make a class with a header and cpp file | split class c++ | class in two files => Put the class declaration in Player.h (with `#pragma once`), define the member functions in Player.cpp as `void Player::jump() { }`, and include Player.h where you use it.
what does :: mean in c++ | scope resolution operator | double colon c++ => `::` names something inside a namespace or class, like `std::cout`, `Player::jump` or `Color::Red`. A leading `::x` means the global x.
what is a member initializer list | colon after constructor | initialize members c++ => `Player(int hp) : health(hp), alive(true) {}` sets members before the constructor body runs. It is required for const and reference members.
what is a copy constructor | copy constructor c++ | copying objects c++ => A copy constructor, like `Player(const Player& other)`, makes a new object as a copy of another. The compiler writes one for you unless your class needs special handling.
what is a getter and setter in c++ | getters setters | accessor methods c++ => Getters and setters are small public functions that read or change private members, like `int getHealth() const` and `void setHealth(int h)`, so the class can check values.
what is encapsulation in c++ | data hiding c++ | why make members private c++ => Encapsulation means keeping a class's data private and offering public functions to use it, so other code cannot put the object into a broken state.
composition vs inheritance c++ | composition c++ | has a or is a in c++ => Inheritance means "is a" (a Boss is an Enemy). Composition means "has a" (a Car has an Engine member). Composition is often simpler and more flexible.
what is multiple inheritance | inherit from two classes c++ | diamond problem => C++ lets a class inherit from several bases. If two bases share a grandparent you get the diamond problem, solved with virtual inheritance. Use it sparingly.
what is an interface in c++ | c++ interface class | pure virtual interface => C++ has no interface keyword. You make a class with only pure virtual functions and a virtual destructor, and other classes inherit from it.
what is object slicing | slicing problem c++ | derived copied to base => Copying a derived object into a base class variable (by value) cuts off the derived parts. Use references or pointers to keep the full object.
what is a vtable | virtual table | how virtual functions work => Classes with virtual functions get a hidden table of function pointers. Each object points to its class's table, so calls go to the right override at run time.
what is a static function in a class | static member function | call without object c++ => A static member function belongs to the class, not an object, so you call `Math::square(3)`. It cannot use `this` or non-static members.
what is a singleton | singleton c++ | single instance class => A singleton is a class with only one instance, reached through a static function. It is like a global variable, so use it carefully.
what is a const reference | const & c++ | pass by const reference => `const T&` lets a function read a big object without copying it and promises not to change it. It is the usual way to pass strings and vectors.
what is an rvalue | lvalue and rvalue | what is an lvalue => Roughly, an lvalue has a name and an address, like a variable. An rvalue is a temporary, like `5` or the result of `a + b`. Move semantics use rvalue references (`T&&`).
what is a function pointer | pointer to function c++ | callback c++ => A function pointer stores which function to call: `int (*op)(int, int) = add;`. Lambdas and `std::function` are usually easier to use.
what is pointer arithmetic | pointer plus one | array and pointer c++ => Adding 1 to a pointer moves it to the next element, not the next byte. An array name turns into a pointer to its first element, so `*(arr + 2)` is `arr[2]`.
what is a double pointer | pointer to pointer | int** c++ => `int** pp` points to a pointer to an int. You mostly see it with C APIs or 2D arrays made with new; modern C++ prefers vectors.
what is a c string | char array string | null terminated string => A C string is an array of chars ending in a `'\0'` null character, like `char name[] = "Sam";` which uses 4 bytes. std::string is safer.
what is a buffer overflow | write past array c++ | array out of bounds c++ => Writing past the end of an array overwrites other memory, causing crashes or security holes. Use `std::vector`, `std::array` and `.at()` to stay safe.
what is const char* | char pointer c++ | string literal type => A string literal like "hi" is an array of const char, and `const char*` points to its first character. Wrap it in std::string to use string features.
what is the difference between new and malloc | malloc vs new | malloc in c++ => `new` creates and constructs objects, and `delete` destroys them. `malloc` and `free` come from C and only grab raw memory, so avoid them in C++ code.
what is delete[] | delete array c++ | delete vs delete[] => Memory from `new int[10]` must be freed with `delete[]`, not `delete`. Mixing them is undefined behavior; `std::vector` avoids the issue.
what is a weak_ptr | weak pointer c++ | break shared_ptr cycle => `std::weak_ptr` watches a shared_ptr's object without keeping it alive. It breaks reference cycles; call `lock()` to get a shared_ptr if the object still exists.
what is a header only library | header only c++ | single header library => A header-only library is all in .h files, so you just include it with no separate compiling or linking. Examples include nlohmann/json and many stb libraries.
what is json in c++ | parse json c++ | nlohmann json => C++ has no built-in JSON. The popular nlohmann/json library lets you write `json j = json::parse(text);` and `j["name"]`.
what is boost | boost library c++ | boost c++ => Boost is a large, well-tested collection of C++ libraries. Many standard features, like smart pointers and optional, started in Boost.
what is qt | qt c++ | gui in c++ => Qt is a big C++ framework for desktop and mobile apps with windows, buttons and more. Dear ImGui is a simpler option popular for game tools.
what is dear imgui | imgui | immediate mode gui => Dear ImGui is a C++ library for quick debug menus and tools inside games. You describe the UI every frame, like `if (ImGui::Button("Play")) { }`.
what is opengl | graphics api => OpenGL is an older cross-platform graphics API for drawing 2D and 3D with the GPU. Vulkan, DirectX 12 and Metal are lower-level modern APIs.
what is vulkan | vulkan api | vulkan vs opengl => Vulkan is a modern low-level graphics API. It is fast and gives lots of control, but it takes far more code than OpenGL to draw your first triangle.
what is godot c++ | gdextension | godot and c++ => Godot games usually use GDScript or C#, but GDExtension lets you write fast parts in C++. The Godot engine itself is written in C++.
what is a game engine written in | engines in c++ | why games use c++ => Most big engines, like Unreal, Unity's core and Godot, are written in C++ for speed and control over memory.
what is competitive programming | c++ for competitive programming | usaco => Competitive programming is solving puzzles with code against the clock, in contests like USACO and Codeforces. C++ is popular there because it is fast and has the STL.
what is bits/stdc++.h | include bits stdc++ | bits stdc => `#include <bits/stdc++.h>` pulls in the whole standard library on GCC. It is common in contests but not standard, slow to compile and does not work on all compilers.
what is fast io in c++ | ios sync_with_stdio | speed up cin => `std::ios::sync_with_stdio(false); std::cin.tie(nullptr);` at the start of main makes cin and cout much faster for big inputs.
what is the difference between float and double | float vs double c++ | which decimal type => A float is 32 bits with about 7 digits of precision; a double is 64 bits with about 15 to 16. Use double unless memory is tight or an API wants float.
why does 0.1 + 0.2 not equal 0.3 in c++ | floating point error c++ | float comparison c++ => Decimals are stored in binary and many cannot be exact. Compare with a small tolerance: `std::abs(a - b) < 1e-9`.
what is long long | 64 bit integer c++ | big numbers c++ => `long long` holds at least 64 bits, up to about 9.2 quintillion. Write literals with LL, like `10000000000LL`.
what is a char to int conversion | char to number c++ | '5' to 5 => `c - '0'` turns a digit character like '5' into the number 5. `static_cast<int>(c)` gives its character code instead.
what is an enum | plain enum c++ | enum in c++ => `enum Direction { Up, Down };` makes named int constants starting at 0. Prefer `enum class` so names do not leak and do not mix with ints.
what is a typedef vs using | using alias c++ | type alias c++ => `using Grid = std::vector<std::vector<int>>;` gives a long type a short name. It does the same as typedef but is easier to read and works with templates.
what is a macro | #define macro problems | why avoid macros => A macro is text replaced before compiling. Macros ignore scope and types, so `#define SQUARE(x) x*x` gives the wrong answer for `SQUARE(1+2)`. Use constexpr functions.
what is #ifdef | conditional compilation | #if c++ => `#ifdef DEBUG ... #endif` includes code only if DEBUG is defined, handy for debug prints or platform-specific code.
what is a translation unit | cpp file compiling | how c++ compiles => Each .cpp file, with all its includes pasted in, is a translation unit compiled separately into an object file. The linker then joins them.
what is an object file | .o file | .obj file => An object file (.o or .obj) is the compiled machine code for one .cpp file. The linker combines object files and libraries into the final program.
what is the odr | one definition rule | defined twice c++ => The One Definition Rule says each function or variable may be defined only once in a program (inline ones once per file, identically). Breaking it causes linker errors or odd bugs.
what is a c++ module | c++20 modules | import std => C++20 modules replace headers with `import`, which can compile faster and avoids macro leaks. C++23 adds `import std;`, though support varies between compilers and build tools.
what is a coroutine in c++ | c++20 coroutines | co_await explained => A coroutine is a function that can pause and resume later, using co_await, co_yield or co_return. They are powerful but need library support to be easy.
what are ranges in c++ | std ranges | ranges c++20 => C++20 ranges let algorithms take whole containers, like `std::ranges::sort(v);`, and chain views like `v | std::views::filter(f) | std::views::transform(g)`.
what is std::views | views filter c++ | lazy ranges => Views like `std::views::filter`, `transform`, `take` and `reverse` create lazy, non-copying views of a range that you can loop over or chain with the pipe symbol.
what is constexpr if | if constexpr | compile time if => `if constexpr (cond)` picks a branch while compiling, so the other branch is not even built. It is very handy inside templates.
what is a variadic template | template parameter pack | typename... args => A variadic template takes any number of arguments: `template <typename... Args> void log(Args... args)`. Fold expressions like `(std::cout << ... << args);` use them all.
what is a functor | function object | operator() c++ => A functor is an object with an `operator()`, so it can be called like a function and also keep state. Lambdas are a short way to make them.
pass function as argument c++ | function parameter lambda | take a callback c++ => Take a `std::function<void()>` (or a template parameter) and call it later. Pass a lambda like `[]() { std::cout << "done"; }`.
what is lambda capture | capture by reference lambda | [=] vs [&] => `[x]` copies x into the lambda, `[&x]` uses x by reference, `[=]` copies everything used and `[&]` references everything used. References must not outlive the variables.
what is a std::array vs vector | array vs vector c++ | when to use std array => `std::array` has a fixed size known at compile time and no heap memory. `std::vector` can grow and shrink. Use array for fixed things like a 3x3 board.
what is std::list | linked list c++ | list vs vector => `std::list` is a doubly linked list: fast to insert or remove in the middle with an iterator, but slow to index. Vector is faster for almost everything else.
what is std::tuple | tuple c++ | get from tuple => `std::tuple<int, std::string, double>` groups several values. Read them with `std::get<0>(t)` or unpack with `auto [a, b, c] = t;`.
what is std::any | any type c++ | store anything => `std::any` (C++17) can hold a value of any type. You get it back with `std::any_cast<int>(a)`, which throws if the type is wrong.
what is std::bitset | bitset c++ | binary number c++ => `std::bitset<8> b(5);` stores bits; printing it shows 00000101. You can test, set and flip bits and count them with `count()`.
how do i print a number in binary c++ | binary output c++ | int to binary => `std::cout << std::bitset<8>(n);` prints 8 bits. C++20 can also use `std::format("{:b}", n)`.
how do i print in hex in c++ | hexadecimal c++ | std hex => `std::cout << std::hex << n;` prints in hexadecimal. Use `std::dec` to switch back.
what is std::numeric_limits | max int value c++ | int max c++ => `std::numeric_limits<int>::max()` from `<limits>` gives the biggest int. There is `min()` and `lowest()` too.
what is int_max | climits | int max macro => `INT_MAX` from `<climits>` is the largest int (2,147,483,647 for 32-bit ints). `std::numeric_limits<int>::max()` is the C++ style.
what is an assert | assert c++ | cassert => `assert(health >= 0);` from `<cassert>` stops the program with a message if the condition is false. It is turned off when NDEBUG is defined, as in many release builds.
what is a unit test in c++ | testing c++ | google test => A unit test checks one small piece of code automatically. Frameworks like GoogleTest and Catch2 let you write `EXPECT_EQ(add(2, 2), 4);`.
what is a debug vs release build | release mode c++ | optimization flags => Debug builds include debug info and checks so you can step through code. Release builds use optimizations like `-O2`, which run much faster but are harder to debug.
what is -o2 | optimization level | -o3 vs -o2 => `-O2` tells GCC or Clang to optimize the program for speed. `-O0` means none (good for debugging) and `-O3` tries harder, though it is not always faster.
what is a dll | dynamic library windows | missing dll error => A DLL is a library loaded when a Windows program starts. A "missing DLL" error means the program cannot find one, so it must sit next to the .exe or be installed.
what is a segfault vs exception | crash vs exception c++ | why no error message => An exception is a C++ error you can catch with try/catch. A segfault is the operating system stopping your program for touching bad memory, which try/catch cannot catch.
what is stack overflow in c++ | recursion too deep | stack overflow crash => Each function call uses stack space. Infinite or very deep recursion, or huge local arrays, run out of stack and crash. Add a base case or use the heap.
what is recursion in c++ | recursive function c++ | factorial recursion c++ => A recursive function calls itself on a smaller problem, like `int fact(int n) { return n <= 1 ? 1 : n * fact(n - 1); }`. It needs a base case to stop.
what does error expected unqualified-id mean | expected unqualified id | unqualified-id error => The compiler hit a keyword or symbol where it expected a name, often an extra semicolon, a stray brace, or using a reserved word as a variable name.
what does error invalid use of incomplete type mean | incomplete type | forward declared class error => You used a class that was only forward declared (`class Enemy;`) in a way that needs its full definition. Include its header in the .cpp file.
what does error redefinition of class mean | class redefinition | header included twice error => The same class was defined twice, usually because a header lacks `#pragma once`. Add it to the top of the header.
what does error use of deleted function mean | use of deleted function | deleted copy constructor => You tried to use something marked `= delete`, often copying a type like `std::unique_ptr`. Pass by reference or use `std::move` instead.
what does error no member named mean | has no member named | class has no member => You used a member that the class does not have. Check spelling and capitals, that you included the right header, and that you used `.` vs `->` correctly.
what does error request for member which is of non-class type mean | non-class type error | most vexing parse => You probably wrote `Player p();`, which C++ reads as a function declaration. Write `Player p;` or `Player p{};` instead.
what does error passing const as this argument mean | discards qualifiers | const member error => You called a non-const member function on a const object. Mark the function `const` if it does not change anything.
what does error invalid operands to binary expression mean | no match for operator | invalid operands => You used an operator, like `+` or `<<`, on types that do not support it, such as printing a struct with no `operator<<`. Define the operator or use the members.
what does warning comparison of integer expressions of different signedness mean | signed unsigned comparison warning | comparison between signed and unsigned => You compared an int with an unsigned value like `v.size()`. Use `size_t` for the loop variable, or cast on purpose.
what does warning unused variable mean | unused variable | variable set but not used => You made a variable and never used it. Delete it, or check whether you forgot to use it, which may be a bug.
what does warning statement has no effect mean | statement has no effect | expression result unused => A line does nothing, like `x == 5;` where you meant `x = 5;`. Check the line the warning names.
what does error ambiguous call mean | call of overloaded is ambiguous | ambiguous overload => Several overloads fit equally well, so the compiler cannot choose. Cast an argument to the exact type you mean.
what does error expected class-name before mean | expected class name | inheritance error => The class you inherit from is not known there. Include its header and check the spelling.
what does fatal error iostream not found mean | iostream file not found | compiler cannot find headers => Your compiler or IDE is not set up correctly, or you compiled C++ as C. Use g++ or clang++ (not gcc), and on Mac install the Xcode command line tools.
what does process returned -1073741819 mean | 0xc0000005 | access violation => On Windows this is an access violation, the same as a segfault: reading or writing memory you should not, often a null pointer or bad index.
what does error ld returned 1 exit status mean | ld returned 1 | collect2 error => The linker failed. Look at the error just above it, usually "undefined reference to ...", or the program is still running so the .exe cannot be overwritten.
what is undefined reference to winmain | winmain error | undefined reference to main => The linker could not find `main`. Check that it is spelled `int main()` and that the file with it is part of the build.
what does error invalid conversion from const char* to char* mean | const char to char error | string literal to char pointer => String literals are const. Use `const char*` or, better, `std::string`.
what does narrowing conversion mean | narrowing conversion error | brace init narrowing => Brace initialization will not silently squeeze a value into a smaller type, like `int x{3.7};`. Use a cast if you really mean it.
