# tag: tech.glossary.chips
what is an npu | neural processing unit => An NPU is a part of a chip built for AI tasks like blurring your webcam background or live captions. It does them using much less power than the CPU or GPU.
what are tops on a chip | ai tops meaning => TOPS means trillions of operations per second, a rough measure of how fast an NPU or GPU can run AI math. Higher is faster, but real apps matter more than the number.
what is a copilot plus pc | copilot+ pc meaning => A Copilot+ PC is a Windows 11 laptop with an NPU of at least 40 TOPS, 16 GB of RAM and 256 GB of storage, which unlocks extra AI features like Recall and Live Captions translation.
what is windows recall | recall feature windows => Recall is a Copilot+ PC feature that takes snapshots of your screen so you can search for things you saw before. It's opt-in and stored on the device, and you can pause or remove it.
what is an arm laptop | arm chip windows laptop => ARM chips, like Snapdragon X and Apple's M chips, use a different instruction set from Intel and AMD's x86 chips. They're usually very power efficient, giving long battery life.
can windows on arm play games | snapdragon laptop games => Many games run through Windows' Prism emulation, but performance is lower and some anti-cheat games don't work. As of 2025, an x86 Windows PC is still the safer choice for gaming.
what is snapdragon x elite | snapdragon x laptop => Snapdragon X Elite and X Plus are Qualcomm's ARM chips for Windows laptops, first released in 2024. They focus on long battery life and a fast NPU.
what is a system on a chip | soc meaning => A system on a chip puts the CPU, GPU, memory controller and other parts onto one chip. Phones, tablets and Apple silicon Macs all use them.
what is unified memory | apple unified memory => Unified memory is RAM shared by the CPU and GPU in one pool, used in Apple silicon. It's fast, but you can't upgrade it later, so pick enough when buying.
what is ipc on a cpu | instructions per clock => IPC is how much work a CPU core does each clock tick. A newer chip with higher IPC can beat an older one with a higher GHz number.
what is a boost clock | base clock vs boost clock => The base clock is the speed a CPU or GPU can always hold, and the boost clock is the higher speed it reaches when it's cool enough and has power to spare.
what are p cores and e cores | performance and efficiency cores => Intel and phone chips mix big performance cores for heavy work with small efficiency cores for background tasks. Windows' scheduler decides which core runs what.
what is hyperthreading | smt meaning => Hyperthreading (Intel) or SMT (AMD) lets one core run two threads at once, using parts of the core that would sit idle. It helps multitasking more than games.
what is a chiplet | chiplet cpu => A chiplet design builds a CPU from several smaller dies joined together, which AMD Ryzen uses. It's cheaper to make than one huge chip.
what is lpddr5x | lpddr ram => LPDDR5X is low-power memory used in thin laptops, phones and tablets. It's fast and efficient but soldered to the board, so it can't be upgraded.
what is soldered ram | can i upgrade laptop ram => Soldered RAM is fixed to the motherboard. Many thin laptops have it, so check before buying because you can't add more later.
what is camm2 ram | camm memory => CAMM2 is a newer flat memory module for laptops and some desktops that's thin like soldered RAM but still replaceable. As of 2025, few devices use it.
what is emmc storage | emmc vs ssd => eMMC is slow, cheap flash storage found in budget laptops and Chromebooks. A real NVMe SSD is many times faster.
what is ufs storage | ufs phone storage => UFS is the fast flash storage used in most Android phones and some tablets. Newer UFS versions load apps and games faster.
what is a sata ssd | sata vs nvme => A SATA SSD uses the older SATA connection and tops out around 550 MB/s. NVMe drives on M.2 are several times faster, though both feel snappy compared with a hard drive.
what is tlc vs qlc ssd | qlc ssd bad => TLC and QLC say how many bits each memory cell stores. QLC is cheaper and holds more but is slower when writing big files and wears out sooner. TLC is the safer pick for a main drive.
what is nand flash | flash memory => NAND flash is the chip type that stores data in SSDs, USB sticks and memory cards. It keeps data without power.
what is trim for ssds | ssd trim => TRIM lets Windows tell the SSD which blocks are no longer used, keeping it fast. It's on by default in Windows for SSDs.
what is curve optimizer | ryzen curve optimizer => Curve Optimizer is a Ryzen BIOS setting that undervolts each core a little. It can lower temperatures and allow higher boost, but too much causes crashes, so change it in small steps.
what is ecores on intel bad for games | e cores games => E-cores rarely hurt games now because Windows 11's scheduler puts games on P-cores. Turning them off is usually unnecessary.
what is a mux switch on a laptop | laptop mux switch => A MUX switch lets the laptop's graphics card connect straight to the screen instead of passing frames through the integrated GPU, which gives more FPS. It's set in the laptop's control app.
what is advanced optimus | nvidia advanced optimus => Advanced Optimus is an automatic MUX switch on some NVIDIA laptops. It switches the screen between the integrated and dedicated GPU without a restart.
what is laptop gpu tgp | laptop gpu watts => TGP is how much power a laptop GPU can use. The same RTX model can be much faster in a laptop that gives it more watts, so check the TGP in reviews.
are laptop gpus the same as desktop ones | laptop rtx vs desktop rtx => No. A laptop GPU with the same name is usually slower because it runs on far less power and cooling.
what is a gaming laptop vs desktop | laptop or desktop for gaming => A desktop gives more performance for the money, runs cooler and is easy to upgrade. A gaming laptop is portable but louder, hotter and harder to upgrade.
what is mini led | mini led screen => Mini-LED is an LCD with thousands of tiny backlight zones that dim separately, giving deeper blacks and brighter HDR than a normal LCD.
what are nits on a screen | screen brightness nits => Nits measure brightness. Around 300 to 400 nits is fine indoors, and good HDR needs much higher peaks, often 1,000 nits or more.
what is hdr10 | hdr10 vs hdr10 plus => HDR10 is the basic HDR format almost every HDR screen supports. HDR10+ and Dolby Vision add info that adjusts brightness scene by scene.
what is dolby vision | dolby vision hdr => Dolby Vision is an HDR format that adjusts brightness and color scene by scene. Many TVs, iPhones and streaming services use it.
what is displayhdr 400 | vesa hdr ratings => DisplayHDR ratings like 400, 600 and 1000 show a monitor's peak HDR brightness. DisplayHDR 400 is quite weak, so HDR often looks better on 600 or higher, or on OLED with True Black ratings.
what is a qd oled | qd oled vs woled => QD-OLED and WOLED are the two main OLED monitor types. QD-OLED has very bright, rich colors, while WOLED often handles reflections in bright rooms better.
what is a retina display | retina screen => Retina is Apple's name for screens sharp enough that you can't see individual pixels at normal viewing distance.
what is promotion on iphone | 120hz ipad => ProMotion is Apple's name for screens that change refresh rate up to 120 Hz, making scrolling smoother. It's on Pro iPhones, iPad Pro and many MacBook Pros.
what is wifi 6e | 6 ghz wifi => Wi-Fi 6E adds the 6 GHz band, which has lots of free space and less interference but shorter range through walls.
what is multi link operation | mlo wifi => Multi-Link Operation in Wi-Fi 7 lets a device use more than one band at once, like 5 GHz and 6 GHz, for faster and steadier connections.
what bluetooth version is best | bluetooth 5.3 => Newer Bluetooth versions improve range, efficiency and features like LE Audio. Both devices need to support a feature for it to work.
what is le audio | bluetooth le audio => LE Audio is a newer Bluetooth audio standard with the LC3 codec, giving better sound at lower power and Auracast broadcasting to many headphones.
what is auracast | auracast explained => Auracast lets one device broadcast Bluetooth audio to any number of compatible headphones or speakers nearby, like a shared audio channel.
5g phone network | 5g vs 4g => 5G is the newer mobile network with more speed and lower lag. Its fastest mmWave version has a short range, so most 5G you'll use is a bit faster than good 4G.
what is lte | lte explained => LTE is the 4G mobile network standard. Phones fall back to it where 5G isn't available.
what is a cpu benchmark score | cinebench => Benchmarks like Cinebench and Geekbench run the same test on every chip and give a score to compare. Game FPS tests are better for judging gaming speed.
what is single core vs multi core performance | single core vs multi core performance explained => Single-core speed matters for many games and snappy apps. Multi-core speed matters for rendering, video export and compiling code.
what is a gpu die | gpu chip => The GPU die is the actual chip on a graphics card. Cards from different brands with the same chip perform about the same, apart from cooling and clock speeds.
what is gddr7 | gddr6 vs gddr7 => GDDR is the fast memory on graphics cards. GDDR7, used on NVIDIA's RTX 50 series, has more bandwidth than GDDR6.
what is memory bus width on a gpu | 128 bit vs 256 bit => Bus width is how many lanes connect the GPU to its VRAM. A wider bus moves more data per tick, which helps at high resolutions.
what is rtx 50 series | rtx 5070 => The RTX 50 series is NVIDIA's graphics card line launched in 2025, with DLSS 4 and Multi Frame Generation. Models range from the 5060 up to the 5090.
what is multi frame generation | dlss 4 mfg => Multi Frame Generation in DLSS 4 on RTX 50 cards creates up to three AI frames per real frame. It makes motion smoother, but input lag still depends on the real frame rate.
what is the rx 9070 | radeon rx 9000 => The Radeon RX 9070 and 9070 XT, launched in 2025, are AMD's RDNA 4 graphics cards with better ray tracing and FSR 4 support.
what is fsr 4 | fsr 4 vs fsr 3 => FSR 4 is AMD's AI-based upscaler for RX 9000 cards, giving much sharper results than older FSR versions.
what is pcie 5 | pcie 5 gpu => PCIe 5.0 doubles the bandwidth of PCIe 4.0. As of 2025, graphics cards barely use the extra, so it matters more for the fastest SSDs.
what is a pcie lane | pcie lane explained => A PCIe lane is one data path. A graphics card usually uses 16 lanes (x16) and an NVMe SSD uses 4 (x4).
what is cuda | cuda cores => CUDA is NVIDIA's platform that lets programs like Blender, Resolve and AI tools use the GPU for heavy math. CUDA cores are the GPU's small processing units.
what is nvenc | nvidia encoder => NVENC is the video encoder chip inside NVIDIA GPUs. It records and streams with very little FPS loss, and OBS and Resolve can use it.
what is av1 encoding | av1 encoder => AV1 is a newer video codec that gives better quality at the same file size. RTX 40 and 50, Radeon RX 7000 and newer, and Intel Arc cards can encode it in hardware.
what is a tensor core | rt cores and tensor cores => Tensor cores on RTX cards speed up AI math, powering DLSS. RT cores speed up ray tracing.
what is a blower gpu cooler | blower vs open air => A blower card pushes hot air out the back of the case, while open-air coolers blow it around inside. Open-air is quieter and cooler in a case with good airflow.
what is a gpu bios switch | dual bios gpu => Some graphics cards have a small switch for two BIOS modes, usually Performance and Quiet. Quiet runs fans slower with slightly higher temperatures.
what is a riser cable | vertical gpu mount => A riser cable lets a graphics card mount vertically to show it off. Use a good PCIe 4.0 riser, as cheap ones can cause crashes or black screens.
what is a heat pipe | how do heat pipes work => A heat pipe is a sealed copper tube with a bit of liquid inside. The liquid boils at the hot end and condenses at the cool fins, moving heat quickly.
what is a vapor chamber | vapor chamber explained => A vapor chamber is a flat heat pipe that spreads heat across a wider area. High-end GPUs, laptops and phones use them.
what is junction temperature on a gpu | hotspot temp => Hotspot or junction temperature is the hottest point on the GPU or its memory. It's normal for it to read 10 to 20 degrees above the main GPU temperature.
what is tjmax | cpu max temp => TjMax is the highest temperature a CPU is designed for before it slows itself down. Ryzen 7000 chips are designed to run up to 95 degrees C under heavy load.
what is wake on lan | turn on pc remotely => Wake on LAN lets another device on the network turn your PC on with a special signal. Turn it on in the BIOS and the network adapter settings.
what is a tpm chip | tpm 2.0 windows 11 => A TPM is a security chip that stores encryption keys. Windows 11 needs TPM 2.0, and on AMD it's called fTPM in the BIOS.
what is a gpt disk | mbr vs gpt => GPT is the modern way to lay out partitions on a drive, needed for UEFI boot and drives over 2 TB. MBR is the older style.
what is a partition | disk partition => A partition splits one drive into separate sections that act like different drives, like C and D. Windows also makes small hidden ones for recovery.
what is ntfs | ntfs vs exfat => NTFS is the file system Windows uses for its drives. exFAT works on Windows, Mac and many cameras, so it's good for USB drives that move between devices.
what is fat32 | fat32 4gb limit => FAT32 is an old file system that works almost everywhere but can't hold a single file over 4 GB. Use exFAT for big video files.
what is a firmware update | firmware meaning => Firmware is the software built into a device like an SSD, controller or router. Updates fix bugs and add features, so install them from the maker's official tool.
what is an api in games | directx vulkan explained => A graphics API like DirectX, Vulkan or Metal is a set of commands games use to tell the GPU what to draw.
what is latency vs bandwidth for ram | ram timings vs speed => RAM speed in MT/s is how much data moves, and timings like CL are delay in clock cycles. Real delay depends on both, so faster RAM with higher CL can still be quicker.
what is mt s on ram | mhz vs mt/s => RAM speed is properly measured in MT/s (transfers per second). DDR5-6000 means 6,000 MT/s, though many shops still write MHz.
what is a cpu ihs | integrated heat spreader => The IHS is the metal lid on top of a CPU that spreads heat to the cooler. Thermal paste goes between it and the cooler.
what is delidding | delidding explained => Delidding means removing a CPU's metal lid to replace the material under it for lower temperatures. It's risky and voids the warranty, so it's only for experts.
what is a pc's post | power on self test => POST is the quick check the motherboard runs when you turn the PC on, testing the CPU, RAM and graphics before loading Windows.
what is a usb flashback button | usb flashback button explained => BIOS Flashback is a button on many motherboards that updates the BIOS from a USB stick, even without a working CPU or RAM installed.
what is a sata cable | sata cable explained => A SATA cable connects a 2.5 inch SSD or a hard drive to the motherboard for data. The drive also needs a SATA power cable from the power supply.
what is a molex connector | molex connector explained => Molex is an old four-pin power connector. Some fan hubs and LED strips still use it, but most new parts don't.
what is a pcie power cable | 8 pin gpu power => PCIe power cables, usually 8-pin, feed extra power to the graphics card. Use separate cables from the PSU for each socket on a power-hungry card if you can.
what is 12v 2x6 | 12v-2x6 vs 12vhpwr => 12V-2x6 is the updated version of the 16-pin 12VHPWR GPU power connector, with changed pins so it only delivers power when fully plugged in. Always push it in all the way.
