# tag: tech.shortcuts.blender
how do i move an object in blender | g key blender | grab in blender => Select the object and press G to grab and move it. Click or press Enter to confirm, or right-click or Esc to cancel.
how do i rotate in blender | r key blender => Select the object and press R, then move the mouse to rotate it. Type a number like 90 and press Enter for an exact angle.
how do i scale in blender | s key blender | make an object bigger in blender => Select it and press S, then move the mouse to scale. Type a number like 2 and press Enter to double the size.
how do i move only along one axis in blender | g then x blender | lock to an axis => After pressing G, R or S, press X, Y or Z to lock to that axis. Press Shift + Z (or X or Y) to lock to the other two axes instead.
how do i go into edit mode in blender | tab blender | edit mode shortcut => Press Tab to switch between Object Mode and Edit Mode for the selected mesh.
how do i switch to vertex edge or face select | 1 2 3 in edit mode blender => In Edit Mode, press 1 for vertex, 2 for edge and 3 for face select (the number keys above the letters).
how do i select everything in blender | a key blender | deselect all blender => Press A to select all and Alt + A to deselect all. Double-tap A also deselects in the default keymap.
how do i invert my selection in blender | ctrl i invert blender => Press Ctrl + I to select everything that isn't selected and unselect what was.
how do i box select in blender | b key blender => Press B and drag a box to select. Hold Shift (or use the middle mouse) while dragging to remove from the selection.
how do i circle select in blender | c key blender => Press C to paint a selection with a circle. Scroll to resize it and right-click or Esc to finish.
how do i select connected parts of a mesh | l key blender | ctrl l blender => In Edit Mode, hover over a part and press L to select everything linked to it, or select some and press Ctrl + L.
how do i add a new object in blender | shift a blender | add a cube in blender => Press Shift + A to open the Add menu and pick a mesh like a cube, sphere or cylinder. It appears at the 3D cursor.
how do i delete in blender | x key blender => Press X (or Delete) to delete the selected objects. In Edit Mode, X asks whether to delete vertices, edges or faces.
how do i duplicate an object in blender | shift d blender => Press Shift + D to duplicate the selection, move it, and click to place it. Alt + D makes a linked copy that shares the same mesh.
how do i extrude in blender | e key blender => In Edit Mode select faces, edges or vertices and press E to extrude them outward. Move the mouse and click to set the length.
how do i inset a face in blender | i key edit mode blender => In Edit Mode select a face and press I to inset it, making a smaller face inside with a border around it.
how do i add a loop cut in blender | ctrl r blender => In Edit Mode press Ctrl + R, hover over the mesh to see the yellow loop, scroll to add more cuts, click to place, then slide and click again.
how do i bevel an edge in blender | ctrl b blender | round edges blender => In Edit Mode select edges and press Ctrl + B, then move the mouse to bevel. Scroll to add segments for a rounder edge.
how do i use the knife tool in blender | k key blender => In Edit Mode press K, click points to cut new edges across faces, and press Enter to finish.
how do i merge vertices in blender | m key edit mode blender => In Edit Mode select vertices, press M and pick At Center, At Cursor or By Distance. By Distance removes doubled vertices.
how do i separate part of a mesh in blender | p key blender => In Edit Mode select the part and press P, then Selection. It becomes its own object.
how do i join objects in blender | ctrl j blender => Select the objects, making the main one active last, and press Ctrl + J to join them into one object.
how do i hide objects in blender | h key blender | unhide blender => Press H to hide the selection, Alt + H to unhide everything, and Shift + H to hide everything else.
how do i see the front view in blender | numpad 1 blender | blender view shortcuts => Press Numpad 1 for front, Numpad 3 for right side and Numpad 7 for top. Add Ctrl for the opposite side.
how do i switch between perspective and orthographic | numpad 5 blender => Press Numpad 5 to switch between perspective and orthographic views.
how do i look through the camera in blender | numpad 0 blender => Press Numpad 0 to look through the active camera.
how do i zoom to the selected object in blender | numpad period blender => Press Numpad . (period) to frame the selected object. Home frames everything in the scene.
how do i use blender without a numpad | emulate numpad blender | view pie menu => Press the ` (backtick) key to open the View pie menu with front, top and side views. You can also turn on Emulate Numpad in Edit, Preferences, Input.
how do i change shading in blender | z key blender | wireframe view blender => Press Z to open the shading pie menu and pick Wireframe, Solid, Material Preview or Rendered.
how do i turn on x ray in blender | alt z blender | see through objects blender => Press Alt + Z to toggle X-Ray so you can see and select through objects.
how do i open the side panel in blender | n key blender => Press N to show or hide the sidebar with exact location, rotation, scale and add-on tabs.
how do i show the toolbar in blender | t key blender => Press T in the 3D Viewport to show or hide the toolbar on the left.
how do i search for a command in blender | f3 blender => Press F3 to search for any operator by name, like "subdivide" or "shade smooth".
how do i render an image in blender | f12 blender => Press F12 to render the frame you're on from the camera. In the render window, use Image, then Save As to save it.
how do i render an animation in blender | ctrl f12 blender => Press Ctrl + F12 to render the whole animation. Set the output folder and file format in Output Properties first.
how do i play the animation in blender | spacebar blender => Press Space to play or pause the animation in the timeline.
how do i insert a keyframe in blender | press i to keyframe blender => Hover over the 3D Viewport and press I to insert a keyframe for the selected object. Alt + I deletes it.
how do i apply scale in blender | ctrl a apply blender => Press Ctrl + A and choose Scale (or All Transforms) to apply it, so the object's scale reads 1. This keeps modifiers and bevels even.
how do i snap things in blender | shift s blender | move 3d cursor => Press Shift + S to open the Snap menu, for things like Cursor to Selected or Selection to Cursor.
how do i reset the 3d cursor in blender | shift c blender => Press Shift + C to move the 3D cursor back to the center and frame all objects.
how do i place the 3d cursor | shift right click blender => Shift + right-click puts the 3D cursor where you click. New objects appear there.
how do i turn on proportional editing | o key blender => Press O to toggle proportional editing, so nearby vertices move too. Scroll while moving to change the size of the circle.
how do i parent objects in blender | ctrl p blender => Select the child, then the parent last, press Ctrl + P and choose Object. Alt + P clears the parent.
how do i make a face from vertices in blender | f key blender => In Edit Mode select vertices or edges and press F to fill them with a face or edge.
how do i fix inside out normals in blender | shift n blender | recalculate normals => In Edit Mode select all with A and press Shift + N to recalculate the normals to point outward.
how do i open the uv unwrap menu | u menu uv blender => In Edit Mode select faces and press U to open the UV menu, then pick Unwrap or Smart UV Project.
how do i undo in blender | ctrl z blender | redo blender => Press Ctrl + Z to undo and Ctrl + Shift + Z to redo. Edit, Undo History shows all steps.
how do i redo the last action with new settings | f9 blender => Press F9 to bring back the Adjust Last Operation panel and change values like the number of cuts.
how do i repeat my last action in blender | shift r blender => Press Shift + R to repeat the last action, like another extrude or duplicate move.
how do i maximize a window area in blender | ctrl space blender => Hover over an area and press Ctrl + Space to make it fill the window. Press it again to go back.
how do i orbit around in blender | blender camera controls mouse | pan in blender => Drag with the middle mouse button to orbit, Shift + middle drag to pan, and scroll or Ctrl + middle drag to zoom.
how do i use blender with a laptop trackpad | blender no middle mouse => Turn on Emulate 3 Button Mouse in Edit, Preferences, Input, then Alt + left drag orbits. Two-finger trackpad gestures also work on many laptops.
how do i add a subdivision surface quickly | ctrl 1 blender | smooth a model in blender => In Object Mode press Ctrl + 1, 2 or 3 to add a Subdivision Surface modifier at that level. Right-click and pick Shade Smooth too.
how do i clear the location of an object | alt g blender => Press Alt + G to reset location, Alt + R to reset rotation, and Alt + S to reset scale.
how do i fly around in blender | walk navigation blender => Press Shift + ` (backtick) for fly or walk navigation, then use W A S D and the mouse. Click to stay or right-click to go back.
how do i line the camera up with my view | ctrl alt numpad 0 => Press Ctrl + Alt + Numpad 0 to move the active camera to match what you see in the viewport.
how do i save in blender | ctrl s blender => Press Ctrl + S to save your .blend file. Ctrl + Shift + S is Save As.
how do i open the edge menu in blender | ctrl e blender => In Edit Mode press Ctrl + E for the Edge menu, Ctrl + V for the Vertex menu and Ctrl + F for the Face menu.
how do i scale an edge loop thicker | alt s blender => In Edit Mode press Alt + S to shrink or fatten, moving faces along their normals.
