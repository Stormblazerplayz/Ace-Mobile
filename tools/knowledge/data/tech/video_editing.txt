# tag: tech.video.resolve
what is davinci resolve | is davinci resolve free => DaVinci Resolve is a professional video editor with editing, color, effects (Fusion) and audio (Fairlight) in one app. The free version is very powerful; DaVinci Resolve Studio is a paid one-time purchase with extra features.
what are the pages in davinci resolve | resolve pages explained => Resolve has pages along the bottom: Media to import, Cut for quick edits, Edit for detailed timeline work, Fusion for effects, Color for grading, Fairlight for audio, and Deliver to export.
whats the difference between the cut page and edit page | cut page vs edit page resolve => The Cut page is a fast, simple editor for quick projects. The Edit page has a classic timeline with more tracks and tools. Both work on the same timeline, so you can switch anytime.
what is the free vs studio difference in resolve | is resolve studio worth it => Studio adds things like many AI tools (such as Magic Mask and voice isolation), more effects, higher than 4K 60 export, better noise reduction and more GPU acceleration. Most beginners do great with the free version.
how do i start a new project in resolve | resolve project manager => Opening Resolve shows the Project Manager. Click New Project, name it, and click Create. Projects are saved in Resolve's database, not as a normal file in a folder.
how do i import videos into resolve | add clips davinci => On the Media or Edit page, drag files from File Explorer into the Media Pool, or press Ctrl + I to import them.
why does resolve ask to change the frame rate | change project frame rate resolve => When your first clip's frame rate doesn't match the project, Resolve offers to change it. Say yes if most footage matches that clip. The timeline frame rate can't change once clips are on it.
how do i make a vertical video in resolve | 9 16 timeline resolve | youtube shorts resolution resolve => Right-click your timeline in the Media Pool, choose Timeline, Timeline Settings, untick Use Project Settings, and set 1080 x 1920. Or set it when making a new timeline.
how do i make a new timeline in resolve | create timeline davinci => Right-click in the Media Pool and choose Timelines, Create New Timeline, or drag clips into the empty timeline area to make one automatically.
how do i move clips on the timeline in resolve | rearrange clips resolve => Click and drag clips with the Selection tool (A). Hold Shift while dragging to swap clip positions, and turn on snapping (N) to line them up.
how do i trim the start or end of a clip in resolve | shorten a clip resolve => Hover over the edge of the clip until the cursor changes, then drag it in. Use Trim mode (T) to have the rest of the timeline move along with it.
how do i unlink audio from video in resolve | separate audio resolve => Right-click the clip and untick Link Clips, or click the chain link button in the timeline toolbar to turn linked selection off.
how do i add text in davinci resolve | titles in resolve => Open the Effects panel on the Edit page, go to Titles, and drag Text or Text+ onto a track above your video. Edit the words and font in the Inspector.
what is text plus in resolve | text vs text+ => Text+ is a Fusion-based title with more options like outlines, shadows, character animation and per-letter styling. Plain Text is simpler and lighter.
where are transitions in resolve | fade between clips resolve => Open Effects, Video Transitions, and drag one like Cross Dissolve onto the cut between two clips. Drag its edges to change the length.
how do i fade audio in resolve | audio fade in => Hover over the top corner of an audio clip and drag the small white handle inward to make a fade in or fade out.
how do i zoom into a clip in resolve | scale up video resolve => Select the clip, open the Inspector, and raise Zoom under Transform. Change Position to move the framing.
how do i animate a zoom in resolve | keyframes resolve inspector => In the Inspector, move the playhead to the start, click the diamond next to Zoom to add a keyframe, move the playhead, and change the value. Resolve animates between them.
how do i make a speed ramp in resolve | smooth slow motion resolve => Right-click the clip, choose Retime Controls, then add speed points and set different speeds. Use Retime Curve and smooth the curve for a gradual ramp.
how do i make smooth slow motion in resolve | optical flow resolve => Shoot at a high frame rate like 60 or 120 fps, then slow it down. For footage shot at lower rates, set Retime Process to Optical Flow in the Inspector for smoother in-between frames.
how do i freeze a frame in resolve | freeze frame davinci => Put the playhead on the frame, right-click the clip and choose Change Clip Speed, then tick Freeze Frame. Cut the clip around it to control how long the freeze lasts.
what is an adjustment clip in resolve | apply effect to many clips => An adjustment clip sits on a track above your video and applies its effects and color to everything below it. Find it in Effects, Effects.
what is a compound clip in resolve | group clips resolve => Select clips, right-click and choose New Compound Clip to combine them into one clip. It's handy for applying one effect to a whole section.
how do i stabilize shaky video in resolve | resolve stabilizer => Select the clip, open the Inspector, find Stabilization, and click Stabilize. Raise Cropping Ratio smoothing or pick Camera Lock for a still shot.
how do i remove a green screen in resolve | green screen resolve => On the Color page, use the qualifier to select the green and invert it with an alpha output, or on the Fusion page use the Delta Keyer. Even lighting on the green makes it much easier.
what is media offline in resolve | red media offline screen => Resolve can't find the original file, often because it was moved or renamed. Right-click the clip in the Media Pool and choose Relink Selected Clips, then pick the folder.
why is resolve so laggy | resolve playback stutter => Phone and camera footage in H.264 or H.265 is hard to play back. Generate proxy media, lower Playback, Timeline Proxy Resolution, and turn on render cache.
what is proxy media in resolve | generate proxy resolve => Proxies are smaller, easy-to-edit copies of your footage. Right-click clips and choose Generate Proxy Media. Resolve edits with them and exports from the originals.
what is the render cache in resolve | smart cache => Render cache pre-renders heavy effects so playback is smooth. Set Playback, Render Cache to Smart, and Resolve caches effect-heavy parts automatically.
why does resolve say gpu memory is full | gpu memory full error => Your graphics card ran out of VRAM, often from 4K footage, noise reduction or heavy effects. Lower Timeline Proxy Resolution, use proxies, and close other GPU-heavy apps.
why does my phone video look weird in resolve | variable frame rate resolve => Phones record variable frame rate video, which can cause audio drift or stutter in editors. Converting it to constant frame rate with a free tool like HandBrake before editing helps.
how do i add music in resolve | background music resolve => Drag the music file into the Media Pool, then onto an audio track below your video. Lower its volume line so voices stay clear.
how do i make my voice louder in resolve | audio levels resolve => Select the clip and raise Volume in the Inspector, or drag the line on the clip up. Right-click and choose Normalize Audio Levels to hit a target level.
what loudness should youtube videos be | lufs for youtube => YouTube normalizes playback to about -14 LUFS, so mixing near -14 LUFS integrated with peaks below -1 dBTP keeps your video from being turned down or sounding quiet.
what is fairlight in resolve | resolve audio page => Fairlight is Resolve's audio page with a mixer, effects like EQ and compression, and meters for loudness. Use it to clean up voice and balance music.
how do i remove background noise in resolve | voice isolation resolve => In Studio, select the clip and turn on Voice Isolation in the Inspector. In the free version, try the Noise Reduction Fairlight effect, or record in a quieter room with the mic closer.
how do i add subtitles in resolve | captions in davinci => Right-click the timeline, choose Add Subtitle Track, then add subtitles at the playhead. Studio can create them automatically from speech.
how do i export a video in resolve | render video davinci => Go to the Deliver page, pick a preset like YouTube or H.264 Master, set the name and location, click Add to Render Queue, then Render All.
what are the best export settings for youtube in resolve | resolve youtube export => Use the YouTube preset or H.264/H.265 MP4 at your timeline resolution and frame rate. A higher bitrate gives YouTube a better source; for 1080p, around 20 to 40 Mbps is plenty.
how do i export only part of my timeline | render in out range resolve => Set In and Out points around the part with I and O, then on the Deliver page pick In/Out Range instead of Entire Timeline.
how do i export just the audio in resolve | render mp3 resolve => On the Deliver page open Custom Export, untick Export Video under Video, and set the audio format like WAV or MP3 under Audio.
what is h264 vs h265 for export | hevc export => H.265 (HEVC) gives the same quality at a smaller size than H.264, but some older devices play it worse. H.264 works almost everywhere.
what is a lut | how do i use a lut in resolve => A LUT is a preset that remaps colors, often to turn flat Log footage into normal colors or add a style. In Resolve, right-click a node on the Color page and choose LUT.
what are lift gamma and gain | color wheels resolve => On the Color page, Lift changes shadows, Gamma changes midtones, and Gain changes highlights. Offset shifts everything. Adjust the wheels or the master dials below them.
what are nodes in resolve | color nodes explained => Nodes are steps in your color grade, like layers that run in order. Use one node for exposure, one for white balance, one for a look, so each fix stays separate and easy to change.
what are video scopes | waveform and vectorscope => Scopes measure your image. The waveform shows brightness from dark to bright, the parade splits red, green and blue, and the vectorscope shows color and saturation.
how do i fix white balance in resolve | video looks too blue => On the Color page, use the white balance picker on something that should be white or grey, or adjust Temp and Tint until whites look neutral on the parade scope.
how do i copy a color grade to other clips in resolve | apply grade to all clips => On the Color page, select the graded clip, then middle-click the clips you want to match in the thumbnail row, or use Ctrl + C and Ctrl + V on clips.
what is color space transform | cst resolve => Color Space Transform is a Resolve effect that converts footage from one color space and gamma, like a camera's Log, to another, like Rec.709, for accurate color.
what is fusion in resolve | fusion page => Fusion is Resolve's node-based visual effects and motion graphics page. You build effects by connecting nodes like Background, Text, Transform and Merge.
how do i track an object in resolve | motion tracking resolve => On the Color page, add a window around the object and use the Tracker to follow it. In Fusion, the Tracker node can stick text or graphics to moving things.
what is magic mask in resolve | select a person automatically resolve => Magic Mask in Resolve Studio uses AI to select a person or object across frames, so you can color or blur just them.
how do i blur a face in resolve | blur part of video => On the Color page, add a circle window over the face, track it, then add Blur in the Blur tab or the Effects library. Keep it on its own node.
how do i save my resolve project | resolve autosave => Press Ctrl + S. Turn on Live Save in Preferences, User, Project Save and Load so it saves every change. Back up by exporting a .drp project file.
how do i move a resolve project to another computer | export project resolve => In the Project Manager, right-click the project and choose Export Project (.drp). For media too, use Export Project Archive (.dra), which copies the clips.
how do i make the resolve interface bigger | resolve ui too small => Open DaVinci Resolve, Preferences, User, UI Settings, and change the UI display scale. Restart Resolve to apply it.
what gpu do i need for davinci resolve | resolve system requirements => Resolve leans heavily on the GPU. A modern NVIDIA, AMD or Apple silicon GPU with 8 GB or more VRAM works well for 1080p and 4K editing, plus 16 to 32 GB of RAM.
what version of davinci resolve is newest | latest resolve version => As of 2025, the newest major version is DaVinci Resolve 20, released that year with new AI tools and editing features.
