# tag: tech.blender.deep
how do i scatter objects with geometry nodes | scatter rocks blender => Use Distribute Points on Faces to place points on a surface, then Instance on Points to put a rock or tree on each point. Plug your object in with an Object Info node.
what is realize instances in geometry nodes | make instances real geometry => Realize Instances turns instanced copies into real mesh geometry, so later nodes can edit each copy. It uses more memory.
what is the set position node | move vertices with nodes => Set Position moves points of the geometry. Plug a Noise Texture into its offset to make bumpy, wavy shapes.
what is join geometry | combine meshes in geometry nodes => Join Geometry merges several geometry streams into one output, like adding a base shape and scattered objects together.
how do i make an animation move at a steady speed in blender | linear interpolation blender => Select the keyframes, press T in the Graph Editor or Dope Sheet and choose Linear. Blender's default Bezier makes motion ease in and out.
what are motion paths in blender | show animation path => Motion Paths draw the route an object or bone travels. Find them in Object or Bone Properties and click Calculate.
what is auto keying in blender | record button blender timeline => Auto Keying, the record button in the Timeline, adds keyframes automatically whenever you move something. Turn it off when you don't want accidental keys.
how do i add a marker on the blender timeline | timeline marker m => Hover over the Timeline and press M to add a marker. Markers help you note important moments like a beat in the music.
what are drivers in blender | link one property to another => Drivers make one value follow another, like a wheel spinning as a car moves. Right-click a property and choose Add Driver.
how do i set the frame rate in blender | blender fps setting => Go to Output Properties and change Frame Rate. Set it before animating so your timing stays right.
how do i change the animation length in blender | frame start end blender => Set Frame Start and End in Output Properties or at the right of the Timeline.
what is a shadow catcher in blender | put 3d object on real photo => In Cycles, select a plane and turn on Shadow Catcher in Object Properties > Visibility. It renders only the shadows, so you can put models onto real footage.
what is a holdout in blender | cut out object from render => A holdout makes an object render as a transparent hole, hiding anything behind it. Turn it on in Object Properties > Visibility.
what is freestyle in blender | outline render blender => Freestyle draws lines along edges in your render for a cartoon or technical look. Turn it on in Render Properties.
how do i make toon shading in blender | cel shading blender => In Eevee, use a Shader to RGB node into a Color Ramp set to Constant. That splits lighting into flat bands like a cartoon.
what is agx in blender | view transform blender => AgX is Blender's default view transform since version 4.0. It handles bright lights and colors more naturally than the old Filmic or Standard.
how do i render only part of the image in blender | render region => In camera view press Ctrl+B and drag a box to render only that area. Ctrl+Alt+B clears it.
what is quick favorites in blender | q menu blender => Right-click any tool or menu item and choose Add to Quick Favorites. Press Q to open your personal menu.
how do i slide an edge in blender | edge slide gg => Select an edge loop and press G twice to slide it along the surface without changing the shape.
how do i rip vertices in blender | v key blender rip => Select vertices and press V to rip them apart, making a gap in the mesh you can move.
how do i select an edge loop in blender | alt click loop select => Alt+click an edge to select its whole loop. Ctrl+Alt+click selects an edge ring instead.
how do i select the shortest path in blender | ctrl click select path => Select one element, then Ctrl+click another, and Blender selects the shortest path between them.
how do i select similar things in blender | shift g blender => Press Shift+G in Edit Mode to select elements similar to what you have, like faces with the same area or material.
what is dissolve in blender | delete without making a hole => Dissolve removes vertices, edges or faces but keeps the surface filled, unlike Delete which leaves a hole. Find it in the X menu.
how do i connect two edge loops in blender | bridge edge loops => Select two open edge loops, press Ctrl+E and choose Bridge Edge Loops to join them with faces.
how do i fill a round hole with a grid in blender | grid fill blender => Select the open loop, open the Face menu and choose Grid Fill. It fills the hole with clean four-sided faces.
what is the multires modifier | multiresolution sculpting => Multires adds subdivision levels you can sculpt on and switch between. You can sculpt big shapes at low levels and details at high levels.
how do i change brush size while sculpting | f key sculpt blender => Press F and move the mouse to change brush size, and Shift+F for strength. Hold Ctrl to make a brush push in instead of out.
how do i smooth while sculpting in blender | shift sculpt smooth => Hold Shift while sculpting to switch to the Smooth brush. It's the fastest way to clean lumpy areas.
what is sculpt symmetry in blender | sculpt both sides => Sculpt Mode mirrors your strokes on the X axis by default. Change the axis with the butterfly icon at the top right.
what is voxel remesh in sculpt mode | ctrl r sculpt remesh => In Sculpt Mode, press R to set the voxel size, then Ctrl+R to remesh. It gives an even mesh so stretched areas can be sculpted again.
what are the light types in blender | point sun spot area light => Point lights shine in all directions, Sun lights are like sunlight from far away, Spot lights make a cone and Area lights give soft light from a shape.
why is my sun light so bright in blender | sun strength blender => Sun strength uses different units from other lights, so small numbers like 1 to 5 are usually enough.
what focal length should my blender camera use | camera lens mm blender => The default is 50mm. Lower numbers like 24mm give a wide view, and higher numbers like 85mm zoom in and flatten faces nicely.
how do i render at lower resolution for a test | resolution percentage blender => In Output Properties, lower the resolution percentage to 50 percent or less for quick test renders.
how do i import a gltf or fbx into blender | open an obj file in blender => Go to File > Import and pick the format, like glTF 2.0, FBX, OBJ or STL.
what is the weld modifier | merge by distance modifier => The Weld modifier merges vertices that are very close together without permanently changing the mesh.
what is the wireframe modifier | wireframe modifier blender => The Wireframe modifier turns every edge into a solid bar, making cage or lattice shapes. It's handy for 3D-printed designs.
what is the displace modifier | displace modifier blender => Displace pushes a mesh in or out using a texture, which is great for terrain. It needs enough subdivisions to show detail.
what is the skin modifier | skin modifier blender => The Skin modifier builds a thick mesh around simple edges, so you can block out creatures or trees from stick figures.
how do i get bloom in blender 4 | eevee bloom missing => Newer Eevee removed the Bloom checkbox. Add a Glare node set to Bloom in the Compositor instead.
what are view layers in blender | render layers blender => View layers let you render different groups of collections separately from one scene, useful for compositing.
what are workspaces in blender | blender tabs at top => The tabs at the top like Layout, Modeling and Shading are workspaces, each with editors arranged for one job.
