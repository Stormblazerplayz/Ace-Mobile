# tag: tech.video.tech
what is dnxhr | dnxhr codec => DNxHR is an editing-friendly codec from Avid. Files are big, but they play smoothly in editors like Resolve because each frame is stored on its own.
what is prores | apple prores => ProRes is Apple's high-quality editing codec. It makes large files that are very smooth to edit and hold up well when you color grade.
what is an intermediate codec | editing codec vs delivery codec => An intermediate codec like ProRes or DNxHR is made for editing, with big files that scrub smoothly. Delivery codecs like H.264 make small files for uploading.
what is long gop | long gop vs intraframe => Long GOP video stores a full picture only now and then and saves just the changes in between, which makes small files. Intraframe saves every frame whole, so it edits more smoothly.
what is an i frame | what is a keyframe in video compression => An I-frame is a complete picture inside a compressed video. The frames between it only store changes, which keeps files small.
what are b frames | b frames obs => B-frames are compressed frames that borrow detail from frames before and after them, saving space. OBS's default setting works well for most people.
what is chroma subsampling | 4 2 0 vs 4 2 2 => Chroma subsampling stores color at lower detail than brightness. 4:2:0 is standard for most video, while 4:2:2 keeps more color detail for green screen and grading.
what is 10 bit video | 8 bit vs 10 bit footage => 10-bit video stores 1,024 shades per color instead of 256, so skies and gradients band less. It matters most for log footage you plan to color grade.
what is rec 709 | rec709 color space => Rec.709 is the standard color space for normal HD video. Most YouTube videos and editing timelines use it.
what is hlg | hybrid log gamma => HLG is an HDR video format that still looks fine on normal screens. Some phones, cameras and drones can record it.
what is cbr vs vbr | constant bitrate vs variable bitrate => CBR keeps the bitrate steady, which streaming sites like Twitch prefer. VBR changes the bitrate with the scene, making better use of space for recordings and exports.
what keyframe interval should i stream with | keyframe interval twitch => Set the keyframe interval to 2 seconds for streaming, which Twitch and YouTube recommend. Leaving it on auto can cause problems on some platforms.
what is crf | x264 crf value => CRF is a quality setting in encoders like x264. Lower numbers mean better quality and bigger files, with values around 18 to 23 common.
what is cqp in obs | cq level recording => CQP or CQ is a constant quality mode for recording in OBS. Lower numbers give better quality and bigger files.
what is two pass encoding | 2 pass export => Two-pass encoding scans the whole video first, then encodes it using that information. It can look better at a set file size but takes longer.
what is timecode | what are the numbers on my timeline => Timecode labels every frame as hours, minutes, seconds and frames, like 01:00:10:12. It helps you find exact moments in a video.
why is it 23.976 fps | what is 29.97 fps => 23.976 and 29.97 are slightly slower versions of 24 and 30 fps that came from old color TV standards. Many cameras still use them, so match your timeline to your footage.
what is optimized media in resolve | resolve optimized media => Optimized media converts hard-to-play clips into an easier format so Resolve edits smoothly. It's similar to proxies and can be deleted later to save space.
what is rolling shutter | jello effect video => Rolling shutter happens because most sensors read the image line by line, so fast motion makes straight things lean or wobble.
what is interlaced video | 1080i vs 1080p => Interlaced video draws every other line in each pass, which can look jagged in motion. Progressive video, the p in 1080p, draws every line every frame.
why does 4k downscaled to 1080p look sharper | record in 4k upload 1080p => Shrinking 4K to 1080p packs more real detail into each pixel and hides noise, so it looks sharper than footage shot at 1080p.
what is letterboxing | black bars on video => Black bars appear when a video's shape doesn't match the screen. Bars on the top and bottom are letterboxing, and bars on the sides are pillarboxing.
what is the difference between bitrate and bit depth | bitrate vs bit depth => Bitrate is how much data a video uses each second, which affects file size and quality. Bit depth is how many shades each color can have.
what is dci 4k vs uhd | 4096 vs 3840 => UHD 4K is 3840 by 2160, used by TVs and YouTube. DCI 4K is 4096 by 2160, a slightly wider cinema format.
what is a video wrapper | what is an mxf file => A wrapper, or container, holds the video, audio and extra info together. MXF is a professional container often used with DNxHR.
what is gop size | gop length => GOP size is how many frames sit between full keyframes. Shorter GOPs are easier to edit and seek through, and longer ones save space.
what is scrubbing in video editing | scrub the timeline => Scrubbing means dragging the playhead along the timeline to quickly preview a clip. Choppy scrubbing usually means you need proxies.
what is render in place | render in place resolve => Render in Place turns a clip with heavy effects into a new rendered file, so playback stays smooth. You can go back to the original if you need to change it.
what is a dropped frame in recording | recording skipped frames => A dropped frame is one the recorder couldn't save in time, causing tiny stutters. Lower the encoder load or record to a faster drive to fix it.
what is constant frame rate | cfr vs vfr => Constant frame rate keeps every frame the same length, which editors handle best. Phones and screen recorders often use variable frame rate to save space.
what is shutter angle | what does 180 degree shutter mean in settings => Shutter angle is another way to state shutter speed. A 180-degree shutter equals half the frame time, like 1/50 second at 25 fps.
