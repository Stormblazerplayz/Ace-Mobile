# tag: tech.ai.concepts
what are weights in a neural network | ai weights meaning => Weights are the numbers that set how strongly each connection in a neural network matters. Training is mostly the process of tuning billions of these numbers.
what are layers in ai | hidden layers neural network => A neural network is built in layers. Early layers spot simple patterns like edges, and later layers combine them into bigger ideas like a whole cat.
what is deep learning | deep learning vs machine learning => Deep learning is machine learning that uses neural networks with many layers. It powers most modern AI, like chatbots, image generators and voice assistants.
what is the difference between ai and machine learning | is machine learning ai => AI is the big goal of making computers do smart things. Machine learning is one way to get there, where the computer learns from examples instead of following hand-written rules.
what is supervised learning | learning from labeled examples => Supervised learning trains an AI on examples that already have the right answer, like photos labeled cat or dog, so it learns to label new ones.
what is unsupervised learning | ai finding patterns without labels => Unsupervised learning gives an AI data without answers and lets it find groups or patterns on its own, like sorting songs by similar sound.
what is gradient descent | how does ai training improve => Gradient descent is how a model improves during training. It checks how wrong it was, then nudges its weights a tiny step in the direction that makes it less wrong, millions of times.
what is backpropagation | backprop explained => Backpropagation works out how much each weight caused an error, starting from the output and going backward. That tells gradient descent which weights to change.
what is a loss function | ai loss meaning => A loss function measures how wrong a model's answer is. Training tries to make that number as small as possible.
what is an epoch in ai training | training epochs => An epoch is one full pass through all the training data. Models often train for several epochs, improving a little each time.
what is a test set in ai | training data vs test data => Developers keep some data hidden from the model during training, called the test set, to check whether it really learned or just memorized.
what is inference in ai | training vs inference => Training is when a model learns, which takes huge computers and a long time. Inference is when you use the finished model to get answers, which is much cheaper.
what is a system prompt | hidden instructions for ai chatbots => A system prompt is a set of instructions an app gives an AI before you start chatting, like telling it to act as a tutor or keep answers short.
what is a reasoning model | ai that thinks before answering => Reasoning models spend extra time working through a problem step by step before answering. They're often better at math and coding, but slower.
what is agi | artificial general intelligence => AGI means an AI that could learn and do almost any mental task a person can. Experts disagree about when, or whether, it will happen.
what are content credentials | ai image labels c2pa => Content credentials are hidden labels some cameras and AI tools add to files, showing how a picture was made or edited. Not every app keeps them, so they can't prove everything.
what is an ai watermark | can ai images be detected => Some AI tools hide an invisible watermark in the images, audio or text they create, so special tools can detect them. Many AI images still have no watermark.
what is computational photography | how do phone cameras use ai => Computational photography means phones combine several shots and use AI to improve photos, like Night mode, portrait blur and HDR.
what is on device ai | does ai run on my phone => On-device AI runs right on your phone or computer instead of in the cloud, so it can work offline and keep your data more private, but it's usually less powerful.
what is a small language model | small vs large ai model => A small language model has fewer parameters, so it runs fast on phones and laptops. It's less capable than big cloud models but cheaper and more private.
what is model distillation | teacher student ai => Distillation trains a smaller student model to copy a bigger teacher model's answers, getting much of the skill in a lighter package.
what is mixture of experts | moe ai model => A mixture of experts model has many specialist sub-networks and only switches on a few for each token. That makes a huge model faster to run.
what is a cnn in ai | convolutional neural network => A convolutional neural network is a type of network built for images. It slides small filters across a picture to find edges, shapes and objects.
what is a gan | generative adversarial network => A GAN pits two networks against each other: one makes fake images and the other tries to spot fakes. Both get better until the fakes look real.
what is synthetic data | ai trained on fake data => Synthetic data is made-up data created by computers, sometimes by other AIs, to train models when real examples are rare or private.
how much energy does ai use | is ai bad for the environment => Training big AI models uses a lot of electricity and the data centers need cooling water. Each single chat uses far less, but billions of them add up.
what is ai memory in chatbots | can chatgpt remember me => Some chatbots have a memory feature that saves facts you share across chats. You can usually view, edit or turn it off in the settings.
why do ai chatbots have rules | why won't ai answer some questions => AI companies give chatbots safety rules so they don't help with dangerous or harmful things. They sometimes refuse too much, which companies keep trying to improve.
what is an ai benchmark | how do they test ai models => A benchmark is a standard set of questions or tasks used to compare AI models, like math problems or coding challenges.
what is speech synthesis | ai that reads text out loud => Text-to-speech AI turns written words into spoken audio. Modern versions sound very natural and can change voice, speed and emotion.
what is object detection | ai finding things in pictures => Object detection is AI that finds and boxes things in images or video, like people, cars or balls. Drones and robots use it to track objects.
