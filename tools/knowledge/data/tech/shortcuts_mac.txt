# tag: tech.shortcuts.mac
how do i take a screenshot on a mac | mac screenshot shortcut | command shift 3 => Press Command + Shift + 3 to capture the whole screen. The picture saves to your desktop by default.
how do i screenshot part of the screen on mac | command shift 4 | mac snip tool => Press Command + Shift + 4, then drag a box over the area. Let go to save it to the desktop.
how do i screenshot one window on mac | command shift 4 space => Press Command + Shift + 4, then press Space. The pointer becomes a camera; click a window to capture just that window.
how do i record my screen on a mac | command shift 5 | mac screen recording => Press Command + Shift + 5 to open the Screenshot toolbar. Pick record entire screen or a portion, then click Record. Click the stop button in the menu bar to finish.
how do i copy a screenshot instead of saving it on mac | command control shift 4 => Add Control to any screenshot shortcut, like Command + Control + Shift + 4, to copy the picture to the clipboard instead of saving a file.
how do i open spotlight | command space | search on mac => Press Command + Space to open Spotlight, then type an app, file or quick math and press Return.
how do i switch apps on mac | command tab => Hold Command and tap Tab to cycle through open apps, then let go to switch.
how do i quit an app on mac | command q | close app completely mac => Press Command + Q to quit the app. Closing its window with the red button often leaves it running.
how do i close a window on mac | command w => Press Command + W to close the front window or tab.
how do i hide an app on mac | command h => Press Command + H to hide the app you're using. Command + Option + H hides all the other apps.
how do i minimize a window on mac | command m => Press Command + M to minimize the front window into the Dock.
how do i force quit on mac | command option esc | mac app frozen => Press Command + Option + Esc to open Force Quit Applications, choose the frozen app and click Force Quit.
how do i lock my mac | control command q => Press Control + Command + Q to lock the screen right away.
how do i open settings in a mac app | command comma | app preferences shortcut => Press Command + , (comma) to open the settings of most Mac apps.
how do i make a window full screen on mac | control command f | fn f mac => Press Control + Command + F, or Fn (Globe) + F on newer macOS, to enter or leave full screen in apps that support it.
how do i switch windows of the same app | command backtick | command grave => Press Command + ` (the key above Tab) to cycle through windows of the same app.
how do i open mission control | control up arrow | see all windows on mac => Press Control + Up Arrow (or swipe up with three fingers) to open Mission Control and see all windows and Spaces.
how do i see all windows of one app on mac | control down arrow | app expose => Press Control + Down Arrow to show all windows of the app you're using.
how do i switch desktops on mac | control left arrow mac | move between spaces => Press Control + Left Arrow or Right Arrow to move between desktop Spaces.
how do i show or hide the dock | command option d => Press Command + Option + D to turn Dock hiding on or off.
how do i type an emoji on mac | control command space | emoji picker mac => Press Control + Command + Space, or the Fn (Globe) key on newer Macs, to open the emoji and symbol picker.
how do i copy on a mac | command c => Press Command + C to copy, Command + X to cut and Command + V to paste.
how do i undo on mac | command z | redo on mac => Press Command + Z to undo and Command + Shift + Z to redo.
how do i paste without formatting on mac | command option shift v | paste and match style => Press Command + Option + Shift + V to paste and match the style of where you're pasting, in apps that support it.
how do i select all on a mac | command a => Press Command + A to select everything.
how do i find text on a mac | command f => Press Command + F to search for text in the app or web page you're on. Command + G finds the next match.
how do i save on a mac | command s | save as on mac => Press Command + S to save. Command + Shift + S is Save As or Duplicate in many apps.
how do i print on a mac | command p => Press Command + P to print.
how do i open a new tab on mac | command t => Press Command + T to open a new tab in Safari, Chrome, Finder and many other apps.
how do i open a new window on mac | command n => Press Command + N to open a new window or document.
how do i move a file to the trash on mac | command delete => Select the file in Finder and press Command + Delete to move it to the Trash.
how do i empty the trash on mac | command shift delete => Press Command + Shift + Delete in Finder to empty the Trash. Add Option to skip the confirm box.
how do i delete a file right away on mac | option command delete => Select it and press Option + Command + Delete to delete it immediately without going to the Trash. You can't undo it.
how do i rename a file on mac | return key finder => Select the file in Finder and press Return. Type the new name and press Return again.
how do i preview a file on mac | quick look | space bar in finder => Select a file in Finder and press Space to Quick Look it without opening an app. Press Space again to close.
how do i make a new folder on mac | command shift n finder => Press Command + Shift + N in Finder to make a new folder.
how do i get info on a file mac | command i => Select a file and press Command + I to see its size, where it is, and which app opens it.
how do i duplicate a file on mac | command d finder => Select a file in Finder and press Command + D to make a copy of it in the same folder.
how do i go to a folder by typing its path on mac | command shift g => Press Command + Shift + G in Finder, type a path like ~/Library, and press Return.
how do i show hidden files on mac | command shift period => Press Command + Shift + . (period) in Finder to show or hide hidden files.
how do i move a file instead of copying on mac | command option v | cut and paste files mac => Copy the file with Command + C, go to the new folder, then press Command + Option + V to move it there.
how do i open the applications folder | command shift a applications => Press Command + Shift + A in Finder to open Applications.
how do i open downloads on mac | command option l => Press Command + Option + L in Finder to open the Downloads folder.
how do i open the desktop folder on mac | command shift d => Press Command + Shift + D in Finder to open the Desktop folder.
how do i open documents on mac | command shift o => Press Command + Shift + O in Finder to open the Documents folder.
how do i open my home folder on mac | command shift h => Press Command + Shift + H in Finder to open your home folder.
how do i open utilities on mac | cmd shift u utilities | find activity monitor => Press Command + Shift + U in Finder to open Utilities, where Activity Monitor, Terminal and Disk Utility are.
how do i go up a folder on mac | command up arrow finder => Press Command + Up Arrow in Finder to go to the folder that holds this one. Command + Down Arrow opens the selected item.
how do i change finder views | command 1 | finder list view => In Finder press Command + 1 for icons, 2 for list, 3 for columns and 4 for gallery.
how do i open a new finder window | command n finder | option command space => Press Option + Command + Space to open a new Finder window with search ready, or Command + N while Finder is active.
how do i jump to the start of a line on mac | command left arrow => Press Command + Left Arrow for the start of the line and Command + Right Arrow for the end.
how do i jump by word on mac | option left arrow => Press Option + Left Arrow or Right Arrow to move one word at a time. Add Shift to select as you go.
how do i go to the top of a document on mac | command up arrow text => Press Command + Up Arrow for the top and Command + Down Arrow for the bottom of a document.
how do i delete a whole word on mac | option delete => Press Option + Delete to delete the word to the left of the cursor.
how do i forward delete on mac | fn delete | delete to the right on a mac => Press Fn + Delete to delete the letter to the right of the cursor, since Mac keyboards don't have a separate forward Delete key.
how do i log out on mac | shift command q => Press Shift + Command + Q to log out. You'll be asked to confirm.
how do i change volume in small steps on mac | option shift volume => Hold Option + Shift while pressing the volume keys to change it in quarter steps.
how do i open sound settings on mac quickly | option volume key => Hold Option and press any volume key to open Sound settings.
how do i open display settings on mac quickly | option brightness key => Hold Option and press a brightness key to open Displays settings.
how do i right click on a mac | control click | secondary click trackpad => Hold Control and click, or click with two fingers on the trackpad, to right-click.
how do i open activity monitor | mac task manager => Activity Monitor is the Mac's task manager. Press Command + Space, type Activity Monitor, and press Return.
how do i turn on the mac screen zoom | zoom in on whole mac screen => Turn on Zoom in System Settings, Accessibility, Zoom. Then press Option + Command + 8 to toggle it, and Option + Command + = or - to zoom.
how do i open the character viewer for symbols on mac | type special characters mac => Press Control + Command + Space and click the expand icon to see all symbols, arrows and special characters.
how do i type an accented letter on mac | type e with accent mac => Hold down a letter key like e, then pick the accent from the pop-up by clicking it or pressing its number.
how do i hide all other apps | command option h => Press Command + Option + H to hide every app except the one in front.
how do i minimize all windows of an app on mac | command option m => Press Command + Option + M to minimize all windows of the app you're using.
how do i copy a file by dragging on mac | option drag => Hold Option while dragging a file in Finder to copy it instead of moving it.
how do i open a link in a new tab on mac | command click link => Hold Command and click a link to open it in a new background tab.
how do i see keyboard shortcuts for an app on mac | find shortcuts in mac menus => Click the app's menus in the menu bar. Each item shows its shortcut on the right side with symbols like ⌘ for Command and ⌥ for Option.
what do the mac key symbols mean | what is the command symbol | mac keyboard symbols => ⌘ is Command, ⌥ is Option, ⌃ is Control, ⇧ is Shift, and ⇪ is Caps Lock. Fn is often a Globe key on newer Macs.
how do i take a screenshot of the touch bar | touch bar screenshot => Press Command + Shift + 6 on a Mac with a Touch Bar to save a picture of it.
how do i open launchpad or apps on mac | open apps grid mac => Press F4 on many Mac keyboards, or pinch with thumb and three fingers on the trackpad, to see all your apps. Spotlight with Command + Space is often faster.
how do i put my mac to sleep with keys | mac sleep shortcut => Press Option + Command + Power (or Media Eject on old keyboards) to put the Mac to sleep. On newer laptops you can also just close the lid.
