# tag: tech.windows.recovery
how do i boot into safe mode | safe mode windows 11 | start pc in safe mode => Hold Shift and click Restart. Then choose Troubleshoot, Advanced options, Startup Settings, Restart, and press 4 for Safe Mode or 5 for Safe Mode with Networking.
what is safe mode | why use safe mode => Safe Mode starts Windows with only basic drivers and no startup apps. It helps you remove a bad driver or program that stops Windows working normally.
how do i exit safe mode | stuck in safe mode => Just restart the PC normally. If it keeps starting in Safe Mode, press Windows key + R, type msconfig, open the Boot tab, and untick Safe boot.
how do i get to safe mode if windows won't start | pc won't boot safe mode => Turn the PC off while Windows is loading, three times in a row. It then opens Automatic Repair; choose Advanced options, Troubleshoot, Advanced options, Startup Settings.
how do i reset my pc | reset this pc windows 11 | factory reset windows => Open Settings, System, Recovery, and click Reset PC. Choose Keep my files or Remove everything, then Cloud download or Local reinstall. Back up first.
how do i reinstall windows without losing files | fix problems using windows update => On recent Windows 11 versions, open Settings, System, Recovery, and click Reinstall now next to Fix problems using Windows Update. It reinstalls Windows and keeps your files and apps.
how do i make a windows install usb | windows 11 bootable usb => Download the Media Creation Tool from Microsoft's Windows 11 download page, plug in a USB stick of at least 8 GB, and follow the steps. It erases the stick.
how do i do a clean install of windows | fresh install windows 11 => Back up your files, boot from a Windows install USB (use the boot menu key like F8, F11 or F12), delete the old partitions on the main drive, and install onto the empty space.
how do i open advanced startup | restart to recovery options => Open Settings, System, Recovery, and click Restart now next to Advanced startup. Or hold Shift while clicking Restart.
what is automatic repair | preparing automatic repair loop => It's Windows trying to fix startup problems. If it loops, choose Advanced options, then try Startup Repair, System Restore or Uninstall Updates.
how do i run sfc scannow | repair windows system files => Open Terminal as admin and type sfc /scannow, then press Enter. It checks Windows files and fixes broken ones. Restart when it finishes.
what is dism restorehealth | sfc found errors it couldn't fix => In admin Terminal type DISM /Online /Cleanup-Image /RestoreHealth and press Enter. It repairs the Windows image, then run sfc /scannow again.
how do i check my drive for errors | chkdsk => Open File Explorer, right-click the drive, choose Properties, Tools, then Check. Or run chkdsk C: /f in admin Terminal, which runs at the next restart.
how do i test my ram for errors | windows memory diagnostic => Search Windows Memory Diagnostic in Start and choose Restart now and check. It tests the RAM and shows results after you sign in. MemTest86 is a more thorough free tool.
what is reliability monitor | find out why my pc crashed => Search View reliability history in Start. It shows a graph of crashes and errors by day, with details on what failed.
what is event viewer | how do i see crash logs => Event Viewer keeps detailed logs. Right-click Start and open it, then look under Windows Logs, System for red Error and Critical events around the time of the crash.
how do i uninstall a windows update from recovery | update broke my pc => In Advanced startup choose Troubleshoot, Advanced options, Uninstall Updates, and remove the latest quality or feature update.
what is bitlocker | bitlocker recovery key => BitLocker encrypts your drive so no one can read it without signing in. If it asks for a recovery key, find it at account.microsoft.com/devicemanager on another device, signed in with your Microsoft account.
# tag: tech.windows.bios
how do i get into the bios | bios key | how to open uefi settings => Restart and tap Delete or F2 as soon as the PC turns on. Most desktop boards use Delete. Or open Advanced startup, Troubleshoot, Advanced options, UEFI Firmware Settings.
what is the bios | what is uefi => The BIOS (on modern PCs, UEFI) is the small program that starts your PC before Windows. It checks the hardware, holds settings like boot order and RAM speed, and then hands off to Windows.
how do i update my bios | flash bios safely => Download the BIOS for your exact motherboard from the maker's support page, put it on a USB stick, and use the BIOS flash tool (like Q-Flash, EZ Flash or M-Flash). Never turn the PC off while it flashes.
is it a good idea to flash a new bios | is updating bios worth it => Update it if you need support for a newer CPU, a fix for a problem you have, or a security fix. New AM5 boards often get BIOS updates that improve memory stability and boot time.
what is bios flashback | update bios without cpu => Many boards have a BIOS Flashback button on the back. With a USB stick holding the renamed BIOS file in the marked port, it updates the BIOS without a CPU or RAM installed.
how do i reset my bios settings | clear cmos => In the BIOS, choose Load Optimized Defaults. If the PC won't start, turn it off and unplug it, then use the Clear CMOS button or jumper, or remove the coin battery for a few minutes.
how do i change the boot order | boot from usb => Enter the BIOS and open the Boot section to move the USB drive to the top, or tap the one-time boot menu key (often F8, F11 or F12) right after turning on.
how do i turn on expo or xmp | ram running slow in bios => Enter the BIOS and find the memory section (often in the Easy or AI Tweaker area). Set EXPO (AMD) or XMP (Intel) to Profile 1, then save and exit with F10.
how do i turn on resizable bar | what is resizable bar => In the BIOS turn on Above 4G Decoding and Re-Size BAR Support (called Smart Access Memory on AMD). It lets the CPU see all GPU memory at once and can add a few FPS in some games. CSM must be off.
how do i turn on virtualization in bios | svm mode amd => On AMD boards turn on SVM Mode, and on Intel boards turn on Intel Virtualization Technology (VT-x). Some emulators and virtual machines need it.
why does my am5 pc take so long to boot first time | memory training am5 => AM5 boards train the DDR5 memory on first boot or after a BIOS or RAM change, which can take a few minutes with a black screen. Wait for it. Turning on Memory Context Restore in the BIOS can speed later boots.
how do i save and exit the bios | f10 bios => Press F10 in most BIOS screens, then confirm with Yes, to save changes and restart.
what is csm in bios | turn off csm => CSM lets very old operating systems and graphics cards boot. Modern Windows 11 PCs should have CSM off, which is needed for Secure Boot and Resizable BAR.
what is the motherboard debug led | cpu dram vga boot lights => Many boards have four small lights labeled CPU, DRAM, VGA and BOOT. The one that stays lit shows which part is stopping the PC from starting, so reseat that part first.
# tag: tech.windows.taskmanager
what do the task manager tabs mean | how to read task manager => Processes shows each app's CPU, memory, disk, network and GPU use. Performance shows live graphs. App history, Startup apps, Users, Details and Services hold more detail.
how do i see my cpu usage | check cpu percent windows => Open Task Manager with Ctrl + Shift + Esc and look at the CPU column in Processes, or the CPU graph in Performance.
how do i see my gpu temperature on windows | gpu temp task manager => Open Task Manager, Performance, and click your GPU. Many dedicated graphics cards show GPU Temperature at the bottom.
how do i check my cpu temperature | cpu temp windows => Windows doesn't show CPU temperature by itself. Use a free tool like HWiNFO, HWMonitor or Core Temp, or check the PC Health or Hardware Monitor page in the BIOS.
what is efficiency mode in task manager | green leaf in task manager => Efficiency mode lowers an app's priority and power use so it doesn't slow other apps. Right-click a process in Task Manager and choose Efficiency mode.
how do i set a game to high priority | process priority windows => In Task Manager, right-click the game, choose Go to details, then right-click its .exe and choose Set priority, High. It resets when the game closes and rarely adds much FPS.
what is system interrupts | why is system using cpu => System interrupts is Windows handling hardware signals. If it uses lots of CPU for a long time, a driver or device is misbehaving, so update drivers and unplug USB devices one at a time.
what is antimalware service executable | msmpeng high cpu => It's Microsoft Defender scanning your PC. It can use a lot of CPU during a scan, then settles down. Don't turn it off, since it protects you.
what is svchost | so many svchost processes => Svchost.exe runs Windows services, so many copies are normal. Expand one in Task Manager to see which services it holds.
what is desktop window manager | dwm.exe using gpu => DWM draws the Windows desktop, windows and effects. Using some GPU is normal, especially with multiple or high refresh rate monitors.
what is the system idle process | idle process 99 percent => System Idle Process shows how much of the CPU is free, not used. A high number there is good.
what is resource monitor | resmon => Resource Monitor shows detailed CPU, memory, disk and network use per process. Open it from Task Manager, Performance, the three dots, or type resmon in Run.
how do i see what is using my internet | which app is using network => Open Task Manager, Processes, and sort by the Network column. Resource Monitor's Network tab shows even more detail.
how do i see memory usage | what is using my ram => Open Task Manager and click the Memory column in Processes to sort by RAM use. Performance, Memory shows the total used.
# tag: tech.windows.commands
how do i open command prompt | what is cmd => Press Windows key + R, type cmd and press Enter. Command Prompt lets you type text commands to Windows.
what is powershell | powershell vs cmd => PowerShell is a newer, more powerful command line than Command Prompt. It works with objects and scripts. Windows Terminal can open both in tabs.
what is windows terminal | terminal app windows 11 => Windows Terminal is the modern app that holds Command Prompt, PowerShell and Linux shells in tabs. On Windows 11 it's the default terminal.
how do i find my ip address on windows | ipconfig => Open Command Prompt and type ipconfig, then press Enter. Your local IP is next to IPv4 Address, and your router is Default Gateway.
how do i flush dns | ipconfig flushdns => Open Command Prompt and type ipconfig /flushdns. It clears saved website addresses, which can fix some sites not loading.
how do i ping a website | ping command => Open Command Prompt and type ping google.com. It shows how many milliseconds each reply takes. Press Ctrl + C to stop if you used -t.
what is tracert | trace route windows => Type tracert google.com in Command Prompt to see each hop your data takes to reach a site and how long each step takes. It helps find where lag starts.
how do i see my wifi password on windows | show saved wifi password => Open Settings, Network and internet, Wi-Fi, Manage known networks, click the network, and click View next to the Wi-Fi security key on recent Windows 11 versions.
how do i make a battery report | laptop battery health windows => In Terminal type powercfg /batteryreport and press Enter. It saves an HTML file showing design capacity and full charge capacity.
how do i shut down with a command | shutdown command => In Command Prompt type shutdown /s /t 0 to shut down now, or shutdown /r /t 0 to restart. shutdown /a cancels a timed shutdown.
how do i schedule my pc to shut down | shutdown timer => In Command Prompt type shutdown /s /t 3600 to shut down in 3600 seconds (one hour). Type shutdown /a to cancel it.
how do i clear the command prompt | cls command => Type cls and press Enter to clear the Command Prompt screen. In PowerShell, cls or clear works.
how do i change folders in command prompt | cd command => Type cd followed by the folder name, like cd Documents. cd .. goes up one folder, and dir lists what's inside.
what does dir do | list files in command prompt => dir lists the files and folders in the folder you're in. In PowerShell, ls and dir both work.
what is msconfig | system configuration windows => Msconfig (type it in Run) opens System Configuration, where you can pick safe boot options and do a clean boot by hiding Microsoft services and turning off the rest.
how do i do a clean boot | find what program is causing problems => Run msconfig, open Services, tick Hide all Microsoft services, click Disable all, then turn off startup apps in Task Manager. Restart, and turn things back on in groups to find the problem.
what is dxdiag | directx diagnostic tool => Type dxdiag in Run to open the DirectX Diagnostic Tool. It shows your CPU, RAM, GPU, driver version and DirectX version, and can save a report.
what is regedit | is it safe to edit the registry => Regedit edits the Windows Registry, a big database of settings. Wrong changes can break Windows, so only follow trusted guides and make a restore point first.
what is group policy editor | gpedit not found => Gpedit.msc edits advanced policies on Windows Pro, Education and Enterprise. Windows Home doesn't include it.
how do i open control panel on windows 11 | where is control panel => Search Control Panel in Start, or type control in the Run box. Most settings moved to the Settings app, but some old ones are still there.
what is god mode in windows | all settings folder => It's a folder that lists every Control Panel setting. Make a new folder and name it GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}. It's a shortcut, not a hack.
# tag: tech.windows.security
how do i run a virus scan on windows | windows defender scan => Open Windows Security, Virus and threat protection, and click Quick scan. Click Scan options for a Full scan or Microsoft Defender Offline scan.
do i need antivirus on windows 11 | is windows defender enough => For most people, the built-in Microsoft Defender is enough if you keep Windows updated and avoid sketchy downloads. Extra free antivirus apps often add pop-ups and slow things down.
what is a defender offline scan | remove stubborn malware => It restarts the PC and scans before Windows loads, which can catch malware that hides while Windows runs. Find it under Windows Security, Virus and threat protection, Scan options.
how do i turn on controlled folder access | ransomware protection windows => Open Windows Security, Virus and threat protection, Manage ransomware protection, and turn on Controlled folder access. It blocks unknown apps from changing your files; you can allow trusted games.
how do i check the windows firewall | is my firewall on => Open Windows Security, Firewall and network protection. Each network type should say Firewall is on.
how do i allow a game through the firewall | firewall blocking game => Open Windows Security, Firewall and network protection, Allow an app through firewall, click Change settings, and tick the game for Private networks.
what is smartscreen | windows protected your pc message => SmartScreen warns you before running apps it doesn't recognize. Click More info, then Run anyway, only if you're sure the file is from a trusted source.
how do i restore a file defender quarantined | defender deleted my file => Open Windows Security, Virus and threat protection, Protection history, open the item and choose Restore if you're sure it's safe.
how do i add an exclusion to windows defender | stop defender scanning a folder => Open Windows Security, Virus and threat protection, Manage settings, Exclusions, and add a file or folder. Only do this for files you fully trust.
what is core isolation | memory integrity windows => Memory integrity, under Windows Security, Device security, Core isolation, blocks malicious code from getting into high security processes. It's a good protection; turn it off only if a trusted game's anti-cheat requires it.
how do i find my lost laptop | find my device windows => Turn on Settings, Privacy and security, Find my device. Then sign in at account.microsoft.com/devices to see where it was last seen.
