# tag: tech.monitors.more
what is dsc on a monitor | display stream compression => DSC compresses the video signal with no visible loss so a cable can carry high resolutions and refresh rates, like 4K at 240 Hz, over DisplayPort or HDMI.
what is displayport 2.1 | uhbr displayport => DisplayPort 2.1 adds much more bandwidth (UHBR speeds) for very high resolution and refresh rates. You need a GPU, monitor and certified cable that all support it.
what is hdmi 2.1 frl | hdmi 2.1 for pc monitors => HDMI 2.1 uses a faster signaling mode called FRL for 4K at 120 Hz and more. Use an Ultra High Speed HDMI cable to get it.
what is low framerate compensation | lfc freesync => LFC keeps G-Sync and FreeSync working when FPS drops below the monitor's lowest VRR rate by showing each frame two or more times.
what is a vrr range | freesync range 48 200 => The VRR range is the refresh rates where adaptive sync works, like 48 to 200 Hz. Below it, LFC takes over if the monitor supports it.
what is g sync compatible | gsync compatible vs gsync => G-Sync Compatible monitors use the standard adaptive sync (FreeSync) tested by NVIDIA. Full G-Sync monitors use NVIDIA's own module or certification with extra features.
what is freesync premium | freesync premium pro => FreeSync Premium adds LFC and at least 120 Hz at 1080p. Premium Pro also adds HDR support requirements.
what is vrr flicker | oled flicker in loading screens => VRR flicker is brightness flicker when FPS swings a lot, mostly in dark scenes and loading screens on OLED and VA monitors. A steady FPS cap helps.
what is backlight strobing | ulmb dyac elmb => Backlight strobing (ULMB, DyAc, ELMB) flashes the backlight between frames to cut motion blur. It lowers brightness and works best at a steady high FPS.
what is pwm flicker | flicker free monitor => Some screens dim by flashing the backlight very fast (PWM), which can cause eye strain for sensitive people. Flicker-free monitors use steady DC dimming.
what is 8 bit plus frc | 8bit+frc => 8-bit + FRC fakes 10-bit color by quickly switching between nearby shades. It looks almost the same as true 10-bit for most people.
what is local dimming | fald monitor => Local dimming turns down the backlight in dark parts of the image. Full-array local dimming (FALD) with many zones gives much better HDR than edge-lit dimming.
what is edge lit | edge lit vs full array => Edge-lit screens have LEDs only around the edges, so blacks can look grey or patchy. Full-array and mini-LED backlights are better for HDR.
what is ips glow | ips glow vs backlight bleed => IPS glow is a faint shine in dark corners that changes with viewing angle. Backlight bleed is light leaking from edges that stays in place. Both are common on IPS.
what is a va panel | va vs ips => VA panels have deeper blacks and higher contrast than IPS, but can show dark smearing in fast motion. IPS has better colors and viewing angles.
what is a tn panel | tn panel explained => TN panels are an old, cheap type with fast response but poor colors and viewing angles. IPS and OLED have mostly replaced them.
how do i look after an oled monitor | oled burn in prevention => Use a dark taskbar or auto-hide it, a black or changing wallpaper, a screen saver or sleep timer, and let the monitor run its pixel refresh when it asks.
what is pixel refresh on oled | oled panel refresh => Pixel refresh is maintenance the OLED runs while it's in standby to even out wear. Don't unplug it while it's running.
is oled good for a desktop pc | oled for productivity => OLED looks amazing for games and movies, but static things like taskbars can slowly cause burn-in. Many OLED monitors have burn-in warranties.
what is matte vs glossy screen | glossy monitor => Glossy screens look sharper and more vivid but reflect lights and windows. Matte coatings cut reflections but look slightly hazy.
what is color gamut | dci p3 srgb => Color gamut is the range of colors a screen can show. sRGB is the web standard, and DCI-P3 is wider, used for HDR and Apple devices.
what is delta e on a monitor | delta e under 2 => Delta E measures how far a screen's colors are from accurate. Under 2 is hard to notice, which is good for photo and video editing.
what is monitor calibration | calibrate monitor colors => Calibration adjusts a screen so colors and brightness are accurate. A colorimeter does it best, but even Windows' Calibrate display color tool helps.
what is gamma on a monitor | gamma 2.2 => Gamma sets how bright the in-between shades look. 2.2 is the standard for PCs and the web. Wrong gamma makes images look washed out or too dark.
what monitor is good for video editing | color accurate monitor => Look for an IPS or OLED with good sRGB coverage, a low Delta E, and ideally factory calibration. 1440p or 4K gives room for the timeline.
what is a usb c monitor | monitor charges laptop => A USB-C monitor carries video, data and power over one cable, so it can charge a laptop while acting as its screen.
what is daisy chaining monitors | displayport mst => Daisy chaining connects a second monitor to the first using DisplayPort MST. Windows supports it, but Macs don't over MST.
what is a monitor arm | monitor arm vesa => A monitor arm clamps to the desk and holds the screen on a movable arm. Check the monitor's weight and VESA mount (often 100 x 100) first.
what is portrait mode for monitors | vertical monitor => Turning a monitor vertical is great for code, chat or long documents. Rotate it in Windows display settings under Display orientation.
should i get 24 or 27 inch for esports | monitor size competitive => Many pro players use 24 to 25 inch monitors so the whole screen is in view without moving their eyes. 27 inch is nicer for 1440p and general use.
what is a monitor overclock setting | overclocked refresh rate => Some monitors list a higher refresh rate that needs an OSD setting turned on first. Check the manual if your monitor's top Hz isn't showing in Windows.
what is cru | custom resolution utility => Custom Resolution Utility edits the resolutions and refresh rates Windows sees. It's for advanced users, and pushing a monitor too far can cause problems.
what is gpu scaling | display scaling vs gpu scaling => When you run a lower resolution, either the GPU or the monitor stretches it to fit. GPU scaling gives more control, like keeping black bars.
what is integer scaling | pixel art sharp scaling => Integer scaling enlarges each pixel by a whole number, so pixel art and 1080p on a 4K screen stay crisp instead of blurry.
what is stretched resolution | stretched res fortnite => Stretched resolution plays at a squarer ratio stretched to fill the screen. Some players think targets look wider, but it distorts the image.
what is input lag on a monitor | monitor input lag vs response time => Input lag is the delay before the monitor shows a new frame. Response time is how fast pixels change color. Gaming monitors keep both low.
what is a monitor's hdr mode washing out colors | hdr looks washed out => On many cheaper HDR monitors, Windows HDR makes the desktop look grey. Use HDR only in games and movies, and run the Windows HDR Calibration app.
what is a 4k monitor good for | 4k vs 1440p for pc => 4K is very sharp for editing, text and big screens, but games need a powerful GPU. 1440p is a good middle ground for most gaming PCs.
what is a dual mode monitor | 4k 240 1080p 480 => Dual-mode monitors switch between a high resolution and a lower resolution at a much higher refresh rate, like 4K 240 Hz or 1080p 480 Hz.
what is a portable monitor | travel monitor => A portable monitor is a thin screen powered by USB-C, great for a laptop on the go or a Switch. Check the laptop's USB-C port supports video.
how do i fix a monitor that keeps going to sleep | monitor no signal sleep => Check the cable is snug, try another port, and turn off any input auto-detect feature in the monitor's menu. Updating the GPU driver can help too.
