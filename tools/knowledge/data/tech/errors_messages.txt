# tag: tech.errors.web
what does error 404 mean | page not found error => 404 means the website is working but that page doesn't exist, often because the link is old or mistyped. Check the address or search the site for the page.
what does error 403 forbidden mean | website says forbidden => 403 Forbidden means the server understood the request but won't let you see the page, usually because you don't have permission or the site blocked your connection.
what does error 500 mean | internal server error => 500 means something broke on the website's server, not on your device. Wait a bit and refresh, because only the site's owners can fix it.
what does 502 bad gateway mean | 502 error => 502 means one server got a bad answer from another server behind it. It's a problem on the website's side and usually clears up after a few minutes.
what does 503 service unavailable mean | 503 error => 503 means the site is overloaded or down for maintenance. It often happens during big game launches. Try again later.
what does error 429 mean | site says slow down too many requests => 429 means you sent too many requests too fast, so the site is making you wait. Stop refreshing for a few minutes and try again.
what does err connection timed out mean | site took too long to respond => The browser waited too long for the site to answer. Check your internet, restart the router, or try again later if only one site does it.
what does dns probe finished nxdomain mean | nxdomain error => The browser couldn't find the address for that website name. Check the spelling, then try flushing DNS or changing your DNS server.
what does err name not resolved mean | name not resolved chrome => The website's name couldn't be turned into an IP address. Check the address, restart your router, and run ipconfig /flushdns on Windows.
what does dns server not responding mean | dns not responding fix => Your device can't reach a DNS server. Restart the router and PC, then try setting DNS to a public one like 1.1.1.1 or 8.8.8.8 in your network settings.
what does your connection is not private mean | privacy error chrome => The site's security certificate couldn't be checked. Check your PC's date and time first. If it's correct, don't type passwords on that site.
what does err cert date invalid mean | certificate expired error => Usually your device's clock is wrong, or the site's certificate expired. Set the time automatically in Windows and reload.
what does err too many redirects mean | redirect loop => The site keeps sending you in a loop. Clear cookies for that site, or try a private window.
what does this site can't be reached mean | website won't connect at all => The browser couldn't connect at all. Check your internet, try another site, and restart the router if nothing loads.
what does err internet disconnected mean | browser says no internet => Your device isn't connected to the internet. Check Wi-Fi or the Ethernet cable, and turn off airplane mode.
what does unidentified network mean | unidentified network windows => Windows connected to something but couldn't get proper network settings. Restart the router, then run the Network reset option in Settings if it keeps happening.
what does limited connectivity mean | limited access wifi => Your device is connected to the network but can't reach the internet properly. Restart the router and device, and check the cable or Wi-Fi signal.
what does 2fa code invalid mean | authenticator code not working => Usually your device's clock is off, so the code is out of sync. Turn on automatic time, then try a fresh code.
# tag: tech.errors.windows
what does code 43 mean in device manager | windows stopped this device code 43 => Code 43 means Windows stopped a device because it reported a problem. Unplug and replug it, try another port or cable, and update or reinstall its driver.
what does code 10 mean in device manager | this device cannot start => Code 10 means the device couldn't start. Reinstalling or updating its driver usually fixes it.
what does code 28 mean in device manager | drivers not installed code 28 => Code 28 means no driver is installed. Use Windows Update or download the driver from the maker's website.
what does the application was unable to start correctly mean | 0xc000007b error => This often means a missing or broken Visual C++ or DirectX file. Install the latest Visual C++ Redistributables from Microsoft and restart.
what does the disk is write protected mean | can't copy to usb write protected => Check for a small lock switch on SD cards or adapters. Otherwise the drive may be failing or set read-only.
what does you need to format the disk mean | format disk popup => Windows can't read the drive's file system. Don't click Format if it holds important files, because formatting erases them. Try it on another PC first.
what does file is too large for the destination file system mean | can't copy big file to usb => The drive is formatted as FAT32, which can't hold files over 4 GB. Back up the drive and reformat it as exFAT.
what does device descriptor request failed mean | unknown usb device => Windows couldn't talk to a USB device. Try another port and cable, plug it straight into the PC instead of a hub, and restart.
what does this app has been blocked for your protection mean | windows blocked an app => Windows blocked an app it thinks may be unsafe. Only unblock it if you're sure it came from a trusted source, and ask a parent if unsure.
what does undoing changes made to your computer mean | update failed undoing changes => An update failed and Windows is rolling it back. Let it finish, then run the Windows Update troubleshooter and try again.
what does your device is missing important security fixes mean | missing security fixes warning => Windows Update is behind or stuck. Run Windows Update, then the troubleshooter in Settings, System, Troubleshoot, Other troubleshooters.
what does error 0x80070005 mean | access denied error code => 0x80070005 means access was denied, usually a permissions problem. Run the installer or tool as administrator, or restart and try again.
what does error 0x800f081f mean | update error 0x800f081f => It usually means Windows Update or a feature install couldn't find files it needed. Run DISM /Online /Cleanup-Image /RestoreHealth, then try again.
what does the requested operation requires elevation mean | needs admin rights => The program needs administrator rights. Right-click it and choose Run as administrator.
what does your pc needs to be repaired mean | error code 0xc0000225 => Windows can't find files it needs to start. Boot from a Windows install USB and choose Repair your computer, Startup Repair.
what does bootmgr is missing mean | pc says bootmgr missing => The PC can't find a boot loader on the drive it's trying. Check the boot order in the BIOS, and run Startup Repair from a Windows USB if needed.
what does the trust relationship failed mean | school laptop domain error => This is a school or work PC problem with its network domain. Ask the school's IT team rather than trying to fix it yourself.
what does a dll was not found mean | dll not found error => The program is missing a file it needs. Reinstall the program or its runtime, like Visual C++ or DirectX. Avoid random DLL download sites.
# tag: tech.errors.games
what does vac banned mean | vac ban => A VAC ban is Valve's permanent ban for cheating in some Steam games. It can't be appealed, which is one more reason never to use cheats.
what does connection to server lost mean in games | lost connection to host => Your connection to the game server dropped. Check your Wi-Fi or Ethernet, restart the router, and check the game's status page for outages.
what does failed to connect to matchmaking mean | can't find a match error => The game couldn't reach its matchmaking servers. Check the game's status page or social posts, because servers often go down during updates.
what does out of video memory mean | out of vram error => The game needed more VRAM than your graphics card has. Lower texture quality and resolution, and close other programs using the GPU.
what does game requires directx 12 mean | dx12 not supported => Your GPU or its driver doesn't support the DirectX 12 features the game needs. Update the graphics driver, and check the game's minimum GPU.
what does battleye error mean | battleye not working => BattlEye is anti-cheat. Verify game files, update Windows, and make sure no overlay or tool is being blocked by it.
what does error code 268 roblox mean | roblox kicked unexpected client behavior => Roblox error 268 means you were kicked for unexpected client behavior, often caused by exploits or cheat tools. Uninstall those and reinstall Roblox.
what does roblox error 529 mean | roblox 529 => Error 529 means Roblox is having service problems. Wait and try again, and check status.roblox.com.
what does minecraft authentication servers are down mean | minecraft login servers down => Minecraft couldn't check your login with Microsoft. Restart the launcher, and check Minecraft's status page or social posts.
what does steam content servers unreachable mean | steam download won't start => Steam can't reach its download servers. Change the download region in Steam, Settings, Downloads, and clear the download cache.
what does steam disk write error mean | disk write error steam => Steam couldn't write to the game folder. Restart Steam, check the drive isn't full, and run Steam as administrator once.
