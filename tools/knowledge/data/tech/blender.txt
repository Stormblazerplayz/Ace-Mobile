# tag: tech.blender
is blender free | what can blender do => Yes, Blender is free and open source. It does 3D modeling, sculpting, texturing, rigging, animation, rendering, video editing and even 2D animation.
what is the difference between object mode and edit mode | blender modes => Object Mode moves, rotates and scales whole objects. Edit Mode changes the shape itself by working with vertices, edges and faces.
what are vertices edges and faces | parts of a mesh => A vertex is a point, an edge connects two vertices, and a face is a flat surface between edges. Together they make a mesh.
what is a modifier in blender | blender modifiers explained => Modifiers change an object without destroying the original, like Subdivision Surface to smooth, Mirror to copy one half, Array to repeat, or Bevel to round edges. Apply them when you're done.
how do i use the mirror modifier | model symmetrically blender => Delete half the model, add a Mirror modifier, and turn on Clipping so the middle vertices stay joined. Now edits on one side show on both.
what is the array modifier | repeat objects blender => The Array modifier makes copies of an object in a line or pattern, like stairs, chain links or fences, and updates them all when you change the original.
what is the boolean modifier | cut a hole blender => Boolean combines two objects by Difference (cut one out of the other), Union (merge) or Intersect. Hide the cutter object afterwards.
what is the solidify modifier | give a plane thickness => Solidify gives thin surfaces real thickness, which is needed before 3D printing a flat or shell shape.
what is shade smooth vs flat | blender smooth shading => Shade Flat shows each face sharply; Shade Smooth blends lighting across faces so curves look round. Right-click an object in Object Mode to switch. Shade Auto Smooth keeps sharp edges sharp.
what is eevee vs cycles | which render engine blender => EEVEE is a fast real-time renderer, great for previews and stylized looks. Cycles traces light rays for realistic results but takes longer. Both are free in Blender.
how do i make cycles render faster | blender render slow => In Preferences, System, turn on your GPU (OptiX for NVIDIA RTX, HIP for AMD), set Device to GPU Compute, lower samples and turn on denoising.
how do i add a material in blender | color an object blender => Select the object, open the Material Properties tab (red sphere), click New, and change Base Color. Switch to Material Preview (Z) to see it.
what is the shader editor | blender nodes => The Shader Editor builds materials with nodes, like connecting an image texture into the Principled BSDF's Base Color. Open the Shading workspace to use it.
what is uv unwrapping | why do i need uvs => UV unwrapping flattens a 3D model's surface into 2D, like peeling an orange, so a 2D image texture can wrap onto it correctly.
how do i add a texture image in blender | put a picture on a model blender => In the Shading workspace, drag the image into the Shader Editor and connect its Color to the Principled BSDF's Base Color. The object needs good UVs.
what is sculpt mode in blender | sculpting in blender => Sculpt Mode lets you shape a mesh like digital clay with brushes like Draw, Clay Strips, Grab and Smooth. It's great for characters and organic shapes.
how do i add lights in blender | blender lighting => Press Shift + A, then Light, and pick Point, Sun, Spot or Area. Area lights give soft shadows. An HDRI in World settings lights the scene like a real place.
how do i set up a camera in blender | move camera to view => Press Shift + A to add a Camera, then Ctrl + Alt + Numpad 0 to snap it to your view. Lock Camera to View in the N sidebar's View tab lets you fly it around.
how do i animate in blender | keyframe animation blender => Move to a frame, pose the object and press I to keyframe it. Move to another frame, change it and keyframe again. Press Space to play. Fine-tune in the Graph Editor.
how do i export from blender for 3d printing | blender stl export => Choose File, Export, STL (or 3MF with an add-on). Make sure the model is solid with no holes, apply scale and modifiers, and check the size in millimeters.
how do i set units to millimeters in blender | blender scale for printing => In Scene Properties, Units, set Unit System to Metric, Length to Millimeters and Unit Scale to 0.001. Then 1 unit equals 1 mm.
what is the 3d print toolbox | check model for printing blender => 3D Print Toolbox is a free Blender add-on (extension) that checks for non-manifold edges, thin walls and overhangs, and can fix some problems.
what is non manifold geometry | holes in mesh blender => Non-manifold geometry means the mesh isn't a closed solid, like holes or edges shared by three faces. Slicers may fail on it. In Edit Mode, Select, Select All by Trait, Non Manifold finds it.
how do i export a model to roblox from blender | blender fbx export => Export as FBX (or OBJ) with File, Export, then import it in Roblox Studio with the 3D Importer. Keep the polygon count reasonable and apply scale first.
how do i add an hdri in blender | hdri lighting => In World Properties, click the yellow dot next to Color, choose Environment Texture, and open an HDRI image. Free HDRIs are on Poly Haven.
what is poly haven | free textures for blender => Poly Haven is a free site with HDRIs, textures and 3D models under the CC0 license, which means you can use them for anything.
what are geometry nodes | blender geometry nodes => Geometry Nodes build or change objects with a node system, like scattering trees on a landscape or making procedural buildings.
how do i fix a model that looks black or dark in blender | flipped normals => Dark patches often mean flipped normals. In Edit Mode, select all and press Shift + N to recalculate normals. Turn on Face Orientation in Overlays to see blue (good) and red (flipped).
why is my bevel weird in blender | modifiers look stretched blender => Uneven bevels and modifiers often come from unapplied scale. Press Ctrl + A and apply Scale, then redo the bevel.
how do i join two meshes into one smooth piece | merge meshes blender => Join them with Ctrl + J, then in Edit Mode bridge edge loops or use a Boolean Union. For sculpting, Remesh fuses everything into one surface.
what is subdivision surface | make it smooth blender => Subdivision Surface splits faces into smaller ones to make a smooth, rounded version of your model. Add support edge loops to keep some edges sharp.
what is topology | good topology blender => Topology is how the faces flow across a model. Clean, mostly four-sided faces in even loops deform well in animation and subdivide smoothly.
what is retopology | retopo => Retopology is rebuilding a messy, high-detail sculpt as a cleaner, lighter mesh that's easier to texture and animate.
what is the outliner in blender | outliner panel => The Outliner at the top right lists every object and collection in the scene. Click the eye to hide things and drag to organize them into collections.
what is a collection in blender | organize objects blender => A collection is a folder for objects in the Outliner, used to organize scenes and to hide or show groups at once.
how do i render a transparent background in blender | png without background => In Render Properties, Film, tick Transparent, then save the render as a PNG with RGBA.
what is a blender add on | install add on blender => Add-ons (now often called extensions) add features. In Blender 4.2 and later, open Edit, Preferences, Get Extensions to search and install them.
where can i learn blender | blender donut tutorial => Blender Guru's free donut tutorial on YouTube is the classic beginner course. Blender's own site and the official manual have free guides too.
