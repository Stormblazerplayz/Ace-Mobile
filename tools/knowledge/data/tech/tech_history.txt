what was the first microprocessor | intel 4004 => The Intel 4004, released in 1971, was the first commercial microprocessor, a whole CPU on one chip.

what was the xerox alto | first computer with windows and icons => The Xerox Alto from 1973 was one of the first computers with a mouse, windows and icons. It inspired the Apple Macintosh and later Windows.
when did the first windows come out | windows 1.0 release => Windows 1.0 came out in 1985 as a program that ran on top of MS-DOS.
what was windows 95 | when did the start menu first appear => Windows 95 was a huge hit that introduced the Start button and taskbar, which Windows still uses.
what was windows xp | windows xp release year => Windows XP came out in 2001 and was so popular that many people kept using it for over a decade.
when did windows 11 come out | windows 11 release date => Windows 11 came out in October 2021 with a centered Start menu and new design.
who created linux | linus torvalds => Linus Torvalds created the Linux kernel in 1991 as a student in Finland and shared it for free, and thousands of people helped build it.
when was the ibm pc released | ibm personal computer 1981 => IBM released its Personal Computer in 1981. Its design became the standard that most Windows PCs still follow.
when did the macintosh come out | first mac 1984 => Apple released the first Macintosh in 1984. It made the mouse and windows popular for regular people.
what was the first nvidia gpu | geforce 256 first gpu => Nvidia called the GeForce 256 from 1999 the world's first GPU, because it handled 3D transform and lighting on the card instead of the CPU.
what was blackberry | blackberry phone keyboard => BlackBerry made popular phones in the 2000s with physical keyboards, loved for email. Touchscreen phones like the iPhone took over.
what was nokia famous for | nokia 3310 => Nokia was the world's biggest phone maker in the 2000s. Phones like the 3310 were famous for being nearly unbreakable and for the game Snake.
what was myspace | myspace social network => MySpace was the most popular social network in the mid-2000s, where people customized their profile pages, before Facebook took over.
what was deep blue | computer beat chess champion => Deep Blue was an IBM chess computer that beat world champion Garry Kasparov in a match in 1997.
what was alphago | ai beat go champion => AlphaGo, made by DeepMind, beat top Go player Lee Sedol in 2016. Go was thought to be much harder for computers than chess.
when did chatgpt come out | chatgpt release date => OpenAI released ChatGPT in November 2022, and it reached millions of users within days.
what was the first industrial robot | unimate robot => Unimate was the first industrial robot arm, put to work at a General Motors factory in 1961.
what is asimo | honda robot => ASIMO was a walking humanoid robot made by Honda and shown in 2000. It could walk, climb stairs and even run.
when was usb invented | first usb => USB was introduced in 1996 to replace the many different ports computers had for mice, keyboards and printers.
when did steam launch | steam release year => Valve launched Steam in 2003, at first mainly to update its own games like Counter-Strike.
when did discord come out | discord release year => Discord launched in 2015 as a voice and text chat app for gamers.
when was wikipedia started | wikipedia founded => Wikipedia started in 2001 as a free encyclopedia anyone can edit.
when did amazon start | amazon used to sell books => Jeff Bezos started Amazon in 1994, and at first it only sold books online.
when did the first android phone come out | t mobile g1 => The first Android phone was the HTC Dream, also called the T-Mobile G1, released in 2008. It had a slide-out keyboard.
when did the ipad come out | first ipad 2010 => Apple released the first iPad in 2010.
when did the arduino come out | arduino history => Arduino started in 2005 in Italy as a cheap, easy board for students and artists.
when did the raspberry pi come out | first raspberry pi => The first Raspberry Pi came out in 2012 to help kids learn computing cheaply.
