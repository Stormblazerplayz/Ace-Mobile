# tag: tech.linux
what is a linux distro | linux distribution => A distro is a complete Linux package: the Linux kernel plus apps, a desktop and an installer. Ubuntu, Linux Mint, Fedora and SteamOS are all distros.
which linux is best for beginners | easiest linux distro => Linux Mint and Ubuntu are popular first picks because they're easy to install and have big help communities. Mint feels a lot like Windows.
what is ubuntu | ubuntu explained => Ubuntu is one of the most popular Linux distros, made by Canonical. It's free and used on PCs, servers and many Raspberry Pi projects.
what is steamos | steamos explained => SteamOS is Valve's Linux-based operating system for the Steam Deck. It uses Proton to run many Windows games.
what is proton | windows games on linux => Proton is Valve's tool inside Steam that lets many Windows games run on Linux. Check ProtonDB to see how well a game works.
what is protondb | check if a game runs on linux => ProtonDB is a community site where players rate how well each Steam game runs on Linux and Steam Deck, with tips for fixing problems.
can i play roblox on linux | roblox linux => Roblox doesn't officially support Linux. Unofficial tools exist, but they can break when Roblox updates, so Windows or another device is more reliable.
do anti cheat games work on linux | fortnite on linux => Some anti-cheat games work on Linux through Proton, but several big ones like Fortnite and Valorant don't, because their anti-cheat blocks it. As of 2025, check each game first.
what is a live usb | try linux without installing => A live USB lets you boot Linux from a flash drive to try it without changing your PC. Make one with a tool like Rufus or balenaEtcher.
what is dual booting | windows and linux on one pc => Dual booting means installing two operating systems and choosing one each time the PC starts. Back up your files before trying, because partitioning can go wrong.
what is a desktop environment | gnome vs kde => The desktop environment is the look and layout of Linux, like the taskbar and menus. GNOME, KDE Plasma and Cinnamon are popular ones.
what does sudo do | sudo meaning => sudo runs one command with administrator (root) rights. It asks for your password, so only use it when a command really needs it.
what is root on linux | root user => Root is the all-powerful admin account on Linux. It can change or delete anything, which is why people use sudo instead of logging in as root.
how do i update ubuntu from the terminal | sudo apt update upgrade => Run sudo apt update to refresh the list of software, then sudo apt upgrade to install the updates.
what does pwd do in linux | print working directory => pwd prints the full path of the folder the terminal is in.
what does rm do in linux | delete a file in terminal => rm deletes a file without sending it to the trash, so be careful. rm -r deletes a folder and everything in it.
what does cp and mv do | copy and move in linux => cp copies a file and mv moves or renames it, like cp a.txt b.txt or mv old.txt new.txt.
what does cat do in linux | show a file in terminal => cat prints a text file's contents in the terminal, like cat notes.txt.
what is nano | edit a file in the terminal => Nano is a simple text editor that runs in the terminal. Open a file with nano file.txt, then press Ctrl + O to save and Ctrl + X to exit.
how do i exit vim | stuck in vim => Press Esc, type :q! and press Enter to quit without saving, or :wq to save and quit.
what does man do in linux | linux manual pages => man shows the manual for a command, like man ls. Press q to leave it.
what does top or htop do | linux task manager => top and htop show running programs and how much CPU and memory they use, like Task Manager. Press q to exit.
what does chmod do | file permissions linux => chmod changes who can read, write or run a file. chmod +x script.sh makes a script runnable.
what does df -h do | check disk space linux => df -h shows how much space is used and free on each drive, in easy units like GB.
what does ssh do | ssh into a raspberry pi => SSH lets you control another computer's terminal over the network, like ssh pi@raspberrypi.local to work on a Raspberry Pi without a screen.
what does ctrl c do in linux terminal | stop a command linux => Ctrl + C stops the running command in a Linux terminal. To copy text in most Linux terminals, use Ctrl + Shift + C instead.
what does tab do in a linux terminal | autocomplete linux => Tab completes file names and commands. Press it twice to see all matches.
what does the tilde mean in linux | ~ folder => The tilde ~ means your home folder, like /home/yourname. cd ~ takes you there.
is linux more secure than windows | does linux get viruses => Linux gets fewer viruses aimed at home users, but it isn't immune. Install software from your package manager and keep it updated.
what is raspberry pi os | raspberry pi os explained => Raspberry Pi OS is the official Linux distro for Raspberry Pi boards, based on Debian. Install it with the Raspberry Pi Imager tool.
what is a server os | linux on servers => Most web servers run Linux because it's free, stable and works well without a screen. Many websites and game servers run on it.
how do i run a minecraft server on linux | host minecraft on ubuntu => Install Java, download the server jar from Minecraft's official site, and run it with a java command. Running a server is a great way to learn Linux.
what is a terminal emulator | linux terminal app => A terminal emulator is the app window where you type commands, like GNOME Terminal or Konsole. The shell inside it, often Bash or Zsh, runs the commands.
what is bash | bash explained => Bash is the most common shell on Linux. It reads the commands you type and runs them.
