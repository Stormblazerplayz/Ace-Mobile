# tag: tech.network.home
what is an ssid | wifi network name => The SSID is your Wi-Fi network's name, the one you pick from the list. You can change it in the router's settings.
how do i change my wifi password | new wifi password router => Log in to the router's app or admin page, open the wireless or Wi-Fi settings, and change the password. Ask a parent first, since every device will need the new one.
what is wpa3 | wpa2 vs wpa3 => WPA3 is the newest Wi-Fi security standard and is harder to crack than WPA2. Use WPA3, or WPA2/WPA3 mixed mode if older devices need it.
what is a guest network | guest wifi => A guest network gives visitors internet without access to your own devices like printers or PCs. It's also a good place for smart home gadgets.
what is wps on a router | wps button => WPS connects devices by pressing a button instead of typing the password. Its PIN method has known security holes, so many people turn WPS off.
should i change my router admin password | default router password => Yes. The admin password for the router's settings page should be changed from the default, so nobody on your network can change your settings.
how do i update my router firmware | router update => Most routers update through their app or admin page. Turn on automatic updates if you can, because updates fix security holes.
what is a wifi channel | change wifi channel => Wi-Fi channels are lanes inside each band. If neighbors use the same channel, it gets crowded. Most routers pick the best channel automatically.
what is band steering | combine 2.4 and 5ghz => Band steering puts 2.4 GHz and 5 GHz under one Wi-Fi name and moves devices to the best band. Some smart home gadgets need it off to connect to 2.4 GHz.
what is dfs on wifi | dfs channels => DFS channels are extra 5 GHz channels shared with weather radar. They're often less crowded, but the router must switch away if it detects radar.
what is mu mimo | mimo wifi => MU-MIMO lets a router send data to several devices at the same time instead of taking turns, which helps busy homes.
what is beamforming | wifi beamforming => Beamforming aims the Wi-Fi signal toward your device instead of spreading it equally everywhere, giving a stronger connection.
where should i put my router | best router placement => Put it high, central and in the open, away from metal, mirrors, fish tanks and thick walls. Don't hide it in a cabinet.
what is moca | internet over coax => MoCA adapters send internet over the TV coax cables in your walls. They're often faster and steadier than powerline.
is cat8 cable worth it | cat8 for gaming => No. Cat8 is for data centers. A Cat6 cable gives the same ping and speed for home internet.
what is 2.5 gigabit ethernet | 2.5gbe port => 2.5 GbE ports run at 2.5 Gbps, faster than normal gigabit. Many AM5 motherboards have one, but you only benefit if your router or internet is faster than 1 Gbps.
what do the lights on an ethernet port mean | ethernet port lights => The lights show a link and activity. A solid light means connected, and blinking means data is moving. No light means a bad cable or port.
what is a static ip | static vs dynamic ip => A static IP never changes, while a dynamic one is handed out by the router and can change. For a game server on your network, set a DHCP reservation in the router.
what is a dhcp reservation | reserve an ip => A DHCP reservation tells the router to always give one device the same local IP, which makes port forwarding reliable.
what is a subnet mask | 255.255.255.0 meaning => A subnet mask says which part of an IP address is the network and which part is the device. Most homes use 255.255.255.0.
what is double nat | two routers problem => Double NAT happens when two routers are both doing NAT, like an ISP box plus your own router. It can cause strict NAT in games. Put one in bridge mode to fix it.
what is bridge mode | modem bridge mode => Bridge mode turns off the routing on an ISP box so your own router does all the work, avoiding double NAT.
what is cgnat | carrier grade nat => CGNAT means your ISP shares one public IP among many customers. Port forwarding won't work, so hosting servers can be hard. Ask the ISP for a public IP.
what is bufferbloat | lag when someone downloads => Bufferbloat is lag that spikes when the connection is busy, like when someone is uploading. Routers with SQM or smart QoS can fix it.
what is sqm on a router | smart queue management => SQM manages traffic so gaming and calls stay smooth while others download. It costs a little top speed but greatly lowers lag spikes.
what is a private wifi address | mac randomization => Phones and PCs can use a random MAC address on each Wi-Fi network for privacy. Turn it off for your home Wi-Fi if the router's parental controls need to recognize the device.
what is dns over https | encrypted dns => DNS over HTTPS encrypts your website lookups so others on the network can't read them. Browsers and Windows 11 can turn it on.
what is the hosts file | windows hosts file => The hosts file on Windows maps website names to IP addresses before DNS is checked. Malware sometimes changes it, so it's worth knowing about.
what is a proxy server | proxy vs vpn => A proxy passes your web traffic through another server, usually for one app or browser. A VPN covers the whole device and encrypts everything.
what is wifi calling | calls over wifi => Wi-Fi calling lets your phone make normal calls and texts over Wi-Fi when cell signal is weak. Turn it on in the phone's settings.
what is 5g home internet | fixed wireless internet => 5G home internet uses a mobile network instead of cables. It's easy to set up but ping can be higher and less steady than fiber or cable.
what is a data cap | internet data limit => A data cap limits how much you can download each month before the ISP charges more or slows you down. Big game downloads use a lot.
what is a speed test server | speedtest results different => Speed tests measure to a nearby server, so results change by server and time. Test on Ethernet for the most accurate number.
why is my download speed slower than my plan | internet slower than paid for => Wi-Fi, old routers, busy times and other devices all slow it down. Test with Ethernet to see your real speed.
what is a network adapter | wifi card pc => A network adapter connects a device to a network. PCs have an Ethernet port and often a Wi-Fi card, and USB Wi-Fi adapters can add one.
how do i add wifi to my desktop pc | pc without wifi => Use a PCIe Wi-Fi card with antennas, or a USB Wi-Fi adapter. Many AM5 motherboards already include Wi-Fi.
what is a wifi antenna on a pc | wifi antenna motherboard => Motherboards with Wi-Fi come with screw-on antennas for the back panel. Without them, Wi-Fi signal is very weak.
how do i reset my router to factory settings | router reset button => Hold the reset button with a pin for about 10 seconds. This erases all settings, including the Wi-Fi name and password, so ask a parent first.
what is a router's admin page | router login page => It's the settings page you open by typing the router's IP, often 192.168.1.1, into a browser. Many routers now use a phone app instead.
what is a lan party | play games on the same network => A LAN party is playing games together with computers on the same local network, which gives very low ping between players.
what is a mac address filter | block a device from wifi => MAC filtering only lets listed devices join. It's easy to fake, so a strong Wi-Fi password is the real protection.
how do parental controls on a router work | router time limits => Many routers can pause the internet for certain devices, block sites or set bedtimes. They're managed in the router's app.
what is a network map | see devices on my wifi => The router's app or admin page lists devices on the network. Unknown devices can be renamed, checked or blocked.
