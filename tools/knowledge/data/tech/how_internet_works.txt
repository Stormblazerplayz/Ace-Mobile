# tag: tech.internet
what is a packet | data packets => A packet is a small chunk of data with an address label. Big things like videos are split into many packets, which can take different paths and get reassembled at the end.
what are undersea internet cables | how does internet cross the ocean => Most data between continents travels through fiber optic cables lying on the ocean floor. There are hundreds of them, carrying far more data than satellites.
what is fiber optic cable | how does fiber work => Fiber optic cables carry data as pulses of light through thin strands of glass. Light travels fast and can carry huge amounts of data over long distances.
what is an isp | internet service provider => An ISP is the company you pay for internet access, like a cable, fiber or phone company. It connects your home to the rest of the internet.
what is http and https | what does the s in https mean => HTTP is the language browsers and websites use to talk. HTTPS is the secure version, where the data is encrypted so others on the network can't read it.
how do website names work | what is the name part of a web address => A domain name is a website's human-friendly name, like example.com. DNS turns it into the server's IP address so your browser can find it.
what is a top level domain | what does .com mean => The ending of a domain, like .com, .org, .edu or .uk, is the top-level domain. Some show a type or country, but anyone can buy most of them.
what is web hosting | how do websites stay online => Hosting is renting space on a server that's always on and connected, so people can visit your website any time.
what is tcp ip | tcp/ip protocol => TCP/IP is the set of rules the internet runs on. IP addresses and routes packets, and TCP checks they all arrive and puts them in order.
what is udp | tcp vs udp games => UDP sends packets without checking every one arrives, so it's faster. Online games and voice chat use it because speed matters more than an occasional lost packet.
what is latency vs speed of light | why far servers have high ping => Even light in fiber takes time. Data crossing an ocean and back takes tens of milliseconds, which is why far-away game servers always have higher ping.
what is a cdn | content delivery network => A CDN stores copies of websites, videos and game downloads on servers around the world, so you download from one close to you for faster speed.
what is streaming | how does netflix stream => Streaming plays video or music while it downloads in small pieces, so you don't wait for the whole file. The player adjusts quality to your internet speed.
what is buffering | why does my video keep buffering => Buffering means the video is waiting for more data. It happens when your internet is slower than the video needs. Lower the quality or move closer to the router.
what is starlink | satellite internet => Starlink is SpaceX's satellite internet. Thousands of satellites in low orbit beam internet to dishes on the ground, useful in places without cables.
what is an email address made of | how does email work => An email address has a name, an @ sign and a domain, like name@example.com. Mail servers pass your message along until it reaches the other person's inbox.
what is spam email | why do i get junk mail => Spam is unwanted bulk email, often ads or scams. Mark it as spam so your email app learns, and never reply or click its links.
who owns the internet | who controls the internet => No one owns the whole internet. It's a network of networks run by many companies, governments and organizations that agree on shared rules.
history of the internet timeline | internet milestones 1969 1983 1991 => The internet grew from ARPANET, a US research network that sent its first message in 1969. TCP/IP was adopted in 1983, and the World Wide Web came in 1991.
what is a web page made of | how are websites built => Web pages use HTML for structure, CSS for style and JavaScript for interactive parts. Your browser downloads these files and draws the page.
what is a web browser engine | chrome vs safari engine => An engine draws web pages. Chrome and Edge use Blink, Safari uses WebKit, and Firefox uses Gecko. Every iPad browser uses WebKit in most regions.
what is bandwidth on a network | bandwidth like a pipe => Bandwidth is how much data a connection can carry each second, like how wide a pipe is. More bandwidth lets more devices stream at once.
what is a social network | how do social media apps make money => Social networks let people share posts and messages. Most are free because they earn money from ads, using what you watch and like to target them.
what is an algorithm on social media | how does a feed pick what i see => The recommendation algorithm guesses what you'll watch next based on what you and similar people watched. It aims to keep you watching, so take breaks on purpose.
what is a captcha | why do websites ask if i'm a robot => A CAPTCHA is a test that tries to tell humans from bots, like picking pictures with buses. It stops bots from spamming sites.
what is web 3 | what is the blockchain => A blockchain is a shared record copied across many computers so no single one controls it. Cryptocurrencies use it. Be careful: crypto and NFT offers aimed at kids are often scams.
what is an online account | why do apps need accounts => An account is your identity on a service, protected by a password. It stores your saves, friends and purchases on the company's servers.
what is cloud gaming | how does game streaming work => Cloud gaming runs the game on a powerful server and streams the video to your device, while your button presses go back. It needs fast, steady internet with low ping.
# tag: tech.computing
how big is a kilobyte megabyte gigabyte | file size units => A kilobyte is about a thousand bytes, a megabyte about a million, a gigabyte about a billion, and a terabyte about a trillion. Windows counts them in powers of 1024, so drives look smaller than labeled.
why does my 1tb drive only show 931gb | missing storage space => Drive makers count 1 TB as 1,000,000,000,000 bytes, but Windows counts in units of 1024, which shows about 931 GB. No space is actually missing.
how many transistors in a cpu | transistors in a chip => A transistor is a microscopic electronic switch. Modern CPUs and GPUs pack tens of billions of them onto one chip.
what does nanometer mean for chips | 3nm chip => Names like 3 nm describe a chip-making process generation. Smaller numbers usually mean more transistors in the same space and better efficiency, though the number isn't a literal measurement anymore.
what is moore's law | do chips keep doubling => Moore's law is the observation that the number of transistors on a chip doubled about every two years. It has slowed down but drove decades of faster computers.
what is a file extension | what does .exe mean => The extension is the end of a file name, like .png, .mp4 or .exe. It tells the computer which app opens the file. .exe files are programs, so only run ones you trust.
what is a zip file | why are files zipped => A ZIP file packs files into one smaller file that's easier to send. You extract it to use what's inside.
what is a pdf | why do people use pdf => A PDF keeps a document looking exactly the same on every device, with fonts and layout locked in. It's great for sharing finished work.
what is an operating system kernel | what is a kernel => The kernel is the core of an operating system that controls the hardware and decides which programs get CPU time and memory.
what is firmware | firmware vs software => Firmware is software built into a device to control its hardware, like a router, controller or printer. Firmware updates fix bugs and add features.
what is a virtual machine | what is a vm => A virtual machine is a computer running inside software on your real computer. It can run another operating system safely in a window.
what is an emulator | are emulators legal => An emulator makes a computer act like another device, like an old console. Emulators themselves are generally legal, but downloading games you don't own usually isn't.
what is a gpu used for besides games | gpu uses other than gaming => GPUs do lots of math at once, which makes them great for AI training, video editing, 3D rendering and science simulations, not just games.
what is a cpu architecture | arm vs x86 => x86 is the CPU design in most Windows PCs, from Intel and AMD. ARM is used in phones, iPads, Apple silicon Macs and some Windows laptops. Programs must be built for the right one or translated.
what is a 64 bit computer | 32 bit vs 64 bit => 64 bit CPUs and software can use much more memory than 32 bit ones, which were limited to about 4 GB of RAM. Almost all modern computers are 64 bit.
what is an ssd made of | how does flash memory work => SSDs store data in flash memory chips that trap electric charge in tiny cells. With no moving parts, they're fast, quiet and tough.
what is cache in a browser | what does clearing cache do => The browser cache saves parts of websites, like images, so they load faster next time. Clearing it fixes some broken pages but makes sites load slower once.
what is a pixel made of | rgb subpixels => Each screen pixel has red, green and blue subpixels. Mixing their brightness makes every color you see.
what is hex color code | what does ff0000 mean => A hex code like #FF0000 sets a color's red, green and blue amounts from 00 to FF. #FF0000 is pure red, #FFFFFF is white and #000000 is black.
what is a qr code made of | how much can a qr code hold => A QR code is a grid of black and white squares storing data like a web link. The three big corner squares help the camera find and line it up.
