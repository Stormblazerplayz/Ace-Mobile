# tag: tech.network
what is the difference between a modem and a router | modem vs router => The modem connects your home to the internet provider. The router shares that connection with your devices and makes Wi-Fi. Many internet boxes do both.
how does a router work | what does a router do => A router gives each device a local address, sends data to the right device, connects your home network to the internet, and makes the Wi-Fi signal.
ethernet vs wifi for gaming | is ethernet better than wifi => Ethernet is better for gaming: lower ping, less jitter and no drops from walls or interference. Use Wi-Fi only if you can't run a cable.
what ethernet cable should i get | cat5e vs cat6 => Cat 5e handles up to 1 Gbps, which covers most homes. Cat 6 adds headroom and handles 2.5 Gbps and more over home distances. Both work for gaming.
how can i get ethernet without running a cable | powerline adapter => Powerline adapters send internet through your home's power wiring. Plug one by the router and one by the PC. MoCA adapters use coax TV cables and are often more stable.
what is a good ping | is 50 ping good => Ping (latency) is how long data takes to reach the server and back, in milliseconds. Under 30 ms is great, 30 to 60 is good, and over 100 feels laggy in fast games.
what is jitter | what is packet loss => Jitter is how much ping jumps around, and packet loss is data that never arrives. Both cause rubber-banding and teleporting in games. Ethernet helps a lot.
what is bandwidth vs latency | do i need faster internet for gaming => Bandwidth is how much data can flow at once (Mbps). Latency is the delay (ping). Games need little bandwidth but low latency, so a faster plan doesn't always fix lag.
what is 2.4 ghz vs 5 ghz wifi | which wifi band is better => 2.4 GHz reaches farther and through walls but is slower and crowded. 5 GHz is faster with less interference but shorter range. 6 GHz (Wi-Fi 6E and 7) is faster still at close range.
what is wifi 6 | wifi 6 vs wifi 7 => Wi-Fi 6 is faster and handles many devices better than Wi-Fi 5. Wi-Fi 6E adds the 6 GHz band, and Wi-Fi 7 is even faster with lower latency. Both the router and the device must support it.
what is mesh wifi | do i need a mesh system => Mesh Wi-Fi uses several units around the home to cover dead zones with one network. It helps in big or multi-floor homes.
what is a wifi extender | extender vs mesh => An extender repeats your Wi-Fi to reach farther, but often halves speed and adds lag. Mesh systems or a wired access point work better.
public vs private ip | what does 192.168 mean => An IP address is a device's address on a network. Your router gives devices private IPs like 192.168.1.20, and the internet sees your home's one public IP.
what is dhcp | how do devices get an ip => DHCP is the router's way of handing out IP addresses automatically when devices join the network.
what is dns | how does dns work => DNS is the internet's phone book. It turns names like google.com into the IP addresses computers use.
what dns server should i use | change dns windows => Your provider's DNS works fine. Public options include Cloudflare (1.1.1.1) and Google (8.8.8.8). Change it in Settings, Network and internet, your connection, Hardware properties, DNS server assignment.
what is a mac address | find mac address => A MAC address is a hardware ID for a network adapter, like 3C:22:FB:12:34:56. Routers use it to recognize devices. Find it with ipconfig /all.
what is the default gateway | router ip address => The default gateway is your router's local address, often 192.168.0.1 or 192.168.1.1. Type it in a browser to open the router's settings (with an adult's permission).
how do i log into my router | router settings page => Type the router's address (often 192.168.1.1 or shown on the router's label) into a browser and sign in with the admin details on the label or set by whoever set it up. Ask a parent first.
how do i restart my router | power cycle router => Unplug the router and modem for 30 seconds, plug the modem back first, wait for its lights, then the router. It fixes many internet problems.
what is port forwarding | how do i port forward => Port forwarding tells the router to send certain traffic to one device, which can help hosting game servers or fixing strict NAT. Set it in the router's settings with an adult's help.
what is nat type | open moderate strict nat => NAT type shows how easily other players can connect to you. Open is best, Moderate is fine, and Strict can block joining some players or parties. UPnP often fixes it.
what is upnp | should upnp be on => UPnP lets games and consoles open the ports they need automatically. Turning it on fixes many NAT issues; it's a small security trade-off that most home gamers accept.
what is a firewall | what does a firewall do => A firewall decides which network traffic is allowed in or out of a device or network, blocking unwanted connections.
what is a vpn used for | does a vpn lower ping => A VPN sends your traffic through another server, hiding it from the local network. It rarely lowers ping and often raises it. Don't use VPNs to get around school or parent rules.
how do i test my internet speed | speed test => Use a site like speedtest.net or fast.com. Test with Ethernet for the most accurate result and close downloads first.
what does mbps vs mb/s mean | why is my download slower than my plan => Mbps is megabits per second; MB/s is megabytes. One byte is 8 bits, so a 100 Mbps plan downloads at about 12.5 MB/s at best.
what is upload speed for | do i need fast upload => Upload speed is how fast you send data. It matters for streaming on Twitch or YouTube, video calls and uploading videos.
what is fiber internet | fiber vs cable => Fiber sends data as light through glass cables, giving very fast speeds and low ping. Cable uses TV coax lines and is also fast but often slower to upload.
what is a lan | lan vs wan => A LAN (local area network) is the network inside your home. The WAN is the wider network outside, like the internet.
what is a network switch | add more ethernet ports => A switch adds more Ethernet ports to your network. Plug it into the router and plug devices into it.
what is ipv6 | ipv4 vs ipv6 => IPv4 addresses are four numbers like 192.168.1.5, and the world is running out of them. IPv6 addresses are much longer and give nearly endless addresses.
what is qos on a router | prioritize gaming traffic => QoS (quality of service) lets the router put games and calls ahead of downloads, which can help lag when others stream or download.
why does my internet lag at night | internet slow in the evening => Evenings are peak time when many people stream, so networks get busy. Use Ethernet and QoS at home, and pause big downloads while gaming.
what is a hotspot | use phone as wifi => A hotspot shares your phone's mobile data as Wi-Fi. It uses data fast, so ask before using it for games or updates.
why is my wifi slow in my room | weak wifi signal bedroom => Walls, floors and distance weaken Wi-Fi. Move the router higher and central, use 5 GHz nearby, or add mesh or a wired access point.
how do i find my public ip | what is my ip => Search "what is my IP" in a browser to see your public IP. Never share it with strangers, since it can show your rough location.
what is a ddos | can someone ddos me => A DDoS floods a connection with junk traffic so it can't work. Keep your IP private, don't click strangers' links, and restarting the router often gives you a new IP.
what is latency in milliseconds | what does ms mean in games => Ms means milliseconds, a thousandth of a second. In games it's your ping: lower means your actions reach the server faster.
what is a server region | pick closest server => Games let you pick server regions like US East or EU West. Pick the closest one to get the lowest ping.
what is rubber banding | why do i teleport back in games => Rubber-banding is when your character snaps back to an earlier spot because data was lost or delayed. It comes from high ping, jitter or packet loss.
what is tick rate | 128 tick server => Tick rate is how many times per second a game server updates. Higher tick rates make hits and movement more accurate.
how do i check for packet loss | packet loss test => Run ping -n 100 google.com in Command Prompt and look at the Lost percentage. Many games also show packet loss in their network stats overlay.
