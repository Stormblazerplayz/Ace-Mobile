# tag: tech.troubleshoot.slow
why is my pc so slow | how do i make my pc faster => Restart it first. Then turn off startup apps, check Task Manager for anything using lots of CPU, memory or disk, free up drive space, update Windows and drivers, and run a virus scan.
why is my pc slow after startup | slow for the first few minutes => Startup apps, Windows Update and Defender scans all run right after you sign in. Turn off startup apps you don't need and give it a minute.
why is my disk at 100 percent | disk usage 100 task manager => Something is reading or writing a lot, often Windows Update, Defender, OneDrive or a game launcher. Sort Task Manager by Disk to find it. On an old hard drive, upgrading to an SSD fixes this most.
why is my ram always full | high memory usage windows => Windows uses spare RAM to cache things, which is normal. If it's over 90 percent and slow, close browser tabs and apps you don't need. 16 GB is the minimum for gaming as of 2025, and 32 GB is comfy.
why is my cpu at 100 percent when idle | high cpu doing nothing => Sort Task Manager by CPU to find the app. Common causes are updates, scans, a stuck browser tab, or malware. Restart, then run a full Defender scan if it's something you don't recognize.
does restarting my pc really help | why should i restart my computer => Yes. Restarting clears memory, stops stuck programs and finishes updates. Shut down with Fast Startup on doesn't fully reset Windows, so pick Restart when fixing problems.
what is fast startup | should i turn off fast startup => Fast Startup saves part of Windows to the drive when you shut down so it boots faster. It can cause driver or dual-boot issues; turn it off in Control Panel, Power Options, Choose what the power buttons do.
how do i speed up my old laptop | old laptop is slow => The biggest upgrade is swapping a hard drive for an SSD, then adding RAM if it has 8 GB or less. Also remove bloatware, turn off startup apps and use a lighter browser setup.
why does my pc lag when i open chrome | chrome uses too much ram => Each tab and extension uses memory. Close tabs you don't need, remove unused extensions, and turn on Memory Saver in Chrome Settings, Performance.
does more storage make my pc faster | will a bigger ssd make my pc faster => Not by itself. A faster drive (SSD instead of hard drive) speeds up loading, but more space only helps if your drive is almost full.
why is my pc slow after a windows update | laggy since the last update => The update may still be finishing in the background. Restart twice, update your graphics and chipset drivers, and check Update history if one update caused it.
how do i know if my pc has a virus | signs of malware => Watch for pop-ups, a new browser homepage, unknown programs, slow speed and fans running hard while idle. Run a Full scan and a Microsoft Defender Offline scan in Windows Security.
# tag: tech.troubleshoot.games
why do my games stutter | game stuttering fix | fps is high but it feels choppy => Update your graphics driver, turn on XMP or EXPO for your RAM, close background apps, install the game on an SSD, and cap your FPS a little below your refresh rate. Shader compiling can also stutter at first; it improves after a while.
what is shader compilation stutter | stutter first time playing => Many games build shaders, small programs for your GPU, the first time an effect appears, causing short hitches. Let the game's shader step finish before playing, and the stutter fades.
why is my fps so low | low fps fix | how do i get more fps => Lower settings like shadows and resolution, turn on DLSS, FSR or XeSS, update your GPU driver, make sure your monitor cable is in the graphics card (not the motherboard), and plug in your laptop.
my monitor is plugged into the motherboard | no fps using wrong hdmi port => Plug the monitor cable into the ports on the graphics card, lower down on the back of the PC. The motherboard ports use the CPU's built-in graphics, which is much slower or not available at all.
why does my game freeze for a second | random freezes in games => Short freezes can come from a full drive, too little RAM, background updates, overheating or a dying drive. Check temperatures and Task Manager while playing.
why does my game crash | game keeps crashing to desktop => Update the game and GPU driver, verify the game files in Steam or the launcher, remove overclocks, and check temperatures. If many games crash, test your RAM.
how do i verify game files on steam | repair game files steam => Right-click the game in Steam, choose Properties, Installed Files, and click Verify integrity of game files. It redownloads any broken files.
why is my game laggy but fps is fine | lag vs low fps => If FPS is high but players jump around, it's network lag. Check ping, use Ethernet, close downloads and pick a closer server.
what is input lag | why does my mouse feel delayed in games => Input lag is the delay between your action and seeing it on screen. Lower it with high FPS, a high refresh monitor, NVIDIA Reflex or AMD Anti-Lag, and V-Sync off (or VRR with an FPS cap).
should i turn off vsync | what does v sync do => V-Sync stops screen tearing but adds input lag and can drop FPS sharply. With a G-SYNC or FreeSync monitor, use VRR and cap FPS a few frames under your refresh rate instead.
what is screen tearing | lines across my screen in games => Tearing is when the screen shows parts of two frames at once, making a horizontal split. Fix it with G-SYNC or FreeSync, or V-Sync if your monitor lacks VRR.
why is my gpu usage low in games | gpu only at 50 percent => The CPU may be the bottleneck, the game may be capped, V-Sync may be on, or the game is very light. Raising resolution or settings shifts more work to the GPU.
what is a cpu bottleneck | is my cpu bottlenecking => A bottleneck is when one part holds back the others. If GPU usage is low and one or more CPU threads are maxed while FPS is low, the CPU is limiting you.
why do games run worse on my laptop when unplugged | laptop fps drops on battery => Laptops lower CPU and GPU power on battery. Plug in the charger and set Power mode to Best performance for full speed.
why is my game running on the wrong gpu | laptop not using nvidia => Open Settings, System, Display, Graphics, add the game, and set it to High performance. In the NVIDIA Control Panel you can also set the preferred graphics processor.
why does my game look blurry | game is fuzzy => Check the game runs at your monitor's native resolution, set render scale to 100 percent, and use DLSS or FSR's Quality mode instead of Performance. Turn off motion blur if you don't like it.
why does alt tab crash my game | alt tab black screen => Some games handle exclusive full screen badly. Use Borderless windowed mode, which makes alt-tabbing smooth.
what is the difference between fullscreen and borderless | borderless windowed vs fullscreen => Exclusive fullscreen gives the game full control of the screen and can have slightly lower lag. Borderless windowed makes alt-tab instant. On Windows 11 the difference is usually tiny.
why do my games keep minimizing | game minimizes randomly => A pop-up, notification or background app is stealing focus. Turn on Do not disturb, close apps like updaters, and check for Windows notifications while playing.
why is my game stuttering after an update | new driver made games worse => Roll back the graphics driver in Device Manager, or install the previous version from NVIDIA or AMD's driver archive, and wait for a fixed release.
# tag: tech.troubleshoot.heat
what temperature should my cpu be | is my cpu too hot | normal cpu temps => Idle around 30 to 50 C and gaming around 60 to 85 C is normal. Ryzen 7000 and 9000 chips are designed to run up to 95 C under heavy load. Constant thermal throttling means cooling needs work.
what temperature should my gpu be | is 80c too hot for a gpu | normal gpu temps => Most graphics cards run 60 to 85 C while gaming. Hotspot readings 10 to 20 C higher are normal. Over 90 C on the main reading means it needs better airflow or cleaning.
why is my pc so loud | fans are really loud | my computer sounds like a jet => Fans speed up when parts get hot. Clean out dust, make sure case fans are set as intake and exhaust, set a fan curve in the BIOS, and check Task Manager for something using lots of CPU or GPU.
how do i clean dust out of my pc | dust in my computer => Shut down and unplug it, take the side panel off, and blow dust out with compressed air or an electric duster in short bursts. Hold fans still so they don't spin too fast.
what is thermal throttling | why does my pc slow down when hot => When a CPU or GPU gets too hot, it lowers its speed to protect itself. You'll see FPS drop after a while of gaming. Better cooling stops it.
how do i make my pc run cooler | lower pc temperatures => Clean dust, add or reorder case fans, make sure the cooler is mounted right, replace old thermal paste, and give the case room to breathe. Undervolting the GPU can also lower heat.
why is my laptop so hot | laptop overheating => Laptops pack hot parts into a small space. Use it on a hard surface, not a bed, clean the vents, use a cooling stand, and set a lower power mode for light tasks.
how do i set a fan curve | control fan speed pc => Enter the BIOS and open the fan or Q-Fan control page, or use a tool like FanControl in Windows. Set fans quiet at low temperatures and faster as they climb.
why is my pc hot when idle | high idle temps => Check Task Manager for background CPU use. If nothing is using it, the cooler may be loose, the paste dried out, or the pump of an AIO may not be running.
why does my pc shut off when gaming | pc turns off randomly => Sudden shutdowns usually mean overheating or the power supply can't keep up. Check temps with HWiNFO and make sure your PSU is good quality and big enough for your GPU.
is it bad if my gpu hits 100 percent usage | gpu usage 100 percent => No. In games, the GPU working at full usage means you're getting all the FPS it can give. Just watch the temperature.
what is gpu coil whine | buzzing noise from graphics card => Coil whine is a high buzz from tiny parts on the GPU when it works hard, often at very high FPS. It's harmless; capping FPS usually makes it quieter.
what is undervolting | should i undervolt my gpu => Undervolting runs the chip at a slightly lower voltage for the same speed, which cuts heat and noise. It's safe, but too far can cause crashes, so test small steps.
# tag: tech.troubleshoot.sound
why is there no sound on my pc | pc sound not working | no audio windows 11 => Check the volume isn't muted, pick the right output in Quick Settings, check cables or Bluetooth, then run Settings, System, Troubleshoot, Other troubleshooters, Audio. Updating or reinstalling the audio driver can help.
why can't people hear me on discord | my mic isn't working in discord => In Discord, User Settings, Voice and Video, pick your mic under Input Device and run Mic Test. Also check Windows Settings, Privacy and security, Microphone allows desktop apps.
why does my headset only work in one ear | sound from one side only => Check the plug is fully in, test another device, and check Settings, System, Sound, your device, for the Left and Right balance. Mono audio in Accessibility, Audio can also be on.
why does my mic sound robotic | mic crackles in calls => Usually your internet is unstable, not the mic. Use Ethernet, close downloads, and in Discord try changing the voice server region.
why is my sound crackling | audio pops and clicks pc => Try another USB port or a rear port, update chipset and audio drivers, set the format to 48000 Hz, and turn off audio enhancements.
why does my audio cut out when i plug in headphones | front audio jack not working => Check the front panel audio cable (HD Audio) is plugged into the motherboard. In Realtek or the maker's audio app, check jack detection settings.
why is my pc volume so low | max volume too quiet => Raise each app's level in the Volume mixer, check the in-game volume, turn off Loudness Equalization if it's on, and make sure headphones aren't set to a low limit.
why is my hdmi monitor playing sound | sound goes to my monitor => Windows picked the monitor's speakers. Click the speaker icon, open the output list, and choose your headphones or speakers.
# tag: tech.troubleshoot.display
why is my monitor saying no signal | no signal on monitor => Check the cable is in the graphics card and the monitor, pick the right input with the monitor's buttons, try another cable or port, and reseat the GPU if it's a new build.
why does my screen go black but pc is on | black screen with cursor => Press Windows key + Ctrl + Shift + B to restart the graphics driver. If that fails, restart into Safe Mode and reinstall the graphics driver.
why does my pc turn on but no display | fans spin but no picture => Check the debug LEDs on the motherboard, reseat the RAM and GPU, try one RAM stick, connect the monitor to the GPU, and wait a few minutes on new AM5 builds for memory training.
why does my screen flicker | monitor flickering => Try another cable, check the refresh rate in Settings, update the GPU driver, and turn off any overdrive set to the max. Flickering in only one app often means a driver problem.
why is my second monitor not detected | windows not detecting monitor => Check both ends of the cable, open Settings, System, Display, and click Detect under Multiple displays. Make sure it's plugged into the graphics card, not the motherboard.
why are my colors washed out | colors look faded on monitor => If HDR is on for a monitor that isn't great at HDR, turn it off. In the NVIDIA Control Panel, set Output dynamic range to Full under Change resolution.
why is everything zoomed in | screen too big pc => Check Settings, System, Display: set the resolution to Recommended and Scale to 100 or 125 percent. Magnifier may also be on; press Windows key + Esc to close it.
why does my screen have a green or pink tint | weird screen color => Reseat or replace the cable, try another port, and check color filters aren't on in Settings, Accessibility, Color filters.
what is screen burn in | will my oled get burn in => Burn-in is a faint ghost image left from something shown in the same spot for a very long time, mostly on OLED. Hide static taskbars, use dark themes and let the monitor's care features run.
what is a dead pixel | how do i check for dead pixels => A dead pixel is a tiny spot that stays black, and a stuck pixel stays one color. Show plain red, green, blue, white and black full screen images to spot them.
# tag: tech.troubleshoot.bsod
what is a blue screen of death | why did my pc blue screen | bsod meaning => It's Windows stopping to protect itself from a serious error, usually from a bad driver, RAM, overheating or a failing drive. As of 2025, newer Windows 11 versions show it on a black screen instead of blue. Note the stop code it shows.
how do i find out why i got a blue screen | read bsod logs => Note the stop code, then check Reliability Monitor or Event Viewer for that time. The free BlueScreenView or WhoCrashed tools read crash dump files and often name the driver.
what does critical process died mean | critical_process_died => A key Windows process stopped. Run sfc /scannow and DISM in admin Terminal, update drivers, and uninstall any recent program or update that came before it.
what does irql not less or equal mean | irql_not_less_or_equal => It usually means a driver accessed memory it shouldn't. Update or roll back recent drivers, especially network and graphics, and test RAM if it keeps happening.
what does memory management blue screen mean | memory_management error => It points to a RAM or memory driver problem. Turn off EXPO or XMP to test, run Windows Memory Diagnostic or MemTest86, and reseat the RAM sticks.
what does whea uncorrectable error mean | whea_uncorrectable_error => It's a hardware error, often from an unstable overclock or undervolt, too little voltage, overheating or a bad part. Reset BIOS settings to defaults first.
what does video tdr failure mean | video_tdr_failure => The graphics driver stopped responding and couldn't recover. Do a clean driver install with DDU, remove GPU overclocks, and check GPU temperatures.
what does dpc watchdog violation mean | dpc_watchdog_violation => A driver took too long to respond. Update storage, chipset and SSD firmware, and check recently added hardware.
what does page fault in nonpaged area mean | page_fault_in_nonpaged_area => Windows tried to use memory that wasn't there. Common causes are bad RAM, antivirus or driver bugs, or a failing drive. Test RAM and update drivers.
what does inaccessible boot device mean | inaccessible_boot_device => Windows can't reach the drive it boots from. Check the drive is detected in the BIOS, undo storage mode changes (like switching AHCI and RAID), and try Startup Repair.
what does kmode exception not handled mean | kmode_exception_not_handled => A driver or program crashed in a part of Windows that it can't recover from. The file named on the screen points to the driver to update or remove.
what does system service exception mean | system_service_exception => A system process hit an error, often from a graphics, antivirus or webcam driver. Update drivers and run sfc /scannow.
what does clock watchdog timeout mean | clock_watchdog_timeout => A CPU core stopped responding. It's often from an unstable overclock or undervolt, a BIOS that needs an update, or overheating. Reset BIOS to defaults and update it.
what does unexpected store exception mean | unexpected_store_exception => It's often linked to the storage drive or antivirus. Check drive health, update SSD firmware and run chkdsk.
what does kernel security check failure mean | kernel_security_check_failure => Windows found corrupted data in its core. Update drivers, run sfc /scannow and DISM, and test RAM.
# tag: tech.troubleshoot.power
my pc won't turn on | computer does nothing when i press power | pc dead no lights => Check the power cable, the switch on the back of the PSU (set to I), and the wall outlet. On a new build, check the 24 pin and CPU power cables and that the front panel power switch pins are on the right motherboard header.
why does my pc turn on then off right away | pc boots then shuts down => It often means a short, a missing CPU power cable, a loose cooler or a RAM problem. Check every power cable, reseat the RAM, and make sure no screw is touching the back of the motherboard.
why does my pc beep when i turn it on | motherboard beep codes => Beeps are the motherboard's error codes. The pattern means different things for each brand, so look up your board's manual. It's often RAM or the graphics card not seated well.
why does my pc restart by itself | random restarts windows => Check temperatures, test RAM, update drivers, and look in Reliability Monitor. In System, About, Advanced system settings, Startup and Recovery, untick Automatically restart to see the error instead.
why won't my pc wake up from sleep | stuck in sleep mode => Press the power button briefly or a key. If it often fails, update the chipset and GPU drivers, or turn off USB selective suspend in power options.
why does my pc wake up by itself | pc turns on from sleep randomly => A mouse, network card or Windows update timer is waking it. In admin Terminal, type powercfg /lastwake to see what did it, then turn off Allow this device to wake the computer for that device in Device Manager.
how do i force shut down my pc | pc frozen completely => Hold the power button for about 10 seconds until it turns off. Only do this when nothing responds, since unsaved work is lost.
should i shut down or sleep my pc | is it bad to leave my pc on => Sleep is fine for short breaks and wakes fast. Restart at least every few days so updates finish. Leaving it on all the time doesn't hurt modern parts much.
why does my laptop battery drain so fast | laptop battery dies fast => Lower brightness, use Best power efficiency mode, close heavy apps, and check Settings, System, Power and battery, Battery usage to see which apps use the most.
should i keep my laptop plugged in all the time | laptop always charging bad => Most modern laptops handle it fine, and many have a setting in the maker's app to stop charging at about 80 percent, which helps the battery last longer.
my laptop is plugged in but not charging | plugged in not charging => Try another outlet, check the charger is the right wattage, and restart. If it says Plugged in, not charging, the laptop may be limiting the charge on purpose to protect the battery.
# tag: tech.troubleshoot.devices
why isn't my usb device recognized | usb device not recognized => Try another USB port (the back ports connect straight to the motherboard), another cable, and restart. Check Device Manager for a warning, and update chipset drivers.
why does my mouse lag or stutter | mouse cursor jumps => Clean the sensor, use a mouse pad, plug a wireless dongle closer with a USB extension, change the battery, and close apps hogging the CPU. Set a polling rate your PC handles well, like 1000 Hz.
why is my mouse double clicking | mouse clicks twice by itself => It's usually a worn switch inside the mouse. Check the double-click speed in mouse settings, try another mouse, and use the warranty if it's new.
why are some keys not working | keyboard keys stopped working => Check Filter Keys is off in Settings, Accessibility, Keyboard. Try another USB port, clean under the keys, and test on another PC to see if the keyboard is the problem.
my keyboard types the wrong symbols | shift 2 gives the wrong character => Your keyboard layout changed. Press Windows key + Space to switch back, or remove extra layouts in Settings, Time and language, Language and region.
why is my windows key not working | windows key disabled => Many gaming keyboards have a Game Mode or Win Lock key that turns off the Windows key, often Fn + the Windows key. Press it again to unlock.
why are my wasd and arrow keys swapped | wasd keys act like arrows => Some gaming keyboards have an Fn + W shortcut that swaps WASD with the arrow keys. Press it again to swap back.
why does my keyboard type numbers instead of letters | laptop typing numbers => Num Lock is turning part of your laptop's letter keys into a number pad. Press Num Lock (sometimes Fn + Num Lock) to turn it off.
why is my webcam not working | camera not working windows 11 => Check Settings, Privacy and security, Camera allows apps to use it. Some laptops have a physical camera switch or a key that turns it off. Close other apps using the camera.
why won't my printer print | printer not working windows => Turn the printer off and on, check paper and ink, make sure it's on the same Wi-Fi, and in Settings, Bluetooth and devices, Printers and scanners, open it and clear any stuck jobs.
why does my controller not work in games | controller not detected game => Try a different USB cable that carries data, turn on Steam Input for that controller in Steam, and check the game supports controllers.
why is my controller drifting on pc | stick drift pc => Set a small deadzone in the game or Steam Input settings. If it's bad, clean around the stick or replace the controller, since drift comes from wear.
why does my headset keep disconnecting | wireless headset cuts out => Keep the dongle in a front or extension USB port, charge it fully, update its firmware, and keep it away from the Wi-Fi router.
# tag: tech.troubleshoot.disk
why is my c drive full | c drive keeps filling up => Big games, Downloads, temporary files, old Windows update files and huge hiberfil or pagefile files fill it. Use Settings, System, Storage to see what's big and clean up from there.
my new ssd doesn't show up | ssd not detected => If it's in the BIOS but not File Explorer, initialize and format it in Disk Management. If it's missing in the BIOS, reseat it and check the M.2 slot isn't sharing lanes with a SATA port.
why is my drive so slow to copy files | file copy speed drops => Big copies start fast then slow as the SSD's cache fills, which is normal for cheaper SSDs. Hard drives and USB 2.0 sticks are much slower than NVMe SSDs.
how do i recover a deleted file | i deleted something important => Check the Recycle Bin first, then OneDrive's recycle bin and File History. Stop using the drive and try the Windows File Recovery tool if it's not there.
is my hard drive dying | clicking noise from hard drive => Clicking, slow access and errors are warning signs. Copy important files off right away, then check health with CrystalDiskInfo.
why is my usb stick write protected | can't save to my flash drive => Look for a small lock switch on the stick or SD adapter. If there isn't one, it may be failing. Try formatting it, then replace it if that fails.
# tag: tech.troubleshoot.network
why does my wifi keep disconnecting | wifi drops on pc => Restart the router, update the Wi-Fi driver, and in Device Manager open the Wi-Fi adapter's Power Management tab and untick letting Windows turn it off. Moving closer or using Ethernet helps most.
why is my pc connected but no internet | no internet secured => Restart the PC and router, run ipconfig /flushdns, and try the Network troubleshooter. If other devices work, reset network settings in Settings, Network and internet, Advanced network settings, Network reset.
how do i reset network settings on windows | network reset => Open Settings, Network and internet, Advanced network settings, Network reset, and click Reset now. It reinstalls network adapters, so you'll need to reconnect to Wi-Fi.
why is my ethernet not working | ethernet unidentified network => Try another cable and router port, restart both, and update the LAN driver from the motherboard support page. Check the cable clicks in and the port lights blink.
why is my internet slow only on my pc | pc slow internet but phone is fine => Check for downloads or updates running, a weak Wi-Fi signal, an old Wi-Fi driver, or a VPN. Test with Ethernet to see if Wi-Fi is the problem.
why can't my pc see my wifi network | wifi network not showing => It may be 5 GHz only and your adapter only supports 2.4 GHz, or the network name is hidden. Restart the router and update the Wi-Fi driver.
why does my game say nat type strict | strict nat fix => Turn on UPnP in your router settings, restart the router, and make sure you aren't behind two routers. Port forwarding the game's ports also helps.
why do downloads on steam go slow | steam download slow => Change the download region in Steam Settings, Downloads, clear the download cache there, and use Ethernet. Steam shows speed in MB/s while internet plans use Mbps, which is 8 times bigger.
