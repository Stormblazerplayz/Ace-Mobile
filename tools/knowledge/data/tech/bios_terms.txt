# tag: tech.pc.bios
what are c states in bios | global c state control => C-states are power-saving modes a CPU drops into when idle. Leave them on unless you're troubleshooting, since turning them off just raises idle power and heat.
what is load line calibration | what is llc bios => Load-line calibration (LLC) stops CPU voltage from dropping too much under heavy load. Higher levels add voltage and heat, so leave it on Auto unless you're overclocking.
what is vcore | cpu core voltage => Vcore is the voltage going to your CPU cores. The motherboard sets it automatically, and raising it by hand adds heat and risk.
what is soc voltage am5 | is my soc voltage too high => SoC voltage powers the memory controller and other parts of the chip. On AM5, keep it at or below 1.3 volts, which newer BIOS versions enforce.
what is memory context restore | mcr bios setting => Memory Context Restore lets an AM5 PC skip retraining the RAM every boot, so it starts faster. If your PC becomes unstable with it on, turn it off.
what is fclk uclk mclk | infinity fabric clock => MCLK is the memory clock, UCLK is the memory controller clock and FCLK is the Infinity Fabric that links parts of a Ryzen chip. EXPO sets these for you in most cases.
what does uclk equals mclk mean | 1 to 1 memory ratio => It means the memory controller runs at the same speed as the RAM, which gives the lowest delay. On AM5, DDR5-6000 usually runs 1:1 easily.
what is erp in bios | erp ready setting => ErP mode cuts standby power when the PC is off. It also stops USB ports charging and some wake features while shut down.
what is fast boot in bios | bios fast boot setting => Fast Boot skips some startup checks to boot quicker. It can make it harder to get into the BIOS or boot from USB, so turn it off if you need those.
what is zero rpm mode | why are my gpu fans not spinning => Many graphics cards stop their fans when cool and idle, called zero RPM mode. The fans start once the GPU warms up, so it's normal.
what is a cpu fan header | cpu fan error on boot => CPU_FAN is the header where the CPU cooler's fan plugs in. If nothing is plugged into it, many boards show a CPU fan error at startup.
what is the aio pump header | where do i plug the aio pump => Plug an AIO pump into the header labeled AIO_PUMP, W_PUMP or PUMP_FAN, which runs at full speed. If there isn't one, use CPU_FAN set to full speed.
what is a cha fan header | sys fan header => CHA_FAN or SYS_FAN headers are for case fans. You can set their speed curves in the BIOS or with an app like FanControl.
what is cpu opt header | cpu_opt fan => CPU_OPT is an extra header for a second CPU cooler fan. It usually follows the same speed as CPU_FAN.
what is a fan curve | how do i set fan speeds => A fan curve tells fans how fast to spin at each temperature. A gentle curve keeps things quiet at idle and ramps up when gaming.
what is above 4g decoding | do i need above 4g decoding => Above 4G Decoding lets PCIe devices use more memory address space. It must be on for Resizable BAR to work.
what is amd eco mode | ryzen eco mode => Eco Mode lowers a Ryzen CPU's power limit so it runs cooler and quieter, often losing only a little performance.
what temperature is normal for ryzen 7000 | is 95c ok for ryzen => Many Ryzen 7000 and 9000 CPUs are designed to boost until they reach about 95°C under heavy load, so that's expected. X3D chips have lower limits.
what is tctl tdie | ryzen temperature sensor => Tctl and Tdie are Ryzen temperature readings. Tdie is the real die temperature, and on many chips they're the same.
what is agesa | amd agesa update => AGESA is AMD's firmware code inside motherboard BIOS updates. New AGESA versions add CPU support and fix memory and stability bugs.
what is pcie bifurcation | split pcie slot => Bifurcation splits one PCIe slot's lanes so it can run several devices, like a card holding multiple M.2 SSDs.
what is restore on ac power loss | auto turn on pc when power returns => This BIOS setting chooses what the PC does when power comes back after a cut: stay off, turn on, or go back to its last state.
what is a bios password | supervisor password bios => A BIOS password stops others from changing settings or booting. If you forget it, clearing CMOS usually resets it on home PCs.
what is dual bios | backup bios chip => Some motherboards have two BIOS chips, so if an update fails the board can recover from the backup.
what is pcie gen setting | pcie link speed bios => This setting picks the PCIe version a slot runs at. Leave it on Auto unless a riser cable or card is unstable, then try a lower gen.
what is integrated graphics in bios | turn off igpu => The iGPU setting turns your CPU's built-in graphics on or off. It's usually fine to leave on, and you can use it as a backup if your graphics card fails.
what is spread spectrum bios | spread spectrum bios explained => Spread Spectrum slightly varies clock signals to reduce electrical interference. Leave it on Auto unless you're doing extreme overclocking.
what is power supply idle control | typical current idle => This Ryzen setting changes how low power goes at idle. Setting it to Typical Current Idle can fix random freezes on some older Ryzen systems.
what is cpu boost clock | why is my cpu speed changing => Modern CPUs raise and lower their clock speed constantly depending on load and temperature. Seeing the speed jump around is normal.
what is turbo boost | intel turbo boost => Turbo Boost is Intel's feature that raises clock speed when there's spare power and cooling. AMD's version is Precision Boost.
