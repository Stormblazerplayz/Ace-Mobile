# tag: tech.shortcuts.explorer
how do i open a new tab in file explorer | file explorer tabs shortcut => Press Ctrl + T in File Explorer on Windows 11 to open a new tab. Ctrl + W closes the tab.
how do i go up one folder | alt up arrow | go to parent folder => Press Alt + Up Arrow in File Explorer to go up to the folder that holds this one.
how do i go back in file explorer | alt left arrow | backspace in file explorer => Press Alt + Left Arrow (or Backspace) to go back to the last folder, and Alt + Right Arrow to go forward.
how do i type a folder path in file explorer | alt d | jump to the address bar => Press Alt + D or Ctrl + L to select the address bar, type a path like C:\Users, and press Enter.
how do i search in file explorer with keys | ctrl e file explorer | f3 search => Press Ctrl + E, Ctrl + F or F3 in File Explorer to jump to the search box.
how do i turn on the preview pane | alt p | see a file without opening it => Press Alt + P in File Explorer to show or hide the preview pane, which shows pictures, PDFs and text files without opening them.
how do i show the details pane | alt shift p => Press Alt + Shift + P in File Explorer to show or hide the details pane with file size, dates and more.
how do i switch to details view | ctrl shift 6 | show files as a list with sizes => Press Ctrl + Shift + 6 in File Explorer for Details view, which shows name, date, type and size in columns.
how do i make icons bigger in file explorer | ctrl shift 2 | large icons view => Press Ctrl + Shift + 1 for extra large icons, 2 for large, 3 for medium and 4 for small. Ctrl + mouse wheel also resizes them.
how do i copy a files path | ctrl shift c | copy as path => Select the file and press Ctrl + Shift + C in Windows 11 File Explorer to copy its full path, in quotes. Or right-click it and pick Copy as path.
how do i select files that aren't next to each other | ctrl click files => Hold Ctrl and click each file you want. Ctrl + click a selected file to unselect it.
how do i select a range of files | shift click => Click the first file, hold Shift, and click the last file to select everything in between.
how do i copy a file by dragging | ctrl drag => Hold Ctrl while you drag a file to copy it instead of moving it. A small plus sign shows it will copy.
how do i move a file to another drive by dragging | shift drag file => Hold Shift while you drag to move a file instead of copying it. Dragging to another drive copies by default.
how do i make a shortcut by dragging | alt drag file => Hold Alt (or Ctrl + Shift) while dragging a file or app to make a shortcut to it instead of moving it.
how do i open the old right click menu | show more options | windows 11 full context menu => In Windows 11, click Show more options at the bottom of the right-click menu, or hold Shift while right-clicking, to see the classic menu.
how do i see hidden files | show hidden files windows 11 => In File Explorer click View, then Show, then Hidden items. Hidden files and folders show up faded.
how do i see file extensions | show .exe or .png at the end of names | file name extensions windows => In File Explorer click View, then Show, then File name extensions. Now names show endings like .png or .mp4.
how do i open file explorer to this pc | file explorer opens to home instead of this pc => Open File Explorer, click the three dots, then Options. Set "Open File Explorer to" This PC and click OK.
how do i pin a folder to quick access | pin folder to the sidebar => Right-click the folder and pick Pin to Quick access (or Pin to Home on newer Windows 11). It shows in the left sidebar.
how do i open a folder in terminal | open terminal here => Right-click inside the folder in File Explorer and choose Open in Terminal. Or type cmd in the address bar and press Enter.
how do i sort files by date | newest files first => In File Explorer click Sort, then Date modified. Click it again to flip between newest and oldest first.
how do i group files by type | group by in file explorer => Click Sort, then Group by, then pick Type (or another option) in File Explorer. Pick None to undo it.
how do i compress files into a zip | make a zip file windows => Select the files, right-click, and choose Compress to ZIP file. Windows 11 can also make 7z and TAR files on newer versions.
how do i unzip a file on windows | extract zip | open a zip folder => Right-click the ZIP file and choose Extract All, pick a place, and click Extract. Opening a ZIP without extracting can make programs inside fail.
how do i restore a deleted file | recycle bin restore => Open the Recycle Bin on the desktop, right-click the file and pick Restore. It goes back to where it was.
how do i empty the recycle bin | clear out the trash on pc => Right-click the Recycle Bin on the desktop and choose Empty Recycle Bin. Those files are then gone for good.
how do i find my downloads folder | where do downloads go on pc => Open File Explorer and click Downloads in the left sidebar. It lives at C:\Users\your name\Downloads.
how do i find big files on my pc | what is taking space on my drive => Open Settings, System, Storage to see what uses space. In File Explorer you can also search size:gigantic to find files over 4 GB.
how do i search for a type of file | find all mp4 files => Type *.mp4 (or any extension) in the File Explorer search box to find every file of that type in the folder and its subfolders.
how do i rename lots of files at once | batch rename windows => Select the files, press F2, type a name and press Enter. Windows names them like Photo (1), Photo (2) and so on.
how do i show the full menu bar options in file explorer | file explorer options => Click the three dots on the File Explorer command bar and pick Options to change views, privacy and what opens first.
how do i expand the folder tree to where i am | ctrl shift e => Press Ctrl + Shift + E in File Explorer to expand the left navigation pane to show the folder you're in.
what does f4 do in file explorer | address bar dropdown file explorer => F4 in File Explorer opens the address bar's drop-down list of folders you've typed before.
how do i open file explorer in a new window | ctrl n in file explorer => Press Ctrl + N in File Explorer to open another window showing the same folder.
how do i open the selected file | enter to open => Select the file and press Enter to open it with its default app.
how do i change which app opens a file | open with => Right-click the file, choose Open with, then Choose another app. Tick "Always use this app" to make it the default.
how do i make a desktop shortcut | shortcut on desktop => Right-click the file or app, choose Show more options, then Send to, then Desktop (create shortcut).
how do i see how big a folder is | folder size windows => Right-click the folder and choose Properties. Size shows how much space everything inside uses.
how do i go to appdata | find appdata folder => Press Windows key + R, type %appdata% and press Enter. That opens the Roaming folder where many apps keep settings.
how do i open the temp folder | clear temp files => Press Windows key + R, type %temp% and press Enter. You can delete what's inside; skip any file Windows says is in use.
how do i open the startup folder | shell startup => Press Windows key + R, type shell:startup and press Enter. Shortcuts placed there open when you sign in.
