# tag: tech.shortcuts.browser
how do i open a new tab | ctrl t | new tab shortcut => Press Ctrl + T (Command + T on Mac) to open a new tab in Chrome, Edge, Firefox or Safari.
how do i reopen a tab i closed by accident | ctrl shift t | bring back closed tab => Press Ctrl + Shift + T (Command + Shift + T on Mac) to reopen the last closed tab. Press it again to bring back more.
how do i switch to the next tab | ctrl tab | go to next tab => Press Ctrl + Tab to go to the next tab and Ctrl + Shift + Tab for the one before.
how do i jump to a tab by number | ctrl 1 browser | ctrl 9 last tab => Press Ctrl + 1 through Ctrl + 8 to jump to that tab, and Ctrl + 9 to jump to the last tab. On Mac use Command.
how do i get to the address bar fast | ctrl l | alt d browser | f6 address bar => Press Ctrl + L, Alt + D or F6 to select the address bar so you can type a new web address or search. On Mac press Command + L.
how do i bookmark a page | ctrl d | save a website to bookmarks => Press Ctrl + D (Command + D on Mac) to bookmark the page you're on.
how do i show the bookmarks bar | ctrl shift b => Press Ctrl + Shift + B in Chrome or Edge (Command + Shift + B on Mac) to show or hide the bookmarks bar.
how do i open history in chrome | ctrl h | see sites i visited => Press Ctrl + H in Chrome, Edge or Firefox to open your history. On a Mac, Chrome uses Command + Y.
how do i see my downloads in the browser | ctrl j | where did my download go => Press Ctrl + J in Chrome, Edge or Firefox to see your downloads. On Mac, Chrome uses Command + Shift + J and Safari uses Command + Option + L.
how do i open incognito mode | ctrl shift n | private window shortcut => Press Ctrl + Shift + N in Chrome or Edge to open an Incognito or InPrivate window. Firefox uses Ctrl + Shift + P, and Safari uses Command + Shift + N.
does incognito make me invisible online | is private browsing safe | what does incognito actually do => No. Incognito only stops the browser from saving your history, cookies and form data on that device. Websites, your school or home network and your internet provider can still see what you visit.
how do i clear my browsing data | ctrl shift delete | clear cache shortcut => Press Ctrl + Shift + Delete in Chrome, Edge or Firefox to open Clear browsing data. Pick a time range and what to clear.
how do i hard refresh a page | ctrl f5 | ctrl shift r | reload without cache => Press Ctrl + Shift + R or Ctrl + F5 to reload the page and ignore the saved copy. On Mac press Command + Shift + R.
how do i reload a page | ctrl r | refresh a website => Press F5 or Ctrl + R (Command + R on Mac) to reload the page.
how do i open developer tools | f12 | ctrl shift i | inspect element shortcut => Press F12 or Ctrl + Shift + I in Chrome, Edge or Firefox to open developer tools. On Mac press Command + Option + I.
ctrl shift j chrome console | console shortcut chrome => Press Ctrl + Shift + J in Chrome or Edge to open developer tools on the Console tab. On Mac press Command + Option + J.
how do i view a pages source code | ctrl u | see the html of a site => Press Ctrl + U in Chrome, Edge or Firefox to see the page's HTML source. On Mac Chrome, press Command + Option + U.
how do i go back a page with the keyboard | alt left arrow browser => Press Alt + Left Arrow to go back and Alt + Right Arrow to go forward. On Mac press Command + [ and Command + ].
how do i open a link in a new tab | ctrl click link | middle click link => Hold Ctrl (Command on Mac) and click the link, or click it with the mouse wheel button, to open it in a new tab.
how do i close a tab with my mouse | middle click tab => Click a tab with the mouse wheel button to close it.
how do i open a link in a new tab and go to it | ctrl shift click => Press Ctrl + Shift and click a link to open it in a new tab and switch to it right away.
how do i close the whole browser window | ctrl shift w => Press Ctrl + Shift + W to close the whole window with all its tabs. On Mac press Command + Shift + W.
how do i add www and com automatically | ctrl enter in address bar => In Chrome, type a word like youtube and press Ctrl + Enter to add www. and .com for you.
how do i see what is slowing chrome | chrome task manager | shift esc chrome => Press Shift + Esc in Chrome on Windows to open its Task Manager, which shows how much memory and CPU each tab and extension uses. You can end a tab from there.
how do i open the chrome bookmark manager | ctrl shift o => Press Ctrl + Shift + O in Chrome to open the bookmark manager.
how do i search my open tabs | ctrl shift a chrome => Press Ctrl + Shift + A in Chrome to search through your open and recently closed tabs.
how do i take a screenshot of a whole web page | edge web capture | ctrl shift s edge => In Edge press Ctrl + Shift + S to open Web capture. Pick Capture area or Capture full page.
how do i use immersive reader in edge | f9 edge => Press F9 in Edge to open Immersive Reader on pages that support it. It removes ads and clutter and can read text aloud.
how do i make edge read a page out loud | read aloud edge | ctrl shift u read aloud => Press Ctrl + Shift + U in Edge to start Read aloud. You can change the voice and speed.
how do i zoom a web page | ctrl plus browser | reset browser zoom ctrl 0 => Press Ctrl + Plus to zoom in, Ctrl + Minus to zoom out, and Ctrl + 0 to reset. On Mac use Command.
how do i search with the selected text | right click search google => Select some text, right-click it and choose Search Google (or Search the web) for it to open results in a new tab.
how do i open the safari tab overview | command shift backslash => Press Command + Shift + \ in Safari to see all your tabs as thumbnails.
how do i use reader mode in safari | command shift r safari => Press Command + Shift + R in Safari to turn on Reader, which shows just the article text.
how do i open history in safari | command y => Press Command + Y in Safari to show your history.
how do i make safari show the develop menu | safari inspect element => Open Safari, then Settings, then Advanced, and tick Show features for web developers. Then Command + Option + I opens Web Inspector.
how do i pause a youtube video with the keyboard | k on youtube => Press K or Space to play and pause a YouTube video.
how do i skip 10 seconds on youtube | l key youtube | rewind 10 seconds youtube j => Press L to skip ahead 10 seconds and J to go back 10 seconds. The Right and Left Arrow keys jump 5 seconds.
how do i make youtube full screen with a key | f on youtube => Press F to switch YouTube into full screen and press it again or Esc to exit. T toggles theater mode.
how do i mute youtube with a key | m on youtube => Press M to mute or unmute a YouTube video.
how do i turn on captions with a key | c on youtube => Press C to turn captions on or off on YouTube, if the video has them.
how do i speed up a youtube video | change playback speed youtube keys => Press Shift + . (the > key) to speed up and Shift + , (the < key) to slow down a YouTube video. You can also use the settings gear.
how do i jump to part of a youtube video with numbers | press 5 on youtube => Press number keys 0 to 9 on YouTube to jump to 0 percent through 90 percent of the video. 5 goes to the middle.
how do i go frame by frame on youtube | period key youtube => Pause the video, then press . (period) to go forward one frame and , (comma) to go back one frame.
how do i open the youtube miniplayer | i key youtube => Press I on YouTube to open the miniplayer so you can browse while watching.
how do i go to the next video on youtube | shift n youtube => Press Shift + N for the next video and Shift + P for the previous one in a playlist.
how do i see all youtube shortcuts | youtube keyboard shortcuts list => Press Shift + ? on YouTube to see the list of keyboard shortcuts.
how do i mute a tab | stop a tab playing sound => Right-click the tab and choose Mute site (Chrome) or Mute tab (Edge and Firefox).
how do i pin a tab | keep a tab always open => Right-click the tab and choose Pin. It shrinks to an icon at the left and stays open each time you start the browser.
how do i group tabs in chrome | tab groups => Right-click a tab and choose Add tab to new group. Give it a name and color, and click the group name to collapse it.
how do i stop a website from asking for notifications | block site notifications chrome => In Chrome open Settings, Privacy and security, Site settings, Notifications, and pick Don't allow sites to send notifications. Remove any site you don't trust from the allowed list.
how do i set my homepage in chrome | change chrome start page => Open Chrome Settings, then On startup, and pick Open a specific page or set of pages. Add the page you want.
how do i change my default search engine | use a different search engine in chrome => In Chrome open Settings, then Search engine, and pick one from the list. In Edge it's under Settings, Privacy, search and services, then Address bar and search.
how do i make chrome my default browser | set default browser windows => Open Windows Settings, Apps, Default apps, click Google Chrome and click Set default. Or click the Make default button in Chrome Settings.
how do i update chrome | is my browser up to date => In Chrome open the three dot menu, Help, About Google Chrome. It checks and downloads updates, then asks you to relaunch.
how do i turn on dark mode in chrome | chrome dark theme => Chrome follows your system theme. Set Windows to dark in Settings, Personalization, Colors, or pick Dark in Chrome Settings, Appearance, Mode.
how do i see saved passwords in chrome | google password manager => Open Chrome Settings, then Autofill and passwords, then Google Password Manager. Windows asks for your PIN before showing a password.
how do i translate a web page | chrome translate => Right-click on the page and choose Translate to your language, or click the translate icon in the address bar.
how do i remove a chrome extension | uninstall an extension => Click the puzzle piece icon, then the three dots next to the extension, and choose Remove from Chrome.
how do i fix a website that won't load | page not loading fix => Reload the page, try another site to check your internet, clear that site's cookies, try an Incognito window to rule out extensions, and restart the router if nothing loads.
what does a lock icon in the address bar mean | is https safe => The lock (or a tune icon in newer Chrome) means the connection uses HTTPS, so data is encrypted on the way. It doesn't prove the site is honest, so still watch for scams.
