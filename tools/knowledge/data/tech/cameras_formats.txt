# tag: tech.cameras
what does iso mean on a camera | iso explained => ISO is how sensitive the camera is to light. Low ISO (100) gives clean images in bright light; high ISO brightens dark scenes but adds grainy noise.
what is shutter speed | fast vs slow shutter => Shutter speed is how long the sensor collects light, like 1/1000 or 1/30 of a second. Fast freezes motion; slow lets in more light and blurs movement.
what is aperture | what does f stop mean => Aperture is the size of the lens opening, written as f-numbers like f/1.8 or f/8. A low number lets in more light and blurs the background more.
what is bokeh | blurry light circles photo => Bokeh is the soft, blurry look of out-of-focus areas, especially round blobs from lights, made by lenses at wide apertures.
what is focal length | what does 50mm mean => Focal length, in millimeters, sets how zoomed in a lens is. Low numbers like 16 mm are wide; high numbers like 200 mm are zoomed in.
what is a prime lens vs zoom lens | prime lens meaning => A prime lens has one fixed focal length and is often sharper and brighter. A zoom lens covers a range, like 24 to 70 mm, for flexibility.
what is white balance | why are my photos orange => White balance tells the camera what color the light is so whites look white. Indoor bulbs make photos orange; shade makes them blue. Set it to Auto or the matching preset.
what is raw photo | raw vs jpeg => RAW files keep all the sensor's data for editing exposure and color later, but are big. JPEGs are smaller and ready to share but have less room for edits.
rule of thirds for photos and video | photo composition tips | camera grid lines for framing => Imagine the frame split into a 3 by 3 grid. Placing your subject on the lines or where they cross often looks more balanced than dead center. Turn on the grid in your camera settings.
what is a dslr vs mirrorless | mirrorless camera => DSLRs use a mirror and optical viewfinder. Mirrorless cameras skip the mirror, so they're smaller with electronic viewfinders. Most new cameras as of 2025 are mirrorless.
what is a sensor size | full frame vs aps c => Bigger sensors, like full frame, catch more light for cleaner low-light images and blurrier backgrounds. APS-C and smaller sensors are cheaper and lighter.
what is megapixels | do more megapixels mean a better camera => Megapixels are millions of pixels in a photo. More helps for big prints and cropping, but sensor size, lens and processing matter more for quality.
what is an action camera | gopro => An action camera like a GoPro is small, tough and often waterproof, with wide lenses and strong stabilization, for sports and drone footage.
what is image stabilization | ois vs eis => Stabilization reduces shake. Optical (OIS) moves lens or sensor parts; electronic (EIS) crops and shifts the image in software. Both help handheld video.
what is hdr photo | hdr mode on phone camera => HDR photos combine several exposures so both bright skies and dark shadows keep detail. Phones do it automatically.
what is a tripod for | do i need a tripod => A tripod holds the camera still for sharp photos in low light, timelapses, long exposures and steady video.
what is a timelapse | how to make a timelapse => A timelapse takes photos at intervals, like every few seconds, then plays them fast so slow things like clouds or 3D prints zoom by. Phones have a Time-lapse mode.
what is slow motion video | 120fps slow mo => Slow motion records at high frame rates like 120 or 240 fps, then plays at normal speed so action looks slowed down.
what is a ring light | do i need a ring light => A ring light is a circle of LEDs around the camera that gives even, soft light on your face, popular for streams and video calls.
what is three point lighting | key fill back light => Three point lighting uses a key light (main), a fill light (softens shadows) and a back light (separates you from the background).
what makes a good webcam | best webcam setup => Good lighting matters more than the camera. Face a window or soft light, keep the camera at eye level, and set it to 1080p. Many phones make great webcams.
# tag: tech.files
what is a png vs jpg | png or jpg => JPG is compressed for photos and makes small files but loses some detail. PNG is lossless and supports transparency, better for screenshots, logos and pixel art.
what is a gif | how do gifs work => A GIF is an image format that can hold short animations with up to 256 colors. It's great for simple loops but makes big files for real video.
what is webp | webp image => WebP is an image format from Google that makes smaller files than JPG or PNG at similar quality and supports transparency. Most browsers support it.
how do i convert webp to png | open webp file => Open it in Paint or Photos on Windows and use Save As to pick PNG, or open it in a browser and save it another way. Many free converters work too.
what is heic | open heic on windows => HEIC is the efficient photo format iPhones and iPads use. Windows can open it with the HEIF Image Extensions from the Microsoft Store, or you can set the iPhone camera to Most Compatible.
what is svg | svg file format => SVG is a vector image made of shapes and paths, so it stays sharp at any size. PNG is made of pixels and gets blurry when enlarged.
what is aac audio | m4a file => AAC is a compressed audio format that sounds better than MP3 at the same size. M4A files usually hold AAC audio, common from Apple devices.
what is a txt file | plain text => A .txt file holds plain text with no formatting. Notepad on Windows and TextEdit on Mac open it.
what is a json file | open a .json file => JSON is a text format for data with keys and values in curly brackets. Apps and games often use it for settings and saves.
what is an iso file | mount iso => An ISO is a full copy of a disc in one file, like a Windows installer. On Windows, double-click it to mount it as a virtual drive.
what is a dll file | dll files on windows => A DLL holds shared code that programs use. "Missing DLL" errors often mean you need to reinstall the program or its runtime, like the Visual C++ Redistributable. Never download single DLLs from random sites.
what is a .bat file | batch file windows => A .bat file is a batch script with Windows commands that run in order when opened. Only run batch files you wrote or fully trust.
what is a .apk file | apk meaning => An APK is an Android app package. Only install APKs from trusted sources, since fake ones often hide malware.
what is a .dmg file | dmg on mac => A DMG is a Mac disk image, often used to install apps. Open it, drag the app to Applications, then eject it.
what is a .exe vs .msi | msi installer => Both install or run programs on Windows. An .exe is a program; an .msi is a Windows Installer package. Only run ones from trusted sources.
what is a 3mf file in bambu studio | bambu 3mf => In Bambu Studio, a 3MF project saves the models, plates, colors and print settings together, so you can reopen or share a ready-to-print job.
what is a .blend file | share a blender project => A .blend file is a Blender project with all objects, materials, animation and settings. Pack textures into it with File, External Data, Pack Resources before sharing.
what is a font file | ttf vs otf => TTF and OTF are font files. Double-click one on Windows and click Install to use it in apps. OTF can hold more advanced typography features.
how do i open a file with no extension | unknown file type => Show file extensions in File Explorer first. If it really has none, try opening it with Notepad to peek inside, or ask whoever sent it what it is. Don't run unknown files.
