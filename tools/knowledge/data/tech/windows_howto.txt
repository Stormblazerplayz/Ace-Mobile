# tag: tech.windows.display
how do i change my refresh rate on windows | set monitor to 200hz | my monitor is stuck at 60hz | how do i change hz on pc => Open Settings, System, Display, Advanced display, and pick the highest rate under Choose a refresh rate. If it's missing, use a DisplayPort or good HDMI cable and update your graphics driver.
how do i check my monitor refresh rate | what hz is my screen running at => Open Settings, System, Display, Advanced display. The refresh rate shows there, along with which graphics card the screen is connected to.
how do i change my screen resolution | resolution settings windows 11 => Open Settings, System, Display, and pick a size under Display resolution. The one marked (Recommended) matches your monitor's real pixels.
how do i make everything bigger on my screen | display scaling windows | text too small on pc => Open Settings, System, Display, and change Scale to 125 or 150 percent. To change only text size, go to Accessibility, Text size.
how do i set up two monitors | second monitor setup windows | extend display => Plug both screens into the graphics card, open Settings, System, Display, and pick Extend these displays. Drag the screen boxes to match how they sit on your desk.
how do i pick my main monitor | make this my main display => Open Settings, System, Display, click the screen you want, and tick Make this my main display. The taskbar clock and new windows go there.
how do i identify which monitor is which | monitor numbers windows => Open Settings, System, Display and click Identify. A big number shows on each screen.
how do i turn on night light | blue light filter windows | make screen warmer at night => Open Settings, System, Display, and turn on Night light. Click it to set the strength and a schedule.
how do i turn on hdr in windows | use hdr setting => Open Settings, System, Display, and turn on Use HDR for a monitor that supports it. HDR400 monitors often look better with it off for everyday use.
how do i calibrate hdr on windows | windows hdr calibration app => Install the free Windows HDR Calibration app from the Microsoft Store and follow its three test screens to set dark, bright and color levels.
what is auto hdr | should i use auto hdr => Auto HDR makes many older DirectX 11 and 12 games look like HDR on an HDR screen. Turn it on in Settings, System, Display, Graphics, if you like how it looks.
how do i turn on variable refresh rate in windows | windows vrr setting => Open Settings, System, Display, Graphics, then Change default graphics settings (or Advanced graphics settings) and turn on Variable refresh rate. Also turn on G-SYNC or FreeSync in your GPU software and monitor menu.
what is hardware accelerated gpu scheduling | should i turn on hags => It lets the graphics card manage its own memory, which can lower latency a little and is needed for DLSS frame generation. Find it in Settings, System, Display, Graphics, Change default graphics settings. Restart after changing it.
how do i make a game use my graphics card | game using integrated graphics | set high performance gpu for an app => Open Settings, System, Display, Graphics, find the game (or click Browse to add its .exe), click Options, and pick High performance. This matters most on laptops.
how do i rotate my screen | screen is sideways fix => Open Settings, System, Display, and change Display orientation to Landscape. Use Portrait for a monitor turned on its side.
how do i change brightness on a desktop monitor | brightness slider missing windows => Desktop monitors usually change brightness with the buttons on the monitor itself. The Windows brightness slider works mainly on laptops.
how do i stop my screen turning off so fast | screen timeout windows => Open Settings, System, Power and battery (or Power), then Screen, sleep and hibernate timeouts, and raise the time before the screen turns off.
how do i change my wallpaper | desktop background windows 11 => Open Settings, Personalization, Background, and pick Picture, Slideshow, Solid color or Spotlight. You can also right-click any picture and choose Set as desktop background.
how do i turn on dark mode in windows | windows dark theme => Open Settings, Personalization, Colors, and set Choose your mode to Dark.
how do i move the start button to the left | taskbar left windows 11 => Open Settings, Personalization, Taskbar, Taskbar behaviors, and set Taskbar alignment to Left.
how do i hide the taskbar automatically | auto hide taskbar => Open Settings, Personalization, Taskbar, Taskbar behaviors, and tick Automatically hide the taskbar.
how do i remove widgets from the taskbar | turn off search box taskbar => Open Settings, Personalization, Taskbar, and switch off items like Widgets, Task view or Copilot. Set Search to Hide or Search icon only.
how do i change the accent color | windows highlight color => Open Settings, Personalization, Colors, and pick an Accent color, or let Windows pick one from your wallpaper.
how do i set a screen saver on windows 11 | screensaver settings => Open Settings, Personalization, Lock screen, and click Screen saver. Pick one and the wait time.
how do i change the lock screen picture | lock screen wallpaper pc => Open Settings, Personalization, Lock screen, and choose Windows spotlight, Picture or Slideshow.
how do i get my desktop icons back | icons disappeared from desktop => Right-click the desktop, choose View, and tick Show desktop icons.
how do i make desktop icons smaller | icons too big => Right-click the desktop, choose View, then Small icons, or hold Ctrl and scroll the mouse wheel on the desktop.
how do i stop icons moving around the desktop | auto arrange icons => Right-click the desktop, choose View, and untick Auto arrange icons. Align icons to grid keeps them neat.
how do i change the mouse pointer size | bigger cursor windows => Open Settings, Accessibility, Mouse pointer and touch, and change the size and style of the pointer.
how do i turn on color filters for color blindness | windows color filters => Open Settings, Accessibility, Color filters, and turn them on. Filters like red-green help people with color blindness tell colors apart.
# tag: tech.windows.gaming
how do i turn on game mode | what is game mode windows | game mode settings => Open Settings, Gaming, Game Mode, and turn it on. It tells Windows to give your game more priority and pause updates and notifications while you play. It's on by default.
does game mode help fps | is windows game mode good => Game Mode mostly helps keep FPS steady by stopping background updates and restarts during play. On a strong PC the change is small, but it's rarely worse, so leave it on.
how do i change game bar settings | turn off xbox game bar => Open Settings, Gaming, Game Bar. You can turn off opening it with the controller button. To remove it fully, uninstall it from Installed apps.
where do game bar recordings save | where are my captures => Game Bar clips and screenshots save to Videos, then Captures, unless you changed the folder in Settings, Gaming, Captures.
how do i turn on background recording | record what happened windows => Open Settings, Gaming, Captures, and turn on Record what happened. Then Windows key + Alt + G saves the last part of your game.
how do i change game bar recording quality | game bar 60 fps => Open Settings, Gaming, Captures. Set Video frame rate to 60 fps and Video quality to High for smoother, sharper clips.
how do i record audio from my mic with game bar | my voice isn't in my clips => Open Settings, Gaming, Captures, and set Captured audio to include your microphone, or press Windows key + Alt + M while recording.
how do i see fps with game bar | game bar performance widget => Press Windows key + G and open the Performance widget. It shows CPU, GPU, RAM and FPS; the FPS counter may need you to accept a permission and restart.
how do i set power mode to best performance | windows power mode => Open Settings, System, Power (or Power and battery) and set Power mode to Best performance. On laptops, plug in the charger for full speed.
what is the ultimate performance power plan | does ultimate performance help games => It's a hidden power plan that keeps the CPU at full speed. It mostly helps workstations. For gaming, Best performance or the Balanced plan with AMD or Intel's own tuning is usually just as good.
how do i stop windows notifications in games | do not disturb windows => Open Settings, System, Notifications and turn on Do not disturb, or set rules so it turns on automatically when playing a game.
how do i turn off mouse acceleration | enhance pointer precision | turn off mouse acceleration for aiming => Open Settings, Bluetooth and devices, Mouse, Additional mouse settings, the Pointer Options tab, and untick Enhance pointer precision. Your aim will feel more consistent.
how do i change mouse sensitivity in windows | mouse too fast on pc => Open Settings, Bluetooth and devices, Mouse, and move the Mouse pointer speed slider. Many gamers leave it in the middle and change DPI and in game sensitivity instead.
how do i swap left and right mouse buttons | left handed mouse setting => Open Settings, Bluetooth and devices, Mouse, and set Primary mouse button to Right.
how do i change scroll speed | mouse wheel scrolls too far => Open Settings, Bluetooth and devices, Mouse, and change Lines to scroll at a time, or Scroll inactive windows when hovering.
how do i set up a controller on pc | connect xbox controller to pc => Plug it in with USB, or pair it in Settings, Bluetooth and devices, Add device, Bluetooth. Hold the pair button on the controller until the light flashes fast.
how do i use a ps5 controller on pc | dualsense on windows => Hold the PS button and Create button until the light flashes, then pair it in Settings, Bluetooth and devices. Steam has built-in support that maps it for most games.
how do i calibrate a controller on windows | joystick calibration windows => Press Windows key + R, type joy.cpl and press Enter. Pick the controller, click Properties, then Calibrate on the Settings tab.
how do i check if my controller works on pc | test gamepad => Open joy.cpl from the Run box (Windows key + R) and click Properties to see the buttons light up, or use Steam's controller test in Settings, Controller.
# tag: tech.windows.apps
how do i stop apps opening when my pc starts | disable startup apps | pc slow to start => Open Settings, Apps, Startup, and switch off apps you don't need at sign-in. You can also use Task Manager's Startup apps tab, which shows each app's startup impact.
how do i uninstall a program on windows 11 | remove an app windows => Open Settings, Apps, Installed apps, click the three dots next to the app, and choose Uninstall.
how do i change default apps | open pdfs with a different app => Open Settings, Apps, Default apps, search the file type like .pdf, and pick the app you want.
how do i stop apps running in the background | background app permissions windows 11 => Open Settings, Apps, Installed apps, click the three dots by an app, choose Advanced options, and set Background apps permissions to Never. Not every app has this option.
how do i install apps safely on windows | where should i download programs => Use the Microsoft Store or the app maker's official website. Avoid download sites with lots of buttons, cracked games or pop-ups, since those often hide malware.
what is winget | install apps from command line => Winget is the Windows Package Manager. In Terminal, type winget search name, then winget install with the app's ID to install it from trusted sources.
how do i update all my apps with winget | winget upgrade all => Open Terminal and type winget upgrade --all. It updates every app winget knows about.
how do i reset a broken app | app won't open windows 11 => Open Settings, Apps, Installed apps, click the three dots, Advanced options, and click Repair. If that fails, click Reset, which clears the app's data.
how do i reset the microsoft store | store not working => Press Windows key + R, type wsreset.exe and press Enter. A blank window opens, then the Store restarts.
how do i run a program as administrator | run as admin => Right-click the app or its shortcut and choose Run as administrator. Only do this for programs you trust.
how do i always run a program as admin | make a game always open as administrator => Right-click the shortcut, choose Properties, open the Compatibility tab, and tick Run this program as an administrator.
how do i run an old program on windows 11 | compatibility mode => Right-click the program, choose Properties, open Compatibility, and tick Run this program in compatibility mode for an older Windows version.
what does do you want to allow this app to make changes mean | uac popup => That's User Account Control. It asks before a program changes system files or settings. Click Yes only if you just opened that program and trust it.
how do i pin an app to the taskbar | add app to taskbar => Open Start, find the app, right-click it and choose Pin to taskbar.
how do i pin an app to start | start menu pins => Right-click the app in All apps and choose Pin to Start. Drag pinned apps to rearrange them.
how do i make a folder in the start menu | group start menu apps => Drag one pinned app onto another in Start to make a folder. Click the folder to rename it.
how do i turn off start menu recommendations | hide recent files in start => Open Settings, Personalization, Start, and switch off Show recently added apps, Show recommended files and Show recommendations.
how do i open an app on startup every time | make a program start with windows => Press Windows key + R, type shell:startup, press Enter, and put a shortcut to the app in that folder.
how do i find where a program is installed | open file location => Find the app in Start, right-click it, and choose Open file location. If that opens a shortcut, right-click the shortcut and choose Open file location again.
how do i kill a frozen program | end task windows => Press Ctrl + Shift + Esc, select the frozen app in Processes and click End task. In Windows 11 you can also turn on End task in Settings, System, For developers to right-click it on the taskbar.
# tag: tech.windows.storage
how do i free up space on my pc | my c drive is full | clean up storage windows 11 => Open Settings, System, Storage, and click Cleanup recommendations to remove temporary files, big unused files and old downloads. Then uninstall games and apps you don't play.
what is storage sense | turn on storage sense => Storage Sense clears temporary files and old Recycle Bin items by itself. Turn it on in Settings, System, Storage, Storage Sense.
how do i run disk cleanup | disk cleanup windows 11 => Search Disk Cleanup in Start, pick the C: drive, tick what to remove, and click Clean up system files for even more, like old update files.
how do i delete temporary files | clear temp files windows 11 => Open Settings, System, Storage, Temporary files, tick the boxes and click Remove files. Check the Downloads box carefully, since it deletes everything in that folder.
how do i see how much storage i have left | check free space on pc => Open File Explorer and click This PC. Each drive shows a bar with free and used space.
how do i move a steam game to another drive | move game to different ssd => In Steam, right-click the game, choose Properties, Installed Files, then Move install folder, and pick another drive's Steam library.
how do i change where new apps and files save | save to d drive by default => Open Settings, System, Storage, Advanced storage settings, Where new content is saved, and pick another drive for apps, documents, music and more.
how do i set up a new ssd in windows | new drive not showing in file explorer => Open Disk Management (Windows key + X, then K). If it asks, pick GPT. Right-click the unallocated space, choose New Simple Volume, and follow the steps to format it.
how do i check if my drive is an ssd or hdd | is my drive ssd => Open Task Manager, Performance, and click each Disk. The type shows as SSD or HDD at the top right.
how do i check my drive health | is my ssd dying => Open Settings, System, Storage, Advanced storage settings, Disks and volumes, then Properties to see drive health on NVMe drives. CrystalDiskInfo is a free tool that shows health for all drive types.
should i defragment my ssd | defrag ssd or hdd => No, SSDs don't need defragmenting. Windows runs Optimize Drives, which sends TRIM to SSDs and defragments hard drives on a schedule, so leave it on.
how do i optimize my drives | optimize drives windows => Search Defragment and Optimize Drives in Start, select a drive and click Optimize. Windows uses TRIM for SSDs and defrag for hard drives.
how do i format a usb stick | format flash drive windows => Open File Explorer, right-click the USB drive in This PC, and choose Format. Pick exFAT to use it on Windows and Mac, then click Start. This erases everything on it.
what file system should i use for a usb drive | exfat vs ntfs vs fat32 => Use exFAT for USB sticks shared between Windows, Mac and consoles. NTFS is best for Windows-only drives. FAT32 works almost everywhere but can't hold files over 4 GB.
how do i safely remove a usb drive | eject usb windows => Click the arrow by the clock, click the USB icon, and pick Eject for your drive. Wait for the message before unplugging.
how do i compress a big file to save space | does zipping make files smaller => Right-click it and choose Compress to ZIP file. Videos, photos and games are already compressed, so zipping them barely saves space.
what is the pagefile | should i turn off virtual memory => The pagefile is space on the drive Windows uses as extra memory when RAM fills up. Leave it on and set to system managed, since turning it off can crash games.
what is hiberfil.sys | huge hiberfil file => It's the file Windows uses for hibernate and Fast Startup, about the size of part of your RAM. If you never hibernate, you can turn it off in admin Terminal with powercfg /hibernate off.
# tag: tech.windows.update
how do i update windows | check for windows updates => Open Settings, Windows Update, and click Check for updates. Restart when it asks to finish installing.
how do i pause windows updates | stop updates for now => Open Settings, Windows Update, and pick a time in Pause updates, from 1 to 5 weeks. Updates resume after that, because they fix security holes.
how do i stop windows restarting during games | set active hours => Open Settings, Windows Update, Advanced options, Active hours, and set them to when you usually play. Windows won't restart for updates during those hours.
what are optional updates | should i install optional updates => Optional updates are extra driver and feature updates in Settings, Windows Update, Advanced options, Optional updates. Only install them if they fix a problem you have.
how do i see my update history | uninstall a bad update => Open Settings, Windows Update, Update history. Scroll down to Uninstall updates to remove one that caused problems.
why is windows update stuck | update stuck at 0 percent => Restart the PC, then run Settings, System, Troubleshoot, Other troubleshooters, Windows Update. Free up space and make sure your internet is steady before trying again.
what version of windows do i have | check windows version | winver => Press Windows key + R, type winver and press Enter. It shows the version like 24H2 and the build number.
what does 24h2 mean | windows version names => It means the second half (H2) of 2024. Windows 11 feature updates are named by year and half, like 23H2, 24H2 and 25H2.
when does windows 10 support end | is windows 10 still supported => Microsoft ended regular support for Windows 10 on October 14, 2025. After that it gets no free security updates unless enrolled in Extended Security Updates, so upgrading to Windows 11 is safer.
can my pc run windows 11 | windows 11 requirements => Windows 11 needs a 64 bit CPU from roughly 2018 or newer, 4 GB of RAM, 64 GB of storage, TPM 2.0 and Secure Boot. The PC Health Check app tells you if yours qualifies.
how do i turn on tpm | tpm 2.0 not detected => Enter your BIOS and turn on the firmware TPM. On AMD boards it's called fTPM, and on Intel boards it's PTT or Intel Platform Trust Technology.
what is secure boot | how do i turn on secure boot => Secure Boot only lets trusted software start the PC, which blocks some malware. Turn it on in the BIOS boot or security settings; Windows needs the drive set up as GPT.
how do i check if my pc is activated | windows activation => Open Settings, System, Activation. It shows whether Windows is activated and which edition you have, like Home or Pro.
what is the difference between windows home and pro | do i need windows pro => Pro adds BitLocker, Remote Desktop hosting, Hyper-V and work management tools. For gaming and school, Home is enough.
# tag: tech.windows.drivers
how do i update my graphics driver | update nvidia driver | update amd driver => Download the latest driver from NVIDIA, AMD or Intel's website, or use the NVIDIA App or AMD Software: Adrenalin Edition to update it with one click.
what is a driver | what do drivers do => A driver is a small program that teaches Windows how to talk to a piece of hardware like a graphics card, mouse or Wi-Fi card.
how do i update all my drivers | which drivers should i update => Windows Update covers most drivers. Get the graphics driver from NVIDIA, AMD or Intel, and chipset and LAN drivers from your motherboard maker's support page. Skip driver updater apps.
are driver updater apps safe | should i use driver booster => Driver updater apps often install wrong drivers or extra junk. Use Windows Update, your GPU maker's app and your motherboard's support page instead.
how do i roll back a driver | go back to the old driver => Open Device Manager, right-click the device, choose Properties, open the Driver tab and click Roll Back Driver, if it's available.
how do i do a clean graphics driver install | what is ddu => DDU (Display Driver Uninstaller) removes old GPU drivers fully. Run it in Safe Mode, then install the new driver. It's useful when switching between NVIDIA and AMD or fixing driver crashes.
how do i install chipset drivers for amd | amd chipset driver => Download the AMD chipset driver for your socket (like AM5) from AMD's website or your motherboard's support page, run it and restart.
how do i open device manager | where is device manager => Right-click Start and choose Device Manager, or press Windows key + X, then M.
what does a yellow triangle in device manager mean | unknown device windows => A yellow warning means Windows has a problem with that device, often a missing driver. Right-click it, choose Update driver, or get the driver from your motherboard or laptop maker.
how do i find my graphics card model | what gpu do i have => Open Task Manager, click Performance, and look at GPU. The name shows at the top right. Device Manager, Display adapters also lists it.
how do i find what cpu i have | what processor is in my pc => Open Settings, System, About. Your processor is listed next to Processor. Task Manager's Performance tab shows it too.
how do i see how much ram i have | check my ram amount => Open Settings, System, About and look at Installed RAM. Task Manager, Performance, Memory also shows the speed and how many slots are used.
how do i check my ram speed | is xmp working => Open Task Manager, Performance, Memory, and look at Speed. If it shows something like 4800 MT/s on DDR5 rated for 6000, EXPO or XMP is off in the BIOS.
how do i find my motherboard model | what motherboard do i have => Press Windows key + R, type msinfo32, and press Enter. Look at BaseBoard Manufacturer and BaseBoard Product.
how do i see all my pc specs in one place | full system info windows => Press Windows key + R and type msinfo32 for full system info, or dxdiag to see CPU, RAM, graphics and DirectX version.
# tag: tech.windows.sound
how do i change my audio output | switch from speakers to headphones pc => Click the speaker icon by the clock, click the arrow next to the volume slider, and pick your headphones or speakers. Windows key + Ctrl + V opens the same list.
how do i change one apps volume | volume mixer windows 11 => Right-click the speaker icon and choose Open volume mixer. Each open app has its own slider.
how do i set my microphone | choose which mic windows uses => Open Settings, System, Sound, and pick your mic under Input. Speak and watch the Volume bar move to test it.
how do i test my microphone on windows | is my mic working => Open Settings, System, Sound, click your mic under Input, and click Start test. Speak normally and check the result.
how do i make my mic louder | mic too quiet pc => Open Settings, System, Sound, click your mic, and raise Input volume. Move the mic closer before boosting it too much, since boost adds hiss.
how do i let apps use my microphone | mic privacy settings windows => Open Settings, Privacy and security, Microphone, and turn on Microphone access and Let apps access your microphone. Turn on the apps you want, like Discord.
how do i hear myself through my mic | listen to this device => Open Control Panel, Sound, the Recording tab, double-click your mic, open the Listen tab, and tick Listen to this device. Untick it when done, or you'll hear yourself in calls.
how do i turn on spatial sound | windows sonic => Open Settings, System, Sound, click your output device, and set Spatial sound to Windows Sonic for Headphones. It can help hear direction in some games.
how do i fix audio delay with bluetooth headphones | bluetooth audio lag => Bluetooth headphones add a delay you notice in games. Use wired headphones, or a headset with its own 2.4 GHz USB dongle, for gaming.
what is the sound control panel | old sound settings windows 11 => In Settings, System, Sound, scroll down and click More sound settings. It opens the classic panel with Playback and Recording tabs.
how do i change the sample rate of my headset | audio format 48000 => Open More sound settings, double-click your device, open Advanced, and choose a Default Format like 24 bit, 48000 Hz.
how do i turn off windows sounds | stop system beeps => Open Settings, Personalization, Themes, Sounds (or More sound settings, Sounds tab), and set the Sound Scheme to No Sounds.
how do i turn off audio enhancements | weird sound effects on headset => Open Settings, System, Sound, click your device, and turn off Audio enhancements. This can fix muffled or strange sound.
# tag: tech.windows.bluetooth
how do i connect bluetooth headphones to my pc | pair bluetooth windows 11 => Put the headphones in pairing mode, open Settings, Bluetooth and devices, click Add device, then Bluetooth, and pick them from the list.
how do i turn on bluetooth on my pc | bluetooth missing windows => Open Quick Settings with Windows key + A and click Bluetooth, or go to Settings, Bluetooth and devices. Desktops without built-in Bluetooth need a USB adapter.
why won't my bluetooth device connect | bluetooth not pairing => Turn Bluetooth off and on, remove the device and pair again, charge it, and move it closer. Make sure it isn't still connected to your phone.
how do i remove a bluetooth device | unpair bluetooth windows => Open Settings, Bluetooth and devices, click the three dots next to the device, and choose Remove device.
how do i send a file over bluetooth => Open Settings, Bluetooth and devices, Devices, then Send or receive files via Bluetooth. Nearby Share or a cloud drive is usually faster.
how do i connect my iphone to my pc | phone link iphone => Open the Phone Link app on Windows and follow the steps to pair your iPhone or Android phone. It shows notifications and messages on the PC.
how do i share files to a nearby pc | nearby sharing windows => Turn on Nearby sharing in Settings, System, Nearby sharing. Then right-click a file, choose Share, and pick the nearby PC.
# tag: tech.windows.accounts
how do i change my windows password | change pc password => Press Ctrl + Alt + Delete and choose Change a password, or go to Settings, Accounts, Sign-in options, Password.
how do i set up a pin on windows | windows hello pin => Open Settings, Accounts, Sign-in options, PIN (Windows Hello), and click Set up. A PIN only works on that one device, which makes it safer than a password.
how do i use face or fingerprint sign in | windows hello face => Open Settings, Accounts, Sign-in options, and set up Facial recognition or Fingerprint. It needs a compatible camera or fingerprint reader.
what is the difference between a microsoft account and a local account | do i need a microsoft account => A Microsoft account syncs settings and OneDrive and lets you use the Store and Xbox. A local account stays only on that PC. Family Safety for kids needs Microsoft accounts.
how do i add another user to my pc | make a second account windows => Open Settings, Accounts, Other users (or Family), and click Add account. Each person gets their own files and settings.
how do i switch users on windows | sign in as someone else => Press Ctrl + Alt + Delete and choose Switch user, or click your profile picture in Start and pick another account.
how do i change my account picture => Open Settings, Accounts, Your info, and click Browse files or Open camera to pick a new picture.
how do i see my family safety settings | microsoft family safety => Parents can manage screen time, app limits and content filters at the Microsoft Family Safety website or app. Settings, Accounts, Family shows the family group.
how do i sign out of windows | log off pc => Click Start, click your profile picture, and choose Sign out. Or press Ctrl + Alt + Delete and choose Sign out.
# tag: tech.windows.backup
how do i back up my pc | windows backup app => Open the Windows Backup app to back up folders, settings and app lists to OneDrive. For a full copy, also copy important files to an external drive.
what is onedrive | should i use onedrive => OneDrive is Microsoft's cloud storage. It can back up your Desktop, Documents and Pictures folders so files survive if your PC breaks. Free accounts get 5 GB as of 2025.
how do i stop onedrive backing up my desktop => Click the OneDrive cloud by the clock, open Settings, Sync and back up, Manage back up, and switch off Desktop. The files stay in OneDrive, so copy any you need back to your PC.
what is file history | back up files to an external drive => File History copies your personal folders to an external drive every hour. Turn it on in Control Panel, File History, after plugging in the drive.
how do i make a restore point | create system restore point => Search Create a restore point in Start, select the C: drive, click Configure to turn protection on, then click Create and name it.
how do i use system restore | undo a bad change windows => Search Create a restore point, click System Restore, and pick a restore point from before the problem. Your personal files stay, but apps installed after it are removed.
what is the 3 2 1 backup rule | how should i back up my projects => Keep 3 copies of important files, on 2 different kinds of storage, with 1 copy somewhere else like the cloud. That way one broken drive or lost laptop can't wipe out your work.
how do i back up my game saves | where are pc game saves => Most games use Steam Cloud, Xbox cloud saves or Epic cloud saves. Others keep saves in Documents, Saved Games or %appdata%, so copy those folders to a backup drive.
