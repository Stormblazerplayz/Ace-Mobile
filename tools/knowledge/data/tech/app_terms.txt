# tag: tech.terms.apps
what is a hamburger menu | three lines menu => The hamburger menu is the button with three stacked lines. Tapping it opens a hidden list of menu options.
what is the three dots menu | kebab menu => The three dots button (a kebab or meatball menu) opens more options, like settings, share or delete, for that app or item.
what is a toggle switch in settings | toggle on off => A toggle is a switch you tap to turn a setting on or off. Green or blue usually means on.
what is a dropdown menu | drop down list => A dropdown is a box that opens a list of choices when you click it, then shows the one you picked.
right click menu | menu when i hold down on something => A context menu pops up when you right-click or touch and hold something, showing actions for that exact item.
what is a tooltip | hover text => A tooltip is the small label that appears when you hover the mouse over a button, explaining what it does.
what is a pop up window | modal dialog => A pop-up or dialog is a small window that appears on top and usually needs you to choose something before going on.
what is a progress bar | progress bar explained => A progress bar fills up to show how far a download, install or task has gone.
what is a notification badge | red dot on app => A badge is the small red circle on an app icon showing how many unread notifications or messages it has.
what is a sidebar in an app | sidebar in an app explained => A sidebar is a panel along the side of a window with links to sections, like folders in File Explorer or channels in Discord.
what is a toolbar | ribbon in office => A toolbar is a row of buttons for common actions. Microsoft Office calls its big tabbed toolbar the ribbon.
what is a status bar | status bar explained => The status bar is a thin strip at the top or bottom of a screen or window that shows info like battery, time or word count.
what is drag and drop | drag and drop explained => Drag and drop means clicking or touching an item, holding, moving it somewhere else and letting go to move or copy it.
what is a hotkey | keyboard shortcut meaning => A hotkey or keyboard shortcut is a key combo that does an action fast, like Ctrl + C to copy.
what is autosave | autosave explained => Autosave saves your work automatically every few minutes or after each change, so you lose less if something crashes.
what does sync mean in apps | syncing data => Syncing keeps the same data matched across devices, so a change on your phone also shows on your PC.
what is offline mode in apps | offline mode in apps explained => Offline mode lets an app keep working without internet using data saved on the device. It syncs changes once you're back online.
what is a session timeout | logged out automatically => A session timeout signs you out after you've been inactive for a while, to keep your account safe on shared devices.
what is bloatware | preinstalled apps => Bloatware is unwanted apps that come preinstalled on a new PC or phone. You can usually uninstall them in settings.
what is freeware | freeware vs open source => Freeware is free to use, but its code is private. Open source software lets anyone see and change its code.
what is a subscription app | subscription vs one time purchase => A subscription charges every month or year while you use it. A one-time purchase is paid once and yours to keep.
what is a license key | product key software => A license key is a code that proves you bought the software and unlocks it. Keep it private and saved somewhere safe.
what is a portable app | portable app explained => A portable app runs without installing, often from a single folder or USB stick, and doesn't change system settings.
what is an installer | setup exe => An installer is the program that copies an app onto your computer and sets it up, often named setup.exe or ending in .msi.
what is the difference between an update and an upgrade | difference between an update and an upgrade explained => An update fixes bugs and adds small features to the same version. An upgrade moves you to a new major version, like Windows 10 to 11.
what does end of life mean for software | software end of support => End of life means the maker stops updating the software, including security fixes, so it becomes riskier to keep using.
what is cross platform software | cross platform software explained => Cross-platform software runs on several systems, like Windows, Mac, iPad and Android, often with your data synced between them.
what is a cloud save in games | cloud save in games explained => A cloud save stores your game progress online so it isn't lost if your device breaks and can continue on another device.
what is a server outage | is it down => An outage is when an online service stops working for many people. Check the service's status page or social accounts before troubleshooting your own device.
what is a status page | status page explained => A status page is a website where a service shows whether its systems are working or having problems, like status.roblox.com or the Discord status page.
what is a release candidate | rc version => A release candidate is a nearly finished version released for final testing. If no big bugs show up, it becomes the real release.
what is early access in games | early access in games explained => Early access lets you buy and play a game before it's finished. It may have bugs and change a lot before the full release.
what is a dark pattern | tricky app design => A dark pattern is a design that tricks you, like a hidden cancel button or a pre-ticked box for extra purchases. Read carefully before clicking.
what is a captive portal | wifi login page => A captive portal is the web page that pops up on hotel, school or cafe Wi-Fi asking you to accept terms or sign in before you get internet.
what is a pin vs password | pin vs password explained => A PIN is a short number code, often only for one device. A password is longer and works across devices, so it needs to be stronger.
what is a username vs display name | username vs display name explained => Your username is the unique name used to sign in or find you. A display name is the name others see, and may not need to be unique.
what is a qr code menu | qr code menu explained => Some places show a QR code you scan to open a menu or page on your phone. Check the link that appears looks right before tapping.
what is a widget on a phone | widget on a phone explained => A widget is a small live panel on your home screen showing info from an app, like weather or your calendar, without opening it.
