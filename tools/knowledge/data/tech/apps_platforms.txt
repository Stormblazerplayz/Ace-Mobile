# tag: tech.apps.discord
how do i make a discord server | create discord server => Click the plus button at the bottom of the server list, choose Create My Own, name it and pick an icon. You can add text and voice channels after.
how do i make roles in discord | discord roles => Open Server Settings, Roles, and click Create Role. Give it a name, color and permissions, then assign it to members.
what are discord permissions | channel permissions discord => Permissions control what each role can do, like send messages, manage channels or kick members. Give admin permissions only to people you really trust.
how do i make a private channel in discord | hidden channel for some people => Create a channel and turn on Private Channel, then pick which roles or members can see it.
how do i invite people to my discord server | discord invite link => Click the server name, choose Invite People, and copy the link. You can set the link to expire or only work a few times.
how do i add a bot to my discord server | discord bots => Bots are added from the bot's official website or the App Directory with an authorize link. Only add well-known bots and check what permissions they ask for.
what is slow mode in discord | discord slowmode => Slow mode limits how often each person can send messages in a channel, like once every 10 seconds, which stops spam.
what is automod in discord | discord automod => AutoMod blocks messages with words you choose, spam or harmful links before they're posted. Set it up in Server Settings, Safety Setup.
how do i change my discord status | discord online status => Click your profile picture at the bottom left and choose Online, Idle, Do Not Disturb or Invisible, or set a custom status.
how do i change my discord nickname in one server | server nickname => Open the server's menu and choose Edit Per-server Profile, then type a server nickname.
what is a discord thread | discord threads => A thread is a mini conversation branching off a message, so side topics don't clog the main channel.
what is discord nitro | is nitro worth it => Nitro is Discord's paid subscription with bigger uploads, custom emoji everywhere, profile perks and higher quality streaming. Discord works fine without it.
what is the discord file size limit | discord upload limit => As of 2025, free accounts can upload files up to 10 MB. Nitro raises the limit a lot. Use a cloud link for bigger files.
how do i stream a game on discord in high quality | discord stream quality => Free users can stream up to 720p at 30 FPS. Nitro unlocks 1080p or higher and 60 FPS.
what is a discord stage channel | discord stage channel explained => A stage channel is for talks and events where only speakers can talk and everyone else listens, like a small radio show.
what is a discord forum channel | discord forum channel explained => A forum channel organizes conversations into posts with titles and tags, like a mini message board.
how do i turn on developer mode in discord | copy message id discord => Open User Settings, Advanced, and turn on Developer Mode. Then you can right-click to copy IDs, which helps with reports and bots.
what is discord's family center | discord's family center explained => Family Center lets a parent see who a teen is friends with and which servers they join, without reading messages. It's set up in User Settings, Family Center.
# tag: tech.apps.steam
how do i make a collection in steam | organize steam library => In the Steam Library, click the plus or Add Shelf and create a Collection. Drag games into it, or make a dynamic one that sorts by rules.
what is the steam workshop | steam mods workshop => The Workshop is where players share mods, maps and items for supported games. Click Subscribe and Steam downloads them automatically.
what is steam cloud | steam cloud saves => Steam Cloud saves your game progress online for supported games, so it follows you to another PC or Steam Deck.
what are steam launch options | launch options steam => Launch options are extra commands for a game, set by right-clicking it, Properties, General. Only use ones the game's official guide suggests.
how do i show fps in steam | steam fps counter => Open Steam, Settings, In Game and set In-game FPS counter to a corner. Newer Steam versions have a fuller Performance Monitor in the same place.
what is steam input | controller config steam => Steam Input lets you remap any controller for any game, even games without controller support. Open a game's Controller settings to change it.
what is remote play together | steam remote play together => Remote Play Together lets friends join local multiplayer games over the internet, even if only you own the game.
what is steam link | steam link explained => Steam Link streams games from your PC to a phone, tablet or TV on the same network, using the Steam Link app.
how do i change steam download region | steam download server location => Open Steam, Settings, Downloads and pick a Download Region near you. Changing it can fix slow or stuck downloads.
how do i clear the steam download cache | reset steam downloads => Open Steam, Settings, Downloads, and click Clear Cache. Steam restarts and you log back in.
what is a steam beta branch | opt into beta steam => Some games let you play a test version. Right-click the game, Properties, Betas, and choose the branch. You can switch back the same way.
what are steam points | steam points shop => Steam Points are earned when you spend money on Steam. Spend them on profile items, stickers and emoticons in the Points Shop.
what are steam trading cards | steam trading cards explained => You get trading cards by playing some games. Collect a full set to craft a badge, or sell cards on the Community Market.
what is the steam wishlist | wishlist sales => Add games to your wishlist and Steam emails you when they go on sale. It's a smart way to wait for a good price.
when are steam sales | steam summer sale => Steam has big seasonal sales, like the Summer and Winter sales, plus Next Fest demo events. Dates are announced ahead on Steam.
how do i play steam games offline | steam offline mode => While online, open the Steam menu and choose Go Offline. Games you've already installed and launched once can usually run offline.
# tag: tech.apps.launchers
what is the epic games launcher | epic games launcher explained => The Epic Games Launcher is where you buy and play games like Fortnite, and claim the free games Epic gives away regularly.
what is battle.net | blizzard launcher => Battle.net is Blizzard's launcher for games like Overwatch 2, Diablo and Call of Duty. It handles downloads and updates.
what is the ea app | ea app explained => The EA app is EA's launcher for games like EA Sports FC and The Sims. Many EA games on Steam still sign in through it.
what is ubisoft connect | ubisoft connect explained => Ubisoft Connect is Ubisoft's launcher and account system, used by games like Assassin's Creed and Rainbow Six Siege.
what is the gog launcher | gog galaxy => GOG sells DRM-free games you can download and keep, and GOG Galaxy is its optional launcher that can also show games from other stores.
what is drm in games | drm meaning => DRM is copy protection that checks you own a game. Some DRM needs you online, while DRM-free games run without checks.
what is itch.io | itch.io explained => itch.io is a site where indie developers sell or share games, many of them free. It's great for small, creative games and game jams.
what is a game jam | game jam explained => A game jam is an event where people make a game in a short time, like 48 hours, often around a theme. Many are online and beginner-friendly.
# tag: tech.apps.email
how do i search gmail for emails from one person | gmail from search => Type from: followed by their email or name in the Gmail search bar, like from:coach@example.com.
how do i find emails with attachments in gmail | has attachment search => Search has:attachment, or combine it, like from:teacher has:attachment, to find emails with files.
how do i find old emails in gmail | gmail search older than => Search older_than:1y for emails older than a year, or before:2025/01/01 for a date.
how do i schedule an email in gmail | send later gmail => Click the arrow next to Send and choose Schedule send, then pick a time.
how do i snooze an email in gmail | remind me of this email later => Hover over the email and click the clock icon, then choose when it should come back to the top of your inbox.
what does archive do in gmail | archive vs delete => Archive removes an email from the inbox but keeps it in All Mail, so you can still search for it. Delete moves it to the bin.
how do i add a signature in gmail | email signature setup => Open Settings, See all settings, General, and create a signature at Signature. Click Save Changes at the bottom.
what are labels in gmail | gmail folders => Labels work like folders, but one email can have several. Make them from the left sidebar or the label button on an email.
how do i star important emails | gmail starred => Click the star next to an email. Starred emails show up in the Starred section so you can find them fast.
how do i set up an out of office reply | vacation responder => In Gmail Settings, General, turn on Vacation responder, set the dates and message, and save.
what is the focused inbox in outlook | focused vs other outlook => Outlook's Focused Inbox puts important emails in Focused and the rest in Other. Move emails between them to teach it.
how do i make a rule in outlook | outlook rules => Right-click an email, choose Rules, then Create rule, and pick what should happen to similar emails, like moving them to a folder.
how do i recall an email in outlook | unsend outlook email => Outlook's recall only works in some work or school setups when both people use the same Microsoft 365 organization. Usually, you can't take back a sent email.
how do i attach a big file to an email | send large file email => Upload it to Google Drive, OneDrive or iCloud and share a link instead of attaching it. Gmail does this automatically for files over 25 MB.
