# tag: tech.troubleshoot.windows
my start menu won't open | start button not working => Press Ctrl + Shift + Esc, find Windows Explorer in Processes, and click Restart. If it keeps happening, run sfc /scannow and install updates.
my taskbar is frozen | taskbar not responding => Restart Windows Explorer from Task Manager (Processes, Windows Explorer, Restart). The taskbar and desktop reload in a few seconds.
windows search isn't finding anything | search bar not working => Restart Windows Explorer, then open Settings, Privacy and security, Searching Windows, and run the indexer troubleshooter or rebuild the index under Advanced indexing options.
file explorer keeps crashing | file explorer not responding => Restart Windows Explorer in Task Manager, clear File Explorer history in its Options, and check for shell extensions from recently installed apps. Running sfc /scannow also helps.
it says the file is open in another program | can't delete file in use => Close the app using it. If you don't know which one, restart the PC, or use Resource Monitor's CPU tab to search Associated Handles for the file name.
why does it say access denied | you need permission to perform this action => You may need admin rights, or the file belongs to another user or Windows itself. Avoid changing ownership of system files; it can break Windows.
why can't i delete a folder | folder won't delete => A program may be using something inside, or the path is very long. Restart and try again, or delete it from Command Prompt with rd /s on the folder.
how do i fix path too long error | file name too long windows => Move the folder closer to the drive root (like C:\Projects) or shorten folder names. Windows 11 can also enable long paths in Group Policy or the registry for apps that support it.
my pc says no bootable device | no boot device found => Check the BIOS sees your drive and that it's first in boot order. If you just added a drive, make sure the Windows drive is still selected. Reseat the SSD if it's missing.
my pc is stuck on getting windows ready | stuck on working on updates => Give it at least an hour, especially for big updates. If it's truly stuck, hold power to restart; Windows usually rolls back or continues.
black screen after windows update | update broke my display => Wait a few minutes, then press Windows key + Ctrl + Shift + B. If still black, boot into Safe Mode and reinstall the graphics driver or uninstall the update.
my pc time is always wrong | clock resets every boot => Turn on automatic time in Settings, Time and language. If it resets after unplugging, the motherboard's CMOS coin battery may need replacing.
my laptop touchpad stopped working | touchpad not moving cursor => Check for a touchpad key like Fn + F6 or a light in the touchpad corner, then check Settings, Bluetooth and devices, Touchpad is on. Update the touchpad driver.
my laptop brightness won't change | brightness keys not working => Install the graphics driver and your laptop maker's hotkey software. If Night light or Energy saver is on, they can change brightness too.
my keyboard lights up but won't type | keyboard on but not typing => Turn off Filter Keys in Settings, Accessibility, Keyboard, try another USB port, and test it in the on-screen keyboard check. Some keyboards have a lock key that disables typing.
why does my pc say this app can't run on your pc | app can't run error => The app may be for a different type of Windows (like 32 bit vs ARM), corrupted, or blocked. Download the right version from the official site.
why do i get a missing vcruntime140 dll error | msvcp140 dll missing => Install the latest Microsoft Visual C++ Redistributable (both x64 and x86) from Microsoft's website. Don't download single DLL files from random sites.
why do i get a directx error | d3d device lost error => Update the graphics driver, remove GPU overclocks, and check temperatures. "Device removed" errors often mean an unstable GPU or power problem.
my nvidia control panel is missing | nvidia control panel gone => Install it from the Microsoft Store (NVIDIA Control Panel) or reinstall the driver from NVIDIA's site. The NVIDIA App also handles many settings.
my graphics card isn't detected | gpu not showing in device manager => Reseat the card in the top slot, check both power cables are fully in, try another PCIe cable, and update the BIOS. If the BIOS doesn't see it, test it in another PC.
what is dpc latency | audio crackles and stutter dpc => DPC latency is delays from drivers handling hardware. High DPC latency causes audio pops and stutters. LatencyMon can show which driver is the cause.
my mouse cursor disappeared | no mouse pointer windows => Press Windows key + D, move the mouse, and try another USB port. On laptops, a key may turn off the touchpad. Restarting Windows Explorer can bring it back.
my screen is upside down | rotated screen fix => Open Settings, System, Display, and set Display orientation to Landscape. Some Intel drivers also use Ctrl + Alt + Up Arrow.
my pc says low on memory | out of memory error => Close programs and browser tabs, make sure the pagefile is on and system managed, and check for memory leaks in Task Manager. More RAM is the real fix if it happens often.
why is microsoft store not downloading | store stuck pending => Sign out and back into the Store, run wsreset.exe, check Windows Update and the date and time, and run the Windows Store Apps troubleshooter.
how do i fix a corrupted user profile | temporary profile signed in => If Windows signs you into a temporary profile, restart first. If it keeps happening, back up your files and create a new user account.
# tag: tech.troubleshoot.apps
steam won't open | steam not launching => End any Steam processes in Task Manager, restart the PC, and run Steam as administrator. Reinstalling Steam keeps your games if you don't delete the steamapps folder.
steam game won't launch | game won't start steam => Verify the game files, update the GPU driver, install the latest Visual C++ Redistributable, and check that antivirus isn't blocking it.
how do i get a refund on steam | steam refund rules => Steam generally refunds games bought within 14 days and played less than 2 hours. Request it at help.steampowered.com. Ask a parent if they paid.
what is steam family sharing | share steam games with family => Steam Families lets up to 6 family members share most games in their libraries. A parent sets it up in Steam's Family settings with parental controls.
what is steam guard | steam two factor => Steam Guard protects your account with codes from the Steam Mobile app or email. Turn on the mobile authenticator for the best security.
how do i add a non steam game to steam | put other games in steam library => In the Library, click Add a Game, Add a Non-Steam Game, and pick the program. It then works with Steam Input and the overlay.
how do i open the steam overlay | shift tab steam => Press Shift + Tab in game to open the Steam overlay with friends, the browser and guides. Turn it on in Steam Settings, In Game.
how do i take a screenshot in steam | f12 steam screenshot => Press F12 in a Steam game to take a screenshot. Find them in Steam, View, Screenshots, or set the folder in Settings, In Game.
discord keeps freezing | discord lagging pc => Turn off Hardware Acceleration in User Settings, Advanced, update Discord, and clear its cache by quitting it and deleting the Cache folders in %appdata%\discord.
discord stuck on updating | discord update failed loop => End Discord in Task Manager, delete the Discord folder in %localappdata% (not your account), and reinstall from discord.com. Your account and servers stay safe.
minecraft java crashes on startup | minecraft exit code 1 => Update your GPU driver, remove recently added mods, make sure mods match your Minecraft and loader version, and check the crash log in .minecraft\crash-reports for the mod named.
minecraft is laggy on a good pc | minecraft low fps good gpu => Make sure Minecraft runs on the graphics card (Windows Graphics settings, javaw.exe, High performance), turn off V-Sync, lower render distance and add Sodium on Java Edition.
roblox error 279 | roblox failed to connect => Error 279 means Roblox couldn't connect to the game server. Check your internet, try another game, allow Roblox through your firewall, and restart the router.
roblox error 277 | roblox lost connection => Error 277 means your connection to the server dropped. Use a steadier connection like Ethernet, close downloads, and rejoin.
roblox keeps crashing | roblox crash pc => Update your graphics driver, lower Roblox's graphics quality, close overlays, and reinstall Roblox if it continues.
fortnite won't launch | epic games launcher problem => Verify the game files in the Epic Games Launcher (Library, three dots, Manage, Verify), update the GPU driver, and restart the launcher.
chrome keeps crashing | chrome aw snap error => Update Chrome, turn off extensions one at a time, and try a new Chrome profile. Restarting the PC clears memory problems.
a game says my graphics card isn't supported | gpu not supported game => Update the graphics driver, check the game's minimum requirements, and make sure the game uses your dedicated GPU, not integrated graphics.
anti cheat won't let me play | easy anti cheat error => Repair or reinstall the anti-cheat from the game's folder, run the game as admin, and close overlays and tools like Cheat Engine that anti-cheat blocks.
game says vram is full | out of video memory => Lower texture quality and resolution, close other GPU-heavy apps like browsers with videos, and update the GPU driver.
