# tag: tech.video.resolve.deep
what are mediain and mediaout in fusion | fusion input output nodes => MediaIn is your clip coming into Fusion and MediaOut sends the result back to the Edit page. Everything you build goes between them.
what is a merge node in fusion | layer things in fusion => A Merge node puts one image on top of another. The green input is the background and the yellow input is the foreground.
what is a background node in fusion | solid color fusion => A Background node makes a solid color or gradient you can use as a backdrop, a mask or a base for effects.
how do i add text in fusion | text plus node fusion => In Fusion, add a Text+ node and merge it over your clip with a Merge node. Fusion text can be animated in much more detail than Edit page titles.
how do i connect nodes in fusion | wire nodes resolve => Drag from a node's output square to another node's input arrow. Holding Shift while dropping a new node onto a line inserts it into the chain.
what is a transform node in fusion | move and scale in fusion => A Transform node moves, rotates and scales whatever comes into it. Keyframe its settings to animate.
what are particles in fusion | pemitter fusion => Fusion has a particle system starting with a pEmitter node, which shoots out particles you can shape into sparks, snow or dust.
how do i view a node in fusion | show node in viewer => Select a node and press 1 or 2 to show it in the left or right viewer. This helps you check each step of your effect.
what is a mask in fusion | rectangle mask fusion => Mask nodes like Rectangle, Ellipse and Polygon limit an effect to one area. Connect them to a node's blue mask input.
what is the eq in fairlight | equalizer resolve audio => The equalizer boosts or cuts certain frequencies. Cutting low rumble and boosting a little around the upper mids can make voices clearer.
what is a compressor in fairlight | even out voice volume resolve => A compressor turns down the loudest parts of audio so the volume is more even. It helps voiceovers sound steady.
how do i normalize audio in resolve | make all clips the same volume => Select audio clips, right-click and choose Normalize Audio Levels. Pick a target like -14 LUFS for YouTube and Resolve adjusts them.
what is a bus in fairlight | audio bus resolve => A bus combines several tracks so you can control them together, like grouping all music tracks to turn them down at once.
what are the audio meters in resolve | audio levels in the red => The meters show how loud your audio is. Keep peaks below 0 dB, ideally around -6 dB, so the sound doesn't clip.
what is a parallel node in resolve | parallel vs serial nodes => Serial nodes adjust one after another, while parallel nodes each work on the same input and get blended together. Press Alt+P to add one.
what is a layer node in resolve | layer mixer resolve => A layer node mixer stacks nodes like layers, with the bottom one on top. It's useful when you want one correction to override another.
what is an alpha output in resolve | transparent part color page => The alpha output on the color page tells Resolve which part should be see-through, letting a lower video track show through.
what are hdr wheels in resolve | hdr palette resolve => The HDR palette gives color wheels for specific brightness zones, like shadows, highlights and specular, for finer control than lift, gamma and gain.
what is the color warper in resolve | color warper resolve => Color Warper lets you grab colors on a grid and drag them to new hues or saturations, like shifting greens toward teal.
what is noise reduction in resolve | grainy footage resolve => Resolve Studio has temporal and spatial noise reduction on the color page to clean grainy low-light footage. It slows playback, so add it last.
what is smart reframe | auto crop for vertical resolve => Smart Reframe in Resolve Studio automatically keeps the main subject in frame when you change a wide video to vertical.
what is a retime curve in resolve | speed curve resolve => The retime curve shows a clip's speed as a graph, so you can drag points to make smooth speed ramps.
what is dynamic zoom in resolve | ken burns effect resolve => Dynamic Zoom slowly zooms or pans across a clip or photo between a start and end frame, known as the Ken Burns effect.
what are composite modes in resolve | blend modes resolve => Composite modes like Screen, Multiply and Overlay change how a clip mixes with the ones below it. Find them in the Inspector.
how do i change clip opacity in resolve | make a clip see through => Select the clip, open the Inspector and lower Opacity under Composite. Lower video tracks will show through.
what are generators in resolve | solid color clip resolve => Generators make clips from nothing, like solid colors, color bars or gradients. Find them in the Effects panel.
how do i lock a track in resolve | stop editing a track => Click the padlock icon on the track header. Locked tracks can't be changed by mistake.
what is linked selection in resolve | select video without audio => Linked Selection makes clicking a clip also select its audio. Turn it off with the chain button or Ctrl+Shift+L to select them separately.
what is the auto select button in resolve | track auto select => Auto Select controls which tracks are affected by ripple edits and deletes. Turn it off on a track to protect it.
how do i swap two clips in resolve | switch clip order => Select a clip and press Ctrl+Shift+period or comma to swap it with the next or previous clip.
what is the render queue in resolve | add to render queue => The render queue holds export jobs. Set up settings on the Deliver page, click Add to Render Queue, then Render All to export them all.
how do i export clips separately in resolve | individual clips render => On the Deliver page, choose Individual Clips instead of Single Clip, and each clip on the timeline exports as its own file.
what is timeline resolution vs output resolution | mismatched resolution resolve => Timeline resolution is what you edit in and output resolution is what you export. Keep them the same unless you mean to scale.
how do i change keyboard shortcuts in resolve | resolve keyboard customization => Open DaVinci Resolve > Keyboard Customization, or press Ctrl+Alt+K. You can also pick presets that copy Premiere or Final Cut.
where are my resolve projects | resolve project library => The Project Manager shows all your projects stored in Resolve's database. Open it from the house icon at the bottom right.
how much does resolve studio cost | is resolve studio a subscription => Resolve Studio is a one-time purchase, not a subscription, and updates are included. The free version is enough for most beginners.
what is the effects library in resolve | where are effects in resolve => The Effects panel on the Edit page holds transitions, titles, generators and video and audio effects. Drag them onto clips or the timeline.
what is the inspector in resolve | clip settings panel resolve => The Inspector shows settings for the selected clip, like size, position, crop, speed and audio volume. Open it from the top right.
what is a fusion title template | animated titles resolve => Fusion titles are animated title templates in the Effects panel. Drag one onto the timeline and change its text in the Inspector.
what is the speed editor | resolve keyboard => The Speed Editor is a special keyboard from Blackmagic with a search dial and editing keys, made for the Cut page.
what is face refinement in resolve | smooth skin resolve => Face Refinement in Resolve Studio finds faces and lets you smooth skin, brighten eyes and adjust color on just the face.
