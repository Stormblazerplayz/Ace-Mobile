# tag: tech.howitworks
how does a computer mouse work | optical mouse sensor => An optical mouse has a tiny camera that takes thousands of pictures of the surface each second and compares them to see which way it moved. An LED or laser lights up the surface.
how does a keyboard know which key i pressed | keyboard matrix => Keys sit on a grid of wires called a matrix. The keyboard's chip scans the rows and columns very fast, and a pressed key connects one row to one column.
how does an lcd screen work | how do lcds make pictures => An LCD has a backlight behind a layer of liquid crystals. Each tiny crystal twists to let more or less light through colored red, green and blue filters.
how does an oled screen work | oled pixels light up => In an OLED, every pixel is a tiny light that glows on its own. Black pixels just turn off, which is why OLED blacks look perfect.
how does a hard drive work | hdd spinning disk => A hard drive stores data as magnetic patterns on spinning metal platters. A tiny arm reads and writes them, which is why HDDs are slower than SSDs and can break if dropped.
how does a cpu work | fetch decode execute => A CPU repeats a simple loop billions of times a second: fetch an instruction, decode what it means, then execute it, like adding numbers or moving data.
what is a clock speed tick | clock cycle meaning => A clock cycle is one tick of the CPU's internal clock. At 5 GHz, the clock ticks 5 billion times per second, and the CPU does work on each tick.
how does face id work | face id dots => Face ID projects over 30,000 invisible infrared dots onto your face and reads the pattern in 3D, so a flat photo can't fool it.
how does a fingerprint sensor work | touch id how it works => Most phone and laptop fingerprint sensors read the tiny ridges of your finger using electrical charge or light, then compare them to a stored pattern, not a photo.
how does a phone know which way it's turned | phone accelerometer => An accelerometer inside the phone senses gravity, so it knows which way is down and rotates the screen to match.
how does a phone compass work | how does my phone find north => A magnetometer senses Earth's magnetic field to find north. Metal and magnets nearby can confuse it.
how does a phone camera sensor work | image sensor pixels => A camera sensor has millions of tiny light-catching wells. Each one measures how much light hits it, and color filters over them let the phone build a color photo.
how does an e ink screen work | e reader screen => E ink screens move tiny black and white particles with electricity. They only use power when the page changes, so e-readers last for weeks.
how does wireless charging work | charging pad coils => A coil in the charger makes a changing magnetic field, and a coil in the phone turns it back into electricity. The coils must line up, which is why MagSafe uses magnets.
how does bluetooth pairing work | bluetooth pair explained => Pairing makes two devices exchange secret keys once, so they can recognize each other and connect securely later without asking again.
how does an inkjet printer work | inkjet ink drops => An inkjet sprays tiny drops of ink through microscopic nozzles as the print head moves across the paper.
how does a laser printer work | toner printer => A laser draws the page onto a drum with static electricity, powder toner sticks to those spots, and heat melts it onto the paper.
how does a barcode scanner work | store scanner barcode => The scanner shines light on the barcode and reads the pattern of dark and light bars, which stands for a number that looks up the product.
how does a smartwatch measure heart rate | watch heart rate light => Green lights on the back flash onto your skin, and a sensor measures how much light your blood absorbs as your heart pumps.
how does autocorrect work | phone predictive text => Autocorrect compares what you typed to likely words, using which keys are near each other and what words usually come next.
how do vr headsets track movement | inside out tracking => Most VR headsets use cameras on the outside to watch the room and controllers, and motion sensors inside to track head movement many times a second.
how does a webcam work | webcam inside => A webcam is a small camera with an image sensor and lens that sends video to the computer over USB, where apps can use it.
how does apple pencil drawing work | stylus on ipad => The iPad's screen scans for the Pencil's tip signal very quickly, and the Pencil reports pressure and tilt, giving precise, low-lag drawing.
how does noise suppression in calls work | ai noise removal => AI noise suppression has learned what speech sounds like, so it keeps your voice and removes sounds like keyboards, fans and dogs.
how does a touchpad work | laptop trackpad => A touchpad senses the small electrical change your finger makes across a grid, like a phone screen, to track movement and gestures.
how does a game controller rumble | controller vibration => Rumble motors spin a small off-center weight to shake the controller. The DualSense uses voice-coil haptics for finer, more detailed vibrations.
how do adaptive triggers work | dualsense trigger resistance => The PS5 DualSense has small motors that push back against the triggers, so they can feel stiff or bumpy, like pulling a bowstring.
how does a usb stick store data | flash drive inside => A USB stick stores data in flash memory chips that trap electric charge in tiny cells, so data stays without power.
how does a wifi router send data through the air | wifi radio waves => The router turns data into radio waves and sends them through antennas. Your device's Wi-Fi chip catches the waves and turns them back into data.
how does a gpu draw a game | rendering pipeline => The GPU takes 3D shapes, works out where each one lands on screen, colors every pixel with lighting and textures, and does this for every frame.
how does a 3d printer know where to move | g code moves => The slicer turns the model into G-code: a long list of moves like go to this X, Y and Z at this speed while pushing this much filament.
how does a drone stay still in the air | drone hover => The flight controller reads its gyro and accelerometer hundreds of times a second and adjusts each motor's speed. GPS drones also use satellites to hold their spot.
how does a phone know where it is indoors | wifi location => Indoors, phones guess location using nearby Wi-Fi networks and cell towers, because GPS signals are weak inside buildings.
