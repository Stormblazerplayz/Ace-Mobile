# tag: tech.shortcuts.vscode
how do i open the command palette in vs code | ctrl shift p vscode | vs code f1 => Press Ctrl + Shift + P or F1 (Command + Shift + P on Mac) to open the Command Palette, where you can search for any VS Code command.
how do i quickly open a file in vs code | ctrl p vscode | go to file vs code => Press Ctrl + P (Command + P on Mac) and type part of a file name to open it fast.
how do i open the terminal in vs code | ctrl backtick | vscode terminal shortcut => Press Ctrl + ` (backtick, the key above Tab) to show or hide the terminal. Ctrl + Shift + ` makes a new terminal.
how do i hide the sidebar in vs code | ctrl b vscode => Press Ctrl + B (Command + B on Mac) to show or hide the sidebar.
how do i open the explorer panel in vs code | ctrl shift e vscode => Press Ctrl + Shift + E to show the Explorer with your project files.
how do i search all files in vs code | ctrl shift f vscode | find in whole project => Press Ctrl + Shift + F to search every file in your folder. Ctrl + Shift + H opens replace in files.
how do i open source control in vs code | ctrl shift g vscode | git panel vs code => Press Ctrl + Shift + G to open Source Control, where you stage, commit and push with Git.
how do i open extensions in vs code | ctrl shift x vscode => Press Ctrl + Shift + X to open the Extensions view and search for extensions like Python or Luau.
how do i open run and debug in vs code | ctrl shift d vscode => Press Ctrl + Shift + D to open the Run and Debug view.
how do i run my code with the debugger in vs code | f5 vscode | start debugging => Press F5 to start debugging. Ctrl + F5 runs without the debugger, and Shift + F5 stops it.
how do i add a breakpoint in vs code | f9 vscode | stop code at a line => Put the cursor on a line and press F9, or click left of the line number, to add a red breakpoint dot. The code pauses there when debugging.
how do i step through code in vs code | f10 step over | f11 step into => While paused in the debugger, press F10 to step over a line, F11 to step into a function, and Shift + F11 to step out.
how do i comment out a line in vs code | ctrl slash | toggle comment shortcut => Press Ctrl + / (Command + / on Mac) to comment or uncomment the selected lines.
how do i make a block comment in vs code | shift alt a => Press Shift + Alt + A (Shift + Option + A on Mac) to wrap the selection in a block comment.
how do i move a line up or down in vs code | alt up arrow vscode => Press Alt + Up Arrow or Alt + Down Arrow (Option on Mac) to move the line or selection up or down.
how do i copy a line down in vs code | shift alt down arrow | duplicate a line vscode => Press Shift + Alt + Down Arrow (Shift + Option + Down on Mac) to copy the line below. Use Up Arrow to copy it above.
how do i delete a line in vs code | ctrl shift k vscode => Press Ctrl + Shift + K (Command + Shift + K on Mac) to delete the whole line.
how do i select the next same word in vs code | ctrl d vscode | multi select same word => Press Ctrl + D (Command + D on Mac) to select the next match of the selected word. Keep pressing to add more, then type to change them all at once.
how do i select every match in vs code | ctrl shift l vscode => Press Ctrl + Shift + L (Command + Shift + L on Mac) to select every match of the selected text.
how do i add multiple cursors in vs code | alt click vscode | type in many places at once => Hold Alt (Option on Mac) and click to add another cursor. Ctrl + Alt + Up or Down Arrow adds a cursor above or below on Windows.
how do i format my code in vs code | shift alt f | auto format vscode => Press Shift + Alt + F (Shift + Option + F on Mac) to format the whole document. It needs a formatter for that language.
how do i go to where a function is defined | f12 vscode | go to definition => Click the function name and press F12 to jump to its definition. Alt + F12 peeks at it in a small window.
how do i find everywhere a function is used | shift f12 vscode => Click the name and press Shift + F12 to see all references to it.
how do i rename a variable everywhere in vs code | f2 vscode | rename symbol vs code => Click the variable and press F2, type the new name and press Enter. VS Code renames it everywhere it's used, if the language supports it.
how do i go to a line number in vs code | ctrl g vscode => Press Ctrl + G (Control + G on Mac), type the line number and press Enter.
how do i jump to a function in a file | ctrl shift o vscode | go to symbol => Press Ctrl + Shift + O to list functions and other symbols in the file and jump to one.
how do i get autocomplete suggestions | ctrl space vscode => Press Ctrl + Space to show IntelliSense suggestions at the cursor.
how do i quick fix an error in vs code | ctrl period vscode => Put the cursor on the squiggly line and press Ctrl + . (Command + . on Mac) to see quick fixes like adding a missing import.
how do i open vs code settings | ctrl comma vscode => Press Ctrl + , (Command + , on Mac) to open Settings.
how do i see vs code keyboard shortcuts | ctrl k ctrl s => Press Ctrl + K then Ctrl + S to open the Keyboard Shortcuts list, where you can search and change them.
how do i split the editor | ctrl backslash vscode | two files side by side => Press Ctrl + \ (Command + \ on Mac) to split the editor and see two files side by side.
how do i close a file in vs code | ctrl w vscode => Press Ctrl + W (Command + W on Mac) to close the editor tab you are on. Ctrl + Shift + T reopens it.
how do i switch between open files in vs code | ctrl tab vscode => Hold Ctrl and press Tab to switch between open editor tabs.
how do i turn on word wrap in vs code | alt z vscode | long lines go off screen => Press Alt + Z (Option + Z on Mac) to turn word wrap on or off.
how do i use zen mode in vs code | distraction free coding => Press Ctrl + K then Z to enter Zen Mode, which hides everything but your code. Press Esc twice to leave.
how do i fold code in vs code | ctrl shift bracket vscode | collapse a function => Press Ctrl + Shift + [ to fold the block at the cursor and Ctrl + Shift + ] to unfold it. Ctrl + K then Ctrl + 0 folds everything.
how do i find and replace in one file vs code | ctrl h vscode => Press Ctrl + H (Command + Option + F on Mac) to find and replace in the open file.
how do i preview markdown in vs code | ctrl shift v vscode => Open a .md file and press Ctrl + Shift + V to preview it, or Ctrl + K then V to preview it side by side.
how do i change the color theme in vs code | ctrl k ctrl t => Press Ctrl + K then Ctrl + T to pick a color theme. Use the arrow keys to preview each one.
how do i show the problems panel | ctrl shift m vscode => Press Ctrl + Shift + M to open the Problems panel with all errors and warnings. F8 jumps to the next one.
how do i hide the bottom panel in vs code | ctrl j vscode => Press Ctrl + J (Command + J on Mac) to show or hide the bottom panel with the terminal, output and problems.
how do i change the language mode of a file | ctrl k m => Press Ctrl + K then M and pick a language, so VS Code colors and checks the file correctly.
how do i insert a line below without breaking the line | ctrl enter vscode => Press Ctrl + Enter to add a new line below, even with the cursor in the middle of a line. Ctrl + Shift + Enter adds one above.
how do i select the whole line in vs code | ctrl l vscode => Press Ctrl + L (Command + L on Mac) to select the whole line. Keep pressing to add the next lines.
how do i indent a block of code | ctrl bracket indent | tab to indent many lines => Select the lines and press Tab to indent or Shift + Tab to outdent. Ctrl + ] and Ctrl + [ also work.
how do i jump to the matching bracket in vs code | ctrl shift backslash => Press Ctrl + Shift + \ to jump to the bracket that matches the one at the cursor.
how do i copy the path of the file in vs code | ctrl k p => Press Ctrl + K then P to copy the full path of the open file.
how do i open the file in file explorer from vs code | ctrl k r => Press Ctrl + K then R to show the open file in File Explorer.
how do i select a column of text in vs code | box select vscode => Hold Shift + Alt and drag with the mouse (Shift + Option on Mac) to select a rectangle of text across lines.
how do i undo a cursor move | ctrl u vscode => Press Ctrl + U to undo the last cursor change, like an extra cursor you added by mistake.
how do i zoom in vs code | make vs code text bigger => Press Ctrl + = to zoom in and Ctrl + - to zoom out the whole window. To change only code size, edit Editor: Font Size in Settings.
how do i open a folder in vs code | open project vscode => Click File, then Open Folder, and pick your project folder. Opening the folder (not single files) lets VS Code see the whole project.
how do i save all files in vs code | turn on auto save vscode => Click File and tick Auto Save, so files save by themselves after you type. Ctrl + K then S saves all open files.
how do i open a new vs code window | ctrl shift n vscode => Press Ctrl + Shift + N (Command + Shift + N on Mac) to open a new VS Code window.
how do i open the output panel | ctrl shift u vscode => Press Ctrl + Shift + U to open the Output panel, where extensions and tasks print messages.
