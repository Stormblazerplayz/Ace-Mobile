# tag: tech.windows.features
how do i turn on live captions on windows | captions for any video pc => Press Windows key + Ctrl + L to turn on Live Captions on Windows 11. It shows captions for any audio playing on your PC, even offline after the first setup.
what is voice access on windows | control pc with voice => Voice access on Windows 11 lets you open apps, click, type and scroll by talking. Turn it on in Settings, Accessibility, Speech.
how do i use focus sessions | windows focus timer => Open the Clock app and start a Focus session, or click the clock on the taskbar and pick Focus. It sets a timer and turns on Do not disturb.
how do i set an alarm on my pc | windows clock app alarm => Open the Clock app, choose Alarm, and add one. Laptops may need to be awake for alarms to ring.
how do i remove a background in windows paint | paint background removal => In the newer Paint app on Windows 11, open the image and click the Remove background button in the toolbar. Paint also supports layers now.
does notepad have tabs | notepad tabs windows 11 => Yes. Notepad on Windows 11 has tabs; press Ctrl + T for a new one. It also keeps unsaved notes between restarts if session restore is on.
how do i use the calculator in programmer mode | windows calculator modes => Open Calculator, click the menu at the top left and pick Scientific, Programmer, Graphing or Date calculation. Programmer mode converts between binary, hex and decimal.
how do i use sticky notes on windows | desktop notes app pc => Search Sticky Notes in Start. Your notes sync with your Microsoft account so they show on other devices too.
what is windows sandbox | test an app safely => Windows Sandbox is a throwaway copy of Windows for testing programs; everything is deleted when you close it. It's on Pro editions and turned on in Windows Features.
what is wsl | linux on windows => WSL (Windows Subsystem for Linux) runs Linux tools on Windows. Open Terminal as admin and type wsl --install to set it up with Ubuntu.
how do i turn on windows features | optional features windows 11 => Open Settings, System, Optional features, More Windows features, and tick features like Windows Sandbox, Hyper-V or Windows Subsystem for Linux.
how do i change the date and time on my pc | pc clock is wrong => Open Settings, Time and language, Date and time. Turn on Set time automatically and Set time zone automatically, then click Sync now.
how do i change the time zone | wrong time zone windows => Open Settings, Time and language, Date and time, and pick your Time zone, or turn on setting it automatically.
how do i use 12 hour or 24 hour time on windows | change clock format pc => Open Settings, Time and language, Language and region, Regional format, Change formats, and set the Short time and Long time formats.
how do i add a keyboard language | add a keyboard layout windows => Open Settings, Time and language, Language and region, click the three dots by your language, Language options, and Add a keyboard.
how do i turn on touchpad gestures | windows touchpad settings => Open Settings, Bluetooth and devices, Touchpad. Set three and four finger swipes and taps, and scroll direction.
what happens when i close my laptop lid | lid close action windows => By default the laptop sleeps. Change it in Control Panel, Power Options, Choose what closing the lid does, for example Do nothing when plugged in.
sleep vs hibernate vs shut down | what does hibernate do => Sleep keeps your work in RAM with a little power, so it wakes fast. Hibernate saves your work to the drive and fully powers off. Shut down closes everything.
how do i turn on hibernate in windows 11 | hibernate option missing => Open Control Panel, Power Options, Choose what the power buttons do, click the link to change settings that aren't available, and tick Hibernate.
how do i use battery saver | energy saver windows 11 => Open Settings, System, Power and battery, and turn on Energy saver (or Battery saver). It lowers background activity and brightness to stretch battery life.
how do i turn my pc into a wifi hotspot | mobile hotspot windows => Open Settings, Network and internet, Mobile hotspot, choose what connection to share, and turn it on. It shows the network name and password.
what is a metered connection | set wifi as metered => Marking a network as metered stops large downloads like updates on it. Open the Wi-Fi network's properties and turn on Metered connection.
how do i see how much data i used on my pc | data usage windows => Open Settings, Network and internet, Advanced network settings, Data usage. It shows data used per app.
how do i forget a wifi network | remove saved wifi windows => Open Settings, Network and internet, Wi-Fi, Manage known networks, and click Forget next to the network.
how do i connect to hidden wifi | network name not broadcast => Open Settings, Network and internet, Wi-Fi, Manage known networks, Add network, and type the exact network name and password.
how do i set up remote desktop | remote desktop windows => Remote Desktop hosting needs Windows Pro. Turn it on in Settings, System, Remote Desktop. Only connect with people and devices you trust.
how do i stop windows showing ads | turn off tips and suggestions => Turn off suggestions in Settings, Privacy and security, General; in Personalization, Start; in System, Notifications, Additional settings; and in Personalization, Lock screen.
how do i stop apps using my location on pc | location privacy windows => Open Settings, Privacy and security, Location, and turn off Location services or choose which apps can use it.
how do i block the camera for all apps | camera privacy windows => Open Settings, Privacy and security, Camera, and turn off Camera access. Some laptops also have a sliding cover or a key to disable it.
how do i change notification settings on windows | stop pop ups in corner => Open Settings, System, Notifications. Turn notifications off for apps that bother you, or turn on Do not disturb.
what is dynamic lighting windows | control rgb in windows settings => Dynamic Lighting in Settings, Personalization lets Windows 11 control RGB on supported keyboards, mice and other devices without extra apps.
what is copilot in windows | turn off copilot => As of 2025, Copilot is Microsoft's AI assistant app in Windows 11. You can unpin it from the taskbar or uninstall it from Installed apps if you don't use it.
how do i use snap groups | restore snapped windows => After snapping windows together, hover over one of them on the taskbar to see the group, then click it to bring all of them back together.
how do i use the photos app to edit | crop a picture windows => Open the picture in Photos, click Edit image, and use Crop, Adjust, Filter or Markup. Save as a copy to keep the original.
how do i print to pdf on windows | save as pdf windows => In the print window, choose Microsoft Print to PDF as the printer, click Print, and pick where to save the file.
how do i share files between two pcs | send files to another computer => Use Nearby sharing for nearby Windows PCs, a cloud drive like OneDrive, a USB stick, or share a folder over your home network.
how do i see my wifi signal strength | how strong is my wifi => Click the Wi-Fi icon by the clock; more bars mean stronger signal. In Settings, Network and internet, Wi-Fi, open your network's properties for more detail.
how do i check if my pc is 64 bit | 32 or 64 bit windows check => Open Settings, System, About, and look at System type. It shows 64-bit operating system on almost all modern PCs.
how do i find my pc name | rename my pc => Open Settings, System, About to see the device name. Click Rename this PC to change it, then restart.
how do i change the default browser on windows | stop edge opening links => Open Settings, Apps, Default apps, click the browser you want, and click Set default. Some links from Windows features may still open in Edge.
how do i make windows look like windows 10 | classic start menu => You can align the taskbar left in Settings, Personalization, Taskbar behaviors. Fully classic menus need third-party apps like Start11 or Open-Shell.
how do i take a scrolling screenshot on windows | screenshot whole long page pc => Windows doesn't have a built-in scrolling screenshot for all apps. In Edge, use Web capture (Ctrl + Shift + S) and Capture full page for web pages. Tools like ShareX can do it for other apps.
what is sharex | free screenshot tool => ShareX is a free, open source screenshot and screen recording tool for Windows with scrolling capture, GIF recording, OCR and quick uploads.
how do i copy text from an image on windows | text extractor => The Snipping Tool's Text actions button can copy text from a screenshot on Windows 11. PowerToys also has Text Extractor.
what is powertoys | microsoft powertoys features => PowerToys is a free Microsoft app with extra tools like FancyZones window layouts, a color picker, Text Extractor, file renaming and keyboard remapping.
how do i remap a key on windows | remap keyboard keys pc => Install Microsoft PowerToys and use Keyboard Manager to remap keys or shortcuts. Many gaming keyboards also have their own remapping apps.
what is fancyzones | custom window layouts => FancyZones, part of PowerToys, lets you design custom window layouts and snap windows into them by holding Shift while dragging.
how do i turn off the startup sound | windows startup sound => Open Settings, Personalization, Themes, Sounds, and untick Play Windows Startup sound.
how do i see my battery percentage on windows | laptop battery percent => The battery icon by the clock shows it when you hover over it. Click it to open Quick Settings with the percentage.
how do i make text and apps bigger on a 4k screen | blurry text scaling => Set Scale to 150 percent or more in Settings, System, Display. If an old app looks blurry, open its .exe Properties, Compatibility, Change high DPI settings, and try Override high DPI scaling.
