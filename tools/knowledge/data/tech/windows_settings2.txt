# tag: tech.windows.settings2
how do i show seconds on the taskbar clock | windows 11 clock seconds => Open Settings, Personalization, Taskbar, Taskbar behaviors, and tick Show seconds in system tray clock.
how do i add end task to the taskbar | end task right click taskbar => Open Settings, System, For developers, and turn on End Task. Then right-click a taskbar app to force close it.
how do i change the date format on windows | dd mm yyyy windows => Open Settings, Time and language, Language and region, Regional format, and click Change formats.
how do i change the windows display language | windows in another language => Open Settings, Time and language, Language and region, add a language, then pick it as the Windows display language. Sign out to apply it.
how do i set up a printer on windows | add printer windows 11 => Connect the printer to the same Wi-Fi or by USB, then open Settings, Bluetooth and devices, Printers and scanners, and click Add device.
how do i scan a document on windows | scan with printer pc => Install the Windows Scan app from the Microsoft Store, pick your scanner, choose the file type and click Scan.
how do i install a font on windows | add fonts pc => Download the font file from a trusted site, right-click the .ttf or .otf file and choose Install, or drag it into Settings, Personalization, Fonts.
how do i change dns on windows 11 | set dns 1.1.1.1 => Open Settings, Network and internet, pick Wi-Fi or Ethernet, open the hardware properties, click Edit next to DNS server assignment, set it to Manual and type the DNS addresses.
how do i stop my pc connecting to a wifi automatically | wifi auto connect off => Open Settings, Network and internet, Wi-Fi, Manage known networks, pick the network and turn off Connect automatically when in range.
how do i only allow apps from the microsoft store | choose where to get apps => Open Settings, Apps, Advanced app settings, and set Choose where to get apps to The Microsoft Store only. It blocks most downloaded installers.
what is developer mode in windows | for developers settings => Developer mode in Settings, System, For developers lets you install apps from any source and turns on extra tools for coding. Most people don't need it.
how do i pin a website to the taskbar | website shortcut on taskbar => In Edge, open the menu, More tools, Pin to taskbar. In Chrome, use Cast, save and share, Install page as app or Create shortcut, then pin it.
how do i stop my pc going to sleep | turn off sleep windows => Open Settings, System, Power and battery, Screen and sleep, and set When plugged in, put my device to sleep after to Never.
how do i change what the power button does | power button action windows => Search for Change what the power buttons do in the Start menu. It opens the classic setting where you can pick Sleep, Hibernate or Shut down.
how do i turn off the lock screen fun facts | lock screen tips off => Open Settings, Personalization, Lock screen, and untick Get fun facts, tips, tricks and more on your lock screen.
how do i change the mouse pointer color | colorful cursor windows => Open Settings, Accessibility, Mouse pointer and touch, choose the custom style and pick a color.
how do i add a clock for another time zone | extra clocks windows => Open the Clock app and add cities in World clock. The classic Additional clocks option can also show up to two extra times when you hover over the taskbar clock.
how do i sync my clipboard between devices | cloud clipboard => Open Settings, System, Clipboard and turn on Clipboard history across your devices, signed in with the same Microsoft account.
how do i use phone link to text from my pc | send texts from pc => Install Phone Link on Windows and Link to Windows on Android, or pair an iPhone with Bluetooth, then send texts and see notifications from the PC.
how do i stop windows asking to finish setting up | windows nag screen => Open Settings, System, Notifications, Additional settings, and untick Suggest ways to finish setting up my device.
how do i turn off suggested apps in start | start menu ads => Open Settings, Personalization, Start and turn off Show recommendations for tips, shortcuts, new apps and more. Uninstall any promoted apps you don't want.
how do i see recently opened files on windows | recent files => Open File Explorer, and Home shows Recent files. You can also press Win + R and type shell:recent.
how do i change my windows sign in to a pin only | windows hello only sign in => Open Settings, Accounts, Sign-in options, and under Additional settings turn on For improved security, only allow Windows Hello sign-in.
how do i turn off a touchscreen on windows | disable touch screen laptop => Open Device Manager, expand Human Interface Devices, right-click HID-compliant touch screen and choose Disable device.
how do i change the refresh rate for a laptop on battery | dynamic refresh rate => Many laptops support Dynamic refresh rate in Settings, System, Display, Advanced display, which lowers Hz to save battery.
how do i stop windows changing my brightness | content adaptive brightness => Open Settings, System, Display, Brightness and turn off Change brightness based on content.
how do i see my windows product key | find windows license => Most PCs have a digital license tied to the hardware or Microsoft account, so you don't need the key. Check Settings, System, Activation to see if it's activated.
how do i change mouse double click speed | double click too slow => Open Settings, Bluetooth and devices, Mouse, Additional mouse settings, and move the Double-click speed slider on the Buttons tab.
what is clipboard history pinning | pin clipboard items => In the Win + V clipboard history, click the pin on an item to keep it even after restarting.
how do i set a sound to play for notifications | custom notification sound pc => Open the classic Sound control panel's Sounds tab, pick an event like Notification, and choose a sound file.
