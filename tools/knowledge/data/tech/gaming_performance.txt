# tag: tech.gaming.settings
which game settings give the most fps | what settings to lower for fps => Shadows, volumetric fog or clouds, ambient occlusion, reflections and ray tracing cost the most. Lower those first and use DLSS or FSR before dropping resolution.
does texture quality affect fps | high textures lower fps => Texture quality mostly uses VRAM, not much GPU power. Keep it high if your card has enough VRAM; lower it if you see stutter from running out.
what is anti aliasing | what does aa do in games => Anti-aliasing smooths jagged edges on objects. TAA is common and cheap but can blur; DLSS and FSR replace it with their own smoothing.
what is ambient occlusion | ssao setting => Ambient occlusion adds soft shadows where surfaces meet, like corners. It adds depth but costs FPS; lower it if you need speed.
what is render distance | view distance setting => Render distance is how far away the game draws things. Lowering it can boost FPS a lot, especially in open-world games and Minecraft.
should i turn off motion blur | motion blur bad => Most competitive players turn it off for a clearer picture. It's only a looks choice and rarely changes FPS much.
what is field of view | what fov should i use => FOV is how wide your view is. Higher shows more around you but makes things smaller and can cost a little FPS. Around 90 to 105 is common on PC.
what are dlss quality balanced performance modes | which dlss mode => Quality renders closest to full resolution and looks best, Balanced is in between, and Performance and Ultra Performance give the most FPS but look softer. At 1080p, Quality is usually the best pick.
what is dlaa | dlaa vs dlss => DLAA is NVIDIA's anti-aliasing that runs at full resolution with no upscaling. It looks very sharp but gives no FPS boost.
what is 1 percent low fps | what are 1 percent lows => 1% lows are the average of your slowest 1 percent of frames. They show stutter better than average FPS; close to the average means smooth gameplay.
what is frame time | frametime graph => Frame time is how many milliseconds each frame takes. At 200 FPS each frame takes 5 ms. A flat frametime graph means smooth play; spikes are stutters.
how do i show fps in games | fps counter pc => Steam has an FPS counter in Settings, In Game. The NVIDIA App overlay (Alt + R), AMD's overlay (Ctrl + Shift + O) and the Xbox Game Bar can show it too.
what is msi afterburner | rivatuner overlay => MSI Afterburner is a free tool to watch and tune GPU speed, fans and voltage. With RivaTuner it shows an overlay of FPS, temps and usage in games.
how do i cap my fps | limit frame rate => Use the in-game frame limit if it has one. Otherwise set Max Frame Rate in the NVIDIA Control Panel or Frame Rate Target Control in AMD Software, or use RivaTuner.
what are the reasons to limit fps | does capping fps help => Capping keeps frame times steady, lowers heat and noise, and keeps you inside your monitor's VRR range. Cap a little under your refresh rate with G-SYNC or FreeSync.
what nvidia control panel settings are best | nvidia settings for gaming => Set Power management mode to Prefer maximum performance for games, Low Latency Mode to On (or use Reflex in game), and G-SYNC on. Leave most other settings at default.
what is the nvidia app | geforce experience replacement => As of 2025, the NVIDIA App replaces GeForce Experience. It updates drivers, records clips with ShadowPlay, shows an overlay with Alt + Z, and tunes game settings.
how do i record clips with nvidia | nvidia instant replay => Open the NVIDIA App overlay with Alt + Z, turn on Instant Replay, then press Alt + F10 to save the last few minutes. Alt + F9 starts and stops recording.
how do i record with amd software | amd instant replay => In AMD Software: Adrenalin Edition open Record and Stream, turn on Instant Replay, then press Ctrl + Shift + S to save a clip. Ctrl + Shift + E starts and stops recording.
what is amd radeon super resolution | rsr => Radeon Super Resolution (RSR) upscales games at the driver level so you can run lower resolutions with more FPS, even in games without FSR.
what is hyprx | amd hypr rx => HYPR-RX is a one-click AMD profile that turns on Radeon Anti-Lag, Boost and Super Resolution or Fluid Motion Frames together for more FPS and less lag.
what is nvidia image scaling | nis sharpen => NVIDIA Image Scaling upscales and sharpens games at the driver level, for games without DLSS. Turn it on in the NVIDIA Control Panel or NVIDIA App.
what are good roblox graphics settings | roblox lag fix pc => In Roblox, open the menu, Settings, set Graphics Mode to Manual and lower Graphics Quality. Close other apps and use Ethernet for less lag. Roblox caps at 60 FPS unless you change Maximum Frame Rate in settings.
how do i uncap roblox fps | roblox max frame rate => Open Roblox Settings in game and change Maximum Frame Rate to 144, 240 or higher to match your high refresh monitor.
how do i make minecraft run better | minecraft java fps boost => Lower render distance and simulation distance, turn off fancy graphics, and on Java Edition install performance mods like Sodium with Fabric. Give it a bit more RAM if you use big modpacks.
how much ram should i give minecraft | allocate ram minecraft => For vanilla or light mods, 2 to 4 GB is enough. Big modpacks may want 6 to 8 GB. Giving too much can cause stutters from garbage collection.
what is fortnite performance mode | fortnite low end setting => Performance mode in Fortnite's video settings lowers graphics detail a lot to get high FPS on weaker PCs. Many competitive players use it.
what is a benchmark | how do i benchmark my pc => A benchmark is a test run to measure performance. Use a game's built-in benchmark or tools like 3DMark and Cinebench, and compare your scores with others who have the same parts.
does windows 11 have worse fps than windows 10 | is windows 11 good for gaming => Windows 11 performs about the same for games and supports features like DirectStorage and Auto HDR. Keep it updated for the best results.
does closing background apps help fps | should i close apps when gaming => It helps if those apps use a lot of CPU, RAM or GPU, like browsers with videos or launchers downloading updates. Small apps barely matter.
are game booster apps worth it | does razer cortex work => Most game booster apps just close background apps, which you can do yourself. They rarely add much FPS and some add junk software.
what is cpu parking | core parking games => Core parking lets Windows sleep unused cores to save power. On some AMD X3D chips, the chipset driver and Game Bar park cores on purpose so games use the cache-heavy cores, so keep both installed.
does more vram give more fps | vram vs fps => More VRAM doesn't raise FPS by itself, but running out of VRAM causes stutter and blurry textures. Enough VRAM keeps performance smooth at high texture settings.
how do i check if my game is gpu or cpu bound | bottleneck test => Lower the resolution. If FPS jumps, you were GPU bound. If FPS stays the same, the CPU is the limit.
what is dx11 vs dx12 vs vulkan | which api should i pick => These are graphics APIs that games use to talk to the GPU. DX12 and Vulkan can use the CPU better in newer games, while DX11 may be smoother in some older ones. Try both if a game offers a choice.
what is shader cache | should i clear shader cache => The shader cache stores compiled shaders so games don't rebuild them each time. Leave it on; clearing it only helps if a driver update causes glitches, and games will stutter briefly while rebuilding.
what is low latency mode nvidia | ultra low latency => Low Latency Mode in the NVIDIA Control Panel reduces queued frames to cut input lag. If the game has NVIDIA Reflex, use Reflex instead, since it overrides this setting.
how do i lower input delay in games | best settings for low latency => Play at high FPS, use a high refresh monitor, turn on NVIDIA Reflex or AMD Anti-Lag, turn off V-Sync, use a wired mouse and keyboard, and use Ethernet for online games.
what is polling rate on a mouse | 1000hz vs 8000hz polling => Polling rate is how often the mouse reports its position each second. 1000 Hz is great for most players. 4000 to 8000 Hz can feel smoother but uses more CPU.
what dpi should i use for gaming | mouse dpi meaning => DPI is how far the cursor moves per inch of mouse movement. Many players use 400 to 1600 DPI and set the rest with in-game sensitivity. What matters is a sensitivity you can aim with consistently.
what is edpi | effective dpi => eDPI is your mouse DPI times your in-game sensitivity. It lets players compare sensitivity across different settings.
what is a mechanical keyboard | mechanical vs membrane => Mechanical keyboards have a separate switch under each key, giving a crisp feel and long life. Membrane keyboards are quieter and cheaper but feel softer.
what are linear tactile and clicky switches | which keyboard switch => Linear switches press smoothly, tactile switches have a bump you can feel, and clicky switches add a click sound. Many gamers like linear for fast presses.
what are hall effect keyboards | rapid trigger => Hall effect (magnetic) keyboards measure how far each key is pressed. Rapid Trigger resets a key as soon as you start lifting it, which helps fast movement in shooters.
what is a 60 percent keyboard | keyboard sizes => A 60% keyboard drops the number pad, arrow keys and function row to save desk space for big mouse movements. TKL (tenkeyless) drops only the number pad.
