# tag: tech.print3d.ext
what is klipper firmware | klipper 3d printer => Klipper is printer firmware that runs most of its math on a separate computer like a Raspberry Pi, allowing fast printing and easy tuning. Bambu printers use their own firmware instead.
what is marlin firmware | marlin firmware explained => Marlin is the most common open-source firmware on hobby 3D printers like many Creality machines. It runs directly on the printer's board.
what is octoprint | octoprint explained => OctoPrint is free software, usually on a Raspberry Pi, that lets you control and watch a printer from a web browser.
what is cura | ultimaker cura => Cura is a free slicer from UltiMaker that supports many printer brands. It has lots of settings and plugins.
what is prusaslicer | prusaslicer explained => PrusaSlicer is a free slicer from Prusa Research. Bambu Studio and Orca Slicer are both based on it.
what is input shaping | resonance compensation => Input shaping measures how the printer shakes and cancels those vibrations, so it can print faster without ringing. The A1 calibrates it automatically.
what is a hotend | hotend parts => The hotend melts filament. It has a heater, a temperature sensor, a heat break and the nozzle.
what are nozzle materials | brass vs hardened steel nozzle => Brass nozzles heat well and suit PLA and PETG. Hardened steel resists wear from carbon fiber and glow filaments. The A1's stock nozzle is stainless steel.
what is glue stick for 3d printing | glue stick bed adhesion => A thin layer of glue stick helps some materials stick and also helps PETG release from smooth plates. Bambu suggests it for certain plates and filaments.
what is acceleration in 3d printing | speed vs acceleration => Acceleration is how quickly the print head reaches its speed. High speed with low acceleration barely helps on small parts, so fast printers raise both.
what is a filament dryer | filament dry box => A filament dryer heats spools to remove moisture, and some let you print straight from them. It's handy for PETG, TPU and nylon.
what is desiccant | silica gel for filament => Desiccant, like silica gel packets, soaks up moisture in a sealed box. Color-changing kinds show when they need drying out.
what is multi material vs multi color printing | multi material vs multi color printing explained => Multi-color printing swaps colors of one material. Multi-material uses different materials, like PLA with soluble supports, which needs matching temperatures.
what is a tool changer 3d printer | tool changer 3d printer explained => A tool changer has several print heads it swaps between, so multi-color prints waste much less filament than one nozzle with purging.
what is a calibration print | benchy => Calibration prints like the 3DBenchy boat test overhangs, bridges and fine detail, so you can see what settings need work.
what is a temperature tower | temperature tower explained => A temperature tower prints sections at different temperatures, so you can see which gives the best strength and least stringing for a filament.
what is a first layer test | first layer test explained => A first layer test prints a thin shape across the bed to check if the nozzle height and bed adhesion are right.
what is the best way to remove a print from the bed | print stuck to plate => Let the plate cool, then take it off and flex it gently. Prints usually pop off. Avoid prying with metal tools on PEI surfaces.
why does my print stick too much to the plate | petg stuck to pei => PETG can bond too strongly to smooth PEI. Use glue stick as a release layer or the textured plate.
how do i print a two part mold | 3d printed mold for casting => Design the mold in two halves with registration keys so they line up, print in PETG or PLA, and use mold release before pouring silicone or resin. Ask an adult for help with chemicals.
what is post processing in 3d printing | finishing prints => Post-processing means removing supports, sanding, priming, painting or gluing a print to make it look finished.
how do i make a 3d print look less like a 3d print | hide layer lines paint => Use thinner layers, sand from rough to fine, fill gaps with filler primer, then paint. Hiding the seam in a corner also helps.
how do i print miniatures on fdm | tabletop minis fdm => Use a 0.2 mm nozzle, low layer height like 0.08 mm, slower speeds and tree supports. Resin printers still capture more detail.
what are print profiles in bambu studio | process presets => Process presets like 0.20mm Standard or 0.08mm High Quality set layer height, speed and walls. Pick one, then change settings for each print.
how do i save my own slicer settings | custom preset bambu studio => Change settings, then click the save icon next to the preset name to save it as a user preset. User presets can sync to your Bambu account.
what is an object's seam setting | seam position aligned => Seam position chooses where each layer starts and ends. Aligned or Back puts it in one line you can hide at the back, while Random spreads it as tiny dots.
why are my overhangs curling up | curled overhangs => Overhangs curl when they don't cool fast enough. Increase part cooling, slow overhang speeds, or rotate the model so steep parts face the fan.
what is a 3d printer enclosure good for | printing abs on a1 => An enclosure keeps warm air around the print, which stops ABS and ASA warping. The A1 is open-frame, so those materials are harder on it.
