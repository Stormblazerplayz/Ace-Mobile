# tag: tech.shortcuts.discord
how do i quickly switch servers in discord | ctrl k discord | discord quick switcher => Press Ctrl + K (Command + K on Mac) to open the Quick Switcher and type a server, channel or friend's name.
how do i mute myself in discord with a shortcut | ctrl shift m discord => Press Ctrl + Shift + M (Command + Shift + M on Mac) to mute or unmute your mic in Discord.
how do i deafen in discord | ctrl shift d discord => Press Ctrl + Shift + D (Command + Shift + D on Mac) to deafen or undeafen, which turns off what you hear and your mic.
how do i see all discord shortcuts | ctrl slash discord => Press Ctrl + / (Command + / on Mac) to show Discord's list of keyboard shortcuts.
how do i move between discord channels | alt up arrow discord => Press Alt + Up Arrow or Alt + Down Arrow to move to the channel above or below.
how do i mark a channel as read in discord | esc discord => Press Esc to mark the channel you're in as read. Shift + Esc marks the whole server as read.
how do i edit my last discord message | up arrow edit discord => Press Up Arrow in an empty message box to edit your last message. Press Enter to save or Esc to cancel.
how do i make a new line in a discord message | shift enter discord => Press Shift + Enter to start a new line without sending the message.
how do i open the emoji picker in discord | ctrl e discord => Press Ctrl + E to open the emoji picker. Ctrl + G opens GIFs and Ctrl + S opens stickers.
how do i upload a file in discord | ctrl shift u discord file => Press Ctrl + Shift + U to pick a file to upload, or just drag the file into the chat.
how do i see pinned messages | ctrl p discord => Press Ctrl + P in a channel to see its pinned messages.
how do i hide the member list in discord | ctrl u discord => Press Ctrl + U to show or hide the member list on the right.
how do i make text bold in discord | discord bold text | discord formatting => Wrap text in two stars for bold, like **hi**. One star each side makes italics, two underscores make underline, and two tildes make strikethrough.
how do i make a spoiler in discord | hide text discord => Put two vertical bar characters (the key above Enter, with Shift) on each side of the text. Others click it to reveal it. You can also mark an image as a spoiler before sending.
how do i send code in discord | code block discord => Wrap short code in single backticks, like `print()`. For many lines, put three backticks on the line before and after, and add a language name like lua after the first three for colors.
how do i quote a message in discord | discord quote => Start a line with > and a space to quote it. Or hover over a message, click the three dots and choose Reply to answer it directly.
how do i make a heading in discord | big text discord => Start a line with # and a space for a big heading. ## and ### make smaller ones, and -# makes small grey subtext.
how do i set up push to talk in discord | discord ptt key => Open User Settings, Voice and Video, pick Push to Talk, and set a key in Keybinds. Your mic only sends while you hold that key.
how do i stop discord echo or background noise | discord noise suppression => In User Settings, Voice and Video, turn on Noise Suppression and Echo Cancellation. Using headphones also stops your speakers feeding into your mic.
how do i share my screen on discord | discord stream screen => Join a voice channel or call, click the Share Your Screen button, pick a window or screen, and click Go Live.
how do i turn on discord overlay in games | discord in game overlay => Open User Settings, then Game Overlay (or Overlay), and turn it on. Ctrl + ` is often the default key to open it in game; check the setting for yours.
how do i make discord safer for me | discord privacy settings => In User Settings, Privacy and Safety (or Content and Social), turn on filters for explicit content, limit who can DM you, and only accept friend requests from people you know.
how do i block someone on discord | discord block user => Right-click their name (or tap their profile) and choose Block. They can't message you, and their messages are hidden. Tell a trusted adult if someone is bothering you.
how do i report someone on discord | report a message discord => Hover over the message (or long-press it on phone), click the three dots and choose Report. Pick the reason that fits best.
how do i turn off discord notifications for a server | mute a discord server => Right-click the server icon, choose Mute Server, or open Notification Settings to only get mentions.
how do i stop discord opening on startup | discord launches when pc starts => Open User Settings, Windows Settings, and turn off Open Discord. You can also turn it off in Task Manager, Startup apps.
how do i lower a friends volume in discord voice | change user volume discord => Right-click their name in the voice channel and drag the User Volume slider.
how do i answer a discord call with keys | ctrl enter discord call => Press Ctrl + Enter to answer an incoming call and Esc to decline it.
