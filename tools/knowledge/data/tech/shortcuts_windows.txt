# tag: tech.shortcuts.windows
whats the shortcut to take a screenshot on windows | windows shift s | how do i snip part of my screen | screenshot shortcut pc => Press Windows key + Shift + S. The screen dims, you drag a box (or pick window or full screen), and the shot is copied so you can paste it with Ctrl + V. Click the pop-up to edit or save it.
what does the print screen key do | what does prtsc do | print screen button on keyboard => On many Windows 11 PCs, Print Screen opens the Snipping Tool so you can pick an area. On older setups it copies the whole screen to the clipboard. You can switch it in Settings, Accessibility, Keyboard.
how do i save a full screenshot straight to a file | windows key print screen | where do screenshots save automatically on pc => Press Windows key + Print Screen. The screen flashes and the picture saves as a PNG in Pictures, then the Screenshots folder.
how do i screenshot only one window | alt print screen | screenshot just the active window => Press Alt + Print Screen to copy only the window you're using. Then paste it with Ctrl + V into Paint, Discord or a document.
how do i open task manager fast | ctrl shift esc | task manager shortcut | what opens task manager => Press Ctrl + Shift + Esc to open Task Manager straight away. You can also press Ctrl + Alt + Delete and pick Task Manager.
what does ctrl alt delete do | ctrl alt del screen | what is ctrl alt del for => Ctrl + Alt + Delete opens a safe screen where you can lock the PC, switch user, sign out, change your password or open Task Manager. It works even when an app has frozen.
how do i lock my pc quickly | windows l | shortcut to lock the computer => Press Windows key + L to lock your PC right away. Your apps stay open, and you sign back in with your PIN or password.
how do i show the desktop | windows d | minimize everything shortcut | hide all windows fast => Press Windows key + D to hide all windows and show the desktop. Press it again to bring them back.
how do i open file explorer with the keyboard | windows e | shortcut for file explorer => Press Windows key + E to open File Explorer.
how do i open settings fast | windows i | settings shortcut windows 11 => Press Windows key + I to open the Settings app.
how do i open the run box | windows r | what does win r do => Press Windows key + R to open Run. You can type things like msconfig, dxdiag or %temp% and press Enter.
how do i search on windows with the keyboard | windows s | open windows search => Press Windows key + S (or just press the Windows key and start typing) to search apps, files and settings.
how do i open quick settings | windows a | shortcut for the wifi and volume panel => Press Windows key + A on Windows 11 to open Quick Settings, where Wi-Fi, Bluetooth, volume and brightness are.
how do i open notifications on windows 11 | windows n | notification center shortcut => Press Windows key + N to open the notification center and calendar on Windows 11.
how do i open widgets | windows w | what does windows w do => Press Windows key + W to open the Widgets board with news, weather and other cards on Windows 11.
how do i see my clipboard history | windows v | paste something i copied earlier => Press Windows key + V to open clipboard history and pick something you copied before. The first time, it asks you to turn it on.
how do i type an emoji on pc | windows period | emoji keyboard windows | how do i get emojis on my computer => Press Windows key + . (period) or Windows key + ; (semicolon) to open the emoji panel. It also has GIFs, kaomoji and symbols.
how do i open the xbox game bar | windows g | game bar shortcut => Press Windows key + G to open the Xbox Game Bar, with widgets for capture, audio, performance and more.
how do i start recording my screen in a game | windows alt r | record gameplay shortcut => Press Windows key + Alt + R to start or stop recording the app or game you're in with the Game Bar. Videos save in Videos, then Captures.
how do i record the last 30 seconds | windows alt g | clip what just happened in my game => Press Windows key + Alt + G to save the last stretch of gameplay. It only works if background recording ("Record what happened") is turned on in Settings, Gaming, Captures.
how do i take a game screenshot with game bar | windows alt print screen => Press Windows key + Alt + Print Screen to save a screenshot of your game through the Game Bar. It goes to Videos, then Captures.
how do i mute my mic while recording with game bar | windows alt m => Press Windows key + Alt + M to turn your microphone on or off while the Game Bar is recording.
how do i show the recording timer | windows alt t => Press Windows key + Alt + T to show or hide the Game Bar recording timer.
how do i switch between apps | alt tab | how to go to another window fast => Hold Alt and tap Tab to cycle through open windows, then let go to switch. Add Shift to go backwards.
how do i see all my open windows | windows tab | what is task view => Press Windows key + Tab to open Task View, which shows all open windows and your virtual desktops.
how do i make a new virtual desktop | windows ctrl d | second desktop on windows => Press Windows key + Ctrl + D to create a new virtual desktop. It's a clean space for a different set of windows.
how do i switch virtual desktops | windows ctrl left arrow | move between desktops shortcut => Press Windows key + Ctrl + Left Arrow or Right Arrow to switch between virtual desktops.
how do i close a virtual desktop | windows ctrl f4 => Press Windows key + Ctrl + F4 to close the virtual desktop you're on. Its windows move to the next desktop.
how do i snap a window to half the screen | windows left arrow | split screen on windows => Press Windows key + Left Arrow or Right Arrow to snap the window to that half of the screen. Windows then offers other windows to fill the other half.
how do i maximize a window with the keyboard | windows up arrow => Press Windows key + Up Arrow to maximize the window. Press Windows key + Down Arrow to restore or minimize it.
how do i open snap layouts | windows z | snap layouts shortcut => Press Windows key + Z on Windows 11 to show snap layouts, then press the number of a layout zone to place the window there.
how do i move a window to my other monitor | windows shift arrow | move window between screens => Press Windows key + Shift + Left Arrow or Right Arrow to move the window to the monitor on that side.
how do i minimize all windows except one | windows home => Press Windows key + Home to minimize every window except the one you're using. Press it again to bring them back.
how do i peek at the desktop | windows comma => Hold Windows key + , (comma) to peek at the desktop. Let go and your windows come back.
how do i minimize all windows | windows m => Press Windows key + M to minimize all windows. Windows key + Shift + M brings them back.
how do i change how my screens are used | windows p | duplicate or extend screen shortcut => Press Windows key + P to choose PC screen only, Duplicate, Extend or Second screen only.
how do i cast my screen to a tv | windows k | wireless display shortcut => Press Windows key + K on Windows 11 to open Cast and connect to a wireless display that supports Miracast.
how do i use voice typing on windows | windows h | talk to type on pc => Press Windows key + H to start voice typing in any text box. Speak, and Windows types it for you.
what is the windows x menu | windows x | power user menu => Press Windows key + X (or right-click Start) to open the Quick Link menu with Device Manager, Disk Management, Terminal, Task Manager and shut down options.
how do i open taskbar apps with numbers | windows 1 | windows number shortcut => Press Windows key + a number to open or switch to that app on the taskbar. Windows key + 1 opens the first pinned app, and so on.
how do i open the magnifier | windows plus | zoom in on the whole screen => Press Windows key + Plus (+) to turn on Magnifier and zoom in. Windows key + Minus zooms out, and Windows key + Esc closes it.
how do i turn on narrator | windows ctrl enter | screen reader shortcut => Press Windows key + Ctrl + Enter to turn Narrator, the Windows screen reader, on or off.
how do i open the on screen keyboard | windows ctrl o | keyboard on screen windows => Press Windows key + Ctrl + O to open the on-screen keyboard. You click keys with the mouse or touch.
how do i restart my graphics driver | windows ctrl shift b | screen went black fix shortcut => Press Windows key + Ctrl + Shift + B. You'll hear a beep and the screen flickers as the graphics driver restarts. It can fix a frozen or black screen.
how do i open accessibility settings | windows u => Press Windows key + U to open Accessibility settings.
how do i turn hdr on and off | windows alt b | hdr shortcut => Press Windows key + Alt + B to turn HDR on or off on a display that supports it.
how do i mute my mic in a call on windows | windows alt k => Press Windows key + Alt + K to mute or unmute your microphone in call apps that support it on Windows 11.
how do i open the volume output menu | windows ctrl v => Press Windows key + Ctrl + V on Windows 11 to open the sound output part of Quick Settings, where you pick speakers or headphones.
how do i open system about page | windows pause | see my pc specs shortcut => Press Windows key + Pause/Break to open System, About, which shows your CPU, RAM and Windows version. Many keyboards hide Pause behind the Fn key.
how do i change keyboard language | windows space | switch input language => Press Windows key + Spacebar to switch between keyboard languages or layouts you've added.
how do i open quick assist | windows ctrl q => Press Windows key + Ctrl + Q to open Quick Assist, which lets a trusted person help on your PC remotely. Only use it with someone you really know.
how do i open feedback hub | windows f => Press Windows key + F to open Feedback Hub, where you can report problems to Microsoft.
how do i focus the system tray | windows b => Press Windows key + B to put focus on the system tray area near the clock, then use the arrow keys and Enter.
how do i cycle through taskbar apps | windows t => Press Windows key + T to move through the apps on the taskbar, then press Enter to open one.
how do i lock screen rotation | windows o => Press Windows key + O to lock or unlock screen rotation on tablets and 2 in 1 laptops.
how do i close an app with the keyboard | alt f4 | shortcut to close a program => Press Alt + F4 to close the app you're using. On the desktop, it opens the Shut Down Windows box.
how do i shut down with the keyboard | shutdown shortcut pc => Press Windows key + D to show the desktop, then Alt + F4, choose Shut down and press Enter. Or press Windows key + X, then U, then U.
how do i copy | ctrl c | copy shortcut => Press Ctrl + C to copy what you've selected.
how do i cut and paste | ctrl x | cut shortcut => Press Ctrl + X to cut the selection, then Ctrl + V to paste it somewhere else.
how do i paste | ctrl v | paste shortcut on pc => Press Ctrl + V to paste what you copied or cut.
how do i undo | ctrl z | undo shortcut => Press Ctrl + Z to undo the last thing you did. Press it again to undo more steps.
how do i redo | ctrl y | redo shortcut windows => Press Ctrl + Y to redo. Some apps use Ctrl + Shift + Z instead.
how do i select everything | ctrl a | select all shortcut => Press Ctrl + A to select everything in a document, box or folder.
how do i paste without the formatting | ctrl shift v | paste plain text => Press Ctrl + Shift + V to paste plain text in many apps like Chrome, Edge, Google Docs and Discord. In Word, use Paste Options and pick Keep Text Only.
how do i save with the keyboard | ctrl s | save shortcut => Press Ctrl + S to save. Many apps use Ctrl + Shift + S for Save As.
how do i print with the keyboard | ctrl p | print shortcut => Press Ctrl + P to open the print window in most apps and browsers.
how do i find a word on a page | ctrl f | search text on screen => Press Ctrl + F and type a word to find it in the page, document or app you're using.
how do i open a new window | ctrl n | new window shortcut => Press Ctrl + N to open a new window or document in most apps.
how do i open a file with the keyboard | ctrl o => Press Ctrl + O to open a file in most apps.
how do i close a tab or window | ctrl w | close tab shortcut => Press Ctrl + W to close the tab or document window you're on.
how do i delete a whole word | ctrl backspace | erase a word at once => Press Ctrl + Backspace to delete the word to the left of the cursor. Ctrl + Delete removes the word to the right.
how do i jump the cursor by words | ctrl left arrow | move by word => Hold Ctrl and press Left Arrow or Right Arrow to jump one word at a time.
how do i select text with the keyboard | shift arrow keys | highlight text without mouse => Hold Shift and use the arrow keys to select letter by letter. Hold Ctrl + Shift to select word by word.
how do i go to the start of a line | home key | end key what does it do => Press Home to jump to the start of the line and End to jump to the end of it.
how do i go to the top of a document | ctrl home | jump to the bottom of a page => Press Ctrl + Home for the very top and Ctrl + End for the very bottom of a document or page.
how do i rename something fast | f2 key | what does f2 do => Select a file, folder or desktop icon and press F2 to rename it. Type the new name and press Enter.
what does f5 do | refresh shortcut | how do i reload => Press F5 to refresh a web page, folder or the desktop.
what does f11 do | make a window full screen | fullscreen shortcut pc => Press F11 to make a browser or File Explorer go full screen. Press it again to exit.
how do i right click with the keyboard | shift f10 | menu key => Press Shift + F10 (or the Menu key if your keyboard has one) to open the right-click menu for the selected item.
how do i move between buttons with the keyboard | tab key | shift tab => Press Tab to move to the next button or box, Shift + Tab to go back, Space or Enter to press it, and Esc to cancel.
how do i zoom in on my pc | ctrl plus | ctrl scroll wheel zoom => Hold Ctrl and roll the mouse wheel, or press Ctrl + Plus and Ctrl + Minus, to zoom in many apps and browsers. Ctrl + 0 resets it in browsers.
how do i delete a file without the recycle bin | shift delete | permanently delete file => Select the file and press Shift + Delete, then confirm. It skips the Recycle Bin, so it's hard to get back.
how do i make a new folder fast | ctrl shift n new folder | new folder shortcut => Press Ctrl + Shift + N in File Explorer or on the desktop to make a new folder, then type its name.
how do i see a files properties | alt enter | file properties shortcut => Select a file and press Alt + Enter to open its Properties, with size, location and dates.
how do i open the start menu with the keyboard | windows key | ctrl esc => Press the Windows key (or Ctrl + Esc) to open Start. Start typing to search right away.
what does the alt key do in menus | alt underlined letters | access keys => Press Alt in many apps to show letters on the menus. Then press a letter to open that menu without the mouse.
how do i switch apps and keep the switcher open | ctrl alt tab => Press Ctrl + Alt + Tab to open the app switcher and keep it open, then use the arrow keys and Enter to pick a window.
how do i open the emoji panel symbols | special characters on windows | how do i type a degree symbol => Open the emoji panel with Windows key + . then pick the Symbols tab (the Omega icon) to insert things like °, ©, € or arrows.
how do i type a capital letter with caps lock on | what does caps lock do => Caps Lock makes letters type in capitals until you press it again. Holding Shift types the opposite case for one letter.
what does num lock do | number pad not working => Num Lock turns the number pad's numbers on. If the pad moves the cursor instead of typing numbers, press Num Lock.
what does the fn key do | function key on laptop => Fn is a laptop key that switches the top row between F1 to F12 and extras like volume or brightness. Hold Fn and press the key to use the other action.
what does the insert key do | typing replaces letters | text keeps getting overwritten => The Insert key switches overtype mode, where new letters replace old ones. Press Insert again to go back to normal typing.
what does scroll lock do | scroll lock key => Scroll Lock is an old key that most apps ignore. In Excel, it makes the arrow keys scroll the sheet instead of moving the selected cell.
how do i stop a command in command prompt | ctrl c in terminal => Press Ctrl + C in Command Prompt or PowerShell to stop the command that's running.
how do i see old commands in terminal | up arrow in command prompt => Press Up Arrow in Command Prompt, PowerShell or Windows Terminal to bring back earlier commands. Press Tab to finish a file or folder name for you.
how do i open terminal as admin quickly | win x then a terminal admin => Press Windows key + X, then A, to open Terminal (Admin) on Windows 11. Click Yes on the prompt.
how do i open device manager fast | win x then m => Press Windows key + X, then M, to open Device Manager.
how do i open disk management | win x then k => Press Windows key + X, then K, to open Disk Management, where you can see drives and partitions.
how do i turn on sticky keys | press shift five times => Press Shift five times to get the Sticky Keys prompt. Sticky Keys lets you press keys like Ctrl and Shift one at a time.
how do i stop sticky keys popping up in games | sticky keys keeps turning on => Go to Settings, Accessibility, Keyboard, open Sticky keys, and turn off the "Keyboard shortcut for Sticky keys" option.
how do i turn on filter keys | hold right shift 8 seconds => Hold the right Shift key for 8 seconds to toggle Filter Keys, which ignores quick or repeated key presses. Turn its shortcut off in Settings, Accessibility, Keyboard if it gets in your way.
how do i paste in command prompt | right click paste terminal => Press Ctrl + V in Windows Terminal or the new Command Prompt. Right-clicking also pastes in classic console windows.
how do i open the snipping tool | snipping tool shortcut => Press Windows key + Shift + S for a quick snip, or search Snipping Tool in Start to open the full app with a delay timer and screen recording.
how do i record my screen with snipping tool | screen record without game bar => Open the Snipping Tool, click the video camera icon, press New, drag the area to record, then press Start. It works on the desktop and on File Explorer, where Game Bar doesn't.
how do i switch between keyboard and touch mode | windows ctrl o on screen => Press Windows key + Ctrl + O to bring up the on-screen keyboard for touch or mouse typing.
how do i open the windows terminal | open command prompt shortcut => Press Windows key + R, type cmd or wt, and press Enter. Or press Windows key + X, then I, to open Terminal.
how do i scroll a page with the keyboard | page down key | space bar scroll => Press Page Down or Space to scroll down a screen at a time, and Page Up or Shift + Space to go back up.
