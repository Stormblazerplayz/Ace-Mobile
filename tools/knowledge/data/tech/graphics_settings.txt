# tag: tech.gaming.settings
what is anisotropic filtering | texture filtering setting => Anisotropic filtering keeps textures on floors and walls sharp at angles. 16x costs almost no FPS on modern GPUs, so it's usually safe to max out.
does shadow quality affect fps | shadows setting => Yes, shadows are often one of the heaviest settings. Dropping from Ultra to Medium or High can give a big FPS boost with little visual change.
what is volumetric fog | volumetric lighting setting => Volumetric fog and lighting make light rays and mist look 3D. They look great but can cost a lot of FPS, so lower them first if you need speed.
what are screen space reflections | ssr setting => Screen space reflections show shiny reflections using what's already on screen, so they vanish when the object goes off screen. They cost a moderate amount of FPS.
what is tessellation | tessellation in games => Tessellation adds extra detail to surfaces like rocks and ground up close. Modern GPUs handle it well, but lower it on older cards.
what is depth of field in games | dof setting => Depth of field blurs things out of focus, like a camera. Many competitive players turn it off for a clearer view.
what is chromatic aberration in games | colored edges blur => Chromatic aberration adds red and blue fringes near the screen edges like a cheap lens. It's purely a look, and turning it off makes the image sharper.
what is bloom in games | bloom setting => Bloom makes bright lights glow and spill over edges. It's mostly a style choice and costs little FPS.
what is film grain in games | turn off film grain => Film grain adds noise to look like old film. Turning it off makes the image cleaner and helps upscalers like DLSS look better.
what is a sharpening filter in games | sharpening slider => Sharpening makes edges crisper, which helps after upscaling. Too much makes halos and noise, so keep it low.
what is resolution scale | render scale setting => Resolution scale renders the game at a percentage of your screen resolution. Below 100 percent gives more FPS but looks blurrier, so DLSS or FSR usually looks better.
what is dynamic resolution | dynamic resolution scaling => Dynamic resolution lowers the render resolution when the game gets heavy to hold your target FPS, then raises it again.
what is native resolution in games | native vs upscaled => Native means the game renders at your screen's real resolution with no upscaling. It's sharpest but costs the most FPS.
what is ray reconstruction | dlss ray reconstruction => Ray Reconstruction is part of DLSS that uses AI to clean up the noise in ray-traced lighting, making reflections and shadows clearer.
what is path tracing | full ray tracing => Path tracing simulates nearly all the light bounces in a scene for very realistic lighting. It's extremely heavy and needs a strong RTX card with DLSS.
what is level of detail | lod setting => Level of detail swaps in simpler models for faraway objects. Higher LOD settings keep more detail at a distance but cost CPU and GPU time.
what settings use the cpu in games | cpu heavy settings => View distance, number of NPCs or players, physics, and crowd density mostly load the CPU. Lowering graphics like shadows won't help much if the CPU is the limit.
what are draw calls | draw calls explained => Draw calls are the CPU's instructions telling the GPU what to draw. Games with lots of separate objects create many draw calls, which can bottleneck the CPU.
what is triple buffering | triple buffering vsync => Triple buffering gives the GPU an extra frame to work on with VSync, making it smoother but adding a bit of input lag.
what is fast sync | enhanced sync amd => NVIDIA Fast Sync and AMD Enhanced Sync cut tearing with less lag than VSync when FPS is far above your refresh rate. G-Sync or FreeSync is usually better if you have it.
what is frame pacing | uneven frames stutter => Frame pacing is how evenly frames are spaced. Even at high FPS, bad pacing feels stuttery, and an FPS cap often fixes it.
what is traversal stutter | stutter when moving to new areas => Traversal stutter happens when a game loads new areas as you move. It's mostly the game's fault, but a fast SSD and a strong CPU help.
does putting a game on an ssd give more fps | ssd vs hdd for games => An SSD mostly speeds up loading and cuts texture pop-in and stutter in open-world games. It doesn't raise average FPS much.
what is max frame rate in nvidia control panel | nvidia fps limiter => It caps FPS for all games or one game at the driver level. Many people set it a few FPS below their refresh rate when using G-Sync.
what is power management mode in nvidia | prefer maximum performance => It controls how fast the GPU drops its clocks. Normal is fine for most games. Prefer maximum performance keeps clocks high but uses more power at idle.
what is shader cache size in nvidia | nvidia shader cache setting => It sets how much drive space the driver uses to keep compiled shaders, which reduces stutter. Driver default or a large size like 10 GB is good.
what is dsr | dldsr => DSR and DLDSR render a game at a higher resolution than your screen and shrink it down, making it sharper. DLDSR uses AI to get similar quality with less FPS cost.
what is rtx video super resolution | rtx vsr => RTX Video Super Resolution uses an RTX GPU to upscale and clean up blurry web videos in Chrome or Edge. Turn it on in the NVIDIA app or Control Panel.
what is rtx hdr | rtx hdr explained => RTX HDR uses AI to turn standard games and videos into HDR on an HDR screen. Windows HDR must be on, and it costs a little FPS.
what is radeon chill | amd chill => Radeon Chill lowers FPS when you're standing still and raises it when you move, saving power and heat. It can add a little lag, so competitive players often leave it off.
what is radeon boost | amd boost => Radeon Boost lowers the resolution during fast mouse movement to keep FPS high, when you're less likely to notice blur.
what is afmf | amd fluid motion frames => AMD Fluid Motion Frames adds driver-level frame generation to many DirectX 11 and 12 games on Radeon cards. It looks smoother but adds some lag.
what is radeon image sharpening | ris amd => Radeon Image Sharpening adds smart sharpening to games, which can make upscaled images look crisper. Turn it on in AMD Software.
what is the amd 3d v cache optimizer | x3d driver => It's a driver for Ryzen chips with V-Cache on only one of two CCDs, like the 7950X3D or 9950X3D, that steers games to the cache cores. Keep the chipset driver and Game Bar updated for it.
what is ryzen master | amd ryzen master app => Ryzen Master is AMD's app for watching Ryzen temperatures and clocks and changing settings like PBO. Many people prefer making those changes in the BIOS instead.
what is frame generation lag | does frame gen add input delay => Frame generation adds a little input lag because it waits for the next real frame. It feels best when the base FPS is already around 60 or higher.
what is a good base fps for frame generation | good base fps for frame generation explained => Aim for around 60 real FPS before turning on frame generation. Below that, it may look smooth but feel sluggish.
should i use dlss or native for competitive games | dlss in esports => In competitive shooters, lower settings at native resolution with high FPS usually feel best. DLSS helps when you can't reach your monitor's refresh rate.
what is a frame rate cap in the game menu | menu fps uncapped => Some games run menus at uncapped FPS, which can make the GPU loud or whine. Turn on a menu FPS cap or a global limit.
why does my gpu whine in menus | coil whine at high fps => Very high FPS in simple menus makes some cards' coils buzz. Capping FPS usually quiets it.
how do i check vram usage in a game | see vram used => Use the MSI Afterburner and RivaTuner overlay, the game's own overlay, or Task Manager's GPU tab to see dedicated GPU memory in use.
what is texture pop in | textures loading late => Pop-in is when textures or objects appear late as you move. It's often worse with low VRAM, slow storage or low streaming settings.
what is an fps counter | show frame rate overlay => An FPS counter shows your frames per second on screen. Steam, Game Bar, the NVIDIA app and AMD Software all have one.
what is a game ready driver | studio driver vs game ready => Game Ready drivers are tuned for new games on launch day. Studio drivers are tested longer for creative apps like Resolve and Blender. Both work for games.
what is the best fov for fps games | fov for shooters => Many players use around 90 to 103 FOV in shooters on a normal monitor. Higher shows more around you but makes targets smaller.
what is hit registration | hit reg => Hit registration is whether the server counts your shot as a hit. Bad hit reg comes from lag, packet loss or the game's netcode.
what is netcode | rollback netcode => Netcode is how a game keeps players in sync online. Rollback netcode, common in fighting games, predicts moves and corrects them so lag feels smaller.
what is peeker's advantage | peeker's advantage explained => Peeker's advantage means the player moving around a corner sees the other player first because of network delay. Lower ping helps both sides.
