# tag: tech.pc.tools
what is hwinfo | hwinfo64 => HWiNFO is a free Windows app that shows detailed sensor readings like CPU and GPU temperatures, clocks, voltages and fan speeds. Run it in Sensors-only mode for monitoring.
what is cpu z | cpu z explained => CPU-Z is a free tool that shows your exact CPU, motherboard and RAM details, including RAM speed and timings.
what is gpu z | gpu z explained => GPU-Z is a free tool that shows your graphics card's model, clocks, memory type and sensors, and whether Resizable BAR is on.
what is crystaldiskinfo | check ssd health tool => CrystalDiskInfo reads your drives' health data and shows Good, Caution or Bad. Caution means back up your files soon.
what is crystaldiskmark | crystaldiskmark explained => CrystalDiskMark tests how fast your drives read and write, so you can check an SSD is running at its expected speed.
what is 7 zip | 7zip => 7-Zip is a free, open-source program for opening and making zip, 7z and rar archives. Download it only from 7-zip.org.
what is winrar | winrar explained => WinRAR opens and makes RAR and zip archives. Windows 11 can now open RAR and 7z files in File Explorer without extra apps.
what is rufus | rufus explained => Rufus is a free tool that makes bootable USB drives from Windows or Linux ISO files.
what is ventoy | ventoy explained => Ventoy turns a USB drive into a multi-boot stick: copy several ISO files onto it and choose which one to boot.
what is wiztree | see what's filling my drive => WizTree and WinDirStat scan your drive and show what's taking up space as a map, making big files easy to find.
what is everything search tool | everything search tool explained => Everything is a free Windows app that finds files by name almost instantly, much faster than Windows search.
what is malwarebytes | malwarebytes explained => Malwarebytes is a well-known malware scanner. The free version can scan and remove malware alongside Windows Defender.
is ccleaner safe | registry cleaners => Registry cleaners rarely help and can cause problems. Windows' built-in Disk Cleanup and Storage Sense are enough for most people.
what is notepad plus plus | notepad plus plus explained => Notepad++ is a free text and code editor for Windows with tabs, color-coded code and powerful find and replace.
what is furmark | furmark explained => FurMark is a heavy GPU stress test. Use it briefly to check temperatures and stability, and stop if anything gets too hot.
what is 3dmark | 3dmark explained => 3DMark is a popular graphics benchmark that gives a score you can compare with other PCs. Time Spy is a common test.
what is occt | pc stress test => OCCT tests CPU, GPU, RAM and power supply stability and watches for errors, useful after building a PC or overclocking.
what is a stress test | stability test pc => A stress test runs a part at full load to check it stays stable and cool. It's how people check a new build or overclock.
what is rivatuner | rtss => RivaTuner Statistics Server shows the on-screen stats for MSI Afterburner and can cap FPS very smoothly.
what is presentmon | frame time capture => PresentMon is a free tool from Intel that measures frame times in games, used for detailed performance testing.
what is process lasso | process lasso explained => Process Lasso is a Windows tool that controls which CPU cores and priority programs use. Most gamers don't need it.
what is fan control app | fancontrol software => FanControl is a free app that sets custom fan curves from Windows using any sensor, like GPU temperature for case fans.
what is openrgb | openrgb explained => OpenRGB is free software that controls RGB lighting from many brands in one app, instead of several heavy brand apps.
what is signalrgb | signalrgb explained => SignalRGB is an app that syncs RGB lighting across many brands with effects. The free version covers basic lighting.
what is a portable usb toolkit | tech rescue usb => A rescue USB holds a Windows installer, Rufus or Ventoy images, drivers and tools like CrystalDiskInfo, so you can fix a PC that won't boot.
what is windows media creation tool | make windows usb tool => Microsoft's Media Creation Tool downloads Windows and makes a bootable USB installer. Get it only from Microsoft's website.
what is the pc health check app | pc health check app explained => PC Health Check is Microsoft's app that tells you whether your PC can run Windows 11 and why not.
what is the apple devices app for windows | apple devices app for windows explained => Apple Devices is the Windows app that backs up, updates and syncs iPhones and iPads, replacing iTunes for devices.
what is nvidia frameview | nvidia frameview explained => FrameView is NVIDIA's free tool for measuring FPS, frame times and power use in games.
