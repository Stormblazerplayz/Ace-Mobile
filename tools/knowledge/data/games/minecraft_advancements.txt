# Minecraft Java Edition advancements, hand-written for 1.21. Bedrock uses achievements instead.

# tag: minecraft.advancements
what are advancements in minecraft | how do advancements work | where do i see my advancements => Advancements are goals in Java Edition that pop up when you do things like mining diamonds or entering the Nether. Press L to open the advancements screen. Bedrock Edition has achievements instead.
what is the difference between advancements and achievements | does bedrock have advancements => Java Edition has advancements, arranged in trees you can see with the L key. Bedrock Edition has achievements, which are linked to your Microsoft account and turn off if you use cheats.
what is the hardest advancement in minecraft | hardest minecraft achievement => How Did We Get Here? is usually called the hardest advancement. You need to have every status effect on you at the same time, including ones from the Wither, a pufferfish and a shulker.
