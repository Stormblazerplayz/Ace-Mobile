which element is named after einstein | einsteinium named after | element named for albert einstein => Einsteinium (Es, element 99) is named after Albert Einstein. It was first found in 1952 in the debris of the first hydrogen bomb test.
which element is named after marie curie | curium named after | element named for the curies => Curium (Cm, element 96) is named after Marie and Pierre Curie, pioneers of radioactivity research.
which element is named after mendeleev | mendelevium named after | element named for the creator of the periodic table => Mendelevium (Md, element 101) is named after Dmitri Mendeleev, who created the periodic table in 1869.
which element is named after nobel | nobelium named after | element named for alfred nobel => Nobelium (No, element 102) is named after Alfred Nobel, the inventor of dynamite who founded the Nobel Prizes.
which element is named after fermi | fermium named after | element named for enrico fermi => Fermium (Fm, element 100) is named after Enrico Fermi, who built the first nuclear reactor.
which element is named after bohr | bohrium named after | element named for niels bohr => Bohrium (Bh, element 107) is named after Niels Bohr, who developed the model of electrons in shells.
which element is named after rutherford | rutherfordium named after | element named for ernest rutherford => Rutherfordium (Rf, element 104) is named after Ernest Rutherford, who discovered the atomic nucleus.
which element is named after copernicus | copernicium named after | element named for nicolaus copernicus => Copernicium (Cn, element 112) is named after Nicolaus Copernicus, who argued that Earth orbits the Sun.
which element is named after lise meitner | meitnerium named after | element named for a woman scientist => Meitnerium (Mt, element 109) is named after Lise Meitner, who helped discover nuclear fission. Curium honors Marie Curie too.
which element is named after seaborg | seaborgium named after | element named for a living person => Seaborgium (Sg, element 106) is named after Glenn Seaborg, who helped discover ten elements. He was alive when it was named in 1997. Oganessian was also alive when oganesson was named.
which element is named after roentgen | roentgenium named after | element named for x ray discoverer => Roentgenium (Rg, element 111) is named after Wilhelm Röntgen, who discovered X-rays.
elements named for scientists | list of elements named after people => Elements named after people include curium, einsteinium, fermium, mendelevium, nobelium, lawrencium, rutherfordium, seaborgium, bohrium, meitnerium, roentgenium, copernicium, flerovium, oganesson, gadolinium and samarium.
which elements are named after ytterby | ytterby village elements | what is special about ytterby => Four elements are named after the Swedish village of Ytterby, where their mineral was mined: yttrium, ytterbium, terbium and erbium.
which elements are named after planets | elements named after planets | uranium neptunium plutonium => Uranium, neptunium and plutonium are named after the planets Uranus, Neptune and Pluto, in the same order. Mercury shares its name with the planet, and cerium and palladium are named after asteroids.
which elements are named after gods | elements named after mythology | mythological element names => Many come from myths: thorium (Thor), titanium (the Titans), promethium (Prometheus), vanadium (Vanadís, a name of the goddess Freyja), niobium (Niobe) and tantalum (Tantalus). Mercury and cerium are linked to Roman gods too.
which element is named after the sun | which element is named after the moon | helium and selenium names => Helium is named after the Greek word for the Sun, helios, and selenium after the Greek word for the Moon, selene. Tellurium is named after the Latin for Earth.
which element is named after japan | what is nihonium | first element discovered in asia => Nihonium (Nh, element 113) is named after Nihon, a Japanese name for Japan. It was the first element discovered in Asia, by RIKEN scientists.
which elements were added to the periodic table last | 2016 new elements => The newest named elements are nihonium (113), moscovium (115), tennessine (117) and oganesson (118), named in November 2016. They completed the seventh row.
what is the only letter not in the periodic table | which letter is missing from the periodic table | letter j periodic table => J is the only letter of the alphabet that doesn't appear in any element symbol.
which element symbols dont match their english names | latin element symbols => Some symbols come from Latin or other names: Na sodium (natrium), K potassium (kalium), Fe iron (ferrum), Cu copper (cuprum), Ag silver (argentum), Sn tin (stannum), Sb antimony (stibium), Au gold (aurum), Hg mercury (hydrargyrum), Pb lead (plumbum), and W tungsten (wolfram).
why is lead pb | where does pb come from | latin name for lead => Lead's symbol Pb comes from its Latin name plumbum. That's also where the word plumbing comes from, because Romans made water pipes from lead.
why is mercury hg | where does hg come from | hydrargyrum meaning => Mercury's symbol Hg comes from the Latin hydrargyrum, from Greek words meaning water silver, because it's a shiny liquid metal.
which element is named after a color | elements named after colors | chlorine name means => Several are: chlorine (pale green), iodine (violet), rubidium (deep red), cesium (sky blue), indium (indigo), rhodium (rose) and iridium (rainbow), often from the colors of their compounds or spectral lines.
which elements have the shortest names | which element has the longest name | longest element name => Tin is the shortest name, with 3 letters. The longest names are rutherfordium and praseodymium, with 13 letters each.
what is the most common element in earths crust | most abundant element in the crust | crust elements list => Oxygen is the most common element in Earth's crust, about 46% by mass, followed by silicon (about 28%), aluminium, iron, calcium, sodium, potassium and magnesium.
what is the most common element in the whole earth | what is earth made of mostly | earths composition by element => Counting the whole planet, iron is the most common element by mass, about a third, mostly in the core. Then come oxygen, silicon and magnesium.
what is the most common element in the human body | what elements make up the human body | body elements percentage => By mass, your body is about 65% oxygen, 18% carbon, 10% hydrogen and 3% nitrogen, plus calcium, phosphorus and small amounts of others. Most of the oxygen and hydrogen is in water.
what elements are in the air | what is air made of by element | elements in the atmosphere => Air is mostly the elements nitrogen (about 78%), oxygen (21%) and argon (almost 1%), plus compounds like carbon dioxide and water vapor.
what is the hardest element | hardest natural substance | which element is hardest => Carbon in the form of diamond is the hardest natural element. Among metals, chromium is one of the hardest.
what is the softest metal | which metals can you cut with a knife | soft metals => Cesium, rubidium, potassium and sodium are soft enough to cut with a knife. Lead and indium are also very soft.
which element has the highest melting point | highest melting point metal | what metal can survive the most heat => Tungsten has the highest melting point of any metal, about 3,422 °C. Carbon sublimes at an even higher temperature, about 3,600 °C or more.
which element has the lowest boiling point | coldest boiling element | helium boiling point => Helium has the lowest boiling point, about minus 269 °C, just 4 degrees above absolute zero. It won't freeze at normal pressure at all.
heaviest metal by density | osmium vs iridium density => Osmium and iridium are the densest elements, about 22.6 g/cm³, roughly twice as dense as lead. Measurements put osmium very slightly ahead.
what is the best conductor of electricity | which metal conducts best | silver vs copper conductivity => Silver is the best electrical conductor of all elements. Copper is a close second and much cheaper, so it's used for most wires.
what is the least reactive element | most unreactive element | noble gas reactivity => The noble gases, especially helium and neon, are the least reactive elements. No stable compounds of helium or neon have been made under normal conditions.
what is the heaviest element found in nature | heaviest natural element | uranium heaviest => Uranium (element 92) is usually called the heaviest element found naturally in large amounts. Tiny traces of plutonium also occur naturally.
what was the first element made by humans | first synthetic element => Technetium (element 43) was the first element made artificially, in 1937, in a particle accelerator. Its name comes from the Greek for artificial.
what is the most recently discovered element | last element discovered | when was oganesson made => Tennessine (117), first made in 2010, was the last element to be discovered. Oganesson (118) was made earlier, in 2002 to 2005. As of 2025, no element beyond 118 has been made.
what is the heaviest element ever made | highest atomic number | oganesson facts => Oganesson, element 118, has the highest atomic number. Only a handful of its atoms have ever been made, and each lasted less than a millisecond.
can new elements still be discovered | island of stability => Scientists are trying to make elements 119 and 120. Some theories predict an island of stability, where some superheavy elements might last longer, but none has been confirmed.
what element do we breathe | what gas do we need to live | what element is in oxygen tanks => We need oxygen, which is about 21% of air. Each breath brings it into the lungs, where it passes into the blood.
which element makes things glow in neon signs | do neon signs use only neon | what makes neon sign colors => True neon gives red-orange light. Other colors come from other gases, like argon with a little mercury for blue, or from colored glass and phosphor coatings.
which element is in batteries | what metal is in phone batteries | lithium batteries element => Phone and laptop batteries are lithium-ion batteries. They also use cobalt, nickel, manganese, graphite and copper.
which element makes bones strong | what element is in bones => Bones get their hardness from calcium phosphate minerals. Calcium is the most common metal in the body.
which element is in salt | what elements make up table salt | salt elements => Table salt is sodium chloride, made of the elements sodium and chlorine.
which element is in diamonds | what are diamonds made of | diamond element => Diamonds are pure carbon, with each atom tightly bonded to four others in a strong 3D pattern.
what does the periodic table look like | why are two rows at the bottom => The periodic table has 7 rows (periods) and 18 columns (groups). The lanthanides and actinides are put in two rows underneath so the table isn't too wide to print.
how many metals are on the periodic table | what fraction of elements are metals | number of metals => Most elements are metals, roughly 90 or so of the 118. Nonmetals sit at the top right, with metalloids along the staircase line between them.
what are the elements that make up almost all living things | chnops | six elements of life => Living things are mostly made of six elements: carbon, hydrogen, nitrogen, oxygen, phosphorus and sulfur, often remembered as CHNOPS.
where do elements come from | how were elements made | stars make elements => Hydrogen and helium were made in the Big Bang. Stars fuse them into heavier elements up to iron, and heavier ones like gold are made in exploding stars and colliding neutron stars.
are we made of star stuff | are humans made of stardust | carl sagan star stuff => Yes. Almost every atom in your body heavier than hydrogen, like the carbon, oxygen and calcium, was made inside stars that lived and died before the Sun formed.
how was gold made | gold from neutron stars => Gold was made in huge cosmic explosions, mainly when neutron stars collide, and possibly in some supernovae. It was mixed into the cloud that formed the solar system.
